# 中模数跨越引理候选

**状态：** `FSC2_reduced_to_medium_modulus_CRT_crossing`

必要列 CRT 逐步合并显示：首个完整覆盖方案的 CRT 代表通常在加入中等素数约束时首次越过 `P`。

典型过程：

- 小骨架 `2,3` 或 `2,3,5` 给出一个小代表 `x0<P`；
- 加入必要列对应的 `q=5` 或 `q=7` 后，CRT 新代表跃迁到 `x>=P`；
- 后续更大素数只在大模数周期中精调，但不再把代表拉回前窗口。

## 1. 观测

- `P=23`：`2,3` 给 `x=4 mod 6`；加入 `q=5` 得 `x=28>P`；加入 `q=7` 精调到 `x=58`。
- `P=29`：加入 `q=7` 后从 `x=19` 跳到 `x=169>P`。
- `P=31`：加入 `q=7` 后从 `x=14` 跳到 `x=104>P`。

## 2. 候选引理 MC（Medium Crossing）

在任意完整覆盖方案中，存在一个必要中模数 `q`，通常位于小素数骨架之后，使得：

设当前 CRT 状态为

`x ≡ x0 mod m`, `0<=x0<P`,

加入必要列同余

`x ≡ a mod q`, `gcd(m,q)=1`。

则新最小代表

`x1 = x0 + m t`, `0<=t<q`

满足

`x1 >= P`。

等价于

`t >= (P-x0)/m`。

要证明 MC，需要从必要列位置 `c_q` 推出其同余 `a=-c_q P^{-1} mod q` 与当前骨架代表 `x0` 的差足够大，使得 `t` 不可能太小。

## 3. 为什么这有希望

若 `t` 很小，则新增中模数 `q` 的禁余类会提前与小骨架兼容。这意味着该必要列本应已在前窗口被覆盖，或者会造成与小骨架覆盖列的重叠，而不能作为唯一必要列。

因此“必要列”属性可能直接强迫 `t` 大，从而把 CRT 代表推出前窗口。

## 4. 证明路径

1. 小素数骨架覆盖大部分列，得到当前相位 `x0 mod m`；
2. 必要列 `c_q` 是未被骨架覆盖的洞；
3. 若加入 `q` 的 CRT 步长 `t` 太小，则对应相位 `x1<P`；
4. 但 `x1<P` 下该列被补，同时骨架仍保持，形成更早近完整覆盖；
5. 与 `c_q` 的必要性/首完整性矛盾；
6. 因此 `t` 足够大，`x1>=P`。

## 5. 下一步

把“必要性强迫 t 大”形式化。具体应研究：

- 当前骨架模数 `m` 下的覆盖洞集；
- 新增素数 `q` 的禁余类在这些洞中的位置；
- 若 `t` 小，则禁余类落入已覆盖区或产生重叠，不能补唯一洞；
- 若要补唯一洞，`t` 必须跨过阈值。

这把 FSC-2 进一步化为一个局部 CRT 步长不等式。

## 6. 最新修正：早期洞命中存在，但不兼容完整方案

进一步扫描显示：跨越素数 `q` 在 `s<threshold` 的早期相位下，往往会命中某些骨架洞；因此不能证明“早期相位不命中任何洞”。

真正现象是：

> 早期命中的洞不能作为完整覆盖方案中的必要列，因为它们与后续中大模数补洞结构不兼容；完整方案兼容的必要列出现在较晚的 `s`，从而跨过 `P`。

例如 `P=23`：在骨架 `2,3` 后加入 `q=5`。

- `s=0,1,2,3` 会命中洞 `3,5,15,17,9` 等，且仍在 `x<P`；
- 但完整方案选择的必要列是 `c=11`，其命中在 `s=4`，得到 `x=28>P`；
- 后续 `7,13,17,19` 才能共同完成全覆盖。

因此 MC 应升级为兼容性版本。

## 7. 引理 MC-2（兼容必要列延迟）

设某完整覆盖方案 `S` 的小骨架阶段给出 `x≡x0 mod m`。加入中模数 `q` 时，`q` 在骨架洞集中的命中序列为

`h_0,h_1,...,h_{q-1}`，对应 `x_s=x0+ms`。

早期 `s` 可能命中洞，但这些洞不能延拓为完整覆盖方案。若 `h_s` 是能延拓为完整方案的必要列，则

`x_s>=P`。

换言之：

`完整方案兼容性 => s >= ceil((P-x0)/m)`。

## 8. 下一步证明目标

要证明 MC-2，需要刻画“可延拓洞”：

- 一个早期洞若被 `q` 补掉，剩余洞集必须能由后续模数补齐；
- 若不能，则该早期洞不是完整方案必要列；
- 完整方案选择的必要列必须使后续剩余洞集满足多模数兼容；
- 这种兼容性强迫相位延迟。

下一步应对早期洞与后续剩余洞集做递归树分析，证明所有 `x<P` 的分支都会留下至少一个洞。
