# CRT 零行位置刚性与前 P 行排斥

**状态：** `zero_rows_can_exist_in_CRT_but_must_be_excluded_from_first_P_window`

完整 CRT 周期扫描显示：在除第 `P` 列外的类素数分布中，完整周期内可能存在“零行”（该行所有列都被根基素数零类覆盖）。例如 `P=13` 时，周期 `M=2310` 内有零行：

`169, 702, 1609, 2142`。

这给出重要修正：

> CRT 列均衡本身不排斥完整周期内的零行；目标命题需要证明零行不可能落在前 `P` 行的方阵窗口内。

## 1. 新的反例形式

目标反例不是“CRT 周期内存在零行”，而是：

`1 <= r <= P` 中存在零行。

在 CRT 周期语言中，这是零行集合 `Z_P subset Z/MZ` 与短窗口 `[1,P]` 相交。

因此应证明：

`Z_P ∩ [1,P] = empty`。

## 2. 零行位置为何有刚性

零行条件为：对每个 `c=1,...,P-1`，存在 `q<P` 使

`(r-1)P+c ≡ 0 mod q`。

令 `x=r-1`，则

`xP+c` 被根基零类覆盖。

由于 `1<=x<=P-1` 时，`xP+c < P^2`。若该数合数，则它必有一个小于等于 `sqrt(xP+c)<P` 的素因子。因此在前 `P` 行内，覆盖条件等价于“该区间内无素数”。

所以前 P 行零行正是 Legendre 型短区间反例。完整 CRT 周期的远处零行不构成反例，因为那里的数远大于 `P^2`，可由根基素数覆盖但不对应短区间 `[1,P^2]` 的 Legendre窗口。

## 3. 与增长量级的结合

完整周期零行的存在说明：仅靠 CRT 周期均衡不能证明无零行；必须加入前 `P` 行的大小约束：

`N=xP+c < P^2`。

这个大小约束带来关键性质：

- 若 `N` 合数，则至少一个素因子 `<P`，所以覆盖等价于合数；
- 若小筛洞被补，则补因子 `q` 与商 `N/q` 都在受限范围内；
- 对大因子 `q>sqrt(P)`，商 `N/q < P^2/sqrt(P)=P^{3/2}`，仍受强约束；
- 若 `q` 接近 `P`，商接近 `<P`，会与根基素数集合产生递归约束。

因此应把矛盾场改成“CRT 相位 + 数值高度”双约束，而不是纯 CRT。

## 4. 下一核心命题

### 引理 Z（零行高度排斥）

设 `1<=x<=P-1`。不可能对所有 `1<=c<=P-1` 选择根基素数 `q_c<P`，使

`q_c | xP+c`。

证明应使用：

1. 相邻刚性：短距离内大因子标签不同；
2. 高度约束：`xP+c<P^2`，因此大因子标签的商也受限；
3. gap 多标签复杂度：高频 gap 产生大量大因子；
4. 递归商约束：`(xP+c)/q_c < P^2/q_c`，若 `q_c` 大则商落回较小尺度；
5. CRT 周期：若标签链要覆盖完整短窗口，需形成相位兼容。

## 5. 下一步实验

针对零行位置集合：

- 对小 P 完整 CRT 周期找所有零行；
- 比较最小零行 `min Z_P` 与 `P`、`P^2`、`M` 的关系；
- 观察是否总有 `min Z_P > P`；
- 研究 `min Z_P` 的构造是否由覆盖系统的最小共同相位决定。

若能证明 `min Z_P>P`，行命题即闭合。

## 6. 最新扫描修正

`P=23` 的完整 CRT 周期最小零行为 `r=59`，对应连续合数串 `1335..1356`。因此零行可以远早于 `P^2` 出现；但仍满足 `r>P`。

这说明目标应精确写成：

`min Z_P > P`，而不是更强的 `min Z_P >= P^2`。

## 7. 高度受限标签链接口

前 `P` 行内若出现零行，则存在 `0<=x<=P-1`，使

`xP+1,...,xP+P-1`

全部合数。选择每个数的最小素因子 `p_c`，得到高度受限标签链。

该链比 CRT 远处零行更受限，因为：

- `xP+c<P^2`；
- `p_c<P`；
- 商 `m_c=(xP+c)/p_c` 满足 `m_c<P^2/p_c`；
- 若 `p_c>sqrt(P)`，则 `m_c<P^{3/2}`；
- 相邻位置的最小因子标签受互斥和 gap 复杂度约束。

下一步应证明：这种高度受限标签链不可能覆盖全部 `P-1` 个位置。

## 8. 当前诚实边界

该命题与 Legendre 型素数间隙问题非常接近。任何完整证明必须真正利用：

- 行列对齐；
- 圆柱斜线相位；
- CRT 列均衡；
- 高度受限商链；
- 相邻互斥与 gap 多标签复杂度。

单独筛估计或单独 CRT 周期性都不够。
