# Transfer-Accounting 形式化附录

本文补齐 `docs/rh-unconditional-final-gap-audit.md` 中最优先的内部账本义务 `Transfer-Accounting`。目标不是证明九出口局部上界，而是严格证明：在统一 `Load/Excess` 口径下，seed 转出、内部势函数转移和失败分流不会重复计数、不会丢失异常质量，并且只造成多对数有限重叠损失。

## 1. 路由原子与负担测度

设 `𝓐_X` 为 GEE-0 产生的有限路由原子族。每个原子 `a∈𝓐_X` 带有非负超额质量

`m(a)=Excess(a)=max(0,σΣ_{n∈a}(w_X(n)-w_X^0(n)))`。

一个路由状态是三元组

`(a,E,s)`，

其中 `E∈𝓔={A,PI,FCT,SC,LV,LSMP,CE,DSO,NRC}`，`s` 是该出口内部的规范状态。路由账本由权重 `θ(a,E,s)≥0` 给出，定义

`Load(E;X)=Σ_{a,s} θ(a,E,s)m(a)`。

我们要求初始路由满足

`Σ_{E,s} θ_0(a,E,s) <= log^{C_route}X`。

## 2. 允许的转移操作

所有转移均由以下四类生成。

### 2.1 细分

把一个状态 `(a,E,s)` 分成有限个子状态 `(a_j,E,s_j)`，其中 `a=⊔_j a_j`，且

`Σ_j m(a_j) <= m(a)`。

细分数至多 `log^{C_split}X`，来自 dyadic 层、频率层、Vaaler 截断、短窗网格和薄层选择。

### 2.2 重标记

把 `(a,E,s)` 改为 `(a,T,t)`，其中 `T` 是 seed 表或事件图指定的唯一目标出口。重标记保持质量：

`m(a)` 不变，源状态权重删除，目标状态权重增加同一数值。

### 2.3 内部下降

在 `A/FCT/SC` 中，把 `(a,E,s)` 改为 `(a,E,s')`，并使对应势函数下降：

- `E=A` 时 `𝓐pot(s')<𝓐pot(s)`；
- `E=FCT` 时 `𝓝(s')<𝓝(s)`；
- `E=SC` 时 `𝓥(s')<𝓥(s)`。

内部下降不登记最终负担，只作为路由中间状态。

### 2.4 吸收

若某状态满足相对阈值，则转入吸收符号 `Abs(E)` 并停止。吸收状态保留质量但不再产生后继。

## 3. 转移算子的质量守恒不等式

**Lemma 3.1（单步账本不增）.** 任一允许转移把权重 `θ` 改为 `θ'` 后，满足

`Σ_{E,s} θ'(a,E,s)m(a) <= log^{C_step}X · Σ_{E,s} θ(a,E,s)m(a)`，

其中 `C_step=0`，除非该步含细分；细分时 `C_step<=C_split`。

**证明。** 重标记只是把同一权重从源状态移到目标状态，质量完全守恒。内部下降保持同一出口和同一原子，只改变规范状态，质量守恒。吸收停止后不再产生后继，质量不增。细分时 `Σ_j m(a_j)<=m(a)`，若使用覆盖型细分而非真分割，则有限重叠由 `log^{C_split}X` 控制。因此单步不等式成立。证毕。

## 4. 路由深度与有限重叠

**Lemma 4.1（内部下降深度）.** 对任一原子 `a`，沿任何只含内部下降的路径，`A/FCT/SC` 的真下降次数分别至多为其初始势函数高度。因此若

`𝓐pot,𝓝,𝓥 <= log^{C_pot}X`，

则总真下降次数为 `O(log^{C_pot}X)`。

**证明。** 三个势函数均取非负整数或离散有下界值，每个真下降步至少下降一个单位。故次数不超过初始高度。证毕。

**Lemma 4.2（全路径有限重叠）.** 假设每次细分的重叠损失由 `log^{C_split}X` 控制，且一条路径中细分层数由 `C_layer log log X` 级的 dyadic/频率/短窗选择支配。则存在常数 `C_transfer`，使所有从同一原子 `a` 派生的最终状态权重满足

`Σ_{final E,s} θ_final(a,E,s) <= log^{C_route+C_transfer}X`。

**证明。** 初始权重和至多 `log^{C_route}X`。重标记、内部下降和吸收不增加权重和。细分层数固定为多对数层，且每层的有限重叠指数固定；把所有指数相加得 `C_transfer`。证毕。

## 5. 无重复计数与无质量丢失

**Theorem 5.1（Transfer-Accounting）.** 在第 2 节允许操作下，可把 GEE 路由规范化为最终账本，使：

1. 每个非吸收 seed 从源出口删除，并唯一转入目标出口；
2. `A/FCT/SC` 的内部下降步不登记最终 `Load`；
3. 所有吸收项只在其最终吸收出口登记一次；
4. 对每个原子 `a`，最终总权重满足

   `Σ_{final E,s} θ_final(a,E,s) <= log^{C_route+C_transfer}X`；

5. 若原子未被阈值吸收，则它必停在某个命名出口或被命名局部定理转出；不存在“源出口与目标出口同时保留同一 seed”的重复计数。

**证明。** 对任一原子建立有向路由树。每条边是第 2 节四类操作之一。若边为 seed 重标记，则按定义删除源状态权重并在唯一目标状态加入同一权重；因此不会源目标双计。若边为内部下降，则该状态标记为中间节点，不列入最终 `Load`；由 Lemma 4.1，连续内部下降有限。若边为吸收，则停止且只登记该叶节点一次。若边为细分，则子原子质量和不超过父原子质量，覆盖型重复由 Lemma 4.2 吸收。于是所有叶节点的总权重满足第 4 项，且每个叶节点要么吸收，要么为命名出口的待处理局部命题。证毕。

## 6. 对 RH/GEE 总稿的影响

本附录闭合的是纯账本层面的最小割集 `Transfer-Accounting`：转移不丢质量、不重复计数、有限重叠可吸收。它不证明 `PI/DSO/NRC` 的解析上界，也不替代九出口局部命题。因此最终缺口从四项缩为三项：

1. `EXT-Precision`；
2. `Local-Exit-Proofs`；
3. `Review-Form-Elimination`。
