# 首个零行的相位延迟与最小正解路线

**状态：** `reduce_front_window_exclusion_to_minimal_solution_lower_bound`

对多个 `P` 的扫描显示：前窗口 `0<=x<P` 中禁余类覆盖始终留洞，而完整覆盖首次出现需要 `x>=P` 之后的相位延迟。对于很多 `P`，前窗口最佳状态只剩 1 到 3 个洞。

这提示下一步不要试图一次性估计全部覆盖能力，而应研究：

> 最后几个洞要被补齐，需要 `x` 满足额外同余条件；这些条件的最小正解大于 `P`。

## 1. 覆盖系统写法

对固定 `P` 和 `x=r-1`，列 `c` 被根基素数 `q<P` 覆盖当且仅当

`xP+c ≡ 0 mod q`，即

`x ≡ -c P^{-1} mod q`。

因此每个洞 `c` 要被补齐，需要存在某个根基素数 `q<P`，使 `x` 落入对应禁余类。

全行零行等价于：

`x` 落入覆盖所有 `c=1,...,P-1` 的一组禁余类并集组合。

## 2. 前窗口排斥的新形式

目标 `x<P` 无零行可写成：

> 对任意 `0<=x<P`，禁余类族 `{x ≡ -cP^{-1} mod q}` 不能覆盖全部列 `c`。

若某个 `x_0<P` 几乎覆盖全部列，只剩洞集 `H(x_0)`，则补齐这些洞要求对每个 `c in H(x_0)` 引入某个素数 `q_c`，并满足

`x ≡ a_{c,q_c} mod q_c`。

从 `x_0` 漂移到真正零行 `x_*`，必须同时满足这些新增同余。若这些模数互素且乘积大于 `P`，则最小共同解通常会越过前窗口。

## 3. P=23 示例

`P=23` 前窗口最佳正行是 `x=14`，剩余洞为 `[9,15]`。第一个零行为 `x=58`。

在 `x=58` 中：

- `c=9` 由 `q=17` 补齐；
- `c=15` 由 `q=19` 补齐。

这两个条件为：

`x ≡ -9*23^{-1} mod 17`

`x ≡ -15*23^{-1} mod 19`

它们共同把相位推迟到前窗口之后。

## 4. 候选引理 S（最后洞最小正解）

设 `x<P` 时存在一个最优近零行相位 `x_0`，剩余洞集为 `H`。若要补齐 `H`，必须使用一组互素根基模数 `Q_H`。若

`Π_{q in Q_H} q > P`

且对应 CRT 共同解的最小非负代表不落入 `[0,P-1]`，则前窗口无零行。

更强的全局形式：

> 任意能覆盖全部 `1..P-1` 的禁余类选择，其 CRT 解的最小非负代表 `x` 都满足 `x>=P`。

这正是 `min Z_P>P`。

## 5. 下一步证明策略

1. 对每个 `x<P`，洞集 `H(x)` 非空；
2. 对最小洞集，证明补齐洞所需模数集合乘积超过 `P`；
3. 证明这些补洞同余的最小共同解不能仍在 `[0,P-1]`；
4. 将该局部最优相位论证推广到任意 `x<P`。

## 6. 与矛盾场的结合

该路线把前面的刚性转为最小正解下界：

- 相邻互斥保证最后洞需要不同大模数；
- gap 复杂度保证补洞模数集合快速变大；
- CRT 周期性给出共同解位置；
- 高度约束要求前窗口 `x<P`，从而排除共同解提前出现。

这是目前最具体、最接近可证明化的突破口。
