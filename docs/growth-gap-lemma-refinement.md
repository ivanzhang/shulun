# 增长缺口引理的修正版

**状态：** `from_every_block_gap_to_no_continuous_full_patch_chain`

本轮实验修正了一个过强断言：长度 `sqrt(P)` 的单块内，小筛洞可能被大因子完全补掉。因此不能证明“每个短块都有素数”。正确的全局增长路线应改成：

> 满补块可以局部存在，但不能连续铺满整行；若连续铺满整行，则会触发大因子互斥的乘积矛盾或 CRT 短周期矛盾。

## 修正后的引理 A

设 `Y=sqrt(P)`，第 `r` 行经过 `q<=Y` 小筛后得到洞集 `H_r`。把行划分或滑动覆盖为长度 `L=C sqrt(P)` 的中块。

允许存在少数中块满足：该块内所有小筛洞都被 `q>Y` 补掉。

但应证明：不存在一串中块覆盖整个 `1..P`，使每个块内洞都完全由大因子补掉。

等价地，整行累计必有至少一个小筛洞未被大因子补掉，即该点为素数。

## 为什么这比逐块命题更可证

逐块命题失败是因为局部可由若干大因子偶然补满；但若全行补满，则需要约 `P/log P` 个粗合数洞，每个洞带一个大因子 `>sqrt(P)`。

这些大因子满足：

- 在长度 `<sqrt(P)` 的局部内不能重复命中两个不同洞；
- 若重复命中距离 `d` 的两个洞，则大因子整除 `d`，但 `0<d<sqrt(P)<q`，矛盾；
- 因此连续满补需要大量彼此不同的大因子按行内位置精密排列；
- 这种排列若跨越多个中块，会形成可检测的同余相位链。

## 与 CRT 刚性的接口

若全行被补满，则每个小筛洞 `c` 被某个大素数 `q(c)>sqrt(P)` 命中：

`(r-1)P+c ≡ 0 mod q(c)`。

当行号推进 `k` 时，该命中列移动为

`c - kP mod q(c)`。

若全覆盖图案以步长 `k` 复现为平移全覆盖，则对一大批关键大因子必须保持相位兼容。这要求许多 `q(c)` 同时约束 `kP`。由于 `gcd(P,q(c))=1`，这些约束转化为 `k` 在许多大模数下的同余限制。

当参与大因子的乘积超过可用行窗口尺度时，短周期不可能存在。

## 下一步严格目标

1. 证明全行补满需要至少 `c P/log P` 个大因子命中点。
2. 证明这些命中点中可抽取一个相互距离 `<sqrt(P)` 不共享因子的稀疏独立集，其大因子乘积超过 `P`。
3. 证明全覆盖复现或连续满补链会迫使一个 `k<P` 同时满足这些大因子的相位约束。
4. 得出 CRT 矛盾。

这条链条避免有限模板，同时避免声称每个短块都必须有素数。
