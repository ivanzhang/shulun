# 高维缺陷流原则：统一分情况背后的本质命题

**状态：** 方法论升级与统一命题框架。

## 1. 为什么不能沉入个别分情况

此前出现了若干分情况：

- 奇偶翻转 / 同奇偶；
- 小壳签名改变 / 保持；
- 壳差逃逸 / 原壳重排释放；
- 容量不足 / 重叠吞噬 / 迁移换核；
- 短差核 / 无短差镜像核。

这些不是彼此独立的特例，而是同一个高维动力系统在不同投影下的表现。

统一对象应是：

> 在 CRT 小模数壳空间中，相位移动导致候选壳整体迁移；剩余素数层试图覆盖迁移后的壳，但有效覆盖受重叠能量、标签互斥与 CRT 同步压力限制；未覆盖缺陷作为列缺陷流在周期内守恒迁移。

## 2. 高维状态向量

定义相位 `x` 的状态向量：

`State(x;B)=(S_B(x), U_{>B}(x), E_{>B}(x), H_P(x), D(x), L(x))`。

其中：

- `S_B(x)`：小素数 CRT 候选壳；
- `U_{>B}(x)`：剩余层有效覆盖并集；
- `E_{>B}(x)`：剩余层重叠能量；
- `H_P(x)=S_B(x)\U_{>B}(x)`：缺陷集；
- `D(x)`：列缺陷流位置；
- `L(x)`：局部标签图。

所有分情况都是 `State(x;B)->State(y;B)` 的不同坐标变化。

## 3. 统一守恒-耗散方程

基础恒等式：

`|H_P(x)|=|S_B(x)|-|U_{>B}(x)|=|S_B(x)|-C_{>B}(x)+E_{>B}(x)`。

它是守恒方程。

相位移动 `x->y` 给出差分：

`Δ|H| = Δ|S_B| - ΔC_{>B} + ΔE_{>B}`。

这就是统一耗散方程。

若想把缺陷降到 `0`，必须让

`ΔC_{>B}-ΔE_{>B}` 至少追上 `Δ|S_B|+|H_P(x)|`。

但补旧核、小壳迁移、标签合法性同时增加 `ΔE` 或降低可用 `ΔC`，形成耗散屏障。

## 4. 统一核心命题 UDF

**UDF：统一缺陷流命题。** 对任意奇素数 `P`、任意前窗口相位 `1<=x,y<P`、任意小素数前缀 `B`，若 `y` 试图减少或消灭 `H_P(x)`，则缺陷不会消失，只会在高维状态中迁移：

`H_P(y) nonempty`，除非相位跨出前窗口或违反 CRT/标签/列均衡约束。

更可证的局部版本：

`|H_P(y)| >= min_defect(State(x;B), transition x->y) >= 1`。

此前所有分情况都是估计这个 `min_defect` 的不同投影。

## 5. 分情况的高维解释

### 5.1 奇偶翻转

是 `B={2}` 的壳坐标大跳变。缺陷从一个半壳迁到另一个半壳。

### 5.2 多小素数同余迁移

是 `B={2,3,5,7,...}` 的多坐标跳变。释放不是单点，而是 CRT 小单元块。

### 5.3 壳差逃逸与原壳释放

是同一差分方程中 `ΔS_B` 与 `ΔU_{>B}` 的两种投影。若壳差无逃逸，则覆盖压力转入原壳，表现为 `InnerRelease`。

### 5.4 容量不足与重叠吞噬

是 `ΔC` 与 `ΔE` 的两种失败方式。容量不足是 `ΔC` 不够；重叠吞噬是 `ΔE` 太大。

### 5.5 短差标签互斥

是标签图 `L(x)` 对 `ΔC` 的约束：看似可用的覆盖容量因标签互异和 CRT 同步不能自由分配。

### 5.6 CRT 列均衡与镜像

是缺陷流 `D(x)` 的全局守恒。局部缺陷迁移必须能嵌入周期守恒与镜像配对；否则反例被全局排斥。

## 6. 高维证明路线

真正应证明的不是一个个特例，而是三层统一原则：

1. **局部耗散原则。** 任意前窗口转移若补旧洞，必产生覆盖耗散：`ΔE` 增加或有效 `ΔC` 减少。
2. **缺陷不可湮灭原则。** 局部耗散至少留下一个缺陷：`|H_P(y)|>=1`。
3. **周期不可补偿原则。** 缺陷流的受限迁移无法在 CRT 周期内制造前窗口零行并同时满足列均衡与镜像。

## 7. 下一步最优任务

下一步不要继续只枚举个别 `B`，而应建立统一的“转移账本函数”：

`Transition(x,y;B)` 输出

`(ΔS, ΔC, ΔE, ΔH, 标签冲突增量, 列缺陷支撑)`。

然后寻找跨 `B` 稳定的不变量，例如：

`Barrier=ΔE - ΔC + ΔS + killed_old_holes`。

若能证明 `Barrier>=1`，则所有分情况统一闭合。

## 8. 对当前研究的校正

后续每次分情况都必须回到统一方程：

`Δ|H| = Δ|S_B| - ΔC + ΔE`。

分情况只允许作为估计 `ΔC` 和 `ΔE` 的工具，不能成为最终证明结构本身。
