# RKS-bridge 近临界分区审查

本文件继续细化 `docs/rks-log-reference-audit.md` 中提出的 RKS-bridge 义务。目标是把 TL4-L 的 Vaughan Type I/II 块按长度区间分成“BG 已覆盖”“Weil/平凡吸收”“仍需桥接”三类。

## 1. Type I/II 的尺度记号

TL4-L 中的非零 Fourier 模经 Vaughan 分解后出现块

`S(M,N)=Σ_{m≈M}Σ_{n≈N} α_mβ_n e_P(ξ(mn)^{-1})`, `MN≈P`, `ξ≠0 mod P`。

系数为 Vaughan/divisor-bounded 系数，dyadic 分层后可视作 `log^{O(1)}P` 损失。

## 2. 已覆盖区域

### 2.1 多线性可分裂区域

若 `m` 或 `n` 的系数可由 Heath--Brown/Vaughan 继续分裂为若干区间变量，使总变量区间乘积超过 `P^{1/2+ε}`，则可调用 BG `Kloost 1/2`。这给幂节省，强于 TL4-L 所需对数节省。

### 2.2 BG 双线性覆盖区域

若两变量长度满足 BG 文献中的双线性范围，例如一侧 `>P^{1/18}` 且另一侧 `>P^{5/12+ε}`，则由对应双线性 Kloosterman 定理给幂节省。

在 `MN≈P` 下，该条件覆盖强不平衡但长侧足够长、短侧超过 `P^{1/18}` 的范围。

### 2.3 一变量长区间完成和区域

若 `M<=log^C P` 或 `N<=log^C P`，则固定短变量后，长变量长度至少 `P/log^C P`。不完全 Kloosterman 完成和给 `O(P^{1/2}logP)`，相对于长变量长度 `P/log^C P` 有巨大节省，足以覆盖 TL4-L。

## 3. 平凡吸收区域

若某端点/低体积块总候选数 `<=P/log^A P`，则平凡估计已经满足 `P/log^44P`，取 `A` 足够大即可。这部分不需要 RKS。

注意：标准 Vaughan 分解中主要 Type I/II 块通常仍有 `MN≈P`，不属于低体积；低体积只指端点截断或被预先剥离的短总长度块。

## 4. 历史风险定位：原先怀疑的 RKS-bridge 区域

剩余危险区是：

- `MN≈P`；
- `M,N` 都远大于对数，但某一侧低于 BG 双线性阈值 `P^{1/18}`；
- 又无法从系数结构继续分裂出满足 BG `Kloost 1/2` 的多线性源；
- 完成和逐短变量求和只给 `M P^{1/2}` 或 `N P^{1/2}`，不足以达到 `P/log^44P`。

该区域可近似描述为 `log^C P << min(M,N) < P^{1/18}` 的近极端不平衡块。它曾被标记为 TL4-L 中可能需要桥接的部分；第 7--9 节进一步核验后，该区域由逐短变量 Weil 吸收，已不再是新估计缺口。

## 5. 历史候选桥接方案

**RKS-bridge-minor.** 对近极端不平衡块，利用短变量系数来自 Vaughan divisor 结构，而非任意系数。把短变量再按因子结构展开；若展开后变量数增加，则进入 BG 多线性区域。若无法展开，则短变量支撑稀疏，其总贡献可用 divisor 平均 + 完成和二阶矩吸收。

形式目标：证明对 `log^C P << M < P^{1/18}`、`N≈P/M`，Vaughan 来源系数满足

`S(M,N) <= MN/log^{44+C_0}P`。

这不是一般任意系数双线性定理，而是带 Vaughan 系数结构的桥接引理。

## 6. 历史审稿结论（已由第 7--9 节修正）

本节原先把最小剩余定位为近极端不平衡块，并要求证明 `RKS-bridge-minor`。第 7--9 节进一步核验 BG 的 Vaughan 处理后，确认短侧低于 `P^{1/18}` 时逐短变量 Weil 已足够吸收。因此本节只保留为风险定位历史，不再代表当前最终剩余。

## 7. 关键修正：短侧低于 `P^{1/18}` 可由逐短变量 Weil 吸收

进一步核验 BG 对素变量倒数和的证明后，发现第 4--6 节把近极端不平衡区列为“真正剩余”仍偏保守。BG 在证明 Corollary `th1KloostPrimespowerFull range` 时，对 Vaughan 项采用了如下原则：若短侧长度 `L<P^{1/3}`，则逐短变量对长变量使用不完全 Kloosterman/Weil 界，得到

`L P^{1/2+o(1)}`。

在本文 TL4-L 的近极端区，短侧 `M<P^{1/18}`，长侧 `N≈P/M`。逐短变量完成和给

`|S(M,N)| <= M P^{1/2} log^C P`。

由于 `M<P^{1/18}`，故

`M P^{1/2} <= P^{5/9}`，

而目标只是

`MN/log^44P≈P/log^44P`。

对充分大 `P`，`P^{5/9}log^C P << P/log^44P`。因此短侧低于 `P^{1/18}` 的近极端不平衡块事实上可由逐短变量 Weil 吸收，不需要新的 RKS-bridge-minor。

## 8. 修正后的 RKS-bridge 结论

TL4-L 的 Type I/II 块现在可分为：

1. **短侧 `<=P^{1/18}`**：逐短变量完成和/Weil 吸收；
2. **短侧 `>P^{1/18}` 且长侧 `>P^{5/12+ε}`**：BG 双线性定理覆盖；在 `MN≈P` 下长侧自动约为 `P/M`，当短侧低于 `P^{7/12-ε}` 时成立；
3. **更平衡或可多线性分裂区**：BG `Kloost 1/2` 或 `Th1GenBil` 覆盖；
4. **端点低体积区**：平凡吸收。

因此原先的 `RKS-bridge-minor` 可降级为一个参数核对义务：确认 Vaughan 分解中所有 Type I/II 块确实落入上述四类之一，并记录 dyadic、系数和 `r,h` 求和的总对数损失。

## 9. 当前最小剩余

RKS-bridge 不再需要新的数论估计；剩余是 **RKS-parameter-audit**：

- 核对短侧阈值 `P^{1/18}` 与 BG 双线性阈值之间无缝覆盖；
- 核对逐短变量 Weil 的 `log^C` 损失被 `K_sieve_log_saving=128` 吸收；
- 核对 Vaughan/divisor-bounded 系数只造成 `log^{O(1)}P` 损失；
- 核对所有 dyadic 块与 `r<=log^8P`, `h<=log^16P` 求和后仍保留 `log^{-44}`。

## 10. 参数账本闭合

对数损失核算见 `docs/rks-parameter-audit.md`。该账本给出 TL4-L 内部 RKS 侧总损失指数 `74<128`，因此 RKS-bridge 已降为最终引用文字与附录化义务。
