# LSMP-Freq：频率原子版小质量逃逸推论

本文补 `docs/rh-pc4-dso-euler-match-audit.md` 留下的最小接口：把 DSO-E4 中“频率集合过大且无重子集”的情形，逐行归入 LSMP 小质量原子机制。本文只闭合 DSO-E4 的组合剥离接口，不声称证明 RH。

## 1. 频率原子模型

设新增局部层 `p` 上有频率集合 `Ω_p` 与系数 `a_ν`。归一化总质量

`M=Σ_{ν∈Ω_p}|a_ν|^2`。

给定阈值 `L=c p^{1/4}`。称子集 `U⊂Ω_p` 为可控块，若 `|U|<=L`。称短深度 span 桶为

`B(Ξ,H)=Ω_p∩Span_H(Ξ)`。

DSO-E4 的困难情形是：

1. 没有 span 桶承载 `>=ρM`；
2. 没有可控块承载 `>=ρM`；
3. 但 `M` 对投影偏差仍有非忽略贡献。

这里 `ρ` 是固定小常数，可并入主文常数包。

## 2. 频率层蛋糕分解

按系数大小作 dyadic 分层：

`Ω(j)={ν: 2^{-j-1}A < |a_ν| <= 2^{-j}A}`。

在 PPI/OMR 的截断包中，低于可吸收阈值的系数先归入尾项；剩余有效系数的大小跨度由模板复杂度与截断高度控制，记有效层数为 `J_eff<=C log^C K`。于是存在一层 `Ω(j_*)` 承载至少 `M/J_eff` 的 `l^2` 质量。

在该层中，每个原子的质量彼此相差至多常数倍；若没有大小 `L` 的可控块承载 `ρM`，则任意可控块最多承载 `O(ρM)`。这意味着质量分散在至少常数倍 `ρ^{-1}` 个互不相同的小块上。

## 3. 频率原子到 LSMP 小块

把每个频率原子 `ν` 对应的局部相位窗口或 Bohr 切片记为 `C_ν`。同一 dyadic 层内，原子权重可视为近似等厚薄层。取 maximal disjoint 子族 `C_{ν_a}`；有限复杂度模板保证放大后的薄层重叠数为 `O(log^C K)`。

由 maximality，原始层的总质量被这些薄层的有限重叠放大覆盖。因此得到薄层族 `B_a`，满足

`Σ_a μ(B_a) >= c M/log^C K`, `K(B_a)<=K log^C K`，其中对数幂吸收 `J_eff` 与有限重叠损失。

这正是 `docs/omr-cgtp-lsmp-theoremization.md` 中 LSMP-1 的离散 coarea 输入。

## 4. 同向偏移与 DPI

若这些频率原子对 DSO-E 的平方误差有同向贡献，则方向筛选给出符号 `σ_a∈{±1}`，使

`Σ_a σ_a Bias(B_a) >= c M/log^C K`。

若无高投影增量、无 FCT，且 NRC 背景可吸收，则 LSMP-2 的 DPI 将该同向偏移推成允许窗口上的高投影增量，矛盾。因此，在非终端假设下，这些小质量频率原子的总贡献必须由 LSMP 吸收。

## 5. LSMP-Freq 推论

**Corollary LSMP-Freq（频率原子小质量逃逸）。** 在 DSO-E4 的大局部复杂度情形中，若：

1. 无短深度 span 桶承载固定比例 `l^2` 质量；
2. 无大小 `<=c p^{1/4}` 的可控子集承载固定比例 `l^2` 质量；
3. 无高投影增量、无 FCT，且 NRC 背景满足 LSMP 吸收条件；

则大复杂度频率原子对 `Σ||b_p||_2^2` 的贡献进入 LSMP 小质量项，并满足

`E_freq-small <= C M/log^A K`

形式的可吸收上界。若该上界失败，则触发 LSMP 终端或高投影增量。

**证明。** 第 2 节给 dyadic 层蛋糕，抽出承载 `M/J_eff` 的近等厚频率层。第 3 节用 maximal disjoint 选择与有限重叠，把该层转为 LSMP-1 的薄层族。第 4 节用方向筛选与 LSMP-2：若薄层偏移不可吸收，则产生高投影增量；若 NRC 不适用，则进入 FCT。排除这些终端后，只能由 Theorem LSMP 吸收，得到所述上界。证毕。

## 6. 对 DSO-E4 的闭合

LSMP-Freq 直接替换 DSO-E4 证明中的“dyadic 层蛋糕与 coarea 给出 LSMP 小质量逃逸”这一压缩句。于是 DSO-E4 的三分变为可逐项引用：

- 重 span：FCT；
- 重可控子集：返回 DSO-E3；
- 二者皆无：LSMP-Freq。
