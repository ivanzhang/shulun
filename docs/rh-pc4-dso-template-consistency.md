# DSO-C-TC：固定投影模板的 CRT martingale 一致性

本文专攻 `docs/rh-pc4-dso-crt-martingale.md` 留下的模板一致性条件 DSO-C-TC。目标是证明一类“固定有限坐标 cylinder 模板”满足自然细化、复杂度稳定和误差平方可和；并把 PPI/OMR 的倒数环带模板归约到该 cylinder 模板加 Vaaler 截断误差。

## 1. Cylinder 模板

在逆极限 CRT 空间

`G_∞=∏_p (Z/pZ)^*`

中，称一个模板是 `m`-坐标 cylinder 模板，若它只依赖有限个已指定坐标的相对模式。对随层增长而每次作用在新增素数坐标上的模板，本文使用“同型 cylinder 族”这一更谨慎的说法：每一层函数与同一个局部模型同构，但它依赖的是当前新增坐标，不应被误认为依赖某个固定旧坐标。例如：

- 指定某些新增素数坐标落在固定比例的子集；
- 指定有限个字符频率的相位落在短弧；
- 有限个这类条件的并、交、差。

在有限层 `G_k` 上，该模板给出函数 `f_k`；在 `G_∞` 上有自然 cylinder 函数 `F`，使

`f_k∘π_{∞,k}=E_kF`

对所有足够大的 `k` 成立。

**Lemma TC-1（cylinder 模板一致性）。** 任意固定 cylinder 模板满足 DSO-C-TC，且误差 `err_k=0`。

**证明。** cylinder 模板依赖有限坐标。取 `F` 为其在 `G_∞` 上的指标函数或有限线性组合。对包含这些坐标的所有 `k`，条件期望 `E_kF=F`；对更小 `k`，`E_kF` 是自然投影平均。有限层函数正是该条件期望，故 `err_k=0`。证毕。

## 2. 有限并差与复杂度稳定

**Lemma TC-2（有限布尔闭包）。** 若模板 `F_1,...,F_m` 满足 DSO-C-TC，且 `m` 固定，则由它们通过有限并、交、差、线性组合生成的模板也满足 DSO-C-TC；误差平方和至多增加固定常数倍。

**证明。** 指标函数的并交差可由有限次乘法和加法表示。对固定 `m`，复杂度不随 `k` 增长。误差项由三角不等式和 `L^2` 有界性吸收；有限项平方可和保持平方可和。证毕。

## 3. 倒数环带模板的 Vaaler 近似

PPI/OMR 的基本窗口是倒数相位环带，例如

`A_k={x in G_k: ξ x^{-1} mod p_k lies in I}`。

其指标函数可用 Vaaler/Fourier 截断近似：

`1_A = main_H + rem_H`,

其中 `main_H` 是 `|h|<=H` 的有限字符组合，`rem_H` 的 `L^2` 误差为 `O(H^{-1})`，边界平滑后更小。

**Lemma TC-3（倒数环带截断一致性）。** 固定截断高度 `H` 的倒数环带主项 `main_H` 满足 DSO-C-TC 的同型新增坐标版本：在每个新增素数层上，它是复杂度固定的局部 cylinder 函数；把这些函数嵌入 `G_∞` 的相应新增坐标后，其 martingale 差属于该新增坐标的正交子空间。

**证明。** 固定 `H` 时，`main_H` 是有限个局部字符 `e_p(hξx^{-1})` 的线性组合。这里的字符依赖当前素数坐标，而不是依赖某个固定旧坐标；但在 `G_∞` 中它仍是对应新增坐标上的 cylinder 字符。不同新增坐标的非主字符彼此正交，同一坐标内只有有限个频率。由 TC-1 的单坐标版本、TC-2 的有限线性组合以及 DSO-C 的 martingale 差正交性，得到一致性。证毕。

## 4. 截断误差平方可和

要让完整倒数环带满足 DSO-C-TC，需要选择随层增长的截断 `H_k`，使

`Σ_k ||rem_{H_k}||_2^2 <∞`。

**Lemma TC-4（Vaaler 误差平方可和）。** 对平滑边界，若 `||rem_{H_k}||_2 <= C H_k^{-1}` 且取 `H_k>=k^2 log^C k`，则

`Σ_k ||rem_{H_k}||_2^2 <∞`。

对硬边界，先作宽度 `η_k` 的平滑；若

`||rem_{H_k,η_k}||_2 <= C(η_k^{1/2}+(H_kη_k)^{-1})`,

则取 `η_k=k^{-4}`、`H_k=k^8log^Ck` 也得到平方可和。

**证明。** 平滑情形下平方误差为 `O(H_k^{-2})`，所以上述选择可和。硬边界的第一项来自边界层测度，第二项来自平滑函数的 Fourier 尾；代入 `η_k=k^{-4}`、`H_k=k^8log^Ck`，得到 `||rem||_2=O(k^{-2})`，故 `Σ_k||rem||_2^2<∞`。证毕。

若主论文固定使用统一对数截断，则不可直接对所有 `k` 求和；此时需把高截断尾项归入 Complexity-Escape/LSMP。本文的 TC 闭合使用平方可和截断方案。

## 5. dyadic 标签与尺度自然细化

dyadic 层标签 `Q,R` 在 CRT 逆极限中不是坐标条件，而是尺度外参数。固定模板要求相对层级固定，例如 `Q=X^θ log^aX` 的类型固定。尺度变化只改变外部归一化，不改变已存在 CRT 坐标条件。

**Lemma TC-5（dyadic 标签不重写旧坐标）。** 固定相对 dyadic 类型的模板在 `k->k+1` 时只新增素数坐标或细化边界，不改变旧坐标上的布尔结构；因此满足自然细化，边界误差由 TC-4 或 LV 吸收。

**证明。** dyadic 标签决定取哪些锚层和尾层；当 CRT 模数增加一个新素数坐标时，旧坐标的剩余类条件保持不变。新条件只涉及新增坐标或尺度边界。尺度边界造成的端点误差是低体积边界项，由 LV 或 TC-4 控制。证毕。

## 6. TC 主命题

**Theorem DSO-C-TC（模板一致性定理，条件化闭合）。** 固定 PPI/OMR 投影模板若满足：

1. 由有限个倒数环带、短弧、Bohr 切片及其有限并差组成；
2. dyadic 相对类型固定；
3. Vaaler/边界截断采用平方可和误差方案，或不可和尾项明确转入 LSMP/LV/Complexity-Escape；

则该模板满足 DSO-C-TC。

**证明。** 固定旧坐标的 cylinder 条件由 TC-1；有限并差由 TC-2；作用在新增素数坐标上的倒数环带主项由 TC-3 的同型新增坐标版本处理；截断误差由 TC-4；dyadic 自然细化由 TC-5。合并得到每一层函数分解为固定复杂度 martingale 差主项加平方可和误差。等价地，在 DSO-C 的 square-function 估计中，主项由正交新增坐标吸收，误差由 `Σ_k||err_k||_2^2<∞` 吸收。证毕。

## 7. 与 DSO-C 的闭合关系

由 `docs/rh-pc4-dso-crt-martingale.md`，DSO-C-TC 推出密集尺度包的 martingale square-function 上界。本文给出 PPI/OMR 固定模板满足 DSO-C-TC 的条件化证明。因此 DSO-C 分支现在闭合到以下诚实边界：

- 若模板复杂度固定且误差平方可和，密集尺度正交成立；
- 若复杂度无界或截断误差不可和，则转入 Complexity-Escape/LSMP/FCT，而不是留在 DSO-C。

下一步最优专攻是 Complexity-Escape：证明复杂度无界逃逸必触发 FCT 或 LSMP 小质量逃逸。
