# RPL 证明路线修正：D 不应要求单调

## 发现

审计 `D=E²-L²/20` 的递推恒等式：

```text
D(S∪A)-D(S) = [E(A)-L(A)^2/20] - L(S)L(A)/10.
```

即使新壳自身缺陷非负，旧-新质量交叉项也可能使总 D 下降。因此 `RPL-stable` 不能表述为 `D_j>=D_{j-1}`。

## 正确方向

stable 层应证明的是：

1. 新壳自身具有非负缺陷；
2. 若总 D 下降，则下降量完全由旧质量与新质量交叉解释；
3. 这种交叉下降必须伴随总质量 L 增加；
4. 总质量 L 受 light/highmass 容量上界约束，因此不能无限累积。

换言之，递归 Lyapunov 函数应是二维资源对：

```text
Phi_j = (L_j, D_j)
```

而不是单个 D。坏结构若通过交叉项降低 D，必须消耗 L 容量；若不消耗 L，则 D 不会下降。

## 修正后的三择

1. **stable-capacity**：新增壳满足 `d(A)>=0`，且 `D` 的负增量由 `L` 增量支付。
2. **jump-absorb**：层跳变导致坏度下降或进入有限证书窗口。
3. **backflow**：若既无容量消耗也无跳变吸收，则坏结构回传到旧尺度。

## 待证核心不等式

需要证明容量支付型不等式：

```text
-D^-_j <= L_{j-1} ΔL_j / 10
```

并结合全局容量界：

```text
L_j <= L_max < threshold
```

推出坏结构不能无限传递。
