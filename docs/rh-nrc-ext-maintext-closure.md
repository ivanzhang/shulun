# NRC/EXT 主文闭合链：非共振倒数完成和

本文把 RH 反例矛盾场中 PPI 非共振输出所需的 `NRC/EXT` 接口写成可直接并入主文的闭合链。核心事实是标准完成法与素数模 Kloosterman--Weil 界；非共振失败不调用估计，而是进入 `FCT`。因此 `NRC/EXT` 不再作为独立黑箱，只剩外部定理 `EXT-KL` 的精确书目页码编辑义务。

本文不宣称 RH 已证明；它只闭合 PPI 非共振分支的解析估计接口。

## 1. 允许窗口的正规展开

允许窗口 `g` 由有限复杂度对象生成：区间或平滑区间权、小模数同余类、祖先倒数相位环带、Bohr 切片及其有限交并差。记复杂度为 `K(g)`。

经有限 Fourier/Vaaler 展开、同余类切分与平滑替换，`g` 可写为

`g(d)=Σ_ν c_ν 1_{d in I_ν}1_{d≡a_ν mod q_ν} e_P(β_ν d^{-1}) + Err`,

其中

`Σ_ν |c_ν| <= K(g)log^C K(g)`, `#ν<=K(g)log^C K(g)`。

这里每个 `β_ν` 是祖先频率的有界整数线性组合。误差 `Err` 由 Vaaler 尾项和边界平滑控制，若该误差承载主偏差，则按 PPI 输出链进入 `CE/LSMP/LV/NRC`，不属于本文的非共振主估计。

## 2. 非共振条件与 FCT 出口

给定当前频率 `ξ` 与祖先频率集合 `Ξ(g)`，定义低频 span

`Span_H(Ξ)= {-Σ_i m_iξ_i mod P: |m_i|<=H, Σ_i |m_i|<=H}`。

称 `ξ` 对 `g` 非共振，若

`ξ notin Span_H(Ξ(g))`。

若该条件失败，则 `ξ` 被祖先短深度频率解释，按定义进入 `FCT_seed`。该分支由 FCT Noether 下降与无循环闭包文档接收。因此 NRC 只处理非共振情形。

## 3. 单原子完成法

考虑一个展开原子

`S=Σ_{d in I, d≡a mod q} e_P((ξ+β)d^{-1})`。

非共振保证 `α=ξ+β` 在 `F_P` 中非零。因 `q<P` 且 `(q,P)=1`，令 `d=a+qn` 是模 `P` 上的仿射变量替换。区间和可由完成法写为

`S=P^{-1}Σ_{h mod P} \widehat{1_I}(h) Σ_{t in F_P^*} e_P(αt^{-1}+ht)`。

内层完整和是素数模上的 Kloosterman 型和。由 `EXT-KL`，当 `(α,h)` 不全为零时，

`|Σ_{t in F_P^*} e_P(αt^{-1}+ht)| <= 2P^{1/2}`。

Fourier 系数满足 `Σ_h |\widehat{1_I}(h)| <= CPlog P`，故

`|S| <= C P^{1/2}log P`。

平滑区间权同理，因其 Fourier 系数总变差不超过固定对数损失。

## 4. NRC 主估计

对所有展开原子求和并吸收复杂度损失，得到

`|Σ_d g(d)e_P(ξd^{-1})| <= C_K K(g) P^{1/2} log^{A_K}P`。

保守常数可沿用常数包：

`C_weil_completion=11664`, `A_weil_completion_log=4`，

额外的 `log^C K(g)` 并入 `K_eff`。

**Theorem NRC-Maintext-Closure。** 若允许窗口 `g` 对当前频率 `ξ` 非共振，则上述 NRC 主估计成立。若非共振条件失败，则该点不由 NRC 处理，而进入 `FCT_seed`。因此 NRC 分支不存在未命名失败出口。

**证明。** 第 1 节给有限原子展开。第 2 节保证每个原子的总频率 `α=ξ+β_ν` 非零；否则 `ξ` 属于祖先低频 span，已进入 FCT。第 3 节对单原子应用完成法和 `EXT-KL`。第 4 节对原子求和并吸收对数复杂度。证毕。

## 5. 与 PPI 输出链的拼接

在 `docs/rh-ppi-terminal-output-maintext-chain.md` 中，PPI 非共振频率包进入 `NRC/EXT`。本文说明：

1. 非共振成功时，倒数指数和被 `P^{1/2}log^A P` 控制；
2. 若该上界不足以解释 PPI 主偏差，则非共振分支被排除；
3. 若非共振失败，则不是估计失败，而是 `FCT_seed`；
4. 若窗口复杂度或尾项失控，则按 PPI 输出链进入 `CE/LSMP/LV`。

因此，PPI 的非共振输出已经被完全归入 `EXT-KL` 标准外部定理与 FCT/CE/LSMP/LV 命名终端。
