# MFAC 无条件 W1→W2 对数节省路线设计

**日期：**2026-08-18
**状态：**已确认，待实施计划

## 目标

对固定的截断 Möbius--log 系数族，建立或严格缩小下面无条件 W1 缺口：存在绝对
常数 `C > 0` 与 `D0 >= 3`，使每个整数 `D >= D0` 都满足

```text
a_D(n) = -mu(n) log(n) (1 - log(n) / log(D))  其中 2 <= n < D
M_D    = sum_{2 <= n < D} a_D(n)^2 / n
E_D    = sum_{2 <= r < D} phi(r) (sum_{r | n} a_D(n) / n)^2

E_D <= C M_D / log(D)
```

常数 `C` 和阈值 `D0` 不得依赖截断参数 `D`。本轮只处理从该系数族的有限恒等式
到统一 `L2` 上界的 W1 层；它不把 W1 自动传递为 W2、Chebyshev 能量界、Mellin
收缩、零自由区或 RH。

## 允许与禁止输入

允许使用：

- Möbius 反演、Dirichlet 卷积、互素分解与 Euler--phi 恒等式；
- 初等估计及经典无条件筛法；
- 对每个有限截断可逐步核验的代数恒等式。

禁止使用：

- Mertens 型界、PNT、RH、零点信息、显式公式与 Mellin 收缩；
- 任何形式的 Chebyshev 目标误差、待证 W1/W2 结论或由它们导出的界；
- 把有限数值、浮点剖面、随机模型或经验常数当作统一解析上界。

每个候选引理都必须列出量词、常数依赖和全部上游输入。若其证明需要禁止输入，
审计状态必须为 `open`，不得以“候选证明”或“数值支持”提升主命题状态。

## 方案比较

### A. 精确卷积--双线性余项（主线）

使用精确恒等式

```text
mu * Lambda = -mu(n) log(n)
```

来展开未加窗的对数系数；随后通过有限 Abel 求和处理线性窗口
`1 - log(n) / log(D)`。窗口是逐点乘法，不得错误地当作 Dirichlet 卷积因子。

把 `E_D` 的 Euler--phi 平方和重新组织为可识别的主项、边界项和双线性余项。只有
主项能够由精确代数抵消时，才可获得对数节省；双线性余项必须被单独表述为新的无条件
引理并接受量词审计。

**优点：** 直接利用目标系数中的 `mu log` 结构，所有等式可有限验证。
**风险：** 余项可能仍要求未有的 Möbius 相关消去；此时路线应输出障碍而非 RH 声称。

### B. 筛法非负基线（护栏）

以 Selberg/大筛型非负权控制互素限制尾和，构造一个明确的无条件基线。该基线的
作用是量化仅靠绝对值或正权平均能达到的尺度，并与主线所需的 `1/log(D)` 节省比较。

**优点：** 输入透明，可作为任何候选引理的上界压力测试。
**风险：** 非负化可能丢失 Möbius 符号，无法产生所需对数节省。

### C. Type-I/II 分段定位（反循环诊断）

按 `r` 与 `n/r` 的大小做双曲线分解，将主线余项划为短、长与平衡三区。短区和长区
只使用允许工具；平衡区必须收敛成一个显式的双线性余项命题。该命题若与 Mertens
型消去、零点信息或目标结论等价或依赖它们，即判为不可用。

**优点：** 把真正未解决的解析强度定位为单一可检验命题。
**风险：** 它可能证明当前工具不足，而不直接给出上界。

## 采用架构

采用 A 为主线、B 为基线、C 为障碍定位，实施时新增一个独立审计模块，不修改既有
`mobius_tail_l2`、条件 Mertens 或 W1→W2 合同模块的结论。

模块分为四层：

1. **精确算术层：** 用 `Fraction` 复核 `mu * Lambda = -mu log`、窗口 Abel 分解及
   Euler--phi 能量重排；这些测试只断言有限恒等式。
2. **引理合同层：** 为主项消去、筛法基线、短/长区估计、平衡余项分别登记来源、
   量词、统一变量与常数依赖；拒绝禁止输入和循环引用。
3. **尺度诊断层：** 对二次幂与非二次幂截断扫描归一化比率，只定位候选最难区间，
   并明确标记为 `numerical_only`。
4. **证书层：** 同时写出有限恒等式残差、每个引理的证明状态和 W1 状态。除非全部
   无条件引理均有可审计证明包，否则固定输出 `w1_l2_upper_status=open` 与
   `rh_proved=false`。

## 验收条件

- 对所有有限输入，卷积、窗口分解和 Euler--phi 重排使用精确有理数并报告零残差。
- 合同测试拒绝 Mertens、PNT、RH、零点、显式公式、Mellin、Chebyshev 目标和任何
  已闭合 W1/W2 声称作为输入。
- 基线报告其实际可证尺度；若不能证明 `1/log(D)` 节省，必须明确报告缺口。
- 平衡区余项以完整量词、常数依赖和可复现有限代理模型登记，不得使用布尔“已证明”
  掩盖缺失推导。
- 默认 JSON/Markdown 证书永远区分 `verified_finite`、`baseline_bound_registered`、
  `open` 与 `unproved`。
- 全部新旧测试通过，但测试通过不得单独改变任何解析状态或 RH 状态。
