# MFAC RH 闭环门槛与攻击面设计

**日期：** 2026-08-11

**状态：** 已批准，待用户审阅书面规格
**北极星：** 仅在每个独立门槛被无条件证明后，才允许从 MFAC 的算术能量进入 RH 相关解析结论。

## 1. 目的与范围

本设计把 MFAC 的后续研究拆为可独立验证、可独立证伪的四条工作线：

\[
\text{结构化强制性}
\Longrightarrow \text{Chebyshev 能量桥}
\Longrightarrow \text{dyadic 可和性}
\Longrightarrow \text{Mellin 无零半平面}
\Longrightarrow \text{RH}.
\]

每条箭头都是独立定理义务。有限矩阵扫描、经验趋势、拟合常数或数值特征值都不得替代其中任一箭头。

本设计不声称已证明统一强制性、Chebyshev 误差界、Mellin 收缩、零点排除或 RH。

## 2. 已知边界与负面控制

中心化整除协方差的有限核为

\[
C_X(d,e)=\left\lfloor\frac{X}{[d,e]}\right\rfloor-
\frac{\lfloor X/d\rfloor\lfloor X/e\rfloor}{X}.
\]

其二次型是中心化整除负载的精确有限平方和。该恒等式只给出有限尺度信息。

后续首先审计极限核的朴素维度无关谱隙（UDC）。平方自由 Möbius 见证及 primorial 序列用于测试该命题是否退化。若该见证给出 Rayleigh 比趋零，只能记录“该特定 UDC 被否定”；不得把负面结论扩大为“所有加权或受限强制性均不可能”。

## 3. 工作线与证明门槛

### W0：反例与归一化筛选

**目标：** 冻结已失败的朴素强制性主张，并定义后续候选必须通过的负面测试。

**输入：** `K_X`、极限核 `K_infinity`、逐项取整误差界、平方自由 Möbius 见证。

**必须证明或证书化：**

1. `K_X-K_infinity` 的误差界只由取整恒等式导出，不读取 Chebyshev、Mellin、零点或 RH 数据。
2. 每个反例证书包含有限索引范围、精确/可验证 Rayleigh 比、见证支持和归一化定义。
3. primorial 见证若令某对象的比值趋零，则该对象不得再被用作正向统一谱隙假设。

**停止条件：** 若一个候选权重仅以人为排除见证获得下界、却不能容纳 W1 所需的截断系数，则淘汰该候选。

### W1：结构化强制性

**目标：** 找到允许目标截断系数进入、且避开已证退化方向的精确二次型不等式。

**候选命题模板：** 对明确的系数空间 `A_X`、权重 `W_X(d)` 和常数 `c>0`，证明

\[
\sum_{n\le X}\left|\sum_{d\le D}a_d\left(1_{d\mid n}-\frac1d\right)\right|^2
\ge cX\sum_{d\le D}W_X(d)|a_d|^2-R_X(a),\qquad a\in A_X.
\]

每个候选必须显式给出 `A_X`、`D`、`W_X`、`c`、余项 `R_X` 及其一致性范围。

**攻击面：**

- 平方自由、primorial、单素数层和高约数复合数见证；
- 随尺度消失的常数；
- 仅对过小子空间成立的伪强制性；
- 不能同时支持 W2 目标系数的权重选择。

**通过标准：** 所有常数与损失在所需 dyadic 范围内可追踪；正向结论不得来自有限特征值外推。

### W2：非循环 Chebyshev 能量桥

**目标：** 从不含目标误差输入的确定性恒等式，导出对 `psi(X)-X` 或等价明确误差量的上界。

**独立性合同：** 目标系数、截断点、权重和余项不得读取下列任一项：

```text
psi(X)-X
Chebyshev_error
Mellin
zeta_zero
explicit_formula
RH
```

**必须交付：**

1. 一条精确的卷积/截断恒等式，明确主项和每个余项；
2. 将主项嵌入 W1 能量的映射；
3. 完全独立的余项界及常数来源；
4. 一个可机器审计的 `uses` 合同和反例测试。

**失败判据：** 若桥接估计在代数重排中使用待估 Chebyshev 误差，或以 Mellin/零点输入控制余项，则标记为循环并停止升级。

### W3：dyadic 到 Mellin 的解析闭合

**目标：** 将 W2 的全尺度误差估计转化为足以支持 Mellin 积分的可和性结论。

**预注册条件：** 先明确需要的误差形式、指数、对数损失和一致常数，再反向约束 W1/W2。单个尺度、稀疏样本或未求和的平均界均不够。

**Mellin 门槛：**

1. 给出实际积分恒等式及其原始收敛域；
2. 用 W2 的全尺度界证明所需半平面的绝对/局部一致收敛；
3. 明确延拓对象与极点，导出目标无零半平面；
4. 只有前述步骤完成后，才调用函数方程与对称性说明 RH 的闭合方式。

**失败判据：** 若只能得到 `Re(s)>sigma` 且 `sigma>1/2`，则只记录相应零自由半平面，不把它写成 RH。

## 4. 统一防循环与状态协议

每项声明必须带有以下状态之一：

```text
proved
conditional
refuted
numerical_only
```

每个正向定理还必须记录：

- 允许输入与禁止输入；
- 参数范围与所有常数；
- 是否使用有限扫描；
- 是否依赖未证明命题；
- 连接到下一工作线所需的额外条件。

禁止将 `conditional`、`numerical_only` 或有限证书升级为 `proved`。

## 5. 推荐执行顺序

1. **先完成 W0：** 证书化朴素 UDC 的失败及其精确范围。
2. **并行准备 W2/W3 规格：** 不实现任何正向结论，只预注册需要的系数合同和解析阈值。
3. **在 W0 过滤后执行 W1：** 只保留兼容 W2 目标系数的候选三元组 `(A_X, W_X, R_X)`。
4. **执行 W2：** 优先攻克无目标依赖的恒等式与余项预算，再使用 W1。
5. **最后执行 W3：** 仅消费已证明的全尺度输入，并输出最强实际无零半平面。

## 6. 验收标准

- W0 对朴素 UDC 给出可复算的正面证明或明确反例，且范围不外推。
- W1 的任何正向不等式都通过四类退化见证，并兼容 W2 系数合同。
- W2 的桥接证明通过禁止依赖审计，不读取待估误差或解析目标。
- W3 明确给出 dyadic 求和与 Mellin 收敛的完整逻辑，不跳过指数和对数损失。
- 任一路未闭合时，证书与文档都保持 `rh_proved=false`。

## 7. 非目标

- 不以有限谱正值、实验趋势或拟合常数宣称 RH。
- 不把 UDC 的反例误述为所有 MFAC 路线都失败。
- 不在 W2 之前调用显式公式、零点数据或 Mellin 输入来制造误差界。
- 不在 W3 之前宣称无零半平面或临界线结论。

## 使用示例

后续 W0 审计的预期命令形式：

```bash
python3 experiments/prime_matrix_mfac_uniform_centered_divisibility_coercivity_audit.py
```

该命令仅输出极限核、误差界和见证证书；不会输出 Chebyshev、Mellin 或 RH 的正向结论。
