# OV2-AAI：允许锚语义无条件化定理

本文把 `docs/rh-ov2-admissible-anchor-interface.md` 中的 AAI 接口抽成无条件代数定理。AAI 的内容本质上是定义与逐点整除事实：允许斜线锚必是素因子锚；真实最小锚账本唯一；overlap 必须定义为允许账本相对唯一账本的冗余；任一冗余点给出双锚正规形。本文不处理 PPI 相位推送和 MLC 主层容量，它们仍是后续无条件化对象。

## 1. 真实唯一锚账本

固定筛层 `z`。对 `z`-粗合数 `n`，即 `P^-(n)>z`，定义真实最小锚

`a_min(n)=P^-(n)`。

对 dyadic 层 `Q<q<=2Q`，定义

`ρ_Q^{min}(n)=1_{Q<a_min(n)<=2Q}`。

**Lemma AAI-U1（唯一锚）。** 对每个 `z`-粗合数 `n`，有

`Σ_Q ρ_Q^{min}(n)=1`，

其中 `Q` 遍历包含 `a_min(n)` 的 dyadic 分割；对非 `z`-粗合数该和为 `0`。

**证明。** 每个整数至多有一个最小素因子；dyadic 分割中该素因子落入唯一一层。证毕。

## 2. 允许锚账本

令 `A(n)` 为给定方阵/CRT 覆盖模型允许解释 `n` 的根基素数集合。AAI 只要求以下结构公理：

`q∈A(n) => q prime 且 q|n`。

方阵圆柱斜线模型满足该公理，因为“由根基素数 `q` 的斜线覆盖”代数上就是 `n≡0 mod q`。额外行列相位条件只会减少 `A(n)`，不会增加允许锚。

定义

`ρ_Q^{allow}(n)=#{q∈A(n): Q<q<=2Q}`。

## 3. overlap 的正确逐点定义

定义层扣重

`o_Q(n)=max(ρ_Q^{allow}(n)-ρ_Q^{min}(n),0)`。

总扣重为

`o(n)=Σ_Q o_Q(n)`。

**Lemma AAI-U2（真实账本无 overlap）。** 若 `A(n)={a_min(n)}` 且无额外允许锚，则 `o(n)=0`。

**证明。** 此时每层允许重数与真实最小锚重数一致，逐层差为零。证毕。

这说明 overlap 是“允许覆盖解释的冗余”，不是真实 Buchstab 最小锚账本自身的重复。

## 4. 整除上包络单调性

定义整除上包络重数

`ρ_Q^{div}(n)=#{q prime: Q<q<=2Q, q|n}`。

由 `A(n)⊂{q:q|n}`，逐点有

`ρ_Q^{allow}(n)<=ρ_Q^{div}(n)`。

**Lemma AAI-U3（上包络单调）。** 逐点有

`o_Q^{allow}(n)<=o_Q^{div}(n):=max(ρ_Q^{div}(n)-ρ_Q^{min}(n),0)`。

因此任何以非负权求和的 overlap 能量或总量都由整除上包络控制。

**证明。** 函数 `x↦max(x-ρ_Q^{min}(n),0)` 单调递增，代入 `ρ_Q^{allow}<=ρ_Q^{div}` 即得。证毕。

## 5. 双锚正规形

**Lemma AAI-U4（同层双锚正规形）。** 若 `ρ_Q^{allow}(n)>=2`，则存在不同素数 `q_1,q_2∈(Q,2Q]` 与整数 `r>=1`，使

`n=q_1q_2r`。

若 `n≈X`，则 `r≈X/Q^2`。

**证明。** 两个不同允许锚都是整除 `n` 的不同素数，故其乘积整除 `n`。写 `r=n/(q_1q_2)`。若 `n≈X` 且 `q_i≈Q`，则 `r≈X/Q^2`。证毕。

**Lemma AAI-U5（跨层双锚正规形）。** 若 `o_Q(n)>0` 但 `ρ_Q^{allow}(n)=1`，则允许锚所在层不是最小锚所在层。设 `q_0=P^-(n)`，`q_1∈A(n)∩(Q,2Q]`，则

`n=q_0q_1r`。

**证明。** `o_Q(n)>0` 且本层只有一个允许锚，说明本层真实最小锚指示为 `0`，否则会被抵消。于是 `q_0` 在别层，且 `q_0|n`、`q_1|n`。若 `q_0≠q_1`，乘积整除 `n`。若相等则它会在同层，矛盾。证毕。

## 6. AAI 无条件主定理

**Theorem AAI-Unconditional（允许锚语义无条件化）。** 对任何满足 `q∈A(n)=>q|n` 的允许覆盖模型，以下结论无条件成立：

1. 真实最小锚账本唯一，不产生 overlap；
2. overlap 必须定义为允许锚相对真实最小锚的逐层正部扣重；
3. 允许 overlap 逐点受整除上包络 overlap 控制；
4. 任一正 overlap 点产生同层或跨层双锚正规形 `n=q_1q_2r`；
5. 方阵/圆柱斜线覆盖模型是该整除上包络的子模型。

**证明。** 第 1 项为 AAI-U1；第 2 项为定义与 AAI-U2；第 3 项为 AAI-U3；第 4 项为 AAI-U4 与 AAI-U5；第 5 项来自斜线覆盖的整除必要条件 `n≡0 mod q`。证毕。

## 7. 与 PC3-OV2 的接口边界

AAI 已无条件化，但它只给出 overlap 的代数语义和双锚正规形。后续仍需：

1. **PPI**：把 `n=q_1q_2r` 的双锚偏差推送到倒数相位/斜线窗口；
2. **MLC**：把大 overlap 能量定位到主层并排除尾层、低体积与不可检测均匀质量；
3. **D 组终端**：把 PPI/MLC 输出接到 OMR/NRC/FCT/LSMP。

因此 PC3-OV2 的第三项无条件化已完成第一块 AAI；下一步应继续攻 PPI。
