# GEE-NRC 逐入口参数核验表

本文承接 `docs/rh-gee-nrc-nonresonant-exit-bound.md`，专门核验 `GEE-NRC` 从“条件参数闭合”升级为“逐入口可审查闭合”所需的参数。核心不是重新证明倒数完成和，而是检查每个入口是否满足以下二选一条件：

- **Sqrt-Sum 条件：** `K_eff,total(X) P_max(X)^{1/2} log^A X=o(Δ)`；
- **PPI-Dominance 条件：** PPI/DSO 主偏差下界严格大于对应 NRC 平方根完成和上界；否则该层必须转入 `LV/LSMP/SC/CE/FCT`，不能停留在 NRC。

这里 `Δ=X^{β-o(1)}` 是离线零点反例场强度，`β>1/2`。

## 1. 统一参数字典

| 符号 | 含义 | 审查要求 |
|---|---|---|
| `P` | 当前 CRT/局部投影工作素模 | 必须满足 `P<=P_max(X)` |
| `K_eff` | 单个窗口的 Fourier/Vaaler/同余切分复杂度 | 固定复杂度时允许 `log^C X` |
| `K_eff,total` | 同一入口内所有非共振包复杂度总和 | 必须逐入口证明不含幂级自由度 |
| `W_Q` | PPI 主层零频/有效容量 | 主层要求 `W_Q^{1/2}>=K_eff log^{C_0}X X^{-ε/4}` |
| `Bias_PPI` | PPI 可检测偏差 | 应至少达到 `c X^{1/2+ε/2}W_Q^{1/2}/log^C X` |
| `NRC(P,K)` | 非共振完成和上界 | `<= C K_eff P^{1/2}log^A P` |

因此最危险的不是单包 `P^{1/2}`，而是入口展开后是否偷偷引入了 `Q`、`R`、窗口数或投影数的幂级总和。

## 2. 入口表

| 入口 | `P_max` | `K_eff,total` | 可用下界/分流 | 当前判定 |
|---|---:|---:|---|---|
| C4-PPI 单变量倒数包 | `<=X` | `log^{C_1}X`，若固定 dyadic 主层与有限窗口 | `Bias_PPI >= cX^{1/2+ε/2}W_Q^{1/2}/log^C X`；主层门槛给 `>>X^{1/2}log^C X` | **可闭合，条件是窗口族固定复杂度已由 PPI-U2/U3 给出** |
| C4-PPI 双变量倒数包 | `<=X` | `log^{C_2}X`，前提是完成和已经对一个变量完成，另一个变量不作平凡幂级求和 | 同上；若双变量拆成 `Q` 个单变量包，则失败并转 `CE/LSMP/SC` | **半闭合：需显式写明双变量完成策略，禁止 `Q·P^{1/2}` 逃逸** |
| DSO-E 非共振包 | `<=X` | `log^{C_3}X` 或由 square-function 总能量控制 | DSO 若承载固定比例异常，必须反馈 PI；非共振残差满足平方函数正交和 | **条件闭合：依赖 DSO/PI square-function 桥接的无幂损失版本** |
| Tail/RKS 附录 NRC | `<=X` | `log^{C_4}X`，若尾层体积已低于 `Δ/log^B X` | 低体积进入 `LV`；非低体积回主层 PPI | **可分流闭合：不应作为独立 NRC 主入口** |

## 3. 单变量 PPI 入口证明

在固定 dyadic 主层 `(Q,R)`、固定投影方向与固定窗口复杂度下，PPI-U3 将窗口偏差写为有限个

`Σ_{q~Q} w(q)e_P(aq^{-1})`

以及常数个同类项。非共振时 NRC 给

`|Σ_{q~Q} w(q)e_P(aq^{-1})| <= C P^{1/2}log^A P`。

由于 `P<=X`，所有窗口、频率和 dyadic 层的总数为 `log^{C_1}X`，故单变量 NRC 总贡献为

`Load_1(NRC;X) <= X^{1/2}log^{C_1+A}X=o(X^{β-o(1)})=o(Δ)`。

所以单变量 PPI 非共振入口在 `β>1/2` 下闭合。

## 4. 双变量 PPI 入口的真正硬点

双变量项形式为

`Σ_{q_1,q_2~Q} w(q_1,q_2)e_P(aq_1^{-1}+bq_2^{-1})`。

若权重可分离或经 Cauchy/完成法直接得到二维平方根型

`<= C P^{1/2}Q^{o(1)}` 或 `<= C P^{1/2}log^C X`，则它与单变量入口同样闭合。

但若证明只允许固定 `q_2` 后对 `q_1` 应用单变量 NRC，再平凡求和，则得到

`<= Q P^{1/2}log^C X`，

该量在 `Q` 为幂级时可能远大于 `Δ`，不能闭合。由此得到审稿级硬要求：

**Requirement NRC-2D.** 双变量 PPI 入口必须证明一个非平凡双变量完成和/乘法能量压缩界，使总复杂度仍为多对数；否则该入口不能标记为 GEE-NRC 闭合。

这也是当前 GEE-NRC 最大剩余硬点。

## 5. DSO-E 入口的平方函数闭合条件

DSO-E 的非共振包不是单个 PPI 窗口，而是新增 CRT/Bohr 频率包的 square-function 残差。若已证明

`Σ_ω |S_ω|^2 <= log^C X · P_max(X)`

且包数/投影数由允许投影族控制为 `log^C X`，则 Cauchy 给

`Σ_ω |S_ω| <= log^C X · P_max(X)^{1/2}`，

从而 `o(Δ)`。若 square-function 到允许投影族桥接只给出定性分流，而无上述二次总量上界，则 DSO-E 只能保持条件闭合。因此需要在 `docs/rh-dso-pi-squarefunction-bridge-audit.md` 中补出无幂损失 Parseval/Carleson 常数版，才能完全解除该入口。

## 6. Tail/RKS 入口分流

Tail/RKS 层若满足低体积阈值

`Vol_eff log^C X <= Δ/log^B X`，

则已经由 GEE-LV 吸收。若不满足低体积阈值，它不是尾层，而回到主层 PPI/MLC 账本。因此 Tail/RKS 不应作为需要独立大规模求和的 NRC 入口；它的 NRC 出现只是在主层 Fourier 展开后的一部分，已由前两类入口覆盖。

## 7. 当前结论

`GEE-NRC` 现在可以精确改写为：

1. 单变量 PPI 非共振入口闭合；
2. Tail/RKS NRC 入口经 `LV` 或主层回流分流闭合；
3. DSO-E 入口闭合取决于 square-function 桥接是否给出无幂损失二次总量；
4. 双变量 PPI 入口闭合取决于 `Requirement NRC-2D`。

因此，下一步最小硬点不是继续扩大出口表，而是专攻：

- `NRC-2D`：双变量倒数非共振完成和的无幂损失压缩；
- `DSO-SF`：DSO 非共振包的 Parseval/Carleson 二次总量上界。

只有这两个入口补齐后，`GEE-NRC` 才能从“条件参数闭合”升级为“逐入口无条件闭合”。
