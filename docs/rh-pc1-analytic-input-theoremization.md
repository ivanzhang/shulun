# PC1：解析输入无条件化定理化

本文把 `docs/rh-pc1-offline-zero-smooth-window.md` 中的解析输入拆成可引用的标准定理包：平滑显式公式、权函数非湮灭、Landau--Ingham 振荡，以及从 Chebyshev 权到素数窗口的转换。本文仍不证明 RH；它只把“离线零点推出平滑素数异常”这一环节从条件化口径提升为标准解析数论输入。

## 1. 平滑显式公式

取 `W∈C_c^∞((0,∞))`，非零且实值。定义

`Ψ_W(X)=Σ_{n>=1} Λ(n)W(n/X)`，

Mellin 变换

`\widehat W(s)=∫_0^∞ W(t)t^{s-1}dt`。

**Theorem PC1-A（平滑显式公式）。** 对任意固定 `W` 与任意 `A>0`，有

`Ψ_W(X)=X\widehat W(1)-Σ_ρ X^ρ\widehat W(ρ)+E_W(X)`，

其中和过 `ζ(s)` 的非平凡零点；平凡零点、截线积分和端点项并入 `E_W(X)`，并满足在任意有限垂直截断后可取 `E_W(X)=O_A(X^{-A})+O_W(1)`，完整零点和按平滑权的快速衰减绝对/条件收敛。

**证明。** Mellin 反演给

`Ψ_W(X)=1/(2πi)∫_{(c)} -ζ'(s)/ζ(s) X^s\widehat W(s) ds`, `c>1`。

把积分线左移，穿过 `s=1` 的极点、非平凡零点和平凡零点。`W` 光滑紧支撑保证 `\widehat W(s)` 在垂直方向快速衰减，水平边积分消失，左侧新线与平凡零点贡献为低阶项。残数计算给主项与零点项。证毕。

## 2. 权函数非湮灭

**Lemma PC1-B（可见权选择）。** 给定任意零点 `ρ_0`，存在非负 `C_c^∞((0,∞))` 权函数 `W`，使 `\widehat W(ρ_0)≠0`。

**证明。** 若对所有非负光滑紧支撑 `W` 都有 `\widehat W(ρ_0)=0`，则分布 `t^{ρ_0-1}` 对所有测试函数为零，这不可能。更具体地，取一小邻域内的 bump `W_u(t)=W_0(e^{-u}t)`，则 `\widehat W_u(ρ_0)=e^{uρ_0}\widehat W_0(ρ_0)`；选取 `W_0` 使积分不为零即可。证毕。

## 3. Landau--Ingham 振荡输入

设 `β>1/2` 是一个可见离线零点实部，或离线零点实部上确界的逼近值。取 `ρ_0=β+iγ` 与 `\widehat W(ρ_0)≠0`。

**Theorem PC1-C（离线零点产生平滑大振荡）。** 若 `ζ(s)` 有零点 `ρ_0=β+iγ`, `β>1/2`，则存在无穷多 `X_j` 与符号 `σ∈{+1,-1}`，使

`σ(Ψ_W(X_j)-X_j\widehat W(1)) >= c X_j^{β-o(1)}`。

若 `β` 是孤立极大实部，则可把 `X^{β-o(1)}` 写成 `X^β` 乘固定正常数；一般情形保留 `o(1)` 以吸收同实部多零点和逼近上确界。

**证明。** 显式公式中 `ρ_0` 与共轭零点给出主振荡

`-2X^β Re(e^{iγ log X}\widehat W(ρ_0))`。

若同一实部上有有限个可见零点，则主项是非零三角多项式，不能在所有大 `log X` 上为零，故有无穷相位子列取得固定比例的正或负值。若同一边界存在局部有限零点族或只取实部上确界的逼近零点，使用 Landau--Ingham 原理：若误差在所有大尺度均为 `o(X^{β-o(1)})`，则 Mellin/Laplace 变换可越过相应奇点解析延拓，矛盾。因此存在所述大振荡子列。证毕。

## 4. 素数幂与 Chebyshev 权去除

`Λ(n)` 中素数幂项满足

`Σ_{k>=2,p^k≈X} log p · |W(p^k/X)| << X^{1/2}log^C X`。

当 `β>1/2` 时，该项为 `o(X^{β-o(1)})`。于是平滑 Chebyshev 异常可转为素数 Chebyshev 权异常：

`Σ_p (log p)W(p/X)-X\widehat W(1) = ±X^{β-o(1)}`。

在支撑 `[X/2,2X]` 上，`log p=log X+O(1)`。若需要无权素数计数，可除以 `log X`，或把窗口细分为 `log^C X` 个 multiplicative 子窗口并用 pigeonhole，得到无权异常仍为 `X^{β-o(1)}`。

## 5. PC1 主命题

**Theorem PC1-Analytic-Input（离线零点到平滑素数异常，无条件解析输入）。** 若 `ζ(s)` 存在离线零点 `β>1/2`，则存在平滑窗口、无穷尺度 `X_j` 与符号 `σ`，使素数窗口异常满足

`σ(P_z(X_j)-P_z^0(X_j)) >= X_j^{β-o(1)}`，

其中可使用 Chebyshev 权版本或无权版本；固定对数损失并入 `X^{o(1)}`。

**证明。** 由 PC1-B 选择不湮灭该零点的平滑权。PC1-A 给显式公式，PC1-C 给无穷多尺度的大振荡。素数幂项由第 4 节低阶吸收。Chebyshev 权到无权版本的转换只损失固定对数因子。因此得到结论。证毕。
