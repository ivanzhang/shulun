# DGap 主文三接口链：盒重叠、投影正交化与低维抽取

本文把 RH 反例矛盾场中过密对偶分支的 `DGap` 接口合成为一条可并入主文的闭合链。它处理从对偶缺口压缩 `DGap_z>=cΔ` 到已命名终端事件的全过程：盒有限重叠、投影正交化、低维频率抽取。目标是排除 `DGap` 作为第七种未命名逃逸通道。

本文不宣称 RH 已证明；它闭合的是 DGap 内部三接口。尾项平方可和已主文化于 `docs/rh-fourier-vaaler-tail-maintext-chain.md`；`LV/LSMP/CE` 外部吸收和精确外部引用仍需继续主文化。

## 1. 过密入口与 DGap 分支

过密分支给出

`(ACC_z^0-ACC_z)+(O_z-O_z^0)+DGap_z >= Δ-o(Δ)`。

因此至少发生 `ACC` 负向同步、overlap 过剩、`DGap` 压缩或边界/基线失败。前两者分别进入 `A` 与 `OV2/D`；边界/基线失败进入 `LV/CE/CapacityFail`。本文处理唯一剩余的主通道：

`DGap_z >= cΔ`。

## 2. 第一接口：盒有限重叠

将 DGap 场局部化到固定复杂度盒族 `𝓑`。每个盒由物理窗、dyadic 锚层、CRT/Bohr 相位窗和平滑边界组成。固定复杂度给点态有限重叠

`Σ_{B in 𝓑} 1_B(n) <= log^C X`。

若有限重叠失败，则原因只能是：物理低体积或端点异常、dyadic 层无限细化、相位模板复杂度逃逸。对应出口为

`LV/SC`, `CE/LSMP`, `CE/FCT/LSMP`。

因此盒有限重叠失败不是新 DGap 分支。

## 3. Frame 下界与常数方向剥离

对归一化盒函数

`φ_B=(1_B-E_0 1_B)/||1_B-E_0 1_B||_2`

有限重叠给 Bessel/frame 上界：

`||Σ_B c_B φ_B||_2^2 <= log^C X Σ_B |c_B|^2`。

于是对任意偏差函数 `h`，若 `V=span{φ_B}`，则

`||P_Vh||_2^2 >= log^{-C}X Σ_B |<h,φ_B>|^2`。

`<h,1_B>` 与 `<h,φ_B>` 的差异仅来自常数方向。若常数方向主导，则违反 PC2 CRT 零频基线 `C_z-C_z^0=o(Δ)` 或进入基线接口失败。故在非基线失败分支中，DGap 正质量给出投影能量下界

`||P_Vh||_2^2 >= X^{2β-1-o(1)}`。

## 4. 第二接口：逐步正交投影

空间分解不能假设天然直和。严格做法是按闭子空间逐步投影。

1. 先投影到允许投影空间 `V_PI`。若承载固定比例能量，进入 `PI`；
2. 在正交剩余中投影到低维/短簇/低体积空间 `V_low`。若承载固定比例，按类型进入 `FCT/SC/LV/LSMP`；
3. 剩余定义为 `V_err`。若承载固定比例，进入 `CE/CapacityFail`；
4. 若三者均不承载固定比例，则与第 3 节总投影能量下界矛盾。

该步骤只用 Hilbert 空间正交投影与有限 frame 上界，不依赖 PC4 终端闭合。

## 5. 第三接口：低维频率抽取

当 `V_low` 中能量不属于 `SC/LV/LSMP/CE`，且 `PI` 不可检测时，对盒模板作 Fourier/Vaaler 截断：

`ψ_B=ψ_{B,<=H}+ψ_{B,>H}`, `H=log^A X`。

若高频尾项承载固定比例能量，则进入 `CE/LSMP` 或尾项平方可和接口。非逃逸分支中，低频截断保留固定比例能量。

将低频谱分成有限频率包。若存在新增独立频率包承载固定比例能量，则由 `docs/rh-pi-dso-maintext-bridge-chain.md` 进入 `PI/DSO`。若无新增独立包，则主要谱支撑落入固定低维 CRT/Bohr 频率族 `Λ_*`，这正是 `FCT_seed` 输入，并由 `docs/rh-fct-maintext-closure-chain.md` 接收。

## 6. DGap 出口穷尽

综上，DGap 正质量只可能进入以下出口：

- 短窗或短 Bohr 原子集中：`SC`；
- 低体积盒或可求和尾层：`LV/LSMP`；
- 分散盒质量可投影检测：`PI`；
- PI 不可检测但低维谱承载：`FCT`；
- 新增独立频率包：`PI/DSO`；
- 覆盖同步或 overlap 解释：`A/OV2`；
- 盒、投影、尾项或基线接口失败：`CE/CapacityFail/LV/LSMP`。

没有第七种 DGap 内部逃逸类型。

## 7. DGap 主文三接口定理

**Theorem DGap-Maintext-Three-Interface。** 假设 PC2 零频基线、固定复杂度盒有限重叠、Fourier/Vaaler 尾项平方可和接口和已命名终端吸收口径可用。若过密分支中 `DGap_z>=cΔ`，则该异常必进入

`A/OV2/PI/FCT/SC/LV/LSMP/CE/DSO/CapacityFail`

之一。特别地，DGap 不产生新的最终逃逸通道。

**证明。** 盒有限重叠由第 2 节给固定复杂度局部化；失败已命名。第 3 节用 frame 下界、Cauchy 能量与 PC2 常数方向剥离得到总投影能量。第 4 节用逐步正交投影分配到 `V_PI,V_low,V_err`。第 5 节处理 `V_low` 的 PI 不可检测剩余：尾项进入 `CE/LSMP`，新增独立频率包进入 `PI/DSO`，无新增独立频率时进入 `FCT_seed`。这些分支与第 6 节出口表完全穷尽。证毕。

## 8. 对全局无条件化的影响

本文把 DGap 三接口合并为主文链。当前剩余最小缺口转为：

1. `LV/LSMP/CE` 外部吸收总链主文化；
3. PC1 一般 Landau--Ingham 输入与 `EXT-*` 精确引用；
4. 全文尺度、符号、权重和 `o(Δ)` 口径一致性审查。
