# D4/R5 G1 low 高分支当前状态

**状态：** `low_high_branch_requires_conditioned_high_bucket_compensation`

本轮审计把 O2 的剩余硬点进一步分解为二选一分支：

- 若 `low_sum=m1+m2+m3 <= 3/5`，则相邻 `3/2` 密度链配合严格 Fraction QP 证书已经覆盖所有近危险支撑向量。
- 若 `low_sum>3/5`，仅增强相邻链或远程 `d4/d1` 仍不足；QP 会把剩余质量转移到 `tau_33_59` 等高桶但不给它足够密度，从而形成新的松弛反例。

## 已排除的不足接口

- 仅用 `d4/d3 >= 8/5`，即使加 `low_sum>=3/5`，仍不足。
- 仅用 `d4/d1 >= 5` 或 `21/4`，仍不足。
- 把所有相邻链提高到 `8/5`，若不加入高桶条件补偿，仍不足。

## 新的最小硬点

必须证明条件化高桶补偿，而不是全域单斜率：

- 若 `tau_33_59` 非空，则其平均密度应不低于 `tau_17_32`，即 `d5>=d4`。
- 若 `heavy_short` 非空，则其平均密度应继续不低于 `tau_33_59` 或 `tau_17_32`。
- 若高桶为空，则 `low_sum>3/5` 与相邻密度链会迫使 `tau_17_32` 承担更大质量，应单独用 QP 闭合。

## 下一步

构造条件化 QP 分族：

- A 类：`n5=n6=0`，只用 `low_sum>=3/5 + d4/d3` 反解闭合阈值。
- B 类：`n5>0`，加入 `d5>=d4` 后验证。
- C 类：`n6>0`，加入 `d6>=d5` 或 `d6>=d4` 后验证。

该分族比统一加高层约束更精确，也更接近 tau 几何可证明结构。
