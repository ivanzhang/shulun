# PC4-PI：Complexity-Escape 复杂度逃逸接口

本文接续 `docs/rh-pc4-dso-template-consistency.md`。DSO-C-TC 已处理固定复杂度、平方可和误差的投影模板；本文件处理其补集：若模板复杂度随尺度增长、截断尾项不可平方求和，或尺度推进时重写旧 CRT 坐标，则该逃逸不能继续留在 DSO-C，而必须转入 FCT、LSMP 或 LV 三类终端。本文不是 RH 证明，而是把 PC4-PI 的下一个硬接口定理化；其中 CE-1 的“独立新频率近正交”仍需 DSO-E Euler 局部因子 decorrelation 支撑，不能视为已无条件闭合。

## 1. 逃逸三类型

设 `A_k` 是尺度 `k` 上由 PPI/OMR 产生的允许窗口，写成

`1_{A_k}=Main_k+Tail_k+Bd_k`,

其中 `Main_k` 是有限字符/倒数环带/Bohr 切片主项，`Tail_k` 是高频截断尾项，`Bd_k` 是尺度边界或低体积边界。

称发生 Complexity-Escape，若至少一项成立：

1. **频率复杂度逃逸**：`Main_k` 所需非主频率集合 `Ω_k` 的有效基数或生成秩无界；
2. **尾项能量逃逸**：`Σ_k ||Tail_k||_2^2=∞`，无法由 DSO-C-TC 吸收；
3. **坐标重写逃逸**：从 `G_k` 到 `G_{k+1}` 时，窗口不只是新增坐标条件，而改变旧坐标上的布尔结构，导致 martingale 差不再只落在新增正交子空间；
4. **边界体积逃逸**：`Σ_k ||Bd_k||_1` 或相应低体积账本不可吸收。

DSO-C-TC 覆盖的是上述四项都不发生的情形。

## 2. 频率复杂度逃逸推出 FCT 候选

**Lemma CE-1（无界频率复杂度到频率碰撞，条件化接口）。** 若存在密集尺度包 `𝓘`，使 `Ω_k` 的有效生成秩在 `k∈𝓘` 上无界，同时投影增量保持同向下界，并且 DSO-E 的新增 Euler 局部因子 decorrelation 对不在短深度 span 中的新频率成立，则必有一个子包满足以下二者之一：

- 频率相位在低维短深度 span 中重复闭合，触发 FCT；
- 或相互独立的新频率贡献给出正交平方和增长，违反 DSO/Carleson 容量上界。

**证明。** 把 `Ω_k` 按祖先 span 分解。若大量频率落在有限短深度 span 中，则正是 `docs/fct-tree-wfe-theoremization.md` 的 frequency-collision terminal：新频率由旧频率低维线性组合生成，形成树状闭包。若不落入短深度 span，则抽取彼此不相关的新增频率子族；此处需要 DSO-E 保证这些新增 Euler 局部因子的非主偏差平方可控。于是独立新频率的平方贡献不能无限累加，而投影增量同向下界会强迫平方和增长，二者矛盾。因此，在 DSO-E 成立的前提下，无界频率复杂度不能作为第四种非终端存在。证毕。

## 3. 尾项能量逃逸推出 LSMP 或高投影增量

**Lemma CE-2（不可和尾项到 LSMP）。** 若 `Σ_k ||Tail_k||_2^2=∞`，但不触发 FCT，且无短簇，则存在子包满足：

- 尾项质量集中在小测度原子或薄边界层上，触发 LSMP；
- 或尾项在某个可检测窗口上产生高投影增量，返回 PI-Seed/OV2 终端。

**证明。** 对 `Tail_k` 作 dyadic 层蛋糕分解。若主要 `L^2` 质量来自小测度高振幅原子，则离散 coarea 抽出有限重叠薄层族，这正是 `docs/omr-cgtp-lsmp-theoremization.md` 中 LSMP-1/LSMP-2 的输入。若质量不集中于小原子，则存在中等体积层承载同向偏差；方向筛选后得到允许窗口上的非零投影增量，接入 PI-Seed 或 OV2 的相位推送接口。若两者都不发生，则各 dyadic 层均可按固定模板截断并平方求和，反与尾项能量逃逸假设矛盾。证毕。

## 4. 坐标重写逃逸推出 LV 或 FCT

**Lemma CE-3（旧坐标重写的二分）。** 若 `A_{k+1}` 在旧 CRT 坐标上的布尔结构相对 `A_k` 发生非平凡重写，则必有以下二者之一：

- 重写只发生在少量边界/端点类上，其总量由 LV 低体积原则吸收；
- 重写在正体积旧坐标集合上反复发生，产生有限深度规则的频率闭包，触发 FCT。

**证明。** 比较 `A_{k+1}` 对 `G_k` 的条件投影与 `A_k`。差集 `Δ_k` 是旧坐标上的重写区域。若 `μ(Δ_k)` 在尺度包中可求和，则由 `docs/rh-lv-low-volume-principle.md` 吸收。若不可求和，则旧坐标规则被反复改写且有正体积影响；由于每次规则仍由有限类型倒数环带、短弧或 Bohr 切片生成，不可求和的反复改写必须共享有限个相位关系。共享关系闭合为短深度频率 span，按 FCT/Tree-WFE 处理。证毕。

## 5. 边界体积逃逸推出 LV 终端

**Lemma CE-4（边界体积逃逸）。** 若边界项 `Bd_k` 的低体积账本不可吸收，则发生 LV 终端；若 LV 终端被排除，则 `Bd_k` 可并入 DSO-C-TC 的平方可和误差。

**证明。** 这是 LV 低体积原则的直接 contrapositive：低体积边界若不能作为误差吸收，必在某个尺度包形成可检测的低体积集中区。该集中区要么造成短簇，要么给出小质量原子偏差，均属于 LV/LSMP 终端范围。证毕。

## 6. Complexity-Escape 主命题

**Proposition CE（复杂度逃逸三分，条件化闭合）。** 在 PC4-PI 密集尺度包内，若 DSO-C-TC 的固定复杂度、自然细化、平方可和误差条件失败，并假设 DSO-E 对独立新增频率成立，则必触发以下至少一项：

1. `FCT` 频率碰撞/低维闭包；
2. `LSMP` 小质量原子或薄边界层逃逸；
3. `LV` 低体积边界终端；
4. 高投影增量返回 `PI-Seed/OV2`，不构成新的非终端分支。

**证明。** DSO-C-TC 失败只可能来自第 1 节四类逃逸。频率复杂度逃逸由条件化 CE-1，因而依赖 DSO-E；尾项能量逃逸由 CE-2；坐标重写逃逸由 CE-3；边界体积逃逸由 CE-4。四种情况均进入既有终端或返回 PI-Seed/OV2，故在 DSO-E 输入成立后，不存在独立的 Complexity-Escape 非终端。证毕。

## 7. 对 PC4-PI 的意义

现在 PC4-PI 的密集尺度分支分成两半：

- 固定复杂度且误差平方可和：由 `docs/rh-pc4-dso-template-consistency.md` 接入 DSO-C；
- 复杂度、尾项、旧坐标或边界逃逸：由本文压入 FCT/LSMP/LV/PI-Seed。

因此剩余硬点不再是“复杂度会无限变化怎么办”，而是更具体的两个接口：

1. 把 CE-1 中的“独立新频率近正交”与 DSO-E Euler factor decorrelation 逐项匹配；
2. 把 CE-2/CE-3 中的 LSMP/LV 触发条件与既有 D 组常数账本逐项核对。

DSO-E 已在 `docs/rh-pc4-dso-euler-decorrelation.md` 中拆成单层字符正交、倒数/混合相位非共振界和大复杂度 LSMP/FCT 二次剥离。本文的剩余审稿义务随之转化为：逐项匹配 DSO-E2 的 NRC/Weil 引用与 DSO-E4 的 LSMP 接口。
