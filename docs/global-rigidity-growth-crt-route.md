# 方阵斜线覆盖命题的全局刚性路线重构

**状态：** `replace_finite_template_by_growth_gap_and_CRT_rigidity`

本路线放弃“有限模板覆盖无限变化”的思路，重新回到目标命题的几何本质：当奇素数 `P` 增长时，方阵宽度、行列长度、根基斜线族、CRT 周期结构同步增长；证明应比较这些增长量级，并利用 CRT 周期刚性排斥全行/全列覆盖反例。

## 1. 目标命题的正确反例形式

在 `P x P` 方阵中，第 `r` 行第 `c` 列的数为

`N(r,c) = (r-1)P + c`，其中 `1<=r,c<=P`。

对每个根基素数 `q<P`，被 `q` 覆盖的格点满足

`N(r,c) ≡ 0 mod q`，即

`c ≡ -(r-1)P mod q`。

在圆柱面上，这就是斜率由 `P mod q` 决定的一条同余螺旋。由于 `P` 与 `q` 互素，每个 `q` 在任意固定行中只覆盖一个 `mod q` 的列同余类。

若第 `r` 行被全覆盖，则每个 `c=1,...,P` 都存在某个 `q<P`，使

`c ≡ a_q(r) mod q`。

换言之，长度为 `P` 的列区间被许多不同模数的单同余类并集完全覆盖。

## 2. 覆盖能力与目标长度的量级差距

对一行而言，小素数 `q` 在 `1..P` 内最多覆盖约 `P/q` 个列；因此所有根基素数的粗覆盖容量为

`Σ_{q<P} P/q ≈ P log log P`。

这个粗容量大于 `P`，不能直接证明不能全覆盖；真正关键不在总容量，而在**重叠刚性**：

- 小素数覆盖多，但彼此重叠严重；
- 大素数覆盖少，每个大素数在一行内通常只打一个点；
- 若试图用大量大素数补洞，则这些点的素因子必须互斥，受到乘积大小和行内距离约束；
- 因此有效新增覆盖能力不是 `Σ P/q`，而应扣除多重重叠后的增量。

所以应证明的是一种**增量覆盖不足定理**：

> 对任意非首行 `r<P`，从已被小根基素数覆盖的集合出发，后续较大根基素数所能补掉的洞数，严格小于剩余洞数。

这比有限模板强，因为它随 `P` 自适应，只比较增长率。

## 3. 分层覆盖的自然尺度

设阈值 `Y`，先用所有 `q<=Y` 的斜线覆盖第 `r` 行。未覆盖列数近似为

`P * Π_{q<=Y}(1-1/q) ≈ e^{-γ} P / log Y`。

若取 `Y=sqrt(P)`，剩余洞数约为

`≈ 2e^{-γ} P / log P`。

而 `q>sqrt(P)` 的素数每个在长度 `P` 的行内至多覆盖一个点，且这些点对应的数若都为 `sqrt(P)`-粗合数，则其大因子高度互斥。

这给出主攻方向：

> 证明 `sqrt(P)` 以上的大根基素数无法补尽 `sqrt(P)` 筛后的全部洞。

它正是“大因子互斥引理”的全局化版本，但不再是局部模板，而是按剩余洞数和可用大因子数的增长量级比较。

## 4. CRT 周期刚性排斥

令

`M = Π_{q<P} q`。

在宽为 `P` 的圆柱长方形中，所有根基斜线覆盖结构以行方向周期 `M` 复现，因为对每个 `q<P`，行推进 `M` 行后

`(r+M-1)P+c ≡ (r-1)P+c mod q`。

所以覆盖图案的严格周期为 `M` 的因子，通常由所有 `P mod q` 的组合共同决定。

如果第 `r` 行全覆盖，并且几何动力能推出全覆盖以较短步长 `k` 重复，则会得到一个额外周期。关键应证明：

> 全覆盖态的重复步长若小于 CRT 周期并非由所有模数共同稳定，则会迫使每个根基素数的覆盖列类同步不变，从而要求 `kP≡0 mod q` 对所有参与覆盖的关键 `q` 成立。

由于 `P` 与所有 `q<P` 互素，这等价于

`k≡0 mod q`。

若覆盖全行实际需要一组素数 `Q_r`，且这些素数的乘积超过 `P` 或包含足够多互素模数，则短周期 `k<P` 不可能同时被这些 `q` 整除。

这就是 CRT 排斥反例的主逻辑：

- 全行覆盖若能沿行方向平移复现，会诱导短周期；
- 但 CRT 结构要求周期必须同时尊重参与覆盖的互素模数；
- 对 `k<P`，不可能被足够多根基素数同时整除；
- 因此全行覆盖不能发生。

## 5. 需要严格化的两个核心引理

### 引理 A：有效覆盖增量不足

设第 `r` 行先由 `q<=sqrt(P)` 覆盖，剩余洞集为 `H_r`。则 `q>sqrt(P)` 的斜线能补掉的洞数严格小于 `|H_r|`。

可行证明接口：

1. 洞点对应的数均与所有 `q<=sqrt(P)` 互素；
2. 若洞点仍为合数，则它必须含有大于 `sqrt(P)` 的素因子；
3. 同一行中距离小于 `sqrt(P)` 的两个粗合数不能共享同一大因子；
4. 因此大因子补洞点在短区间内高度稀疏；
5. 将行分割为长度约 `sqrt(P)` 的块，累计得到补洞能力小于筛后洞数。

### 引理 B：全覆盖诱导非法短 CRT 周期

若第 `r` 行全覆盖，则覆盖该行的最小根基素数集合 `Q_r` 必须具有足够大的互素模数复杂度。若全覆盖沿圆柱动力在步长 `k<P` 处复现，则必须有

`kP≡0 mod q` 对所有 `q in Q_r` 的关键覆盖类成立。

因 `gcd(P,q)=1`，得到 `q|k`。当 `Q_r` 含有至少两个乘积超过 `k` 的互素素数时矛盾。

更强形式：如果 `Q_r` 的必要模数乘积超过 `P`，则任何 `k<P` 的复现都不可能。

## 6. 行命题的新证明骨架

反设第 `r` 行全覆盖，`2<=r<=P`。

1. 先按 `q<=sqrt(P)` 形成基础筛，得到洞集 `H_r`；
2. 若 `H_r` 中存在未被大根基素数补掉的点，则该点为素数，矛盾于全覆盖；
3. 因此全覆盖要求 `q>sqrt(P)` 完全补洞；
4. 由引理 A，大因子补洞能力不足，矛盾；
5. 或者若补洞能力被假设达到全覆盖，则覆盖态必须具有短复现结构；
6. 由引理 B，短复现与 CRT 周期刚性冲突。

这条路线避免固定有限模板，而用两个全局机制夹击：

- 增量覆盖能力不足；
- CRT 周期刚性禁止短复现。

## 7. 列命题对应路线

固定列 `c<P`，数列为

`N(r,c)=(r-1)P+c`。

对根基素数 `q<P`，覆盖条件为

`r ≡ 1 - c P^{-1} mod q`。

因此每个 `q` 在列方向也只覆盖一个行同余类。列命题与行命题同构，但有一个优势：列方向正是 CRT 周期方向，周期结构更直接。

列反例若存在，会在 CRT 周期内形成某个列的完整覆盖段。应证明：

- 小素数筛后仍有约 `P/log P` 个洞；
- 大素数补洞受同样互斥；
- 若全列覆盖诱导周期复现，则周期必须被足够多根基模数整除，与 `P` 长度窗口冲突。

## 8. 下一步实际攻坚

最优下一步不是继续模板化，而是建立两个可验证的全局实验：

1. **增量覆盖实验**：对每个 `P` 与每行 `r`，计算 `q<=sqrt(P)` 后洞数，以及 `q>sqrt(P)` 实际补洞数，观察补洞缺口随 `P` 的增长。
2. **周期复现实验**：若某行覆盖率极高，计算其覆盖模式与后续行的平移相关性，检测是否存在短周期；验证短周期必须携带大量 `q|k` 条件。

若实验稳定显示：

`large_prime_patch_capacity / small_sieve_holes < 1 - δ`

或短周期必要模数乘积快速超过 `P`，则可将其升级为全局引理。


## 9. 关键修正：sqrt(P) 单块命题过强

后续短块扫描显示，长度约 `sqrt(P)` 的单个块内可能出现小筛洞被大因子完全补掉的情况；因此不能证明“每个 sqrt(P) 块都有素数”。正确方向应改为：

- 在长度 `C sqrt(P)` 或更大的中块中证明补洞缺口；
- 或只证明整行总补洞缺口，而非逐块缺口；
- 局部块引理必须允许少量满补块，但证明满补块不能连续铺满整行。

这与 CRT 刚性自然结合：若满补块连续形成全行覆盖，会诱导覆盖模式的连续复现，从而触发周期矛盾。
