# PC4-Dual：DGap 压缩异常结构分解定理

本文接续 `docs/rh-pc4-dual-gap-ledger.md`，专攻剩余硬点：若

`DGap_z(X)=Gap_z^0(X)-Gap_z(X) >= cΔ`, `Δ=X^{β-o(1)}`, `β>1/2`，

则该“缺口低于零频”的异常压缩必须进入短簇、投影、频率、低体积或覆盖同步分支。本文仍是条件化结构定理；它的价值在于把 `DGap` 黑箱拆成可逐项审查的有限接口。

## 1. DGap 场的局部化

令

`h(n)=g_z^0(n)-g_z(n)`，

其中 `g_z(n)=χ_B(n)(1-χ_A(n))` 是逐点非负缺口，`g_z^0` 是同一 CRT 零频模型下的基线密度。于是

`DGap_z(X)=Σ_n h(n)W(n/X)`。

`h` 不逐点非负，但大正总和表示真实缺口被压缩。取一组多尺度分解盒 `𝓑`：每个盒由物理短窗、dyadic 锚层、有限 CRT/Bohr 相位原子共同确定；其有限重叠由 `docs/rh-pc4-dual-box-overlap.md` 给出。记

`H(B)=Σ_{n in B} h(n)W(n/X)`。

盒分解满足有限重叠：

`Σ_{B in 𝓑} 1_B(n) <= log^C X`。

因此若 `DGap_z>=cΔ`，则要么存在短簇盒承载显著质量，要么质量分散到大量盒中并产生平方能量。

## 2. 短簇与低体积分支

设盒体积基线为 `μ^0(B)=Σ_{n in B} g_z^0(n)W(n/X)`。给定阈值 `η=log^{-C_1}X`。

若存在盒 `B` 使

`H(B) >= η μ^0(B)` 且 `μ^0(B) <= X^{1/2+o(1)}`，

则该异常由低体积盒承载，进入 LV/LSMP。

若存在盒 `B` 使

`H(B) >= η Δ`

且 `B` 的物理长度或 Bohr 半径低于主尺度，则该异常是短窗/短相位集中，进入 PC4-SC 的对偶短簇压缩分支。

这两种情形对应 `DGap` 在局部盒内直接可见。

## 3. 投影能量分支

排除短簇与低体积后，所有正质量 `H(B)_+` 分散于大量中等体积盒。由 Cauchy 能量下界，若

`Σ_B H(B)_+ >= cΔ`

且每个盒的质量均小于 `ηΔ`，则

`Σ_B H(B)_+^2/μ^0(B) >= Δ^2 / Σ_B μ^0(B)`。

在非低体积主层中，右侧给出超过零频噪声的投影平方能量压力。盒指示函数到允许投影族的正交化由 `docs/rh-pc4-dual-projection-orthogonalization.md` 给出，因此得到某个投影包满足

`Σ_B |<h,𝓦_B>|^2 >= X^{2β-1-o(1)}`

或其局部归一化版本。由于 `β>1/2`，该量在跨尺度求和中不可由零频噪声长期吸收，进入 PC4-PI。

## 4. 频率锁定分支

若第 3 节的投影能量没有进入 PC4-PI，则只能是盒投影高度相关：多数 `H(B)_+` 落在固定低维 CRT/Bohr 频率 span 内。形式化地，存在固定维数 `d=O(1)` 的频率族 `Λ_*`，使正质量主要由

`span{e(λ n/M): λ in Λ_*}`

解释。

这就是 FCT 低维频率闭包。若新增 CRT 坐标漂移后仍保持该解释，则进入 `docs/rh-pc4-fct-closure-theorem.md`；若漂移失败，则返回 PC4-PI 或短簇。

## 5. 覆盖同步分支

还有一种可能：`DGap` 看似为缺口压缩，实际来自允许覆盖指示 `χ_A` 的同步变化，即大量本应未解释的粗合数被同相位允许锚解释。此时 `m_A(n)` 或 `O_z(n)` 的同相位增量不可忽略。

按 `docs/rh-pc4-dual-gap-ledger.md` 的恒等式，这会表现为：

- `ACC_z^0-ACC_z` 的负向同步异常已不足以解释；
- `O_z-O_z^0` 出现正异常；或
- 允许锚覆盖点数相对零频出现同相位波。

前两者进入 PC4-A 或 OV2/D 组终端；第三者经 AAI 双锚正规形转入短簇、PI 或 FCT。

## 6. DGap 分解定理

**Theorem DGap-Decomposition（对偶缺口压缩结构分解，条件化）。** 假设 `docs/rh-pc4-dual-box-overlap.md` 的盒分解有限重叠、`docs/rh-pc4-dual-projection-orthogonalization.md` 的投影正交化、AAI 允许锚语义、LV/LSMP 低体积吸收、PC4-PI 投影能量接口与 PC4-FCT 频率闭包接口成立。若无穷多尺度上

`DGap_z(X)>=cX^{β-o(1)}`, `β>1/2`，

则至少发生一项：

1. **SC**：短窗、短 Bohr 原子或少数相位盒承载 `DGap` 正质量；
2. **LV/LSMP**：正质量由低体积盒或可求和尾层承载；
3. **PI**：分散正质量产生高投影平方能量；
4. **FCT**：投影能量被固定低维频率 span 吸收；
5. **A/OV2**：缺口压缩实际由覆盖同步或 overlap 过剩解释；
6. **接口失败**：盒分解有限重叠、基线匹配、投影正交化或边界误差失败。

**证明。** 对 `h=g_z^0-g_z` 作盒分解。若正质量集中在单个短盒或少数短相位原子，得到 SC。若集中盒体积低或层数可求和，得到 LV/LSMP。排除这两种后，正质量只能分散在中等体积盒中。Cauchy 给出平方能量下界；若该下界在允许投影族中可检测，得到 PI。若不可检测，则盒投影高度相关，只能落入固定低维频率 span，得到 FCT。若相关性来自允许覆盖指示同步变化，则由覆盖恒等式转入 A/OV2。若上述分解任一步失败，正是盒分解、基线或边界接口失败。证毕。

## 7. 对 RH 反例矛盾场的作用

DGap-Decomposition 把过密对偶剩余黑箱缩小为五个已列分支：SC、LV/LSMP、PI、FCT、A/OV2。于是过密链条现在为：

`过密 => Dual-Gap-Ledger 三分 => ACC负向 / overlap过剩 / DGap压缩`

其中 `DGap压缩` 再由本文转入 PC4 的既有 closure 分支。盒分解有限重叠已由 `docs/rh-pc4-dual-box-overlap.md` 定理化，投影正交化已由 `docs/rh-pc4-dual-projection-orthogonalization.md` 定理化。下一步真正剩余不是再增加新分支，而是无条件化低维频率抽取。
