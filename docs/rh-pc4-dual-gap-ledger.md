# PC4-Dual：对偶缺口账本与非负分解

本文补强 `docs/rh-pc4-dual-overdense-closure.md` 中最硬的接口：`Gap_z` 不能只是口头“缺口”，必须有逐点定义、非负性、与覆盖容量的恒等式，并能把过密分支转入 PC4-A/SC/PI/FCT/LV。本文给出可审查的条件化账本定理。

## 1. 基本集合与权重

固定平滑窗口权 `W_X(n)=W(n/X)`，筛层 `z=(log X)^A`，CRT 候选集合

`C_z={n: (n,M_z)=1}`，其中 `M_z=∏_{p<=z}p`。

定义逐点候选指示

`χ_C(n)=1_{(n,M_z)=1}`，

素数指示

`χ_P(n)=1_{n prime}`，

真实粗合数指示

`χ_B(n)=χ_C(n)-χ_P(n)-χ_{bd}(n)`。

这里 `χ_{bd}` 收集素数幂、端点正规化与模型边界项；在 PC2/PC3 接口中，其平滑总量为 `Err_bd=o(Δ)`。

因此平滑总量满足

`C_z=P_z+B_z+Err_bd`。

## 2. 允许覆盖与唯一解释

令 `A(n)` 为方阵/CRT 允许斜线锚集合。按 AAI，若 `q in A(n)`，则 `q|n`，且允许锚是整除锚的子集合。

定义允许覆盖指示

`χ_A(n)=1_{χ_C(n)=1 and A(n) nonempty}`。

定义唯一真实粗合数指示 `χ_B(n)` 如上。逐点有三类候选点：

1. `χ_P(n)=1`：真实素数；
2. `χ_B(n)=1` 且 `χ_A(n)=1`：被允许覆盖解释的粗合数；
3. `χ_B(n)=1` 且 `χ_A(n)=0`：真实粗合数但当前允许斜线模型未解释的缺口点。

于是定义对偶缺口逐点函数

`g_z(n)=χ_B(n)(1-χ_A(n))`。

显然

`g_z(n)>=0`。

平滑缺口账本为

`Gap_z(X)=Σ_n g_z(n)W_X(n)`。

## 3. 覆盖容量与扣重

允许覆盖容量可以按锚重数计数，也可以按被覆盖点计数。为与 PC3 overlap 扣重一致，设

`m_A(n)=#A(n)`，

平滑允许重数容量

`ACC_z(X)=Σ_n χ_B(n)m_A(n)W_X(n)`。

允许覆盖点数为

`Cov_z(X)=Σ_n χ_B(n)1_{m_A(n)>=1}W_X(n)`。

定义 overlap 扣重

`O_z(X)=Σ_n χ_B(n)max(m_A(n)-1,0)W_X(n)`。

则逐点恒等式为

`χ_B(n)m_A(n)-χ_B(n)max(m_A(n)-1,0)+g_z(n)=χ_B(n)`。

因为：若 `m_A=0`，左边为 `0-0+χ_B=χ_B`；若 `m_A>=1`，左边为 `χ_B m_A-χ_B(m_A-1)+0=χ_B`。

平滑求和得到精确恒等式

`B_z(X)=ACC_z(X)-O_z(X)+Gap_z(X)`，

外加 PC2/PC3 中已单列的边界项时写作

`C_z(X)-P_z(X)=ACC_z(X)-O_z(X)+Gap_z(X)+Err_bd(X)`。

## 4. 零频基线与符号分解

对同一模型取零频基线：

`B_z^0=ACC_z^0-O_z^0+Gap_z^0`。

通常零频模型中 `Gap_z^0` 可以并入 `ACC_z^0` 的补集基线；为避免隐藏项，本文保留它。两式相减得

`B_z-B_z^0=(ACC_z-ACC_z^0)-(O_z-O_z^0)+(Gap_z-Gap_z^0)+Err_o`。

PC2 过密输入给

`B_z-B_z^0<=-Δ+o(Δ)`。

因此

`(ACC_z^0-ACC_z)+(O_z-O_z^0)+(Gap_z^0-Gap_z) >= Δ-o(Δ)`。

这说明真正由过密推出的是三种“负向压力”之一：ACC 不足、overlap 过剩、或缺口低于零频基线。若改用“未解释点异常”作为正缺口，则定义

`DGap_z=Gap_z^0-Gap_z`。

`DGap_z` 不逐点非负，但其大正值表示实际缺口少于零频缺口，即更多候选被素数占据或覆盖解释不足被压缩。它才是过密对偶中的正向异常账本。

## 5. 两种缺口账本的诚实区分

为避免符号错误，PC4-Dual 使用两个账本：

1. `Gap_z=Σχ_B(1-χ_A)W_X`：逐点非负的未解释粗合数缺口；
2. `DGap_z=Gap_z^0-Gap_z`：相对零频的对偶缺口压缩，可能为正或负。

过疏分支通常使 `B_z` 增大，需要 ACC 过剩或 overlap/D 终端吸收。过密分支使 `B_z` 减小，需要 ACC 不足、overlap 过剩或 `DGap_z` 正异常吸收。

因此原 `PC4-Dual` 中“`Gap_z>=cΔ`”应严格替换为

`DGap_z>=cΔ`

或等价地

`Gap_z<=Gap_z^0-cΔ`。

这表示：相对零频基线，未解释粗合数缺口被异常压缩，候选点过多转成素数或异常覆盖结构。

## 6. DGap 的结构分解

若 `DGap_z>=cΔ` 在无穷多尺度持续存在，则并不是逐点缺口过多，而是缺口相对基线过少。它的详细分解见 `docs/rh-pc4-dual-dgap-decomposition.md`。该分解把 `DGap` 正异常压入五类既有分支：

1. **短窗压缩**：进入 PC4-SC 的对偶短簇；
2. **投影压缩**：进入 PC4-PI 的高投影能量；
3. **频率锁定压缩**：进入 PC4-FCT；
4. **低体积压缩**：进入 LV/LSMP；
5. **覆盖同步**：进入 PC4-A 或 OV2/D 组终端。

## 7. 对偶三分定理

**Theorem Dual-Gap-Ledger（对偶缺口账本三分，条件化）。** 在 AAI 允许锚语义、PC2 边界误差、PC3 overlap 扣重定义成立的前提下，过密输入

`P_z-P_z^0>=Δ`, `Δ=X^{β-o(1)}`, `β>1/2`

推出至少一项：

1. `ACC_z^0-ACC_z>=cΔ`：允许覆盖容量负向同步异常；
2. `O_z-O_z^0>=cΔ`：overlap 过剩，触发 OV2/D 组终端；
3. `DGap_z=Gap_z^0-Gap_z>=cΔ`：对偶缺口压缩异常；
4. 边界或正规化误差超过 `o(Δ)`，即 PC2/PC3 接口失败。

其中 `Gap_z` 逐点非负，`DGap_z` 是相对零频异常，不要求逐点非负。

**证明。** 由第 3 节恒等式与第 4 节基线差分，过密给

`(ACC_z^0-ACC_z)+(O_z-O_z^0)+(Gap_z^0-Gap_z) >= Δ-o(Δ)`。

若边界误差为 `o(Δ)`，则三项之和至少为 `Δ/2`。取 `c=1/6`，至少一项不小于 `cΔ`。三项分别对应 1、2、3。若边界误差不可忽略，则为 4。证毕。

## 8. 对 PC4-Dual 的修正

`docs/rh-pc4-dual-overdense-closure.md` 应把“覆盖缺口过剩”修正为“对偶缺口压缩异常”。直观上，过密不是未解释粗合数变多，而是候选粗合数账本被压低；这个压低可以表现为覆盖容量不足、overlap 扣重增加，或未解释粗合数缺口低于零频基线。

修正后，过密对偶链条为：

`素数过密`
`=> B_z 低于零频`
`=> ACC 负向同步 / overlap 过剩 / DGap 正异常`
`=> PC4-A / OV2-D / SC-PI-FCT-LV`
`=> 条件化矛盾`。
