# PC4-Dual：过密对偶分支闭合框架

本文补齐 RH 反例矛盾场路线中 PC-1/PC-2 可能输出的过密符号。PC3-OV2 已处理“素数过疏 => 覆盖容量过剩或 D 组终端”。过密分支则应转化为“覆盖缺口过剩、候选空洞不足或对偶 D 组终端”。本文给出条件化闭合框架，不宣称已经证明 RH。

## 1. 对偶输入

由 PC-1 与 PC-2，若离线零点在某无穷尺度子列上只稳定给出过密符号，则存在平滑窗口与 `Δ=X^{β-o(1)}`, `β>1/2`，使

`P_z(X) >= P_z^0(X)+Δ`。

CRT 候选总量刚性给

`C_z(X)=C_z^0(X)+o(Δ)`，

故粗合数候选满足

`B_z(X) <= B_z^0(X)-Δ+o(Δ)`。

这不是覆盖过剩，而是覆盖缺口过剩：相对零频基线，候选集合中被允许合数斜线解释的点不足。

## 2. 对偶恒等式

写候选集合分解为

`C_z=P_z+B_z+Err_bd`。

令允许覆盖容量 `ACC_z` 表示由允许锚斜线解释的粗合数容量，令 `Gap_z` 表示候选中没有被该容量解释、但又不贡献真实素数主项的对偶缺口账本。则形式上有

`C_z-P_z = ACC_z - O_z + Gap_z + Err'_bd`。

过密输入给

`ACC_z^0-ACC_z + O_z - Gap_z >= Δ-o(Δ)`。

因此至少发生一项：

1. `ACC_z <= ACC_z^0-cΔ`：覆盖容量同步不足；
2. `Gap_z >= cΔ`：覆盖缺口过剩；
3. overlap 或边界项异常，触发 D 组终端。

这就是 PC4-Dual 的基本三分。

## 3. 反相位优先原则

若离线零点主导项是单一实部极大零点，PC1 的三角振荡通常同时给出过疏与过密子列。此时取反相位过疏子列即可回到 PC3-OV2，PC4-Dual 不承担主证明压力。

PC4-Dual 真正需要处理的是多零点相干或权函数选择导致的符号不稳定情形：在所有可用子列中，过密更容易保持相干，而过疏子列不能同步通过 PC2/PC3 的同一 CRT 正规化。本文把该情形视为“符号选择失败”。

## 4. 对偶缺口的结构排斥

若 `Gap_z>=cΔ` 在无穷多尺度上持续存在，则候选集合的非零同余类中出现过多未解释点。按局部结构，它只能有三种来源。

**第一类：短簇缺口。** 未解释点集中在短窗或少数相位原子中。则它是 PC4-SC 的对偶形式：短窗内锚复用不足或空洞集中。由 `docs/rh-pc4-short-cluster-closure-theorem.md` 的同一局部密度账本，除非触发 PI/A/FCT/LV，否则不能长期承载 `X^{β-o(1)}` 级缺口。

**第二类：投影缺口。** 未解释点在某个允许投影中产生可检测负增量。对平方能量而言，负增量的绝对值仍贡献投影能量，因此进入 `docs/rh-pc4-pi-closure-theorem.md` 的高投影增量排斥。

**第三类：频率锁定缺口。** 缺口只沿固定低维 CRT 频率 span 出现。则它是 FCT 的对偶形式，进入 `docs/rh-pc4-fct-closure-theorem.md`；若频率不闭合，则相位漂移产生可检测投影增量。

## 5. 覆盖容量同步不足的排斥

若不是缺口过剩，而是 `ACC_z<=ACC_z^0-cΔ`，则允许覆盖容量出现与离线零点相位同步的负波。PC4-A 原文处理正向同步过剩；同一 ACC 同步压力也适用于负向波动，因为核心矛盾来自容量函数试图模拟 `X^β` 级连续相干振荡，而非符号本身。

更具体地，`ACC_z-ACC_z^0` 的正负波动都必须由锚层数量、局部 Euler 因子与 CRT 非零类分布实现。若无穷多尺度存在 `|ACC_z-ACC_z^0|>=cΔ` 且不触发短簇、PI、FCT 或 LV/LSMP，则得到与 `docs/rh-pc4-acc-closure-theorem.md` 相同的同步压力矛盾。

## 6. PC4-Dual 条件化闭合命题

**Theorem PC4-Dual-Closure（过密对偶分支，条件化）。** 假设以下接口成立：

1. PC2 的 CRT 候选基线匹配与边界误差控制成立；
2. 对偶覆盖恒等式中的 overlap、缺口与边界项满足 OV2/AAI/PPI/MLC 同型分解；
3. PC4-A、PC4-SC、PC4-PI、PC4-FCT 均按现有 closure 文档条件化闭合；
4. LV/LSMP 低体积吸收与复杂度逃逸接口成立。

则过密分支不能作为 RH 离线零点反例场的最终逃逸通道。若 PC1 在某子列只输出过密，则该过密必触发已闭合的 ACC 负向同步、短簇缺口、投影缺口、频率锁定缺口、低体积吸收或参数接口失败。

**证明。** 由 PC2，过密 `P_z-P_z^0>=Δ` 强迫 `B_z-B_z^0<=-Δ+o(Δ)`。代入对偶覆盖恒等式，得到覆盖容量同步不足、覆盖缺口过剩或 overlap/边界异常三分。overlap/边界异常由 OV2 同型接口转入 D 组终端。覆盖容量同步不足由 PC4-A 的符号对称同步压力排斥。覆盖缺口过剩按第 4 节分解：集中则进入 PC4-SC，对可检测投影则进入 PC4-PI，对低维频率锁定则进入 PC4-FCT，对低体积或复杂度逃逸则由 LV/LSMP 吸收。所有终端均被假设闭合，故过密不能最终逃逸。证毕。

## 7. 对总反例矛盾场的贡献

PC4-Dual 的作用是消除“只能取过密子列”的符号缺口。它把反例场统一为绝对波动排斥：无论 PC1 产生过疏还是过密，只要幅度超过平方根量级并能通过 PC2 接入 CRT 零频基线，PC3/PC4 就迫使该波动进入 ACC、短簇、投影、频率或低体积账本；这些账本均不能长期模拟离线零点的 `X^β` 级相干波动。
