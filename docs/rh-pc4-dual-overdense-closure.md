# PC4-Dual：过密对偶分支闭合框架

本文补齐 RH 反例矛盾场路线中 PC-1/PC-2 可能输出的过密符号。PC3-OV2 已处理“素数过疏 => 覆盖容量过剩或 D 组终端”。过密分支则应转化为“覆盖容量负向同步、overlap 过剩、对偶缺口压缩异常或 D 组终端”。本文给出条件化闭合框架，不宣称已经证明 RH。

## 1. 对偶输入

由 PC-1 与 PC-2，若离线零点在某无穷尺度子列上只稳定给出过密符号，则存在平滑窗口与 `Δ=X^{β-o(1)}`, `β>1/2`，使

`P_z(X) >= P_z^0(X)+Δ`。

CRT 候选总量刚性给

`C_z(X)=C_z^0(X)+o(Δ)`，

故粗合数候选满足

`B_z(X) <= B_z^0(X)-Δ+o(Δ)`。

这不是覆盖过剩，而是粗合数账本低于零频：相对零频基线，候选点过多转成素数，必须由覆盖容量负向同步、overlap 扣重增加或对偶缺口压缩来解释。

## 2. 对偶恒等式

写候选集合分解为

`C_z=P_z+B_z+Err_bd`。

令允许覆盖容量 `ACC_z` 表示由允许锚斜线解释的粗合数容量，令 `Gap_z` 表示真实粗合数中未被允许覆盖解释的逐点非负缺口，令 `DGap_z=Gap_z^0-Gap_z` 表示相对零频的对偶缺口压缩异常。严格定义见 `docs/rh-pc4-dual-gap-ledger.md`。覆盖恒等式为

`C_z-P_z = ACC_z - O_z + Gap_z + Err'_bd`。

过密输入给

`(ACC_z^0-ACC_z)+(O_z-O_z^0)+DGap_z >= Δ-o(Δ)`。

因此至少发生一项：

1. `ACC_z <= ACC_z^0-cΔ`：覆盖容量同步不足；
2. `O_z>=O_z^0+cΔ`：overlap 过剩，触发 D 组终端；
3. `DGap_z>=cΔ`：对偶缺口压缩异常；
4. 边界项异常，触发接口失败。

这就是 PC4-Dual 的基本三分。

## 3. 反相位优先原则

若离线零点主导项是单一实部极大零点，PC1 的三角振荡通常同时给出过疏与过密子列。此时取反相位过疏子列即可回到 PC3-OV2，PC4-Dual 不承担主证明压力。

PC4-Dual 真正需要处理的是多零点相干或权函数选择导致的符号不稳定情形：在所有可用子列中，过密更容易保持相干，而过疏子列不能同步通过 PC2/PC3 的同一 CRT 正规化。本文把该情形视为“符号选择失败”。

## 4. 对偶缺口的结构排斥

若 `DGap_z>=cΔ` 在无穷多尺度上持续存在，则候选集合的非零同余类中出现“未解释粗合数缺口低于零频”的异常压缩。按局部结构，它只能有三种来源。

**第一类：短簇压缩。** 缺口压缩集中在短窗或少数相位原子中。则它是 PC4-SC 的对偶形式：短窗内候选点异常转成素数或覆盖解释异常同步。由 `docs/rh-pc4-short-cluster-closure-theorem.md` 的同一局部密度账本，除非触发 PI/A/FCT/LV，否则不能长期承载 `X^{β-o(1)}` 级压缩。

**第二类：投影压缩。** 缺口相对零频在某个允许投影中产生可检测负增量。对平方能量而言，负增量的绝对值仍贡献投影能量，因此进入 `docs/rh-pc4-pi-closure-theorem.md` 的高投影增量排斥。

**第三类：频率锁定压缩。** 缺口压缩只沿固定低维 CRT 频率 span 出现。则它是 FCT 的对偶形式，进入 `docs/rh-pc4-fct-closure-theorem.md`；若频率不闭合，则相位漂移产生可检测投影增量。

## 5. 覆盖容量同步不足的排斥

若不是 `DGap` 压缩异常，而是 `ACC_z<=ACC_z^0-cΔ`，则允许覆盖容量出现与离线零点相位同步的负波。PC4-A 原文处理正向同步过剩；同一 ACC 同步压力也适用于负向波动，因为核心矛盾来自容量函数试图模拟 `X^β` 级连续相干振荡，而非符号本身。

更具体地，`ACC_z-ACC_z^0` 的正负波动都必须由锚层数量、局部 Euler 因子与 CRT 非零类分布实现。若无穷多尺度存在 `|ACC_z-ACC_z^0|>=cΔ` 且不触发短簇、PI、FCT 或 LV/LSMP，则得到与 `docs/rh-pc4-acc-closure-theorem.md` 相同的同步压力矛盾。

## 6. PC4-Dual 条件化闭合命题

**Theorem PC4-Dual-Closure（过密对偶分支，条件化）。** 假设以下接口成立：

1. PC2 的 CRT 候选基线匹配与边界误差控制成立；
2. `docs/rh-pc4-dual-gap-ledger.md` 的对偶覆盖恒等式、非负 `Gap_z` 与相对异常 `DGap_z` 三分成立；
3. PC4-A、PC4-SC、PC4-PI、PC4-FCT 均按现有 closure 文档条件化闭合；
4. LV/LSMP 低体积吸收与复杂度逃逸接口成立。

则过密分支不能作为 RH 离线零点反例场的最终逃逸通道。若 PC1 在某子列只输出过密，则该过密必触发已闭合的 ACC 负向同步、overlap/D 组终端、短簇压缩、投影压缩、频率锁定压缩、低体积吸收或参数接口失败。

**证明。** 由 PC2，过密 `P_z-P_z^0>=Δ` 强迫 `B_z-B_z^0<=-Δ+o(Δ)`。代入 `Dual-Gap-Ledger` 三分，得到覆盖容量同步不足、overlap 过剩、`DGap` 压缩异常或边界异常。overlap/边界异常由 OV2 同型接口转入 D 组终端或接口失败。覆盖容量同步不足由 PC4-A 的符号对称同步压力排斥。`DGap` 压缩异常按第 4 节分解：集中则进入 PC4-SC，对可检测投影则进入 PC4-PI，对低维频率锁定则进入 PC4-FCT，对低体积或复杂度逃逸则由 LV/LSMP 吸收。所有终端均被假设闭合，故过密不能最终逃逸。证毕。

## 7. 对总反例矛盾场的贡献

PC4-Dual 的作用是消除“只能取过密子列”的符号缺口。它把反例场统一为绝对波动排斥：无论 PC1 产生过疏还是过密，只要幅度超过平方根量级并能通过 PC2 接入 CRT 零频基线，PC3/PC4 就迫使该波动进入 ACC、短簇、投影、频率或低体积账本；这些账本均不能长期模拟离线零点的 `X^β` 级相干波动。
