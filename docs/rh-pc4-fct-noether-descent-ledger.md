# PC4-FCT：Noether 下降量账本与防循环审查

本文补强 `docs/rh-pc4-fct-noether.md` 中最容易被审稿追问的接口：FCT 闭包链为什么不能通过“换一个等价低维关系”无限循环。核心做法是把每一步闭包证书写成离散势函数下降，若势函数不降，则证明它不是新 FCT 步，而是同一 Bohr 交集反复承载偏差，必须转入 PI/SC/LV/LSMP/CE 终端。

## 1. 标准化 FCT 状态

一个 FCT 状态写为

`S=(Λ,R,𝓑,τ)`，

其中：

- `Λ` 是当前低维频率格，秩为 `r(S)`；
- `R` 是整数关系矩阵，取 Hermite normal form 作为规范代表；
- `𝓑` 是由 `Λ` 与 `R` 生成的 Bohr/倒数相位切片；
- `τ` 是 dyadic/CRT 深度标签。

两个状态等价，指它们的规范代表相同，且对应 Bohr 交集在零频测度意义下只差固定模板常数倍。采用规范代表后，“同一关系换写法”不再算作新状态。

## 2. 离散势函数

定义势函数

`𝓝(S)=A_1 r_free(S)+A_2 q(S)+A_3 L(S)-A_4 τ(S)`。

各项含义如下：

- `r_free(S)`：尚未被闭包关系固定的自由频率秩；
- `q(S)`：规范关系矩阵的剩余 Smith/Hermite 指数预算；
- `L(S)=ceil(log_2( μ(𝓑)/μ_min ))_+`：Bohr 交集到低体积阈值的离散体积层数；
- `τ(S)`：已消耗的闭包深度。

常数按

`A_1 >> A_2 >> A_3 >> A_4 >> 1`

固定。由于 `r_free,q,L,τ` 都是整数，`𝓝(S)` 是离散量。排除 LV/LSMP/SC 后有 `μ(𝓑)>=μ_min`，故 `L>=0`；排除复杂度逃逸后 `r_free,q,τ` 都在固定复杂度层内，故 `𝓝` 有下界。

## 3. 单步类型表

每个新 FCT 证书规范化后只可能属于下列四型。

| 类型 | 结构变化 | 下降量 | 非下降出口 |
| --- | --- | --- | --- |
| 独立固定 | 新关系固定一个自由相位 | `r_free` 降低 | 无；若不是固定则是 NRC/DSO 新频率 |
| 指数压缩 | Smith/Hermite 指数预算减少 | `q` 降低 | 规范代表不变 |
| Bohr 细化 | 新短弧条件真缩小 `𝓑` | `L` 降低或触发 LV/SC | 若测度不降，则等价状态 |
| 重复关系 | 新证书在旧 span 与旧切片内 | 无下降 | 同一 `𝓑` 再承载偏差，转 PI/SC |

选择 `A_1,A_2,A_3,A_4` 的层级后，前三型一旦发生真变化，都给

`𝓝(S_{t+1}) <= 𝓝(S_t)-1`。

第四型不是新的闭包进展，而是固定模板上的重复承载。

## 4. 单步下降引理

**Lemma FCT-ND1（规范单步下降）。** 设 `S_t -> S_{t+1}` 是一个非终端 FCT 闭包步，并且新证书在规范代表下不是重复关系。若不触发 NRC/DSO、PI、SC、LV、LSMP 或 CE，则

`𝓝(S_{t+1}) <= 𝓝(S_t)-1`。

**证明。** 若新证书引入旧 span 外的独立频率，则它不是 FCT 闭包，而是 NRC/DSO 分支，已被排除。因此新证书在旧 span 内。规范化后：若它固定自由相位，`r_free` 降低；若它不降秩但缩短整数关系指数，`q` 降低；若它只增加 Bohr 短弧条件且条件非冗余，则零频测度至少跨过一个 dyadic 体积层，`L` 降低，若测度低于阈值则触发 LV/SC/LSMP。若三者都不发生，则规范代表和 Bohr 交集均未真变，是重复关系，违背本引理假设。按权重层级吸收低阶项，得到 `𝓝` 至少下降 `1`。证毕。

## 5. 重复关系到投影压力

**Lemma FCT-ND2（重复闭包的能量出口）。** 若从某一时刻起 FCT 证书在同一规范状态 `S` 上重复出现，并且每次仍吸收同向离线零点偏差，则至少触发一项：

1. `PC4-PI` 高投影增量；
2. `PC4-SC` 短簇或 LV/LSMP 低体积；
3. CE/DSO 容量失败。

**证明。** 同一规范状态给同一固定 Bohr 模板 `𝓑_S` 与固定投影窗口族。重复吸收同向偏差意味着这些窗口上的偏差平方和在无穷截断上增长。若窗口零频质量不集中且复杂度固定，则这正是 PI-Seed 的固定模板能量下界，进入 `docs/rh-pc4-pi-terminal-final-reduction.md`。若质量集中在少数短弧/低体积切片，则是 SC/LV/LSMP。若偏差只通过新增坐标分散保持，则由 DSO-E/CE 容量账本处理。证毕。

## 6. Noether 防循环定理

**Theorem FCT-Noether-Descent。** 在排除 NRC/DSO、PI、SC、LV、LSMP 与 CE 终端的非终端假设下，不存在无限 FCT 闭包链。

**证明。** 对无限链逐步规范化。若无限多步为非重复闭包，由 FCT-ND1，整数势函数 `𝓝` 无限严格下降，违背其下界。若只有有限多步非重复，则从某时刻起全部为同一规范状态上的重复关系；由 FCT-ND2 触发 PI/SC/LV/LSMP/CE，违背非终端假设。因此无限 FCT 闭包链不存在。证毕。

## 7. 接入 PC4-FCT

`规范代表 -> 四型单步表 -> 离散势函数下降 -> 重复关系能量出口`。
