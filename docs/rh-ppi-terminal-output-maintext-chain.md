# PPI 终端输出主文链：从倒数相位偏差到命名终端

本文继续压缩 RH 反例矛盾场中的 PC3/OV2 无条件化接口。`docs/rh-ov2-ppi-unconditional-theorem.md` 已证明：AAI 双锚主层中的可检测偏差可推送为有限复杂度倒数相位窗口，并可经 Fourier/Vaaler 展开为单/双变量倒数指数和。本文进一步把 PPI 的输出端从“终端列表”改写为一条可审查的主文分流链。

本文仍不宣称 RH 已证明；它只减少 PPI 输出端的黑箱程度。真正的 RH 无条件闭合还需要 PC1 一般振荡输入、PC4 终端排斥、Dual/DGap 与容量常数包全部闭合。

## 1. 输入状态

PPI 输入是一个稳定 dyadic 双锚主层 `(Q,R)` 上的可检测偏差。AAI 给出正规形

`n=q_1q_2r`, `q_1~Q`, `q_2~R`, `q_1,q_2 prime`,

PPI 给出相位

`Θ(q_1,q_2;r)=a(r)q_1^{-1}+b(r)q_2^{-1}+γ(r) mod p`。

有限复杂度窗口检测给出某窗口 `A` 满足

`|ν(A)-ν^0(A)| >= B/log^C X`，

其中 `B` 是主层可检测偏差质量。Fourier/Vaaler 展开把该偏差写成有限多个频率项与尾项误差之和。

## 2. 频率包标准化

设 `Ω(A,H)` 为窗口 `A` 在截断高度 `H` 下产生的非零 Fourier 频率集合。每个频率项都具有如下形式之一：

1. 单变量倒数和：`Σ α(q) e_p(h a(r)q^{-1})`；
2. 双变量倒数和：`Σ α(q_1,q_2,r) e_p(h a(r)q_1^{-1}+h b(r)q_2^{-1})`；
3. 由有限并差、Bohr 切片或交窗口产生的有限乘积项。

固定复杂度保证 `#Ω(A,H)<=log^C X`。因此若总窗口偏差达到 `B/log^C X`，则存在一个规范频率包承载至少 `B/log^{C'}X` 的偏差；否则所有频率项和尾项之和不足以解释窗口偏差。

## 3. 第一分流：尾项与复杂度逃逸

若 Vaaler 尾项、硬边界误差或窗口并差复杂度承载主偏差，则由 `docs/rh-fourier-vaaler-tail-maintext-chain.md` 接收，并进入以下命名事件之一：

- `CE`：复杂度无界或窗口不能保持固定模板；
- `LSMP`：偏差集中于小质量原子或低质量相位片；
- `LV`：有效支撑体积低于主层容量；
- `NRC`：截断需要越过非共振完成和可控范围。

这一步只是三角不等式与有限复杂度 pigeonhole：若主偏差不在规范非零频率包内，就必在尾项、边界或复杂度失败项内；这些失败项已经有固定命名出口，不能自由回流到 PPI。

## 4. 第二分流：非共振频率

若规范频率包中存在不属于祖先短深度 span 的非零频率，则进入 `NRC/EXT`。主文闭合链见 `docs/rh-nrc-ext-maintext-closure.md`。理由如下。

非共振意味着该频率没有被前序 FCT 闭包解释，也不能由已有低维相位关系吸收。于是相应倒数指数和是一个真正的新完成和对象。若完成和上界成立，则该频率包不能承载 `B/log^{C'}X` 级偏差；若完成和上界失败，则失败本身就是 `NRC/EXT` 事件。

因此非共振频率不能作为 PPI 内部吸收通道。

## 5. 第三分流：共振频率

若所有主频率均落入祖先短深度 span，则进入 `FCT`。这是定义性但并非空洞的分流：

1. 祖先 span 的生成元有限，并由此前相位闭包步骤记录；
2. 当前主频率若全在该 span 内，则没有新增独立投影方向；
3. 偏差仍然显著，说明旧 span 内出现新的相位闭包关系、重复状态或离散势函数下降机会。

对应文档 `docs/rh-fct-closure-no-cycle-final-audit.md` 已把该情形整理为 `Seed -> Drift -> NewClosure -> NoetherDescent/RepeatState -> terminal` 的无循环事件图。故共振主频率不是自由终端，而是 FCT 终端输入。

## 6. 第四分流：投影容量与短簇

若频率包不是纯非共振，也不是纯 FCT 共振，而表现为投影质量在许多相近窗口中重复出现，则进入 `PI/SC/DSO` 三类容量终端。

- `PI`：存在高投影增量或 lacunary/dense 投影包；
- `SC`：相近物理窗中双锚复用过高，形成短簇；
- `DSO`：新增频率包可被 CRT martingale 或 square-function 坐标自然细化捕捉。

`docs/rh-pi-dense-dso-bridge-no-return-audit.md` 规定这些桥接失败不能无标记回流：非允许投影进入 `CE/FCT`，误差吞噬进入 `LV/LSMP/CE`，包重叠过高进入 `SC`。

## 7. PPI 输出链定理

**Theorem PPI-Terminal-Output-Chain（条件化终端版）。** 在 AAI 双锚主层、固定复杂度 PPI 窗口族、Fourier/Vaaler 截断和全局容量出口命名规则下，任一 PPI 可检测偏差必进入以下之一：

1. `NRC/EXT` 非共振完成和事件；
2. `FCT` 共振闭包事件；
3. `PI` 高投影增量事件；
4. `SC` 短簇/局部乘积容量事件；
5. `DSO` square-function/投影桥接事件；
6. `LV/LSMP/CE` 低体积、小质量或复杂度逃逸事件。

特别地，PPI 输出端不存在未命名的自由吸收通道。

**证明。** 由 PPI-U2 和 PPI-U3，主偏差落入有限 Fourier 频率包或尾项/复杂度项。尾项/复杂度项由第 3 节进入 `CE/LSMP/LV/NRC`。非尾项中，频率按是否落入祖先短深度 span 二分：不落入者由第 4 节进入 `NRC/EXT`，全部落入者由第 5 节进入 `FCT`。若频率质量通过投影包或短物理窗重复出现而不是单一频率包承载，则由第 6 节进入 `PI/SC/DSO`，其失败边再进入 `CE/FCT/LV/LSMP/SC`。这些分支穷尽 PPI-U3 的所有输出项，故结论成立。证毕。

## 8. 对全局无条件化路线的影响

本文把 PC3/OV2 链条中 PPI 输出端的剩余义务从“PPI 产生若干终端”细化为一条可审查分流：

`可检测偏差 -> 频率包/尾项 -> 非共振、共振、投影容量、短簇、低体积/复杂度`。

下一步最优攻坚不应再重复 PPI 分流，而应选取最弱的下游终端继续主文化：优先顺序为 `NRC/EXT` 完成和上界、`FCT` 无循环闭包、`PI/DSO` 容量桥接、`SC` 局部乘积容量。
