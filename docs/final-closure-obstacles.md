## 2. 最后硬障碍

### 2.1 `B.0.4*` admissibility 核查

需要逐项确认附录 B 叶剥离产生的所有对象满足：

- `Q\le \log^{C_Q}P`；
- `b(a)` 在正常层是有限复杂度有理/CRT 可逆分片函数；
- `W(a)` 有统一有界变差或可分片为有界变差权；
- 非可逆分母、导数小、ramification、Jacobian 退化与步长共振均进入 `6.14` 六类坏层。

若某一项不满足 admissibility 且不落入坏层，则它是新的唯一剩余缺口。

### 2.2 `USC(log P)` 常数增长

需要把附录 A 的 connected cumulant 展开整理为正式引理，重点核查：

- `r≤c\log P` 下 Bell/Möbius 分区常数不爆炸；
- skeleton 计数与 tiny/near/far 三层 Rankin 账本可和；
- 中心化叶剥离在高模数 CRT 投影中只产生可吸收误差。

### 2.3 四点能量到 UAS 的逆推

需要确认四点能量异常确实反推短弧少根性失败，且所有退化四元组已经被：

- 对角/半对角计数；
- `4E-DISP`；
- 离散 coarea；
- `DBA-closure` 坏层矩阵

完整覆盖。

### 2.4 列方向坏列整数化

列命题的最终闭合需要把坏列期望/概率界严格转成坏列数 `<1`，并核对容量比较中 `e^{-γ}>2(1-α)` 的余量没有被对数损失吃掉。

### 2.5 显式阈值与有限验证

当前数值验证仅覆盖 `P≤1000`。若论文要声明“所有奇素数”，必须先从所有渐近估计中抽取显式 `P_*`，再运行：

```bash
python3 experiments/verify_finite_p_grid.py --max-p P_* --quiet
```

## 6. 本轮新推进：admissibility 与相消分层

## 6.18 sawtooth 相消链条严写补充

新增 `6.18` 节把硬窗口 `B.0.4*` 的 sawtooth 相消拆成三段：`LV` 大 Fourier 值反推短弧集中，`AE` 短弧集中反推四点厚化能量异常，最后由四点 rank、离散 coarea 与 `DBA-closure` 排除异常。该节还把旧的 `FNL/NL => B.0.4S-short` 主线修正为 `FNL/NL => B.0.4*`，平滑素数权接口继续只作为备选路线。

当前最后审稿点进一步缩小为：AE 层化损失 `L^3` 是否保持对数幂，以及 coarea/DBA 坏层覆盖是否无遗漏。


## 6.18.2 AE 层化能量严写补充

本轮专攻 `AE`：把原先粗略的 `M^4/L` 四点能量下界修正为安全的层化 Holder 下界 `M^4/L^3`。新增短弧层化定义、层化四点能量引理和严写版 `AE` 命题。结论是：若 `L=O(1)` 或 `L\le\log^{O(1)}P`，该损失可由参数余量吸收；若某分片导致 `L` 超过对数幂，则它不再是组合能量问题，而必须作为分母、导数或 ramification 坏层进入 `DBA-closure`。

这次修正提高了逻辑严谨性：短弧集中并不无条件给出过强能量下界，而是经层化后给出可审查的厚化四点异常。


## 6.18.1 LV 加权 van der Corput 严写补充

本轮专攻 `LV`：将原先概略的“大 Fourier 值反推短弧集中”拆成三个标准引理：加权 van der Corput、大值给出大相关步长、相关大值反推短弧集中。新增了权重总变差 `Var(W)` 的显式账本，说明 Stieltjes 卷积权在 dyadic 正常盒内只带来对数幂损失，由 6.15 参数余量吸收。共振步长 `q|h`、`q|mT` 与分母不可逆层继续交由 6.14 的步长共振层和分母层处理。

这使 `LV` 从直觉性反推变成可审查链条；本轮后 `W_h` 的有界变差继承与共振步长剔除已被写成独立微引理，剩余只需在最终审稿中核对其参数常数。


## 6.18.1d--e 权重继承与非共振密度补充

本轮继续排除 `LV` 的两个最小硬点：新增 `W_h` 变差继承引理和非共振步长密度引理。`W_h(a)=W(a+h)W(a)` 的变差由乘积变差不等式控制，保持对数幂损失；坏步长由 `q|h`、`q|mT` 和分母不可逆因子生成，在步长平均中贡献 `O(1/q+1/H)`，由 6.14 的 DBA-closure 与 6.15 的 `B_4` 余量吸收。

因此 `LV` 的剩余问题不再是结构性缺口，而是最终参数常数复核。
