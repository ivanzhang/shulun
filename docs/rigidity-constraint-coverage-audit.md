# 矛盾场方程中的刚性约束覆盖审计

**状态：** 审计与路线校正；不是最终证明。

## 1. 已进入矛盾场的刚性约束

### 1.1 小素数多同余壳刚性

已进入。对应方程：

`S_B(x)={c: xP+c not≡0 mod p, p in B}`。

这包含：

- 奇偶壳 `B={2}`；
- `{2,3,5,7}` 的多同余壳；
- 相位移动时禁余类平移 `a_p(y)-a_p(x)=-(y-x)P mod p`。

文件：`docs/small-prime-shell-dynamics-lemma.md`。

### 1.2 层叠剥离衰减刚性

已进入。对应嵌套链：

`S_0(x) superset S_1(x) superset ... superset S_m(x)=H_P(x)`。

每加入一个根基素数，候选壳被一个同余类切去。该链精确表达小素数约束逐步累积。

文件：`docs/layered-decay-contradiction-field.md`。

### 1.3 覆盖容量与重叠能量刚性

已进入。核心恒等式：

`|H_P(x)|=|S_j(x)|-C_j(x)+E_j(x)`。

它表达：覆盖能力不是容量总和，而是容量扣除同余锁相重叠后的并集。

文件：`docs/odd-shell-overlap-energy-route.md` 与 `docs/layered-decay-contradiction-field.md`。

### 1.4 短差同因子互斥

已部分进入。事实：若 `q>|c_2-c_1|`，同一 `q` 不能同时覆盖短差两点。

该事实已用于短 gap 核、patch-release 与 LD-1，但还未完全升级为全局不等式。

文件：`docs/ose-local-patch-release-lemma.md`。

### 1.5 局部补洞释放刚性

已进入候选引理。补掉旧短差核的前窗口相位会释放新洞：

`release(y;x)=|H_P(y)\H_P(x)|>=1`。

实验支持强，但严格证明仍是待攻硬点。

文件：`docs/ose-local-patch-release-lemma.md`。

## 2. 尚未完整进入矛盾场的刚性约束

### 2.1 CRT 周期列均衡刚性

只在路线层提到，尚未进入主方程。

已知：完整 CRT 周期内，除第 `P` 列外，各列的类素数数量相等。

需要加入一个列缺陷流变量：

`D_c(I)=# {r in I: c in H_P(r-1)} - expected(I)`。

反例若在前窗口产生零行，会对某些列缺陷流造成异常下冲；列均衡要求周期内补偿回流。

缺口：尚未证明这种补偿与镜像/首零行最小性矛盾。

### 2.2 CRT 镜像密度刚性

已有独立文档，但未并入层叠场。镜像为：

`A(r)=A(M+1-r)`，列映射 `c -> P-c`。

应加入镜像势：

`MirrorDef(r)=A(r)-A(M+1-r)=0`。

反例前窗口零行会镜像到周期末端零行；这本身不矛盾，但会约束密度波的补偿位置。

缺口：需要把前端零洞与末端零洞之间的中段高密度补偿写成不等式。

### 2.3 相邻商互质刚性

尚未充分形式化。用户指出：相邻数必须由不同因子解释，同余链上的相邻商必须互质。

应进入为局部标签图约束：

若列 `c,c+1` 都被覆盖，其解释标签 `q_c,q_{c+1}` 必不同；同一标签链上相邻商互质限制可形成路径能量。

缺口：尚未形成可用于排除零行的图论不等式。

### 2.4 行列长宽增长 vs 覆盖能力增长

已通过壳大小与容量账本部分表达，但仍缺明确数量级定理。

当前方程给出：

`|S_B| ~ P prod_{p in B}(1-1/p)`。

剩余大素数层多数每层只覆盖 `0/1` 个壳点，但同步补多个点有 CRT 跨窗压力。

缺口：需证明一个显式“剩余壳规模 - 大层有效并集”正下界，而不是只做实验观察。

### 2.5 列命题刚性

当前主场主要是行命题。列命题除第 `P` 列外，每列有素数，还未完全进入同一个矛盾场。

列方向可用数列 `c+kP`，等价于固定列的短区间/同余约束。需要单独定义列壳与行壳的对偶场。

## 3. 核心反例方程

前窗口行反例等价于存在 `1<=x<P` 使：

`H_P(x)=empty`。

在任意层 `j`，这等价于零场方程：

`|S_j(x)|=C_j(x)-E_j(x)`。

反例必须同时满足：

1. 小素数壳迁移不释放新洞；
2. 中层容量刚好抵消重叠；
3. 大层唯一补点不产生 CRT 跨窗；
4. 列均衡与镜像补偿不产生周期性异常。

因此后续应集中证明至少一个条件必失败。

## 4. 数量级差异的正确表达

不能简单说“斜线覆盖能力不够”，因为原始容量可能超过行宽。正确数量级差异是：

`有效覆盖能力 = 原始容量 - 强制重叠 - CRT同步损耗`。

小素数层增长带来候选壳衰减；但随着 `P` 增长，剩余壳仍线性增长，而大素数层的多点同步能力受 CRT 模数乘积限制。

应证明的量级不等式形态：

`C_j^{eff}(x) := C_j(x)-E_j(x) <= |S_j(x)|-1`。

对零行反例，它必须反向为等号或超过，故矛盾。

## 5. CRT 周期排斥反例的接口

若前窗口存在零行 `x<P`，则在完整周期 `M=prod_{q<P}q` 中有同相位复现。

但更强约束是：零行的局部壳签名、镜像零行、列均衡补偿必须同时存在。可定义周期场：

`F(r)=|H_P(r-1)|`，

满足：

- `F(r+M)=F(r)`；
- `F(r)=F(M+1-r)`；
- 各列在周期中总出现次数相等。

反例会令 `F(x+1)=0` 出现在前窗口。要排斥它，需要证明前窗口零点强迫一个不允许的补偿波形，例如：过早零点会使某些列缺陷流无法在镜像与均衡条件下回补。

这是尚未闭合的周期性硬点。
