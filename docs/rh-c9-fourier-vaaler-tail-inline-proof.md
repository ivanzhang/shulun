# C9 Fourier/Vaaler 尾项内联证明

本文补 `docs/rh-merge-unconditional-checklist.md` 中的 C9。目标是把 DGap、PPI、PC4 中的 Fourier/Vaaler 尾项处理改写为单篇合并稿可直接引用的编号引理。本文只处理尾项逻辑本身；Vaaler 定理的正式书目、定理号和页码归入 C10。

## 1. 允许模板族

正式主稿只允许固定复杂度模板。每个模板由以下原子经固定次数并、交、差和有限线性组合生成：

1. 平滑物理窗 `W(n/X)` 与 dyadic Whitney 窗；
2. 硬边界区间的平滑替代；
3. dyadic 层标签 `Q,R`；
4. CRT 字符原子；
5. 倒数环带 `ξx^{-1} mod p ∈ I`；
6. Bohr 短弧或一维短区间原子。

若出现无界坐标数、无界布尔深度、无界关系高度或非 dyadic 端点堆叠，则不属于 C9 模板族，而按定义进入 `CE/LSMP/FCT/SC/LV` 中的相应复杂度或边界事件。

## 2. Lemma C9.1：单原子尾项平方可和

**Lemma C9.1（Atomic tail）。** 对每个允许原子，存在平滑参数 `η_k` 与截断高度 `H_k`，使尺度列上的尾项满足

`Σ_k ||r_{k}||_2^2 < ∞`，

除非该原子触发已命名出口 `CE/LSMP/LV/SC/DSO/PI`。

**证明。** 平滑物理窗具有快速 Fourier/Mellin 衰减；取 `H_k>=k^4` 即得任意多项式衰减，故平方可和。硬边界先以宽度 `η_k` 平滑，边界层贡献为 `O(η_k^{1/2})`，截断尾为 `O((H_kη_k)^{-1})`；取 `η_k=k^{-4}`、`H_k=k^8log^Ck` 得 `O(k^{-2})` 尾项。若边界层承载固定比例异常，则它正是 `LV/LSMP/SC` 事件。倒数环带与 Bohr 短弧由一维 Vaaler/Beurling--Selberg 截断给 `O(H_k^{-1}+η_k^{1/2})` 型误差；同样选择参数得平方可和。CRT 字符是精确 Fourier 基元素，无截断尾项；若字符数量无界，则进入 `CE` 或新增独立频率包的 `DSO/PI`。证毕。

## 3. Lemma C9.2：固定布尔组合稳定性

**Lemma C9.2（Boolean stability）。** 若固定个数原子满足 `a_i=m_i+r_i`，且 `Σ_k||r_{i,k}||_2^2<∞`，则任一固定复杂度布尔组合也可写为主项加尾项，且尾项平方可和。

**证明。** 并、交、差可由加法、乘法和有限线性组合展开。所有指标函数、平滑主项在 `L^∞` 中有统一固定界。展开中含至少一个尾项的部分满足

`||R_k||_2 <= C_T Σ_i ||r_{i,k}||_2`。

固定原子数下由 Cauchy 得

`Σ_k||R_k||_2^2 <= C_T' Σ_iΣ_k||r_{i,k}||_2^2 <∞`。

故固定布尔闭包保持平方可和。证毕。

## 4. Lemma C9.3：有限重叠下的盒族求和

**Lemma C9.3（Box summation）。** 对 C5/DGap 盒族 `𝓑`，若点态有限重叠

`Σ_{B∈𝓑}1_B(n)<=log^C X`

成立，则 C9.1--C9.2 的尾项在盒族能量估计中至多产生 `log^C X` 损失，仍为 `X^{o(1)}` 可吸收。若有限重叠失败，则进入 C5.1 已命名出口。

**证明。** 盒函数由物理窗、dyadic 标签、CRT/Bohr 相位窗和平滑边界组成；dyadic 标签无 Fourier 尾项，其余由 C9.1 控制，组合由 C9.2 控制。求和到盒族时，有限重叠给 Schur/Cotlar 型 `log^C X` 算子范数损失。由于全局常数层级允许固定多对数损失，该损失吸收到 `X^{o(1)}`。有限重叠失败已由 C5.1 定义为 `LV/SC/CE/LSMP/FCT` 出口。证毕。

## 5. Lemma C9.4：高频异常的命名出口

**Lemma C9.4（No free high-frequency tail）。** 若某尺度列上高频尾项承载固定比例异常，则该异常不能作为新误差项保留；它必进入 `CE/LSMP/FCT/SC/LV/DSO/PI` 之一。

**证明。** 高频尾项承载异常只有四种来源：模板复杂度无界、边界层/短窗集中、新增独立频率包、或频率落入低维祖先 span 并产生相位漂移。它们分别是 `CE/LSMP`、`SC/LV`、`DSO/PI`、`FCT/SC` 的定义入口。因此“尾项失败”不是自由失败，而是已命名结构事件。证毕。

## 6. Theorem C9：尾项内联闭合

**Theorem C9-Fourier-Vaaler-Tail-Inline.** 对合并稿中任一固定复杂度 PPI/DGap/PC4 模板，存在分解

`ψ_k=ψ_{k,main}+ψ_{k,tail}`，`Σ_k||ψ_{k,tail}||_2^2<∞`。

若平方可和分解失败，则失败必进入

`CE/LSMP/LV/SC/FCT/DSO/PI`。

因此 Fourier/Vaaler 尾项不形成新的无条件化缺口；它只依赖 C10 中 `EXT-Vaaler` 的正式引用。

**证明。** C9.1 处理所有单原子。C9.2 证明固定布尔组合稳定。C9.3 说明 DGap/PPI 盒族有限重叠只造成多对数损失。C9.4 排除高频异常作为自由尾项残留。故尾项要么平方可和吸收，要么进入已命名事件。证毕。

## 7. 对割集的影响

C9 可从“待内联”更新为“已内联，待 C10 的 `EXT-Vaaler` 正式引用”。剩余真正割集变为：

`{C1, C4, C6, C10, C11}`。
