# LD-2w：小壳迁移不能把极小核降到空集

**状态：** 候选证明接口；实验支持，无条件证明待补。

## 1. 命题形式

固定小素数前缀 `B`，例如 `{2,3}`、`{2,3,5}` 或 `{2,3,5,7}`。

设 `K=H_P(x)` 是前窗口中某个偏序极小残洞核。若 `1<=y<P` 满足：

1. 小壳签名改变：`S_B(y) != S_B(x)`；
2. 旧核被全补掉：`K ∩ H_P(y)=empty`；

则应有

`H_P(y) nonempty`。

这就是 LD-2w：小壳迁移可以移动残洞核，但不能把极小核净消成空集。

## 2. 实验事实

`ld2w-full-kernel-kill-scan` 对 `B={2,3}`、`{2,3,5}`、`{2,3,5,7}` 与多个 `P` 扫描：

- 没有发现 `H_P(y)=empty`；
- 最优转移通常满足 `|H_P(y)|>=|K|`，少数为同大小核迁移；
- 新洞来源可分为 `OuterEscape` 与 `InnerRelease`。

典型：

- `P=23, K=[9,15]` 迁移到 `[12,16,22]` 或 `[6,10,18]`；
- `P=29, K=[12,18,28]` 迁移到 `[1,19,25]` 或 `[5,13,23]`；
- `P=83` 多个大小为 `6` 的核互相迁移，但不降到空集。

## 3. 反证结构

假设 LD-2w 失败，即存在 `y<P` 使

`K ∩ H_P(y)=empty` 且 `H_P(y)=empty`。

则 `y` 是前窗口零行。对小壳 `S_B(y)`，剩余层必须全覆盖：

`S_B(y) subset U_{>B}(y)`。

于是层叠零场方程成立：

`|S_B(y)|=C_{>B}(y)-E_{>B}(y)`。

但小壳签名改变意味着 `S_B(y)` 不是旧壳；它包含新释放区 `S_B(y)\S_B(x)`，同时旧核补洞要求剩余层或小层额外覆盖 `K`。这给剩余层造成双重任务：

1. 覆盖新释放区；
2. 覆盖旧核残余；
3. 不释放原壳中已覆盖列。

应证明这三者不能同时满足零场等式。

## 4. 可证化分解

将 `H_P(y)` 分解为：

`H_P(y)=OuterEscape ∪ InnerRelease`，其中

`OuterEscape=(S_B(y)\S_B(x))\U_{>B}(y)`，

`InnerRelease=H_P(y)∩S_B(x)`。

若 `H_P(y)=empty`，则两者同时为空：

- `OuterEscape=empty`：新壳差集被剩余层全覆盖；
- `InnerRelease=empty`：旧壳内部无释放。

因此 LD-2w 等价于证明二者不能同时为空。

## 5. 下一步硬核不等式

需要证明：

`Cover_{>B}(S_B(y)\S_B(x)) + Cover_{>B}(K_remaining)`

若达到全覆盖，则必产生重叠能量增量

`ΔE_{>B}`，使

`C_{>B}(y)-E_{>B}(y) <= |S_B(y)|-1`。

换言之，小壳迁移带来的新任务会吞掉至少一个有效覆盖单位。

## 6. 与列均衡的连接

若 LD-2w 成立，则任何小壳迁移都只会把核从列集 `K` 移到新列集 `H_P(y)`。这给列缺陷流一个受限转移：

`D_K` 的下冲必须由 `D_{H_P(y)}` 的上冲补偿。

由于 `H_P(y)` 由小模数壳差与中大层重排决定，它不能任意选择；这为 CRT 周期列均衡排斥前窗口零行提供接口。

## 7. 下一步最优攻坚

继续证明第 5 节的不等式。具体从两个子情形入手：

1. `OuterEscape=empty`：证明新壳差集全覆盖会强制产生重叠能量；
2. `InnerRelease=empty`：证明旧壳内部无释放会强制标签链保持，和补旧核的同余要求冲突。
