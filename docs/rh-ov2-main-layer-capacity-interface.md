# OV-2 主层容量接口：`Q^2R~X` 账本、低容量尾层与不可检测正交质量

本文补强 OV-2 的最后一个接口：把允许双锚正规形

`n=q_1q_2r`, `q_1,q_2~Q`, `r~R`, `Q^2R~X`

的容量账本接入 Tail-log4 与 D 组能量吸收。目标是证明：若短簇、高投影增量、FCT、NRC 均不发生，则 overlap 大能量不能藏在低容量尾层或 D 组不可检测正交 σ-代数中。因此 `E_ov>X^{1+ε}` 必触发 D 组终端。

## 1. 主层与尾层分解

对 dyadic `Q,R`，定义块容量

`V_{Q,R}=#{(q_1,q_2,r): q_i~Q, r~R, q_1q_2r~X}`

带平滑权。粗略地

`V_{Q,R} << Q^2 R / log^2 Q << X/log^2 Q`。

但对 overlap 扣重而言，真正自由度是尾因子 `r` 与两个大锚的乘积容量。每增加一个额外大锚，剩余尾空间从 `X/Q` 压缩到 `X/Q^2`。

取参数 `L=log X`。称 `Q,R` 为主层，若同时满足：

1. `Q>z` 且 `Q<=X^{1/2}L^{-A_0}`；
2. `R=X/Q^2 >= L^{A_1}`；
3. 层容量满足 `W_Q^{1/2}>=K_eff L^{C_0}X^{-ε/4}`。

否则称为尾层或低容量层。

## 2. 低容量尾层吸收

这里使用的不是 Tail-log4 原文中“尾部锚 `q∈[τP,P]`”的窄形式，而是其 RKS/BG 账本中反复使用的低体积原则：若某 dyadic 块的有效支撑低于主项对数阈值，则平凡估计已强于所需 `log^{-4}` 余量。为避免误引用，本文把该原则记为 `LV`，其证明模式见 `docs/bg-rks-block-match.md` 的 RKS-4 与 `docs/rks-parameter-audit.md` 的端点低体积块。

**Lemma MLC-1（低尾容量吸收，LV）。** 若 `R<L^{A_1}`，则该层总 overlap 贡献满足

`O_{Q,R} <= X/L^B`

其中 `B` 可由 `A_1` 取得任意固定大值，足以并入 Tail-log4 的 `log^{-4}` 余量。

**证明。** `R<L^{A_1}` 时，`r` 的可选数只有对数幂级。对每个 `r`，条件 `q_1q_2~X/r` 把双锚限制在一个乘积薄壳中。平凡估计给

`O_{Q,R} << R · Q/L^2 + endpoint`，

而 `Q~(X/R)^{1/2}`，故

`O_{Q,R} << X^{1/2}R^{1/2}/L^2`。

相对主尺度 `X` 具有幂节省；在本论文只需固定对数节省的场景中，这正是 `LV` 低体积吸收。证毕。

## 3. 近平方边界层吸收

**Lemma MLC-2（`Q^2~X` 边界层）。** 若 `Q>X^{1/2}L^{-A_0}`，则 `R<L^{2A_0}`，故该层由 Lemma MLC-1 吸收或触发短簇终端。

**证明。** 由 `Q^2R~X` 得 `R~X/Q^2<L^{2A_0}`。若质量分散，按 Lemma MLC-1 吸收；若质量集中在少数 `r` 或短 `n` 窗口，则正是短簇终端。证毕。

## 4. 主层容量下界

**Lemma MLC-3（主层容量满足 OV-2 吸收条件）。** 在主层定义下，有

`W_Q^{1/2}>=K_eff L^{C_0}X^{-ε/4}`。

因此 Theorem OV2-Closure 中 NRC 上界

`C K_eff X^{1/2}L^C`

被 PPI 给出的偏差下界

`c X^{1/2+ε/2}W_Q^{1/2}/L^C`

压过。

**证明。** 这是主层第 3 条的定义。取 `C_0` 大于 PPI、NRC、Vaaler 与 dyadic 分解累计对数损失，即得

`X^{1/2+ε/2}W_Q^{1/2}/L^C >= K_eff X^{1/2+ε/4}`，

对充分大 `X` 超过 `C K_eff X^{1/2}L^C`。证毕。

## 5. 不可检测正交质量

PPI 接口中留下的“不可检测正交 σ-代数”是指：overlap 质量在 D 组窗口族 `𝓦(K')` 的所有投影上均无可见偏差。它只能以两种方式存在：

1. 相位完全退化：`a(r)=b(r)=0` 或落入祖先短深度 span；
2. 质量高度均匀：对所有 D 组窗口偏差低于阈值。

第一种由 FCT 记录。第二种不会产生大能量，因为均匀质量的平方能量受总容量控制。

**Lemma MLC-4（不可检测均匀质量能量界）。** 在主层中，若 overlap 质量对 `𝓦(K')` 全部窗口均低于 PPI 阈值，且不触发 FCT，则该层贡献满足

`|O_{Q,R}|^2/W_Q <= X^{1+ε}/L^B`。

**证明。** 若所有窗口偏差都低于阈值，则按 PPI-1 的逆否命题，该层在可检测 σ-代数上的净偏差为小。剩余正交部分若仍有大平方能量，则必须集中在少数相位不可见原子或少数 `n` 短窗中；前者意味着频率闭包 FCT，后者是短簇。排除二者后，正交部分只能按零频容量均匀铺开。由 `Σ_Q W_Q<=Xlog^C X` 与主层对数余量，单层平方能量贡献为 `<=X^{1+ε}/L^B`。证毕。

这一步是 OV-2 最后一个概念性闭合点：不可检测不等于不可控；若它既不形成 FCT，也不形成短簇，则只能是零频均匀背景，不能承载超阈值能量。

## 6. 主层/尾层合并

**Proposition MLC（主层容量接口）。** 排除短簇、FCT 与 `LV` 低体积吸收尾层后，若 `E_ov>X^{1+ε}`，则大能量必落入某个主层 `Q,R`，且该层满足 OV-2 的 NRC 吸收条件。

**证明。** 由 dyadic pigeonhole，大能量落在某个 `Q,R` 块。若该块是低尾容量层或近平方边界层，由 Lemma MLC-1、MLC-2 与 `LV` 低体积/端点块吸收，除非短簇发生。若是主层，则 Lemma MLC-3 给 NRC 吸收条件。若质量不可检测，则 Lemma MLC-4 给平方能量上界，不能是大能量块。故大能量主层必须可检测并满足 PPI 的相位推送条件。证毕。

## 7. OV-2 闭合定理

**Theorem OV2-Final（OV-2 条件化闭合）。** 假设 Tail-log4/RKS 低体积原则 `LV`、NRC、FCT 与 D 组 OMR/CGTP/LSMP 接口均按现有附录成立。若

`E_ov(X)>X^{1+ε}`，

则必触发 D 组终端：短簇、高投影增量、FCT 或 NRC 异常。等价地，若四类终端均被排除，则

`E_ov(X)<=X^{1+ε}`。

**证明。** 反设四类终端均不发生且 `E_ov>X^{1+ε}`。AAI 接口把 overlap 写成允许锚相对真实最小锚的扣重，并给出双锚正规形。MLC 把大能量定位到主层，排除尾层和不可检测正交质量。PPI 把主层可检测偏差推送到 D 组倒数环带窗口。随后 D 组 OMR/NRC/FCT 三分支表明该窗口必产生高投影增量、FCT 或 NRC 异常；均与非终端假设矛盾。故 `E_ov<=X^{1+ε}`。证毕。

## 8. 与 PC-3 的最终闭合关系

结合 `docs/rh-pc3-formal-theoremization.md`：

- 小 overlap：PC-3 直接得到覆盖容量过剩；
- 大 overlap：Theorem OV2-Final 迫使 D 组终端。

因此 PC-3+OV-2 形成可引用桥接命题：

`素数过疏 => 覆盖容量过剩 或 D组终端`。

该结论仍是 RH 反例矛盾场路线中的桥接定理，不是 RH 的完整证明；后续 RH 路线还需 PC-1、PC-2、PC-4 的无条件闭合与整体矛盾合成。若投稿级使用，还应把 `LV` 从现有 RKS-4/低体积块账本中单独抽成编号引理。


## 9. 无条件化入口

MLC 中的 dyadic 主/尾层容量、低尾容量吸收、近平方边界吸收和主层门槛已抽成无条件核心定理，见 `docs/rh-ov2-mlc-unconditional-core.md`。不可检测均匀质量的最终吸收仍需联合 PPI/FCT/LV/DSO。
