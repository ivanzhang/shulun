# Q_eff 分桶筛上界路线

**状态：** 专攻 `Effective_j` 上界；检验能否推出 `Q_eff<=βN`。

## 1. 有效锚的筛计数形式

固定列 `c` 与锚素数 `q>D=sqrt(P)`。它在行窗口 `[0,P)` 中命中

`k=r_q+nq`, `0<=k<P`。

命中点成为粗候选还需

`kP+c` 避开所有小素数 `p<=D`。

因为 `q|kP+c`，写

`kP+c=q m`。

当 `k=r_q+nq` 时，`m` 是关于 `n` 的线性函数：

`m=m_0+nP`。

所以有效锚命中数等于短等差序列

`m_0, m_0+P, ..., m_0+(L_q-1)P`

中避开所有小素数 `p<=D, p≠q` 的项数，其中

`L_q=1+floor((P-1-r_q)/q)≈P/q`。

由于 `P` 与所有 `p<=D` 互素，该序列模 `p` 均匀避开一个禁余类。

## 2. 上界筛目标

需要证明

`S(q):=#{0<=n<L_q: m_0+nP not≡0 mod p for all p<=D}`

满足

`S(q) <= C L_q / log D + O(1)`。

因 `log D=(1/2)log P`，这就是

`S(q) <= C' L_q/log P + O(1)`。

于是锚 `q` 有效的条件是 `S(q)>=1`。用 Markov 型求和：

`Effective_j <= Σ_{q in B_j} S(q)`。

因此

`Effective_j <= C' /log P * Σ_{q in B_j} P/q + O(#B_j_small_error)`。

对 `q≈2^jD`，得

`Effective_j <= C' #B_j * sqrt(P)/(2^j log P) + error`。

这正是分桶估计。

## 3. 关键误差问题

若对每个 `q` 都有 `O(1)` 误差，求和得到 `O(#B_j)`，在高桶会压倒主项，无法给有效率损耗。

因此不能使用逐 `q` 的粗误差。必须用平均上界：

`Σ_{q in B_j} S(q) <= C' /log P * Σ_{q in B_j} P/q + acceptable error`。

这需要把 `q` 与 `n` 双重求和，作为二维筛问题处理。

## 4. 二维筛重写

有效锚出现对为 `(q,k)`，满足：

- `q in B_j`；
- `q|kP+c`；
- `kP+c` 避开所有 `p<=D`。

等价于数

`N=kP+c`

有一个锚因子 `q in B_j`，且 `N/q` 避开小素数。

计数为

`Occ_j = Σ_{k in R} #{q in B_j: q|kP+c}`。

这是桶内锚出现数，而 `Effective_j <= Occ_j`。

若能证明

`Occ_j <= C_j N_j`

并与桶结构结合，可得 Qeff 上界。

## 5. 与半素数筛的关系

`Occ_j` 本质上统计列中数 `kP+c` 的一个因子落在 `B_j`，另一个余因子避开小素数。它是半素数/粗合数层计数。

标准筛预期：

`Occ_j ≈ P * (Σ_{q in B_j} 1/q) * δ_D`。

其中 `δ_D≈1/log P`。而粗候选总数

`N≈P δ_D`。

所以

`Occ_j/N ≈ Σ_{q in B_j}1/q ≈ log 2 / log(2^jD)`。

求和所有桶得到约 `log log P` 量级出现数；但有效种类数 `Qeff` 不等于出现数，高桶出现数约种类数，低桶复用较多。

## 6. 常数困难

上述期望给 `Occ_total` 可能大于 `N`，所以单靠 `Occ` 上界不能推出 `Qeff<N`。

需要结合：

- 低桶：`Qeff_j` 数量少，虽 `Occ_j` 大；
- 高桶：`Qeff_j≈Occ_j`，但 `Occ_j/N` 按 `Σ1/q` 衰减；
- 中桶：需优化分界。

## 7. 分界优化框架

取阈值 `Y=D L`。

低锚 `D<q<=Y`：

`Q_low <= π(Y)-π(D) ≈ Y/log Y = D L/log P`。

相对 `N≈P/log P`，比例约

`Q_low/N ≈ L/D`，很小，只要 `L<<D`。

高锚 `q>Y`：每个有效锚出现次数通常 1，因此

`Q_high <= Occ_high`。

而

`Occ_high/N ≈ Σ_{q>Y}^{P} 1/q ≈ log(log P/log Y)`。

若取 `Y=P^θ`，则该比例约 `log(1/θ)`。

要使 `<1`，需 `θ>e^{-1}`。也就是高锚从 `P^θ` 起才有明显小于 1 的总比例。

中间 `D<q<=P^θ` 不能简单处理，需要利用复用与冷却能量。

## 8. 结论：单纯筛上界不足

分桶筛上界给出了正确机制，但单独不足以直接证明 `Qeff<=βN`。真正可行的是三段法：

1. 低桶数量小；
2. 高桶筛出现总量小；
3. 中桶若要覆盖很多顶点，必产生复用能量 `E`，进入联合能量矛盾。

因此 `Qeff<=βN` 可能不应单独证明，而应替换为带 `E` 的联合上界：

`Qeff + σ E <= β N` 或 `Qeff <= βN + τE`。

## 9. 下一步硬攻方向

把目标改为联合分桶不等式：

`Qeff - τE <= βN`。

低桶的高有效率由高复用 `E` 付费；高桶由筛损耗控制；中桶在两者之间优化。

这比单独 `Qeff<=βN` 更符合实验：低桶贡献的 `Qeff` 不大但复用高，高桶复用低但有效率低。

## 10. 参数试探

基于已有联合能量扫描，`Qeff-τE<=βN` 具有明显余量。保守目标可先设为

`Qeff - 0.1E <= 0.7N`。

该不等式允许低桶通过复用能量付费，同时要求高桶由筛损耗控制。下一步应对三段桶分别证明这一式子的贡献上界。
