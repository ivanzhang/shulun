# PC4-FCT-Seed：频率闭包跨尺度种子命题

本文转攻 PC4-FCT。目标不是一次性排斥所有频率闭包，而是先证明一个可审查种子命题：若无穷多尺度的 RH 反例链条最终由 FCT 吸收，则可抽取固定低维频率 span、固定证书类型与同相位子列，使离线零点相位 `γ log X` 被同一个有限复杂度 CRT 频率模型长期编码。本文为后续真正排斥该编码做准备。

## 1. 单尺度 FCT 输出

由 `docs/fct-tree-wfe-theoremization.md`，在单尺度 D 组递推中，NRC 非共振失败或频率复杂度逃逸可产生证书

`ξ_v = Σ_i m_i ξ_i mod P`, `Σ_i |m_i| <= H`,

其中祖先频率集合 `Ξ_v={ξ_i}`、深度、倍频高度都由复杂度 `K` 的对数幂控制。若碰撞反复发生，则进入 frequency-closure terminal：后续频率都落入某个短深度低维 span。

单尺度 FCT 的信息包括：

1. 一个低维 span 类型；
2. 有界整数系数证书；
3. 一个对应的倒数/Bohr 相位窗口；
4. 该窗口吸收当前离线零点驱动偏差的符号信息。

## 2. 跨尺度固定类型抽取

**Lemma FCT-1（固定证书类型抽取）。** 若无穷多尺度 `X_j` 的异常均最终由 FCT 吸收，且复杂度不进入 LSMP/LV/PI 已处理的逃逸，则存在无穷子列与固定 FCT 证书类型 `𝓕_*`，使每个尺度上的 FCT 证书都是 `𝓕_*` 的自然缩放实例。

**证明。** 单尺度 FCT 证书的深度、span 维数、整数系数 `m_i` 的 `l^1` 大小、Bohr 切片种类与并差树形都由 `log^C K` 控制。按相对复杂度类型分层；若复杂度层无界，则按 `docs/rh-pc4-complexity-escape-interface.md` 转入已处理逃逸。固定复杂度层内只有有限种组合类型。无穷多个尺度落入有限类型之一，取该无穷子列。证毕。

## 3. 离线相位同向抽取

**Lemma FCT-2（离线相位短弧抽取）。** 对固定离线零点频率 `γ`，任意无穷尺度序列 `X_j` 存在无穷子列，使

`γ log X_j mod 2π`

落在同一个长度 `1/H` 的短弧内。取 `H` 足够大时，该子列上离线零点贡献的符号保持同向。

**证明。** 圆周有限分割 pigeonhole。符号稳定由平滑显式公式中同一零点项的连续相位依赖给出。证毕。

## 4. FCT 编码种子

固定类型 `𝓕_*` 后，每个尺度给出一个低维 span

`Span_{H_*}(Ξ_j)`。

自然缩放意味着 `Ξ_j` 由同一有限规则从尺度 `X_j` 的 CRT 模数、dyadic 层和倒数相位参数生成。于是 FCT 吸收离线零点异常可表述为：存在整数向量 `m` 与局部 CRT 频率 `ξ_i(X_j)`，使有效相位满足

`Φ_FCT(X_j)=Σ_i m_i ξ_i(X_j) mod P_j`

并在允许窗口上模拟离线相位 `γlogX_j` 的同向偏差。

**Proposition FCT-Seed（固定低维编码种子）。** 若无穷多尺度的高偏差最终由 FCT 吸收，并排除 Complexity-Escape、LSMP、LV、PC4-PI 终端，则存在：

1. 固定 FCT 类型 `𝓕_*`；
2. 固定短弧 `I_*⊂R/2πZ`；
3. 无穷子列 `X_{j_k}`；
4. 固定低维整数关系模板 `m`；

使得每个 `X_{j_k}` 上，FCT 频率闭包模型 `Φ_FCT(X_{j_k})` 在同一短弧相位方向上吸收离线零点项 `γlogX_{j_k}` 的偏差。

**证明。** 由 FCT-1 固定证书类型与低维整数关系模板；由 FCT-2 固定离线零点相位短弧。若某尺度无法由固定低维模型吸收同向偏差，则单尺度递推必须转入高投影增量、LSMP、LV 或 NRC 非共振分支，均被假设排除。因此剩余无穷子列给出所述固定低维编码。证毕。

## 5. 下一步真正排斥方向

FCT-Seed 把 PC4-FCT 的目标压缩为一个更具体的跨尺度不相容命题：

**PC4-FCT-Core（待攻）。** 固定有限复杂度 CRT 低维 span 不能在无穷增长尺度上同向编码连续相位 `γlogX`，除非产生可检测投影增量或短簇。

可攻方向有三条：

1. **相位漂移路线**：`γlogX` 的连续增量与 CRT 频率自然缩放的离散跳变不同步；
2. **CRT 新坐标路线**：每个新增素数层引入独立坐标，固定低维 span 无法长期预测新增坐标相位；
3. **容量路线**：若低维 span 长期吸收偏差，则同一 Bohr 交集上能量集中，触发 PC4-PI 或短簇。

新增 CRT 坐标相位漂移压力引理已在 `docs/rh-pc4-fct-phase-drift.md` 中写出：固定低维 span 若长期命中离线相位短弧，要么只有零频贡献，要么产生平方能量压力转入 PC4-PI/短簇/LSMP/LV，要么形成新的 FCT 闭包证书。下一步最优专攻是 `FCT-Noether`，排除 FCT 闭包证书无限递归。
