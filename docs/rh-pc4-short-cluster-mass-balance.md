# PC4-SC：短簇质量平衡命题

本文接续 `docs/rh-pc4-short-cluster-seed.md`。SC-Seed 已把无穷多短簇归约为固定短窗/低维 Bohr 交集模板 `S_*` 的同相位子列。本文建立质量平衡：固定短簇若在无穷多尺度承载 `X^β` 级偏差，则要么零频体积可求和而由 LV/LSMP 吸收，要么不可求和并产生 PC4-PI、PC4-A 或 PC4-FCT 输入。

## 1. 固定短簇模板

固定短簇模板 `S_*` 在尺度 `X` 上给出集合或平滑权 `S_X(n)`。记零频体积

`V_X = Σ_n S_X^0(n)W(n/X)`,

实际同向偏差

`D_X = Σ_n (S_X(n)-S_X^0(n))W(n/X)`。

SC-Seed 给出无穷子列，使

`D_X >= cX^{β-o(1)}`, `β>1/2`。

## 2. 可求和体积分支

**Lemma SC-M1（可求和体积吸收）。** 若固定短簇模板在同相位子列上满足

`Σ_X V_X < ∞`

或更一般地 `V_X <= X/log^{B+C}X` 并只产生对数损失，则该短簇贡献由 LV/LSMP 吸收，不能承载 `X^β` 级最终偏差。

**证明。** 若总零频体积可求和，则无穷子列上的总可用质量有限，不能持续提供离线零点级偏差。若逐尺度体积低于 `X/log^{B+C}X`，由 `docs/rh-lv-low-volume-principle.md` 的 LV 平凡估计吸收；若质量由许多小原子组成，则由 LSMP/coarea 吸收。证毕。

## 3. 不可求和体积分支产生结构压力

若 `V_X` 不可求和，固定短簇模板在跨尺度上有足够零频体积。此时同向偏差不能藏在低体积误差中，必须表现为可检测结构。

**Lemma SC-M2（不可求和体积到结构压力）。** 若固定短簇模板 `S_*` 在无穷多尺度上满足 `V_X` 不可求和且 `D_X>=cX^{β-o(1)}`，则至少发生一项：

1. `S_*` 作为允许投影窗口产生高投影增量，转入 PC4-PI；
2. `S_*` 作为覆盖组件产生 ACC 同步过剩，转入 PC4-A；
3. `S_*` 的低维 Bohr 相位反复锁定，转入 PC4-FCT；
4. 同一物理短窗承载过密锚复用，触发更强短簇密度矛盾。

**证明。** 不可求和体积意味着短簇模板不是低体积尾项。若偏差在相位/CRT σ-代数上可检测，则它给出投影窗口密度增量，进入 PC4-PI。若偏差表现为覆盖容量过剩，则进入 PC4-A。若偏差只在低维 Bohr 相位上可见且非共振失败，则进入 PC4-FCT。若三者都不发生，则偏差只能是同一物理短窗内的锚复用过密；这正是短簇密度矛盾的核心形式。证毕。

## 4. SC-Mass-Balance 主命题

**Proposition SC-Mass-Balance（短簇质量平衡，条件化）。** 固定短簇模板若在无穷多尺度上同向承载 `X^β` 级偏差，`β>1/2`，则至少发生一项：

1. LV/LSMP 低体积吸收；
2. PC4-PI 高投影增量；
3. PC4-A ACC 同步过剩；
4. PC4-FCT 频率闭包；
5. 物理短窗锚复用密度矛盾。

**证明。** 按零频体积 `V_X` 分二类。若可求和或低于 LV 阈值，由 SC-M1。若不可求和，由 SC-M2。证毕。

## 5. 下一步核心：短窗锚复用密度矛盾

由于 PC4-PI、PC4-A、PC4-FCT 已条件化闭合，SC-Mass-Balance 后只剩最后的短簇内部硬点：同一物理短窗内锚复用过密是否可能长期存在。

下一步最优专攻是 `SC-Local-Density`：证明固定短窗内若反复承载离线零点级锚复用，则违反乘积容量 `q_1q_2r`、CRT 非零类均衡或 LV 体积账本；否则转入已闭合分支。
