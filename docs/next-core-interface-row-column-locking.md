# 下一核心接口：行列双向闭锁引理

**状态：** `short_recurrence_bridge_reduced_to_row_column_locking`

相位回归实验表明：大因子标签集合的模数乘积通常很快超过 `P`。因此 CRT 矛盾的后半段是强的：一旦短复现需要稳定这些标签，就会立刻矛盾。

剩余唯一核心缺口是前半段：

> 如何从全行/全列覆盖反例推出短复现或短相位回路？

## 1. 为什么单行动力不够

单行全覆盖只说明每个列点有某条斜线经过。斜线继续向下推进后，各标签按不同模数漂移。没有额外条件时，覆盖图案可能只在完整 CRT 周期后复现；这本身不矛盾。

因此不能直接断言“全行覆盖推出短周期”。

## 2. 行列双向闭锁的思路

若存在反例，则可能存在：

- 某一行全覆盖；或
- 某一列全覆盖；或
- 方阵内某个极端覆盖结构同时压迫行与列。

行覆盖给出横向标签链；列覆盖给出纵向标签链。二者在格点交叉处必须使用同一个数 `N(r,c)` 的素因子结构，因此不是独立的。

这种交叉兼容可能强迫标签链形成短闭路：

`行相位推进 -> 列相位约束 -> 返回行相位`

若闭路步长小于 `P`，就进入 CRT 矛盾。

## 3. 候选闭锁引理

### 引理 RCL（Row-Column Locking）

假设 `P x P` 方阵内存在一条全覆盖行或全覆盖列，且所有未被小素数覆盖的洞都由大根基素数补掉。则存在一个非空大因子集合 `Q_*` 与一个短向量 `(u,v)`，满足

`0<max(|u|,|v|)<P`

并且对所有 `q in Q_*`，相位闭锁要求

`uP+v ≡ 0 mod q`。

若 `Π_{q in Q_*} q > |uP+v|`，则矛盾。

## 4. 这个引理为什么有希望

在方阵中，两个格点差为

`N(r+u,c+v)-N(r,c)=uP+v`。

如果同一大因子 `q` 同时解释闭锁链上的两个格点，则必有

`q | uP+v`。

但 `|uP+v| < P^2`，而每个大因子 `q>sqrt(P)`。只要闭锁链包含两个或更多独立大因子，乘积就可能超过可用差值尺度。

更局部地，若 `|u|,|v|` 都小，则 `|uP+v|` 远小于多个大因子的乘积，矛盾更强。

## 5. 下一步实验

构造交叉闭锁扫描：

1. 对每个格点记录其大因子标签；
2. 寻找小位移 `(u,v)`，使大量格点与其位移点共享或兼容大因子标签；
3. 计算这些标签的乘积是否超过 `|uP+v|`；
4. 若高覆盖结构总诱导这种闭锁，则可升级为 RCL 引理。

## 6. 下一步证明目标

证明一个组合事实：

> 若一整行被大因子标签链补满，则在 `P x P` 有限宽高盒中，该标签链不可能完全无交叉、无回归、无闭锁地穿过所有列；否则需要超过方阵可容纳的互素模数复杂度。

这就是从“全覆盖”到“短 CRT 矛盾”的桥。
