# PC-4：覆盖容量过剩与 D 组终端的最终排斥框架

本文专攻 RH 反例矛盾场路线中的 PC-4。PC-1 给出离线零点导致平滑素数异常；PC-2 把连续基线与 CRT 零频基线对齐；PC3-OV2 给出

`素数过疏 => 覆盖容量过剩 或 D组终端`。

PC-4 要回答最后问题：这两个输出为什么不能在 RH 反例场中长期存在？本文给出总攻前的严格框架，区分已经局部闭合的部分与仍需跨尺度攻克的核心硬点。

## 1. PC3-OV2 的两个输出

设离线零点产生无穷多尺度 `X_j` 上的过疏输入 `Δ_j=X_j^{β-o(1)}`, `β>1/2`。由 PC3-OV2，每个尺度至少发生：

1. **ACC 过剩分支**：

   `ACC_z(X_j)>=ACC_z^0(X_j)+cΔ_j`；

2. **D 组终端分支**：短簇、高投影增量、FCT 或 NRC 异常。

PC-4 的目标是证明这两类分支不能在无穷多尺度上吸收离线零点波动。

## 2. 局部终端的已知排斥

D 组附录已经证明一种局部命题：在固定尺度、固定坏配置、固定非终端假设下，短簇/高投影增量/FCT/NRC 的排斥机制会迫使坏配置停止或产生矛盾。形式上：

`非终端持续推进 => 平方能量递增 => 超过总能量上界`。

这说明单个尺度中的“结构性坏配置”不能无限递推。

但 RH 反例产生的是无穷多个尺度上的波动。局部排斥还不足以排除“每个尺度触发一个不同终端并被局部消化”的可能性。因此 PC-4 的关键是跨尺度排斥。

## 3. ACC 过剩分支的排斥目标

ACC 过剩表示允许合数覆盖容量相对零频基线同步增加。若这种过剩在无穷多 `X_j` 上跟随离线零点相位出现，则形成一个全局覆盖容量波：

`𝓐(X_j)-𝓐^0(X_j) >= cX_j^{β-o(1)}`。

**PC4-A（ACC 不同步排斥，待证核心）。** 合法覆盖容量函数 `𝓐(X)` 在所有 AAI/PPI/MLC/D 组约束下，不能在无穷多尺度上模拟同一离线零点的 `X^β` 级相干波动；其非终端波动上界应为

`𝓐(X)-𝓐^0(X) = O(X^{1/2+o(1)})`

或触发 D 组终端。

该命题是此前 “ACC 不同步引理” 的最终形式。当前 PC3-OV2 已把大 overlap 转成 D 组终端；剩余是证明小 overlap/正常 overlap 下的 ACC 自身没有 `X^β` 级自由度。

## 4. D 组终端分支的跨尺度排斥目标

若每个 `X_j` 都触发 D 组终端，则需要证明终端不能无限相容。

### 4.1 短簇终端

短簇表示大量 overlap 或覆盖偏差集中在少数短窗口。若无穷多尺度出现同相位短簇，则这些短簇对应素因子/锚层的过度复用。跨尺度上会导致：

- 同一小素因子同余类被重复过载；
- 大锚乘积容量 `q_1q_2r` 在多个尺度重复压缩；
- CRT 周期非零类均衡被破坏。

**PC4-SC（短簇跨尺度排斥，待证）。** 离线零点级短簇不能在无穷多尺度保持相干；否则违反 CRT 周期均衡或 LV 低体积账本。

### 4.2 高投影增量终端

高投影增量沿 D 组 CGTP 会增加平方能量。单尺度内能量有界；跨尺度若反复同相位出现，则构成全局投影能量发散。

**PC4-PI（投影能量跨尺度排斥，条件化闭合）。** 无穷多 `X_j` 上的同相位高投影增量不能同时满足全局 Euler product/CRT 零频均衡；否则投影平方能量总和超过全局容量。当前闭合稿见 `docs/rh-pc4-pi-closure-theorem.md`：它把 PI-Seed、PI-Cap lacunary/dense 分包与 PC4-PI-Dense 合并，失败分支转入 FCT/LSMP/LV/OV2。

### 4.3 FCT 终端

FCT 表示频率落入祖先短深度 span。若无穷多尺度都由 FCT 吸收，则离线零点相位必须被有限复杂度频率 span 长期编码。

**PC4-FCT（频率闭包跨尺度排斥，种子命题已写）。** zeta 离线零点的连续相位 `γ log X` 不能在无穷多增长尺度上被固定短深度 CRT 频率 span 完全吸收，除非产生可检测投影增量。当前种子稿见 `docs/rh-pc4-fct-seed.md`：若无穷多尺度由 FCT 吸收，则可抽取固定低维 span、固定证书类型与同相位子列。

### 4.4 NRC 异常终端

NRC 异常意味着标准完成和/Weil 界不足以吸收某个非共振倒数相位平均。若外部 NRC 定理成立，则该异常本身不应发生；若发生，则说明参数接入错误或频率其实共振，应转 FCT。

**PC4-NRC（NRC 终端排斥，基本闭合）。** 在已接受 NRC 定理的条件下，非共振异常不能是最终吸收分支；它必须转化为高投影增量、FCT 或参数账本失败。当前文档把它视为已由 NRC 附录条件化闭合。

## 5. 过密分支的对偶处理

PC-1/PC-2 可能给出过密而非过疏。过密表示素数空洞过多、合数覆盖不足。其对偶输出应为：

`覆盖缺口过剩 或 D组终端`。

**PC4-Dual（过密对偶，待证）。** 若平滑窗口素数过密 `P_z>=P_z^0+Δ`，则候选恒等式给

`B_z<=B_z^0-Δ+o(Δ)`。

这意味着允许覆盖容量不足或空洞过剩。若空洞过剩集中，触发短簇/投影终端的对偶形式；若分散，则违反 CRT 非零类均衡。

当前最省路线仍是通过 PC-1 的反相位子列获得过疏；若反相位选择因多零点相干变复杂，则必须补 PC4-Dual。

## 6. PC-4 总框架定理

**Theorem PC4-Framework（最终排斥框架）。** 假设以下四个跨尺度命题成立：

1. PC4-A：ACC 不同步排斥；
2. PC4-SC：短簇跨尺度排斥；
3. PC4-PI：投影能量跨尺度排斥（见 `docs/rh-pc4-pi-closure-theorem.md` 条件化闭合）；
4. PC4-FCT：频率闭包跨尺度排斥；

并采用 NRC 条件化闭合与必要时的 PC4-Dual。则 RH 反例不能通过 PC1+PC2+PC3-OV2 链条被吸收；从而离线零点不存在。

**证明。** 假设有离线零点。PC-1 给无穷多平滑异常窗口；PC-2 把它们匹配到 CRT 零频基线；取过疏分支或使用 PC4-Dual。PC3-OV2 给每个尺度的 ACC 过剩或 D 组终端。ACC 分支由 PC4-A 排斥；短簇、高投影增量、FCT 分别由 PC4-SC、PC4-PI、PC4-FCT 排斥；NRC 由 NRC 附录排斥。所有可能分支均矛盾，故离线零点不存在。证毕。

## 7. 总攻优先级

为了真正向 RH 总攻推进，下一步不应再扩散，而应按可证性排序专攻：

1. **PC4-FCT 频率闭包跨尺度排斥**：种子命题见 `docs/rh-pc4-fct-seed.md`；下一步攻“新增 CRT 坐标相位漂移引理”；
2. **PC4-A ACC 不同步排斥**：直接承接 PC3-OV2，是最核心但较难；
3. **PC4-SC 短簇跨尺度排斥**：需要 CRT 周期均衡与短簇密度的跨尺度版本；
4. **PC4-Dual 过密对偶**：若不能完全依赖反相位过疏，则必须补齐。

本文完成的是 PC-4 的总攻地图和分支归约，不宣称已证明 RH。PC4-PI 已推进到条件化闭合形态；最优下一步是专攻 PC4-FCT，因为 PC4-PI、NRC 与 Complexity-Escape 的失败分支都汇入频率闭包。

## 8. PC4-PI 的最小可证接口

下一步若专攻 PC4-PI，应先证明以下较弱但可审查的命题。

**Lemma PI-Seed（跨尺度投影能量种子）。** 若无穷多尺度 `X_j` 的 D 组分支均给出高投影增量，且这些增量来自同一离线零点相位的过疏输入，则存在一个固定有限复杂度投影族 `𝓦_*` 与无穷子列，使归一化平方能量增量满足

`Σ_j δ_j^2 μ_j(A_j)=∞`。

若同时存在全局容量界

`Σ_j Energy_j(𝓦_*)<∞`

或任意等价的 Euler product 正交界，则矛盾。

该种子命题已在 `docs/rh-pc4-pi-seed.md` 中定理化，但只闭合有界复杂度子列情形；复杂度无界逃逸需接入 FCT/LSMP 跨尺度账本。PC4-PI 由此拆成三项：固定模板抽取、复杂度逃逸排斥、跨尺度投影容量上界 `PI-Cap`。
