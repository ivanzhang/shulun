## 审稿解释

每条高素 q 斜线不再被看成随机命中列，而是被写成短互补因子窗口中的单位类计数。若 `uncovered_count>0`，这些未覆盖偏移就是该轮骨架下的端点幸存点。若某个坏窗试图让 `uncovered_count=0`，必须让多个 q 桶在同一轮平移骨架上形成异常集合覆盖；这就是 `Wheel-Rigid Set Cover -> PDEC/SAE/ColumnCRT` 的证书入口。
