# GEE-NRC 非共振出口上界与参数硬障碍

本文专攻 Global-Exit-Exclusion 的 `GEE-NRC`。结论必须诚实分层：`EXT-KL` 给出单个非共振倒数和的平方根上界；但要推出 `Load(NRC;X)=o(Δ)`，还必须证明 PPI 主层偏差门槛严格高于所有 NRC 完成和总和。该参数匹配是 GEE-NRC 的真正硬点。

## 1. NRC 单包上界

对允许窗口 `g∈𝓦(K)` 与非共振频率 `ξ`，NRC 定理给

`|Σ_d g(d)e_P(ξd^{-1})| <= C_K K_eff P^{1/2} log^{A_K}P`。

这里 `P` 是工作素模，`K_eff` 吸收窗口复杂度、Vaaler 截断、同余切分和 dyadic 层数。非共振失败不计入 NRC，而转入 `FCT`。

## 2. 从单包到 NRC 负担

设 PPI 输出的非共振频率包集合为 `𝓟_NRC(X)`。定义

`Load(NRC;X) <= Σ_{ω∈𝓟_NRC(X)} C_K K_eff(ω) P(ω)^{1/2} log^{A_K}P(ω)`。

由固定复杂度和 GEE-0 路由表，包数与 `K_eff` 的总损失至多为 `log^{C_NRC}X`，除非复杂度逃逸进入 `CE/LSMP`。因此若所有工作模满足 `P(ω)<=P_max(X)`，则

`Load(NRC;X) <= P_max(X)^{1/2} log^{C_NRC}X`。

这只是平方根完成和界的直接后果。

## 3. 与主异常 `Δ` 的比较

要得到 `Load(NRC;X)=o(Δ)`，需要

`P_max(X)^{1/2} log^{C_NRC}X = o(X^{β-o(1)})`。

即需要

`P_max(X) <= X^{2β-o(1)}`。

若 `P_max(X)` 与主尺度 `X` 同阶，则该条件对所有 `β>1/2` 成立，因为 `X^{1/2}log^C X=o(X^{β-o(1)})`。但若完成和之前还乘上主层体量因子、包数因子或双变量自由度因子，则必须把这些因子纳入 `K_eff`，重新验证：

`K_eff,total(X) P_max(X)^{1/2} log^{A}X=o(Δ)`。

这就是 GEE-NRC 的参数匹配核心。

## 4. 主层门槛版本

在 OV2/PPI 主层文档中，常用门槛形式为：PPI 给出的可检测偏差至少为

`Bias_PPI >= c X^{1/2+ε/2} W_Q^{1/2}/log^C X`，

而 NRC 上界为

`NRC <= C K_eff X^{1/2}log^C X`。

若主层满足

`W_Q^{1/2} >= K_eff log^{C_0}X · X^{-ε/4}`，

且 `C_0` 足够大，则

`Bias_PPI >= X^{1/2+ε/4}K_eff log^{C'}X >> NRC`。

因此在该主层门槛下，非共振包不能承载 PPI 主偏差，NRC 出口负担为零或 `o(Δ)`；否则不满足门槛的层必须转入 `LV/LSMP/SC/CE` 或低容量层，而不得计入 NRC。

## 5. Theorem GEE-NRC（条件参数闭合版）

**Theorem GEE-NRC-Parametric.** 假设每个 NRC 入口满足以下二者之一：

1. **平方根总和小于异常：** `K_eff,total(X)P_max(X)^{1/2}log^A X=o(Δ)`；
2. **PPI 主层门槛压过 NRC：** 可检测偏差下界严格大于 `C K_eff P^{1/2}log^A P`，否则该层转入 `LV/LSMP/SC/CE/FCT`。

则

`Load(NRC;X)=o(Δ)`。

**证明。** 非共振成功时，每个包由 `EXT-KL` 和完成法给平方根上界。对包求和，若满足条件 1，直接得 `o(Δ)`。若处于 PPI 主层模式，条件 2 说明 NRC 上界不足以解释 PPI 可检测偏差；故该非共振分支被排除，异常必须转入其它出口。非共振失败按定义进入 `FCT`，复杂度/尾项失败进入 `CE/LSMP/LV`。因此留在 NRC 的负担为 `o(Δ)`。证毕。

## 6. 顶刊审稿硬障碍

GEE-NRC 目前不是无条件闭合，而是“参数条件闭合”。要升级为无条件，需要补一张逐入口参数表：

| 入口 | `P_max` | `K_eff,total` | 偏差下界 | 是否满足条件 |
|---|---|---|---|---|
| C4-PPI 单变量倒数包 | 待填 | 待填 | 待填 | 待核 |
| C4-PPI 双变量倒数包 | 待填 | 待填 | 待填 | 待核 |
| DSO-E 非共振包 | 待填 | 待填 | 待填 | 待核 |
| Tail/RKS 附录 NRC | 待填 | 待填 | 待填 | 待核 |

若存在入口无法满足平方根总和小于 `Δ`，也无法由 PPI 门槛转出，则 GEE-NRC 不能闭合，RH 总攻链在此处断开。

## 7. 当前结论

`EXT-KL` 本身没有问题；真正硬点是参数匹配。当前 GEE-NRC 可标记为“条件参数闭合，待逐入口表核验”，不能标记为完全闭合。
