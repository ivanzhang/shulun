# D4/R5 全局 RPL 抽象定理

## 1. 容量支付望远镜界

设 stable 步中 `ΔL_j>=0`，容量支付项为

```text
P_j = L_{j-1} ΔL_j / 10.
```

则

```text
L_j^2 - L_{j-1}^2 = 2 L_{j-1} ΔL_j + (ΔL_j)^2 >= 2 L_{j-1} ΔL_j.
```

因此

```text
P_j <= (L_j^2 - L_{j-1}^2)/20.
```

沿 stable 步求和得到望远镜上界：

```text
Σ P_j <= (L_final^2 - L_initial^2)/20 <= L_max^2/20.
```

这正是容量支付可求和的全局机制。

## 2. 抽象 RPL 定理

假设存在尺度序列和状态 `(L_j,D_j,B_j,C_j)`，满足：

1. 容量界：`0<=L_j<=L_max`；
2. stable 步：所有负 `D` 下降由 `P_j=L_{j-1}ΔL_j/10` 支付；
3. jump 步：`B_j<=B_{j-1}-kappa_j` 或落入有限证书窗口；
4. backflow 步：`B_{j-1}>=B_j-eps_j`；
5. `Σ eps_j + Σ jump_error_j < B_*`，其中 `B_*` 是局部证书排除余量。

则坏结构不能沿无限尺度链存在。否则：

- stable 步的总负下降被 `L_max^2/20` 控制；
- jump 步要么有限吸收，要么累计坏度下降；
- backflow 把坏度传回基尺度，只损失可求和误差；
- 最终与基尺度外向舍入证书矛盾。

## 3. 剩余无条件输入

要把该抽象定理接回原命题，需要证明：

- 全局容量界 `L_max`；
- jump 边界误差可求和；
- backflow 投影误差可求和；
- 基尺度局部证书覆盖所有回传终点。
