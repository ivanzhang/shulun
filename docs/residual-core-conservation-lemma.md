# 残洞核迁移守恒引理：从“局部补洞”到“全局跨窗”的接口

**状态：** 候选引理与实验支撑；不是最终证明。

## 1. 形式化对象

固定奇素数 `P`，根基素数集合为

`Q(P)={q prime: q<P}`。

第 `r=x+1` 行、列 `1<=c<P` 的数为

`N_x(c)=xP+c`。

给定相位 `x`，列 `c` 被根基素数 `q` 覆盖当且仅当

`xP+c≡0 (mod q)`，等价于

`c≡-xP (mod q)`。

残洞集定义为

`H_P(x)={1<=c<P: 对所有 q<P, xP+c not≡0 (mod q)}`。

目标行命题等价于

`1<=x<P => H_P(x) nonempty`。

## 2. 局部补洞约束为什么不足

若某个残洞 `c in H_P(x)` 要被某个素数 `q` 补掉，则新相位 `y` 必满足

`y ≡ -c P^{-1} (mod q)`。

这只是一个局部 CRT 约束。它能保证 `c` 被补掉，却不保证原来已覆盖的列仍被覆盖。

实验 `front-window-completion-cost-scan` 显示：

- 对 `P=13,17,19,23,29,31`，前窗口最佳近零行的残洞都可被很小的局部同余补掉；
- 但一旦要求这些补洞约束延拓为完整零行，样本中的最早完整完成相位回到全局首零行；
- 所有首零行相位均满足 `x>=P`，例如 `P=23` 的 `x=58`，`P=29` 的 `x=5209`。

因此，真正的障碍不是“能不能补掉某个洞”，而是：

> 补掉旧残洞时，覆盖结构整体相位改变；若仍留在前窗口，则旧覆盖层会释放新残洞。

这正是残洞核迁移守恒。

## 3. 候选引理 RCC

**残洞核迁移守恒引理 RCC。** 对任意奇素数 `P` 与任意前窗口相位 `1<=x<P`，若把 `x` 改为另一个前窗口相位 `1<=y<P`，并使 `H_P(x)` 中的一批残洞在 `y` 中被覆盖，则必存在至少一个新列 `c'` 满足

`c' notin H_P(x)` 但 `c' in H_P(y)`。

等价地，前窗口内残洞不能被净消灭，只能迁移：

`H_P(y)=empty` 不可能由有限批局部补洞约束在 `y<P` 内完成。

更强的势函数形式是：存在前窗口势函数 `Φ_P(x)`，满足

`Φ_P(x)>=1` 对 `1<=x<P`，并且每个局部补洞操作若保持 `y<P`，则 `Φ_P(y)>=1`。

最自然的第一候选是 `Φ_P(x)=|H_P(x)|`；若直接证明太强，可改用带权残洞势：

`Φ_P(x)=sum_{c in H_P(x)} w_P(c)`，其中权重体现镜像、短 gap、同余商互质与列均衡刚性。

## 4. 与增长量级差距的连接

局部覆盖能力随 `q<P` 增加，但在一行宽度仅为 `P-1` 的窗口中，各根基素数只提供一个禁余类。

若考虑相位移动 `x -> y`，素数 `q` 的覆盖列整体平移：

`c_q(y)-c_q(x) ≡ -(y-x)P (mod q)`。

所以一次相位移动不是“增加覆盖”，而是所有斜线层同时重排。补洞收益必须扣除旧列释放损失。

这给出矛盾场不等式的目标形式：

`净补洞数(y;x) = 被 y 新覆盖的旧洞数 - 被 y 释放的新洞数 <= 0`，只要 `1<=x,y<P`。

若能证明该不等式，则从任意前窗口近零行出发都无法达到 `H_P(y)=empty`；完整零行只能出现在跨窗相位 `y>=P`。

## 5. 可证明化的下一步

为了避免“有限模板控制无限变化”的误区，下一步不枚举模板，而证明三类结构性事实：

1. **同因子短差互斥。** 若两列距离小于某阈值且均为粗合数解释，则它们不能共享同一大素因子；这限制局部补洞的重叠收益。
2. **相邻商互质释放。** 相邻列被不同因子解释，且同余链上的相邻商必须互质；这迫使补洞相位改变时释放缺口。
3. **CRT 列均衡回流。** 完整周期中除第 `P` 列外各列类素数数目相等；若前窗口存在净消洞偏置，则必须在周期其它位置产生反向过冲，与镜像密度刚性和首零行最小性冲突。

这三点合起来应导向可审查的 RCC 证明：前窗口内覆盖重排没有净消洞能力，只有残洞核迁移能力。
