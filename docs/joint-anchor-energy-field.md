# 联合锚能量场：A、E、Cross 的三重约束

**状态：** 将一阶覆盖缺口、二阶复用、近碰撞谱合并。

## 1. 指标

固定列 `c`，粗候选集合 `R`，`N=|R|`。

锚命中总数：

`A=Σ_k |L(k)|=Σ_q n_q`。

复用能量：

`E=Σ_q binom(n_q,2)`。

近碰撞交错：

`Cross` 为相邻锚命中点之间 gap `<sqrt(P)` 的锚对事件数。

列反例要求 `A>=N`，并且锚命中点覆盖全部粗候选，所以 `Cross` 至少要复现粗候选小 gap 谱，约 `N` 级。

## 2. 扫描事实

新增脚本：`experiments/joint_anchor_energy_scan.py`。

代表列中：

- `A/N≈0.74--0.86`，即真实系统有明显一阶缺口；
- `Cross/N≈1`，说明锚命中点本身仍形成足够小 gap 交错；
- `E/N≈0.3--0.7`，二阶复用为线性级；
- 若强行把 `A` 提升到 `N` 且保持同一 `Q_eff`，Cauchy 所需 `E` 接近或超过真实 `E`。

这说明反例的关键负担是补齐一阶覆盖缺口；补齐后必然增加复用能量或有效锚种类。

## 3. 联合矛盾场

列反例要从真实型结构变成全覆盖结构，必须至少做一件事：

1. 增加 `Q_eff`：引入更多有效锚颜色；
2. 增加复用 `E`：让已有锚覆盖更多粗候选；
3. 增加 Cross：使新增锚命中保持粗候选 gap 谱。

但三者互相牵制：

- 增加 `Q_eff` 需要更多锚同余图像命中过小筛骨架，受 `Q_eff` 损耗限制；
- 增加 `E` 受冷却距离限制；
- 增加 `Cross` 受邻域稀疏限制。

## 4. 候选联合不等式

设反例结构满足：

`A>=N`。

由 Cauchy：

`E >= (N^2/Q_eff - N)/2`。

另外粗候选 gap 谱要求：

`Cross >= N-1`。

若能证明上界

`E + μ Cross <= α N`

而下界给

`(N^2/Q_eff - N)/2 + μ(N-1) > α N`，

则矛盾。

等价地，需要三项显式常数：

1. `Q_eff <= βN`；
2. `E + μCross <= αN`；
3. `(1/β-1)/2 + μ > α`。

## 5. 当前实验常数

实验中 `β≈0.5--0.65`，`E/N≈0.3--0.7`，`Cross/N≈1`。

如果能证明例如

`β<=2/3`, `E<=0.8N`, `Cross<=1.2N`,

则取合适 `μ` 可能接近矛盾，但常数仍需打磨。

## 6. 下一步硬攻

最关键是证明 `Q_eff <= βN`，且 `β<1` 为绝对常数。随后再优化 `E+μCross` 上界。

这条路线现在已经是明确的内部矛盾不等式，不再是命题转换。

## 7. Qeff 目标修正

`docs/qeff-sieve-upper-bound-route.md` 显示，单独证明 `Qeff<=βN` 可能不是最优。更自然的联合形式是

`Qeff - τE <= βN`。

这把低桶高复用的锚颜色用 `E` 付费，高桶低复用的锚颜色用筛损耗控制。下一步应把该不等式代入 Cauchy 下界，寻找可闭合的 `τ,β,μ,α` 常数。

## 8. 参数试探

用扫描样本粗略拟合 `Qeff-τE<=βN`：

- `τ=0.10` 时，样本最大 `β≈0.592`；
- `τ=0.20` 时，样本最大 `β≈0.556`；
- `τ=0.30` 时，样本最大 `β≈0.524`。

这说明带复用付费的 Qeff 上界比单独 `Qeff<=βN` 更有余量。

下一步候选目标可取保守形式：

`Qeff - 0.1E <= 0.7N`。

若能证明该式，再与 Cauchy 下界组合，可能获得更稳定的矛盾链。
