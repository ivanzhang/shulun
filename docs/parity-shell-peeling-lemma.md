# 奇偶壳剥离引理：短 gap 核迁移的第一层刚性

**状态：** 可严格证明的基础层 + 候选推广接口。

## 1. q=2 层的精确方程

由于 `P` 为奇素数，模 `2` 中 `P≡1`。第 `x+1` 行列 `c` 的数

`N_x(c)=xP+c`

为偶数当且仅当

`x+c≡0 (mod 2)`。

因此 `q=2` 覆盖的列壳为

`E_2(x)={c: c≡x (mod 2)}`。

未被 `q=2` 覆盖的列全部落在反壳

`O_2(x)={c: c≠x (mod 2)}`。

所以任意残洞集满足

`H_P(x) subset O_2(x)`。

这解释了实验中极小核几乎总是单奇偶壳：残洞不可能出现在 `q=2` 已覆盖的壳内。

## 2. 奇偶翻转只能迁移不能消灭

若从 `x` 移到 `y` 且 `x not≡ y (mod 2)`，则 `q=2` 覆盖壳完全翻转。

于是原残洞壳 `O_2(x)` 被 `q=2` 大量覆盖，但新的反壳 `O_2(y)=E_2(x)` 失去 `q=2` 的保护。

因此奇偶翻转的净效果不是增加覆盖能力，而是把问题转移到另一半列：

`H_P(y) subset E_2(x)`。

要在翻转后得到零洞，必须由所有奇素数层在整整一半列上承担覆盖。该要求远强于只补掉原短 gap 核。

这就是实验 `parity-shell-migration-scan` 中的现象：

- `P=23`：`[9,15]` 被翻转补掉后，最佳对壳出现 `[12,16,22]`；
- `P=37`：`[29,35]` 翻转后释放 `[10,20,32,34]`；
- `P=71`：`[3,33,43,49,61]` 翻转后释放 `[12,18,24,32,50,60]`。

## 3. 剥离后的奇素数问题

由第 1 节可将前窗口行命题分解为：

1. `q=2` 自动覆盖一半列；
2. 残洞只存在于另一半列；
3. 若试图用奇偶翻转消灭残洞，另一半列成为新风险壳；
4. 因此真正需要证明的是：奇素数层无法在 `y<P` 内覆盖完整反壳。

令

`Q_odd(P)={q prime: 3<=q<P}`。

对固定奇偶壳 `S`，奇素数层在相位 `x` 的覆盖为

`C_odd(x,S)= union_{q in Q_odd(P)} {c in S: c≡-xP (mod q)}`。

需证明：对任意 `1<=x<P`，反壳 `O_2(x)` 中至少有一点不在 `C_odd(x,O_2(x))`。

这已经等价于原行命题，但它把 q=2 的大覆盖剥离出去，使剩余矛盾集中到奇素数层。

## 4. 短 gap 核的可证压力

在同一奇偶壳内，任意两个列差为偶数 `d`。若同一奇素数 `q` 同时覆盖两列 `c1,c2`，则

`q | (c2-c1)=d`。

因此当 `q>d` 时，同一 `q` 不能同时覆盖这两个短差洞。

若极小核含短差 `d`，则补掉该短差对需要：

- 使用某个小因子 `q|d`；或
- 使用两个不同奇素数同步命中。

第一种受小因子容量限制，第二种带来 CRT 模数乘积压力。若多个短 gap 共享成链，该压力叠加。

## 5. 下一步命题 PSG

**PSG：奇偶剥离短 gap 命题。** 设 `K` 是前窗口偏序极小残洞核，且 `K` 含短差链

`c1<c2<...<cm`，其中相邻差 `d_i=c_{i+1}-c_i` 的奇素因子集合很小。若某 `y<P` 覆盖 `K`，则 `H_P(y)` 在对侧奇偶壳中非空。

证明策略：

1. 若 `y≠x mod 2`，由奇偶翻转，必须证明奇素数层不能覆盖整对壳；
2. 若 `y≡x mod 2`，则 `q=2` 不帮助补 `K`，短差互斥迫使多奇素数同步，产生 CRT 跨窗压力或邻域释放；
3. 两种情况合并给出短 gap 极小核不可零释放消除。

## 6. 重要诚实边界

第 1 节与第 4 节的同因子短差互斥是严格初等事实；第 5 节 PSG 仍是待证命题。

当前突破点是：先把 q=2 的“半列覆盖能力”从总覆盖能力中剥离，避免误把奇偶翻转当作净补洞。
