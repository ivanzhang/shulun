# 二次筛二点粗候选命题：顶刊式审稿归档

日期：2026-05-01  
范围：`docs/monograph/two-point-secondary-sieve-research.md` 与合著稿《方阵与CRT数论矛盾场研究》的二点粗候选研究章节。

## 1. 审稿结论

该部分形成了一条高度结构化的条件证明路线：

```text
二点反例
→ 顶尺度容量超标
→ TCA 线性桥接
→ SMC/SC2 近交叉约束
→ 45-Main/Fourier CRTDefect 削峰
→ Zero Mass 正部
→ 顶尺度容量不足矛盾
```

但按顶级数学期刊标准，当前不能表述为无条件证明。原因是若 A/B 命题无条件成立，将包含固定偶差素数对存在性，特别 `w=2` 将推出孪生素数级结论。因此必须将该部分列为“研究命题/条件框架/待审稿输入”，而非定理。

## 2. 已闭合或基本闭合的结构部分

- `Reuse` 异常：由大因子大于短差值严格排除。
- `Shared` 异常：由互补商 `Y_H`-rough 与 `L<Y_H` 严格排除。
- `45-Main` 主同步：已分解为 `Reuse/Shared/Good-to-CRTDefect`，并通过辅助素差值能量与 Directional Balance 给出条件闭合链。
- `Fourier CRTDefect`：大非零 Fourier 系数被转化为真实短差值方向偏差，再由 Directional Balance 排除。
- `TCA` 桥接：已从平方损失改写为块级线性正部。
- `Zero Mass`：通过加权 Bonferroni C' 路线得到宽松常数空间，当前文档给出 `rho0 >= 0.57` 的条件闭合。
- 中尺度 `K=2` 复核：在固定阶局部交叉、薄层递推、`Q_eff <= polylog(P)` 框架下，`alpha0=0.75` 的参数可行。

## 3. 仍需正式逐行证明的输入

| 输入 | 当前状态 | 审稿要求 |
|---|---|---|
| A. 固定阶局部交叉 `Q_eff <= polylog(P)` | 证明骨架完成 | 需逐项展开截断权重、局部同余系统与边界项 |
| B. `SC2` 二阶相关误差 | 条件闭合 | 需将 45-Main/Fourier 削峰转成正式矩估计 |
| C'. Zero Mass 加权 Bonferroni | 常数闭合 | 需正式证明一阶、二阶、三阶矩界，特别三线退化项 |
| D. 平滑回退尖锐窗口 | 技术骨架完成 | 需给出平滑函数、夹逼宽度与端点层计数 |

## 4. 推荐并入合著稿的表述方式

建议在合著稿中作为“二点二次筛矛盾场研究命题”记录：

- 说明 A/B 命题的强度：其无条件证明将触及孪生素数/固定偶差素数对级问题。
- 给出条件闭合框架和参数组：`alpha0=0.75`、`c0=1/2`、`nu=0.4`。
- 明确 A--D 为待审稿输入。
- 不使用“proved theorem”或“unconditional proof”措辞。

## 5. 最终审稿意见

该章节适合作为《方阵与CRT数论矛盾场研究》中的新研究命题章节，展示矛盾场方法从一点粗候选到二点粗候选的扩展。但必须保留诚实边界：它是条件化研究框架和未来突破路线，不是当前已完成的无条件孪生素数/哥德巴赫型证明。
