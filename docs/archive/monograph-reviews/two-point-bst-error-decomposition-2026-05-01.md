# BST 误差细分与最终硬点审查

日期：2026-05-01

## 实验增强

`experiments/rb_tli_w2_scan.py` 增加：

- 大素数指数壳层命中；
- Buchstab 壳层期望；
- 两侧命中协方差；
- 双侧均命中比例；
- 同侧双命中比例。

## 主要发现

对 `P=10007, alpha=3/4`：

- 总均值 `E_U D=0.691696`，Buchstab 主项 `K=0.676220`。
- 两侧协方差 `Cov(D_x,D_{x-2})=-0.000093`，没有常数级正相关。
- 各壳层实际/期望接近，例如 `(0.80,0.85]` 为 `0.1368/0.1366`。
- `D=0` 个数在不同 `alpha` 下不变，均为 `201481`。
- 端点类型严格落入素数、单半素数、双半素数三类。

## 新最小硬点

BST-2：

\[
\#\{p,m:pm\in I,\ pm-2\in U_Y\}
\le
(B(\alpha)+o(1))|U_Y|.
\]

这要求证明移位双素变量 `pm-2` 的 `Y`-rough 条件不会产生常数级正偏。该命题比原 RB-TLI 更具体，但仍未无条件证明。
