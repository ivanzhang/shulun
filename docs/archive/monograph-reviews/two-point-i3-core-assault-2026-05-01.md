# I3-Core 最终核心审查（2026-05-01）

## 结论

本轮集中处理 I3 后，完成了两项实质压缩：

1. 小素有限包不再保留为 `q<=100` 常数包；改取 `Q0=2`，只把 `q=2` 归一化为奇数骨架，损失为 0。
2. 所有奇素 `q>2`，包括 `q|w`，统一纳入 45-Main/SC2/CRTDefect 机制。

因此剩余不再是多个分散条件，而是单一核心定理 I3-Core。

## I3-Core 内容

I3-Core 需要证明真实剩余集 `U_Y` 对下一自适应薄层满足：

1. 单素数缺陷排除；
2. 二阶矩下界 `M2>=0.05`；
3. 三阶尾部上界 `M3<=0.03`；
4. 一阶命中上界 `M1<=0.45`；
5. 端点 Directional Balance。

同时所有奇素 45-Main 同步峰必须被辅助 Fourier CRTDefect 或 Directional Balance 排除。

## 当前诚实状态

I1、I2、I4 已经不再是独立条件：

- I1：固定阶复杂度已内联证明；
- I2：自适应分层已放电为贪心分层/Single-Prime CRTDefect 二分；
- I4：Zero-Mass 与平滑回退已放电为 I3 矩常数/端点接口。

但 I3-Core 本身尚未逐行无条件证明。当前不能把二次筛命题标为无条件证明完成。

## 下一步唯一有效攻坚点

证明异常二分：

若 I3-Core 任一矩常数或端点平衡失败，则产生：

1. Single-Prime CRTDefect；
2. 奇素 `q>2` 的 45-Main 主同步峰；
3. 辅助素 `r~L` 上的二阶 Fourier CRTDefect；
4. 端点 Directional Balance 失败；
5. 三线退化超过 I1 固定阶局部交叉允许界。

并逐项证明这些异常不可能。完成这一步后，二次筛命题才能升级为无条件定理。
