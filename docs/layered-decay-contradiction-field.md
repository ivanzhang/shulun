# 层叠衰减矛盾场方程

**状态：** 核心框架方程；关键不等式待证。

## 1. 层叠壳定义

令根基素数按升序为

`q_1=2<q_2=3<...<q_m<P`。

对每个前缀

`B_j={q_1,...,q_j}`，定义第 `x+1` 行的小素数剩余壳：

`S_j(x)={1<=c<P: xP+c not≡0 (mod q_i), 1<=i<=j}`。

于是

`S_0(x)={1,...,P-1}`，且

`S_0(x) superset S_1(x) superset ... superset S_m(x)=H_P(x)`。

每加入一个素数 `q_j`，壳按禁余类剥离：

`S_j(x)=S_{j-1}(x) \ {c in S_{j-1}(x): c≡-xP (mod q_j)}`。

这就是小素因子约束逐步累积的精确动力系统。

## 2. 剩余层恒等式

固定层 `j`。剩余素数层为

`R_j={q_{j+1},...,q_m}`。

在壳 `S_j(x)` 上定义：

`U_j(x)= union_{q in R_j} {c in S_j(x): xP+c≡0 (mod q)}`，

`C_j(x)=sum_{q in R_j} |{c in S_j(x): xP+c≡0 (mod q)}|`，

`E_j(x)=C_j(x)-|U_j(x)|`。

那么有严格恒等式：

`|H_P(x)| = |S_j(x)| - C_j(x) + E_j(x)`。

这是矛盾场主方程。它说明：

- `|S_j|` 是小素数剥离后剩余候选量；
- `C_j` 是剩余中大素数原始覆盖能力；
- `E_j` 是因同余锁相造成的重叠损耗；
- 三者差值是最终残洞数，并且对所有层 `j` 不变。

## 3. 衰减与压力转移

加入 `q_j` 时，`|S_j|` 近似乘以 `(1-1/q_j)` 衰减。但主方程要求

`|S_j|-C_j+E_j` 保持不变。

因此“小素因子越来越多”不是单调地走向全覆盖，而是在三项之间转移压力：

1. 小素数剥离使 `|S_j|` 下降；
2. 同时剩余层减少，使 `C_j` 下降；
3. 重叠能量 `E_j` 也随剩余层减少而下降；
4. 最终洞数作为不变量保留下来。

实验中最典型的是：前几层 `q=2,3,5,7` 快速压缩壳；之后大素数层多数只能覆盖一个点，`C_j` 逐渐接近 `|S_j|-|H|`，重叠能量趋于零，但残洞已被锁定。

## 4. 反例意味着什么

若存在前窗口零行，则对某个 `x<P` 有

`|H_P(x)|=0`。

于是每一层都必须满足

`|S_j(x)| = C_j(x)-E_j(x)=|U_j(x)|`。

也就是说：在每个小素数剥离层之后，剩余素数层都必须刚好覆盖整个剩余壳。

这极其刚性：

- 早期层要求剩余层的并集没有最后缺口；
- 中期层要求容量与重叠精确平衡；
- 后期层要求大素数层以几乎唯一覆盖方式补完所有剩余点；
- 最末端若剩余壳含两个短差点，则同一大素数无法同时覆盖，必须 CRT 同步多个大素数。

所以反例不是“覆盖多一点”即可，而是要在所有层同时满足零场方程。

## 5. 候选 Lyapunov 量

为了证明零场不可能，考虑层级量

`L_j(x)=C_j(x)-E_j(x)-|S_j(x)|`。

由主方程，

`L_j(x)=-|H_P(x)|`。

直接使用它等价于目标命题，因此需要可估计的下界版本。一个可攻方向是分层近似：

`L_j^{loc}=C_j^{large}-E_j^{forced}-|S_j^{critical}|`。

其中只统计临界剩余壳、短差核与大素数层。若能证明

`L_j^{loc}<=-1`，则推出存在残洞。

## 6. 下一步可证子命题 LD-1

**LD-1：后期短差锁定。** 若某层 `S_j(x)` 已缩小到 `O(sqrt(P))` 级别，并且其中存在短差对 `c1,c2`，则剩余大素数层不能在 `x<P` 内以零重叠、零释放方式覆盖整个 `S_j(x)`。

理由：

- 对 `q>|c2-c1|`，同一 `q` 不能同时覆盖短差对；
- 需要不同大素数同步命中；
- 同步同余模数乘积超过前窗口尺度；
- 若偶然有前窗口代表，则它改变小壳签名，释放新候选点。

这正是此前 patch-release 扫描观察到的现象。

## 7. 下一步可证子命题 LD-2

**LD-2：早期壳迁移释放。** 若相位移动改变某个小素数 `p<=z` 的禁余类，并因此补掉旧核点，则新壳差集

`S_{B_z}(y)\S_{B_z}(x)`

中至少存在一个点不能被剩余层覆盖。

这把奇偶翻转释放推广到 `{2,3,5,7,...}` 多同余壳迁移。

## 8. 证明路线闭环

层叠衰减矛盾场的闭环应为：

1. 任意前窗口反例要求所有层满足零场方程；
2. 若反例通过改变小素数壳补洞，则由 LD-2 释放新洞；
3. 若反例保持小壳签名，只靠中大素数补洞，则进入后期短差锁定，由 LD-1 排除；
4. 无短差核留给镜像缺陷/列均衡回流处理。
