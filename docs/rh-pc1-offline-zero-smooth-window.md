# PC-1：离线零点到平滑素数过疏/过密窗口

本文专攻 RH 反例矛盾场路线中的 PC-1：若 `ζ(s)` 存在离线零点 `ρ=β+iγ`, `β>1/2`，则平滑 Chebyshev 素数权必在无穷多尺度上出现 `X^{β-o(1)}` 级过疏或过密窗口。本文只处理从零点到平滑素数波动的显式公式环节；后续由 PC-2/PC-3/PC-4 接入 CRT 与覆盖矛盾场。

## 1. 平滑素数权

取固定非负光滑紧支撑函数 `W`，支撑在 `[1/2,2]`。定义

`Ψ_W(X)=Σ_n Λ(n)W(n/X)`。

其零频主项为

`Ψ_W^0(X)=X \widehat W(1)`。

Mellin 变换记作

`\widehat W(s)=∫_0^∞ W(t)t^{s-1}dt`。

`W` 光滑紧支撑，故 `\widehat W(s)` 在垂直线快速衰减。

## 2. 平滑显式公式

**Lemma PC1-1（平滑显式公式）。** 对任意固定 `A>0`，有

`Ψ_W(X)-X\widehat W(1)=-Σ_ρ X^ρ \widehat W(ρ)+O_A(X^{-A})+E_triv(X)`，

其中和过 `ζ(s)` 的非平凡零点，`E_triv` 来自平凡零点与极点外的标准小项，满足 `E_triv=O_W(1)` 或更强低阶界。

**证明。** 用 Mellin 反演写

`Ψ_W(X)=1/(2πi)∫_{(2)} -ζ'(s)/ζ(s) · X^s \widehat W(s) ds`。

移动积分线穿过 `s=1` 的极点与非平凡零点。`s=1` 给主项 `X\widehat W(1)`；每个零点 `ρ` 给残数 `-X^ρ\widehat W(ρ)`；平凡零点与新积分线由 `\widehat W` 快速衰减控制。证毕。

## 3. 单零点可见权选择

固定一个实部最大的离线零点 `ρ_0=β+iγ`, `β>1/2`，即没有零点实部大于 `β`。若存在更大实部零点，则改取那个零点。若 `\widehat W(ρ_0)≠0`，则该零点在显式公式中贡献

`-X^{ρ_0}\widehat W(ρ_0)+conjugate`。

若某个给定 `W` 使 `\widehat W(ρ_0)=0`，可用有限个平移/缩放平滑权 `W_j(t)=W(e^{-u_j}t)` 替换；其 Mellin 变换为 `e^{u_jρ_0}\widehat W(ρ_0)`，除非原始 `\widehat W(ρ_0)=0`。更稳妥地选取一族测试权，使至少一个 `\widehat W_j(ρ_0)≠0`。本文后续固定这样的 `W`。

## 4. 相位选择与大波动

**Lemma PC1-2（离线零点产生大平滑波动；Landau--Ingham 型）。** 若存在零点 `ρ_0=β+iγ`, `β>1/2`，且可选平滑权满足 `\widehat W(ρ_0)≠0`，则存在无穷多 `X_j` 使

`|Ψ_W(X_j)-Ψ_W^0(X_j)| >= c X_j^{β-o(1)}`。

更具体地，存在符号 `σ∈{+1,-1}` 与无穷多 `X_j`，使

`σ(Ψ_W(X_j)-Ψ_W^0(X_j)) >= c X_j^{β-o(1)}`。

**证明。** 显式公式中 `ρ_0` 与共轭零点贡献为

`-2 Re(X^{ρ_0}\widehat W(ρ_0))`。

令 `T=log X`，该项为

`-2X^β Re(e^{iγT}\widehat W(ρ_0))`。

严格地说，若同一实部 `β` 上有多个零点，主振荡项是有限或局部有限的三角多项式极限。若还有更大实部零点，则可改用更大实部，得到更强波动。一般情形使用标准 Landau--Ingham 振荡原理：显式公式中存在实部 `>1/2` 的非零奇点贡献，且测试权不湮灭该贡献，则误差项不能是 `o(X^{β})`；在可能存在逼近实部上确界的零点时，结论写为 `X^{β-o(1)}`。由三角多项式非恒零性，可取无穷相位子列使绝对值有正下界，并再取某一固定符号子列。证毕。

## 5. 从 Chebyshev 权到素数个数窗口

PC-3 使用的是无权素数计数 `P_z(X)=Σ_p W(p/X)`。Chebyshev 权与无权计数满足在支撑 `[X/2,2X]` 上

`Σ_p log p W(p/X)=(log X)Σ_p W(p/X)+O(Σ_p |log(p/X)|W(p/X))`。

对固定支撑，该误差可通过把窗口细分为 `O(log^C X)` 个更短 multiplicative 子窗口消除；或者直接把 PC3-B 的 Buchstab 加权版本作为接口。

**Proposition PC1（离线零点到平滑素数异常窗口）。** 若 `ζ(s)` 有离线零点，令 `β>1/2` 为离线零点实部上确界或一个可见极大实部。则存在平滑权 `W`、无穷多尺度 `X_j`、以及符号 `σ∈{+1,-1}`，使 Chebyshev 素数权满足

`σ(Σ_p (log p)W(p/X_j)-X_j\widehat W(1)) >= X_j^{β-o(1)}`。

进一步，二者至少有一条成立：

1. Buchstab/Chebyshev 权接口中存在 `X_j^{β-o(1)}` 级素数过疏或过密；
2. 经过 multiplicative 子窗口细分后，存在无权素数计数窗口满足

   `σ(P_z(X_j)-P_z^0(X_j)) >= X_j^{β-o(1)}/log^{C}X_j`。

**证明。** 第一部分由 Lemma PC1-2 与素数幂贡献低阶得到，因为 `Λ(n)` 中素数幂 `p^k,k>=2` 的总贡献为 `O(X^{1/2}log^C X)`，低于 `X^{β-o(1)}`。第二部分由 `log p~log X` 的局部常值性和有限子窗口 pigeonhole 得到；若不做无权化，则直接保留 Chebyshev/Buchstab 权接口。证毕。

## 6. 与 PC3-OV2 的对接

PC3-OV2 需要过疏形式

`P_z(X)<=P_z^0(X)-Δ`, `Δ=X^{β-o(1)}`, `β>1/2`。

PC-1 给出的是带符号异常：可能过疏，也可能过密。处理方式为：

1. 若得到过疏，直接接入 PC3-OV2；
2. 若得到过密，则显式公式振荡在相位反向序列上给出过疏，除非所有大峰同号；但单个余弦零点贡献沿 `log X` 必有正负两相位，因此可选反相位子列；
3. 若只保留 Chebyshev 权，则接入 PC3-B 加权版本。

因此 PC-1 为 PC3-OV2 提供所需的候选过疏输入，代价至多为固定对数损失。

## 7. 诚实边界

PC-1 依赖标准平滑显式公式与 Landau--Ingham 型振荡原理，数学上相对稳固；但用于完整 RH 证明仍需后续两步：

- PC-2：把 `Ψ_W^0` / `P_z^0` 与 CRT 筛余候选零频基线精确匹配；
- PC-4：证明 PC3-OV2 的两个输出“覆盖容量过剩”或 “D 组终端”都与 RH 反例场不可相容。

因此 PC-1 不是 RH 证明，只是把假想离线零点转换成可输入覆盖矛盾场的平滑素数异常窗口。
