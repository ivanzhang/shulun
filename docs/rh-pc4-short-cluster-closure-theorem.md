# PC4-SC：短簇分支闭合命题

本文合并 `docs/rh-pc4-short-cluster-seed.md`、`docs/rh-pc4-short-cluster-mass-balance.md` 与 `docs/rh-pc4-short-cluster-local-density.md`，给出 PC4 短簇分支的条件化闭合形式。本文不是 RH 的无条件证明；它只说明：在已经接受 AAI 正规形、LV/LSMP 体积账本、PC4-PI/PC4-A/PC4-FCT 条件化闭合与复杂度逃逸接口的前提下，短簇不能作为离线零点反例场的最终逃逸通道。

## 1. 输入与目标

设离线零点反例在无穷多尺度 `X_j` 上产生 PC3-OV2 输出。短簇分支表示：异常质量没有表现为全局 ACC 同步过剩，也没有直接表现为高投影增量或频率闭包，而是反复集中到物理短窗、短 Bohr 窗或有限锚复用簇中。

PC4-SC 的目标是证明以下排斥：若短簇在无穷多尺度上承载 `X_j^{β-o(1)}` 级异常，`β>1/2`，则该短簇必然转化为已闭合分支、低体积吸收，或违反局部乘积容量；因此它不能成为最终终端。

## 2. 规范化种子

由 `docs/rh-pc4-short-cluster-seed.md`，若短簇可以作为最终逃逸通道，则可抽取一个无穷子列，使得以下对象固定：

1. 短簇类型：锚复用、短 Bohr 窗、相位锁定或混合型；
2. 尺度参数：短窗长度、主要 dyadic 层 `Q,R` 与主锚数；
3. CRT 相位：新增局部因子在固定同相位或准同相位子列中出现；
4. 非终端假设：PC4-PI、PC4-A、PC4-FCT 与 LV/LSMP 在该子列上均不触发。

这一步把“无限变化的短簇”压缩成一个可重复审查的固定局部动力系统。若无法抽取，则复杂度逃逸已经进入 FCT/LSMP/CE 接口，而不是短簇终端。

## 3. 质量平衡排斥

由 `docs/rh-pc4-short-cluster-mass-balance.md`，固定短簇的异常质量只有两种可能。

**第一种：零频体积可求和。** 短簇只占有限或可求和体积预算，则它对素数计数或覆盖容量的贡献被 LV/LSMP 吸收，不能维持离线零点级异常。

**第二种：零频体积不可求和。** 若短簇长期承载不可求和质量，则质量必须在至少一个可观测投影中显露：

- 若表现为允许投影窗口增量，进入 PC4-PI；
- 若表现为覆盖容量同步过剩，进入 PC4-A；
- 若表现为低维相位锁定，进入 PC4-FCT；
- 若继续压缩到更短窗或低体积尾层，进入 LV/LSMP 或下一层短簇。

因此，在所有其他终端被禁止的非终端假设下，短簇只能落入最后一种“更短簇递归”。

## 4. 局部密度与递归终止

由 `docs/rh-pc4-short-cluster-local-density.md`，短窗 `I_X` 内双锚复用点在 AAI 正规形下有

`n=q_1q_2r`, `q_i~Q`, `Q^2R~X`，

并满足局部容量界

`Vol_eff(I_X;Q,R) << (L_X/X)RQ log^C X + R log^C X`。

若短簇异常不超过该容量，则其零频贡献不足以支撑 `X^{β-o(1)}` 异常，除非已经由 LV/LSMP 吸收。若超过该容量，则超额必须触发 PC4-PI、PC4-A、PC4-FCT、LV/LSMP，或违反 AAI+LV 的局部乘积容量。

更短簇递归不能无限进行。严格下降账本见 `docs/rh-pc4-short-cluster-descent-ledger.md`：将短簇规范化为 `S=(I,𝓑,Q,R,κ,σ)` 后，物理长度层、Bohr 体积层、锚/相位自由度和 dyadic 层高度组成离散势函数。每个真正的 `shorter_SC` 步都使该势函数下降；若不下降，则是同一短簇模板重复承载偏差，转入 PC4-PI/PC4-A/PC4-FCT、LV/LSMP 或局部乘积容量违反。

## 5. 闭合定理

**Theorem PC4-SC-Closure（短簇分支闭合，条件化）。** 假设以下接口成立：

1. AAI 正规形与局部乘积容量估计成立；
2. LV/LSMP 低体积、低层数与可求和尾层吸收成立；
3. PC4-PI、PC4-A、PC4-FCT 已按各自 closure 文档条件化闭合；
4. 复杂度逃逸只能进入 FCT/LSMP/CE 已列接口。

则短簇不能作为 RH 离线零点反例场在 PC4 中的最终逃逸通道。更精确地说，若无穷多尺度上短簇承载离线零点级异常，则必有一个已闭合分支被触发，或者违反 AAI+LV 的局部乘积容量界。

**证明。** 反设短簇是最终逃逸通道。由短簇种子命题，抽取固定短簇类型、固定 dyadic 层和同相位子列，并排除复杂度逃逸。由质量平衡命题，若短簇质量零频可求和，则 LV/LSMP 吸收，矛盾；若不可求和，则异常必须显露为 PI、A、FCT 或更短簇。前三者由假设闭合，故只能进入更短簇。

对更短簇应用局部密度命题。若其复用密度不超过局部乘积容量，异常量级不足以维持离线零点输入，矛盾；若超过局部乘积容量，则触发 PI、A、FCT、LV/LSMP 或违反 AAI+LV。前四者均被假设闭合，最后一项违背接口假设。于是每一层更短簇递归都必须继续缩短窗口或降低体积预算。

由 `SC-Descent-Termination`，在排除 PI/A/FCT、LV/LSMP、CE 并接受 AAI+SC-LD1 局部乘积容量界后，不存在无限 `shorter_SC` 递归链。终止时只能落入 LV/LSMP、PI、A、FCT 或容量违反，均不允许。这与“短簇为最终逃逸通道”矛盾。证毕。

## 6. 对 PC4 总攻的影响

PC4-SC-Closure 将短簇分支从“剩余局部硬点”推进为条件化闭合分支。至此，PC4 的主要显性逃逸分支中，PC4-A、PC4-PI、PC4-FCT 与 PC4-SC 均已有 closure 文档。剩余总攻义务集中在：

1. PC4-Dual：过密对偶、多零点相干或反相位选择失败的统一排斥；
2. PC1-PC2-PC3-PC4 的全文接口一致性审查；
3. 把所有条件化接口逐项替换为精确引用或逐行证明。
