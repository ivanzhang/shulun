# MME-2 乘法能量硬攻稿

**状态：** 直接攻击短窗口粗合数匹配的内部矛盾场。

## 1. 对象

固定奇素数 `P` 与列 `c`。粗合数点为

`N_i=k_iP+c=u_i v_i`

其中所有素因子均 `>sqrt(P)`。在短窗口中取

`0<=k_1<...<k_m<P`, `k_m-k_1<sqrt(P)`。

列反例要求这些粗筛残洞全部由这类粗合数匹配吸收。

## 2. 已严格闭合的互因子刚性

若两个点共享大因子 `q>sqrt(P)`，则

`q | (N_i-N_j)=(k_i-k_j)P`。

因 `(q,P)=1`，得 `q|k_i-k_j`。但短窗口中

`0<|k_i-k_j|<sqrt(P)<q`，矛盾。

因此短窗口粗合数点两两互素：

`gcd(N_i,N_j)=1`。

等价地，它们的所有大因子标签集合两两不交。

实验 `experiments/mme2_short_window_energy_scan.py` 在高粗合数密度列中验证：最佳短窗口内 `repeated=0`、`max_pair_gcd=1`。

## 3. 乘法差方程

对任意 `i<j`：

`u_jv_j-u_iv_i=(k_j-k_i)P`。

记 `d_{ij}=k_j-k_i<sqrt(P)`。则

`u_jv_j ≡ u_iv_i mod P`，且差值为小倍数 `d_{ij}P<P^{3/2}`。

由于每个因子 `>sqrt(P)`，乘积在 `[P, P^2)` 尺度。两个互素乘积要相差小于 `P^{3/2}`，意味着它们在乘法双曲线上高度聚集。

## 4. 互素短乘积能量

定义短窗口乘积集合

`A={N_i}`。

其差集满足

`A-A subset P * [-sqrt(P),sqrt(P)]`。

因此所有差都落在 `O(sqrt(P))` 个 `P` 的倍数上。加性能量至少为

`E_+(A) >= m^4 / |A-A| >= m^4 / O(sqrt(P))`。

另一方面，`A` 中元素两两互素且每个都是 `>sqrt(P)` 粗合数。互素粗合数集合的短区间加性能量应有上界；若能证明

`E_+(A) <= C m^2 polylog(P)`

则得到

`m^2 <= C sqrt(P) polylog(P)`。

这只能给 `m<=P^{1/4}` 级，不足以直接矛盾，但可与粗筛残洞局部密度结合。

## 5. 更强结构：差为 P 的小倍数

普通加性能量太弱。这里差不是任意小差，而是固定大素数 `P` 的倍数：

`N_i ≡ c mod P`。

所有 `N_i` 落在同一模 `P` 剩余类。互素粗合数在同一剩余类内短聚集，等价于许多互素因子对 `(u_i,v_i)` 落在曲线

`uv≡c mod P`

且高度 `uv` 连续接近。

固定一个因子 `u_i` 后，`v_i` 在模 `P` 中唯一：

`v_i≡c u_i^{-1} mod P`。

若还要求 `uv` 落在短窗口 `[KP, (K+sqrt(P))P]`，则 `v_i` 被限制在长度约

`P^{3/2}/u_i`

的实区间中。对 `u_i>sqrt(P)`，该长度小于 `P`，所以每个 `u_i` 至多给一个 `v_i`。

这说明短窗口粗合数点对应一组互异 `u_i` 的图像，而非多重覆盖。

## 6. MME-2 候选不等式

设短窗口长度 `D=sqrt(P)`。令

`M_c(I)=#{k in I: kP+c is粗合数}`。

目标证明存在绝对 `α<1` 或更具体上界，使

`M_c(I) <= D - R_c(I)`，

其中 `R_c(I)` 是同窗口粗筛残洞数中必须留下的素数数量。等价地，粗合数匹配不能填满粗筛残洞窗口。

更可操作的版本：

**MME-2a.** 在任意长度 `D=sqrt(P)` 的行窗口中，互素粗合数匹配数量满足

`M_c(I) <= D * (1 - κ/log P)`

而粗筛残洞数量满足

`H_{sqrt(P)}(I) >= D * (1 - o(1))/log P`。

此版本仍难，因为主量接近。

## 7. 更有希望的不等式：覆盖所有粗洞会强迫因子过密

若窗口中所有粗筛残洞都是粗合数，则每个粗洞 `N_i` 至少有一个因子

`u_i <= sqrt(N_i) < P`，且 `u_i>sqrt(P)`。

这些 `u_i` 两两不同。于是窗口中粗合数数量 `m` 需要 `m` 个不同素数/粗因子落在 `(sqrt(P),P)`。

并且每个 `u_i` 必须满足

`u_i | k_iP+c`

即

`k_i ≡ -cP^{-1} mod u_i`。

在长度 `D=sqrt(P)` 的窗口中，每个 `u_i>D` 的同余类命中至多一次。要覆盖 `m` 个指定粗洞，必须选择 `m` 个不同大模数，每个模数的指定剩余代表都恰好落入同一短窗口。

这就是大模数命中集中问题：

`#{u in (D,P): r_u(c) in I} >= m`。

实验中短窗口最大粗合数数仅约 `4,5,6,9`，远低于 `D/log P` 的粗候选总量；这提示大模数命中集中有强上界。

## 8. MME-2b：大模数命中集中上界

定义

`r_u(c) ≡ -cP^{-1} mod u`, `0<=r_u<u`。

对于行窗口 `I=[K,K+D)`，若 `u>D`，则 `u` 覆盖 `I` 当且仅当存在唯一 `k in I` 使

`kP+c≡0 mod u`。

等价于

`u | kP+c`。

因此命中数为

`Σ_{k in I} #{u>D: u|kP+c, u<P}`。

但若 `kP+c<P^2`，每个 `kP+c` 拥有的大因子个数有限；短窗口内这些大因子集合两两不交。于是总命中数等于因子出现总数。

若全部粗洞为粗合数，每个洞至少贡献一个命中。要推出矛盾，必须证明短窗口粗洞数超过可用大因子命中数。实验显示未必逐窗口成立，但全局列上可能成立。

## 9. 当前最真实的硬点

MME-2 的内部矛盾已经压到：

> 同一列、长度 `sqrt(P)` 短窗口内，大模数同余命中是否能覆盖所有粗筛残洞？

这不是简单互素矛盾；它需要一个大模数命中分布定理。若能证明对每个短窗口存在至少一个粗筛残洞没有大因子命中，则列命题闭合。

## 10. 下一步实验与理论入口

下一步应扫描每个短窗口：

- 粗筛残洞数；
- 粗合数数；
- 粗素数数；
- 大因子命中数；
- 最大连续粗合数覆盖块。

寻找可证明的规律：例如粗素数在每个 `sqrt(P)` 窗口是否至少出现一次，或粗合数覆盖块长度是否受小素数骨架限制。

若发现“每个粗筛短窗口有粗素数”规律，则它是列命题的局部加强版本；证明它仍很难，但会给出真正的内部矛盾场目标。

## 11. 窗口级扫描修正

新增脚本：`experiments/rough_window_prime_presence_scan.py`。

结果显示，“每个 `sqrt(P)` 短窗口都有粗素数”是错误的强命题。例如：

- `P=1009` 存在长度 `31` 窗口，含 `8` 个粗筛候选，全部为粗合数；
- `P=503` 存在长度 `22` 窗口，含 `6` 个粗筛候选，全部为粗合数。

因此 MME-2 不能以逐短窗口必有素数为目标。正确目标应转为：

1. 零粗素数窗口只能是局部孤岛；
2. 其前后必须出现补偿性粗素数密集；
3. 若整列无素数，则这些孤岛必须串接覆盖全列，但串接会迫使大因子复用或列均衡/镜像缺陷。

## 12. 新目标：零粗素数窗口的隔离不等式

定义坏窗口 `I`：`I` 中粗筛候选非空但全为粗合数。

实验提示坏窗口存在，但其粗合数数目较小且大因子全互异。下一步应证明：坏窗口之间不能无缝拼接；两个相邻坏窗口若重叠/接近，则大因子标签集合增长过快，或产生共享因子短差矛盾。

候选引理：

**Bad-window isolation.** 长度 `sqrt(P)` 的坏窗口族在同一列中具有正间隔，且每个坏窗口消耗互异大因子资源。若坏窗口覆盖整个 `[0,P)`，所需大因子资源超过可用乘法匹配容量。

这保持在列反例内部，不转换命题。

## 13. Bad-window isolation 推进

已新增：`docs/bad-window-isolation-hard-attack.md` 与 `experiments/bad_window_isolation_scan.py`。

扫描显示坏窗口大量存在，但坏运行只覆盖粗候选的一部分，且坏窗口内大因子完全互异。由此 MME-2 的硬点变为坏运行资源账本：若整列无粗素数，坏运行必须覆盖全部粗候选；但粗筛候选存在大量短间隔簇，每个坏簇都要求互异大因子资源。

下一步专攻粗筛候选间隔谱：证明短间隔簇数量足够多，从而坏簇的大因子资源需求超过列内可复用资源。

## 14. 锚因子列表着色接口

`docs/bad-window-anchor-factor-lemma.md` 将粗合数匹配改写为锚因子列表着色：每个粗候选 `k` 的可用颜色为

`L(k)={u: sqrt(P)<u<P, u|kP+c}`。

若列反例成立，则所有粗候选列表非空；若两个点距离 `<sqrt(P)`，它们不能选同一颜色。下一步硬点是证明粗候选大簇不可能全部拥有这样的可用锚因子列表。

## 15. 二阶锚复用能量接口

`docs/anchor-list-coloring-pressure.md` 表明一阶容量不足以闭合。新的硬点是二阶复用能量：列反例要求所有粗候选都有非空锚列表；若锚因子不大量复用，需要过多不同锚；若复用，则复用点间距至少为该锚因子 `q>sqrt(P)`，且必须落在粗候选大簇中。下一步应证明这种复用能量不足以覆盖整个大簇。

## 16. 锚复用能量不等式候选

`docs/anchor-reuse-energy-hard-attack.md` 将 MME-2 压成二阶能量形式：覆盖所有粗候选要求 `A>=N`，而锚种类若不足则由 Cauchy 迫使复用能量下界；冷却距离给复用能量上界。下一步核心是证明有效锚种类 `Q_eff` 相对粗候选数 `N` 有固定比例损耗。
