# 稀疏残洞的重叠能量账本

**状态：** SCD 全单点分支的局部 Barrier 接口。

## 1. 目标

短差核心分解后，若没有非平凡短差核心，则待补/残洞集合是 `sqrt(P)`-分离集，规模至多 `O(sqrt(P))`。

要让这种稀疏集合仍维持行反例，剩余素数层必须把小壳 `S_B(y)` 的线性多候选几乎全部覆盖。覆盖线性多点而最终只剩稀疏残洞，必然产生重叠能量或有效覆盖不足。本稿把这点写成账本恒等式。

## 2. 基本账本

固定行 `y` 与小壳 `B`。令

`S=S_B(y)`，`s=|S|`。

对剩余根基 `q notin B`，令

`A_q=S ∩ {c: yP+c≡0 mod q}`。

定义原始覆盖容量

`C=sum_{q notin B} |A_q|`，

覆盖并集

`U=|⋃_{q notin B} A_q|`，

重叠能量

`E=C-U`。

完整洞数为

`H=s-U=s-C+E`。

这是精确恒等式。

## 3. 稀疏残洞下界

若残洞集合 `H_P(y)` 是 `D=sqrt(P)`-分离，则

`H<=ceil(P/D)<=sqrt(P)+1`。

因此

`U=s-H >= s-sqrt(P)-1`。

代入 `E=C-U` 得

`E >= C-s+H >= C-s`，

并且若 `H>=1`，则

`E >= C-s+1`。

若行反例要求 `H=0`，则

`E=C-s`。

此时要产生新洞 Barrier，需要比较转移前后的账本，而不是单行账本。

## 4. 转移账本

对 `x->y`，有

`H_y-H_x = Δs-ΔC+ΔE`。

若旧核被杀灭且无新洞释放，则 `H_y=0` 而 `H_x=|K|>0`，所以

`ΔE = -H_x-Δs+ΔC`。

Barrier 恒等式写为

`LB=ΔE-ΔC+Δs+KILL`。

若全杀旧核，`KILL=H_x`，故

`LB=0`。

所以静默杀核要求三项精确抵消：

`ΔE-ΔC+Δs=-H_x`。

这说明单看 `E` 大不够；必须证明在稀疏分支中这种精确抵消不可能，或者抵消会导致列均衡/镜像缺陷。

## 5. 稀疏分支的可证强化

若 `S_B(y)` 线性规模，而 `H_y=0` 或 `O(sqrt(P))`，则剩余层覆盖并集 `U_y` 几乎等于 `S_B(y)`。

在全单点分支中，每个残洞/待补点彼此距 `sqrt(P)` 以上。于是大标签覆盖的短差互斥不再局部触发，但覆盖并集要贴近整个小壳。为做到这一点，剩余层必须使用大量不同根基的禁余类。

这些禁余类在小壳迁移 `x->y` 时不能只增加覆盖而不释放：每个根基 `q` 的覆盖列也按

`-tP mod q`

平移。若其新增覆盖吞掉某些旧洞，则其旧覆盖位置同步释放。全单点静默要求所有释放再被其它层覆盖，形成覆盖交换链。

交换链若有短边，进入 KFCI；若全为长边，则链长度受宽度 `P` 限制，不能覆盖线性多释放点而保持全单点。

## 6. 覆盖交换链不等式

定义每个根基 `q notin B` 的覆盖迁移差

`ΔA_q=A_q(y)\A_q(x)`，

释放差

`∇A_q=A_q(x)\A_q(y)`。

在完整列窗口中，`|ΔA_q|` 与 `|∇A_q|` 至多差边界 `O(1)`，因为都是同一模 `q` 余类在长度 `P` 窗口中的平移。

若静默无新洞，则所有释放点 `∇A_q` 中落入小壳的新候选必须被其它根基覆盖。于是形成有向交换图：

`released point -> covering root q'`。

若交换图有两个释放点距离 `<sqrt(P)` 且被大标签补，则 KFCI 启动。若没有，则释放点集是 `sqrt(P)`-分离，规模 `O(sqrt(P))`。

因此静默稀疏分支要求总释放规模 `O(sqrt(P))`。

但若小壳线性迁移，某个小素数坐标非静止，则 `S_B(y)\S_B(x)` 的规模为线性量级，约

`P/M_B` 级别。

当 `P/M_B >> sqrt(P)` 时，释放规模线性超过稀疏上界，矛盾。

## 7. 得到的条件版闭合

设 `B` 选取使

`M_B < c sqrt(P)`

且小壳迁移非静止。则

`|S_B(y)\S_B(x)| >= c_B P/M_B >> sqrt(P)`。

若静默无新洞，释放差必须被剩余层覆盖。若不存在短差核心，则释放差必须 `sqrt(P)`-分离，最多 `O(sqrt(P))`，矛盾。

所以在该参数区间：

- 要么存在短差核心，KFCI 闭合；
- 要么释放规模超过稀疏容量，给出 `LB_B>=1`。

## 8. 参数含义

这揭示了最优选壳原则：不能把 `B` 取得过大。若 `M_B` 远超 `sqrt(P)`，小壳基本单元太大，释放规模下界可能不足。应选择 `B` 为最小 primorial 超过或低于某个阈值，使

`P/M_B` 仍大于 `sqrt(P)`。

也就是取

`M_B < sqrt(P)`。

这与用户强调的“不要有限模板控制无限变化”一致：`B` 应随 `P` 缓慢增长到 `M_B≈sqrt(P)`，作为递归剥离层，而不是固定模板。

## 9. 剩余严审点

需要把第 7 节中的释放规模下界写成精确引理：

**Shell-difference lower bound.** 若 `M_B<sqrt(P)/C` 且存在 `b in B` 使 `b∤t`，则

`|S_B(y)\S_B(x)| >= c(B) P/M_B - O(M_B)`。

一旦该引理成立，稀疏分支由容量矛盾排除。

若所有 `b in B` 都整除 `t`，小壳静止，不能杀旧核中属于 `S_B(x)` 的点；转回静止无杀伤引理。

## 10. SDL 闭合推进

已新增：`docs/shell-difference-lower-bound.md`。

原先 `P/M_B` 型下界已修正为密度级壳差公式。令

`δ_B=prod_{b in B}(1-1/b)`。

若小壳相位非静止，则完整 CRT 单元中

`D_B=|Ω(a(y))\Ω(a(x))|>0`，并且

`D_B/M_B >= δ_B/(max B-1)`。

因此

`|S_B(y)\S_B(x)| >= [δ_B/(max B-1)]P - O(M_B)`。

这给出线性释放规模。若取第一个不整除 `t=y-x` 的小素数 `b_*` 作为前缀终点，则所有更小素数整除 `t`，故其 primorial 小于 `P`，从而 `b_*` 只有对数级；于是线性系数虽衰减，也仍使释放规模远大于 `sqrt(P)`（充分大 `P`）。

当前剩余参数点：把 `b_*` 上界和 `δ_B/(b_*-1)` 下界显式化，并给出小 `P` 有限验证阈值。
