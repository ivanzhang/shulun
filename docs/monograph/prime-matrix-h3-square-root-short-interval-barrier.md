# H3 与平方根长度短区间素数问题的硬边界

**状态：** `proved_equivalence_to_sqrt_short_interval_input_not_closure`

本文把 H3 逐行正余量放到标准解析数论坐标中：它不是普通平均素数定理，而是 `x≈q^2` 处
长度 `q=sqrt x` 的逐窗短区间素数下界。

## 1. H3 点态下界等价于对齐短区间下界

设 `p<q` 为相邻素数，`2<=s<=q`，`I_s=[(s-1)q+1,sq]`。由相邻壳层单点性，

\[
M_{H3}(p,s)
=
\pi(sq)-\pi((s-1)q)+O(1).
\tag{SIB-1}
\]

因此任意固定 `kappa>0` 的点态第一行尺度转移

\[
M_{H3}(p,s)\ge \kappa\,\pi(q)
\tag{SIB-2}
\]

等价于对所有对齐短区间

\[
\pi(x+q)-\pi(x)
\ge
(\kappa+o(1)){q\over\log q},
\qquad x=(s-1)q,\quad q\le x<q^2.
\tag{SIB-3}
\]

因为 `x≈q^2` 时 `log x≈2log q`，这就是平方根长度窗口的正比例素数下界。

## 2. 与素数间隙的关系

若每个对齐 `q` 行都有素数，则 `(q,q^2]` 内不存在长度超过约 `2q` 的素数空隙。原因是任何长度
`>2q` 的区间必包含某个完整对齐行 `I_s`。所以 H3 点态正余量推出平方根量级素数间隙控制：

\[
g(x)\ll \sqrt{x}
\quad (x\le q^2\text{ 的该壳层内}).
\tag{SIB-4}
\]

更强的 `(SIB-2)` 还要求每个对齐窗口里不仅有一个素数，而且有正比例 `q/log q` 个素数。

## 3. 为什么常规已知输入不足

素数定理只给总量：

\[
\pi(q^2)-\pi(q)\sim {q^2\over2\log q},
\]

不能控制单个长度 `q` 窗口。

即使使用常见显式误差项，误差也远大于单窗主项 `q/log q`。在 RH 型误差
`O(sqrt{x} log^2 x)` 下，窗口主项为 `sqrt{x}/log x`，仍被误差中的对数因子压住。

已知无条件短区间素数定理给出的长度指数仍大于 `1/2`；例如 Baker--Harman--Pintz 给出足够大
`x` 时 `[x,x+x^{0.525}]` 含素数。这不能推出长度 `x^{1/2}` 的逐窗结论。

因此 H3 逐行闭合必须提供新的结构性输入：不是再调用平均 PNT，也不是线性筛临界下界，而是证明
方阵/CRT 刚性排斥所有能制造平方根长度空窗的低模缺陷。

## 4. 与筛法奇偶障碍

H3 位于 Buchstab 参数

\[
u={\log(q^2)\over\log q}=2
\]

的边界。线性筛在 `u=2` 不能给正下界，因为素数与双粗半素数在筛层面不可区分。这就是为什么
单纯“覆盖能力不足”论证会反复遇到双粗补洞问题。

统一缺陷判据的作用正是把奇偶障碍显性化：

```text
若双粗/尾标签试图补掉全部素数质量，
则必须产生 D_y rough-count 缺陷或 F_y tail-Fourier 缺陷。
```

但要完成无条件证明，还必须证明这些缺陷不能持续。

## 5. 当前可证明的最强闭合形式

当前已证链条为：

```text
H3 低余量
=> D_y 缺陷或 F_y 缺陷
=> 若二者均有统一上界，则 H3 正余量。
```

因此 H3 的真正最小新输入是：

```text
Square-root Defect Exclusion.
For y=q^theta and suitable d, every aligned q-window in (q,q^2]
satisfies D_y <= eta*q/log q and F_y(d) <= d*lambda*q/log q.
```

这就是平方根长度短区间问题在方阵/CRT 矛盾场语言中的精确版本。证明它即可完成 H3/行命题；
没有它，则不能诚实宣称逐行正余量已经无条件闭合。
