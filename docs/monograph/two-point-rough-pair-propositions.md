# 两点 P-rough 命题 A/B 的严格审查

本文审查用户提出的两个命题：

- **(A)** 对任意偶数 `w>0`，`P×P` 方阵后半数行中，存在 `x` 使 `x` 与 `x-w` 都是对所有 `p<=P` 的素数非零同余数。
- **(B)** 对任意偶数 `w>0`，`P×P` 方阵后半数行中，存在 `x` 使 `x` 与 `w-x` 都是对所有 `p<=P` 的素数非零同余数。

这里 `P×P` 方阵取 `1<=x<=P^2`，后半数行为 `P^2/2 < x <= P^2` 的相应行段。

## 1. A 与 B 的同余条件等价

对任意素数 `p<=P`，条件

`x-w not≡0 (mod p)`

等价于

`x not≡ w (mod p)`。

而

`w-x not≡0 (mod p)`

也等价于

`x not≡ w (mod p)`。

因此 A 与 B 在同余意义下完全相同，均要求

`x not≡0,w (mod p)` 对所有 `p<=P`。

偶数 `w` 的作用是使 `p=2` 处两个禁余类合并为同一个奇偶约束；对奇素数 `p∤w` 则排除两个同余类。

## 2. 关键障碍：在 P×P 方阵内 P-rough 等于素数

若 `1<x<=P^2` 且 `x` 对所有素数 `p<=P` 非零同余，则 `x` 没有不超过 `P` 的素因子。若 `x` 合数，则有素因子 `q<=sqrt(x)<=P`，矛盾。因此：

> 在 `P×P` 方阵内，任意大于 1 的 `P`-rough 数必为素数。

于是若 A 对固定偶数 `w` 与所有充分大的 `P>w` 成立，则存在

`P^2/2 < x <= P^2`

使 `x` 为素数，且 `0<x-w<P^2` 也为 `P`-rough，因此 `x-w` 也是素数。

## 3. 推论：A/B 蕴含 Polignac 型强结论

固定任意偶数 `w>0`。若 A/B 对所有充分大的 `P` 成立，则存在无穷多素数对

`(x-w, x)`

相差 `w`。当 `w=2` 时，这直接推出孪生素数猜想；对一般偶数 `w`，推出 Polignac 型固定偶差素数对无穷多。

而且命题还要求素数对出现在每个形如后半方阵区间的窗口中，强于单纯“无穷多”。这已经远超当前已知定理。

## 4. 因此不能作为当前论著的无条件定理

当前矛盾场框架、方阵行列结构与 CRT 刚性，尚不能无条件证明这两个命题。若把 A/B 当作已证，将等价于把孪生素数/Polignac 级别的核心难题直接放入论证。

因此在合著论著中，A/B 应标记为：

`CONJECTURAL / requires prime-pair-level breakthrough`。

## 5. 可保留的严格版本

可以无条件保留以下弱化命题：

1. **CRT 周期版本。** 在完整 CRT 周期 `M=prod_{p<=P}p` 中，若局部禁余类不覆盖所有类，则由 CRT 存在 `x` 使 `x` 与 `x-w` 同时非零。这是局部可容许性，不给出短区间位置。
2. **条件筛法版本。** 在 Hardy--Littlewood prime-pair conjecture、强 Elliott--Halberstam 或足够强的两点 rough Jacobsthal 界下，A/B 可推出。
3. **平均或有限验证版本。** 对有限 `P,w` 可计算验证；对平均 `w` 或长于 `P^2` 很多的窗口，可用筛法得到候选存在。

## 6. 进入矛盾场论著的正确位置

A/B 是矛盾场思想的自然“二点粗候选”强化，但它不是当前已闭合链条的一部分。它应作为未来突破方向：

- 二点 Jacobsthal 函数 `J_2(P,w)` 的短窗口上界；
- 两点粗候选容量不能被禁余类完全覆盖；
- 从 CRT 可容许性到 `P^2` 级短窗口存在性的局部-全局桥。

只有证明类似

`J_2(P,w) <= P^2/2`

的无条件上界，才可把 A/B 放入无条件主链。
