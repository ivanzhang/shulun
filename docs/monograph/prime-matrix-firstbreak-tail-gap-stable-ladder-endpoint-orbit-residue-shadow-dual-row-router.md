## 1. 行/列对偶投影

CRT residue shadow `s` 通过对偶投影进入 dual-row shadow `R_s`，并保留 signed excess：

```text
s -> R_s
E(R_s)=E(C_s).
```

若 `R_s` 没有真实行压力，列 shadow excess 会在行纤维平均中被吸收，回到 mean/singleton/sparse 或三出口。
