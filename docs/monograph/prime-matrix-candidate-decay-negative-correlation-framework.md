# 候选收缩与斜线负相关：BPN(P) 的概率-组合论证框架

**状态：** `candidate_decay_framework_established_strict_independence_open`

## 1. 核心新思路

不直接证明"某个特定 a 的列含素数"，而是证明"所有候选 a 在有限步内被淘汰"。

## 2. 定义

设 P > 11 奇素数，y = P^{1/3}（小骨架阈值）。

- **小骨架洞集** B_y(a,R) = {r ∈ [1,R] : a+rP 不被任何 p ≤ y 整除}
- **补丁命中** = ∃ q > y 使 q | a+rP
- **候选集** A_R = {a ∈ [1,P] : B_y(a,R) 中每个洞都被补丁命中}
- **淘汰** = a ∉ A_R（存在未补洞，即 a+rP 是 y-smooth 或素数）

## 3. 候选收缩定理（概率模型）

**定理（启发式）**：在独立模型下，

```
E[|A_P|] ≤ P · (1 - ρ(u))^{H}
```

其中 H ≈ P · ∏_{p≤y}(1-1/p) 是洞数，u = 2log P / log y，ρ 是 Dickman 函数。

对 y = P^{1/3}：u ≈ 6，ρ(6) ≈ 2·10^{-5}，H ≈ P·0.56/log(P^{1/3})。

数值验证：P ≥ 10007 时 E[|A_P|] < 0.013 << 1。

## 4. 斜线负相关性（严格）

**引理（斜线复用刚性，§85 已证）**：
若素数 q > y 同时整除 a+r₁P 和 a+r₂P，则 q | (r₁-r₂)。

**推论**：对洞距 |r₁-r₂| < q 的两个洞，它们不能共享同一补丁素数 q。
特别地，对 q > P-1 的素数，任何两个洞都不能共享 q 作为补丁。

**负相关含义**：不同洞的"被补丁命中"事件之间有负相关——
一个洞消耗了补丁 q 后，距离 < q 的其他洞不能再用 q。

## 5. 严格化路径

### 5.1 Second Moment Method

设 X_r = 1[r 是洞且 a+rP 是 y-smooth]（淘汰指示器）。
则 a 被淘汰 ⟺ ∑_r X_r ≥ 1。

E[∑ X_r] = H · ρ(u)（主项）。

由 Paley-Zygmund：P(∑ X_r ≥ 1) ≥ E[∑X_r]² / E[(∑X_r)²]。

E[(∑X_r)²] = ∑_{r,s} E[X_r X_s] = ∑_r E[X_r] + ∑_{r≠s} E[X_r X_s]。

**关键**：由斜线负相关，E[X_r X_s] ≤ E[X_r]·E[X_s]（负相关或独立）。
若严格负相关成立：E[(∑X_r)²] ≤ (∑ E[X_r])² = (Hρ(u))²。
则 P(∑X_r ≥ 1) ≥ 1。

但这太强了——实际上负相关只对共享补丁的洞对成立，不是所有洞对。

### 5.2 Lovász Local Lemma 路径

定义"坏事件" B_a = {a 的所有洞都被补丁命中}（即 a 未被淘汰）。
P(B_a) ≤ (1-ρ(u))^H。

洞之间的依赖图：两个洞 r₁, r₂ 相关当且仅当 ∃ q > y 使 q | gcd(r₁-r₂, ...)。
依赖度 d ≤ ∑_{q>y} (洞数/q) ≈ H · ∑_{q>y} 1/q ≈ H · (log log P - log log y)。

LLL 条件：e · P(B_a) · (d+1) < 1。
即 e · (1-ρ(u))^H · H·log(log P/log y) < 1。

对 P 充分大，(1-ρ(u))^H → 0 指数快，而 d 只多项式增长，所以 LLL 条件最终满足。

### 5.3 显式阈值

需要找 P_0 使得对 P ≥ P_0，LLL 条件成立。
数值估计：P_0 ≈ 10^4 量级（与 codex 的 BPN 有限证书范围衔接）。

## 7. 仍需严格化的步骤

1. **Dickman ρ(u) 的精确下界**：对 u=6，ρ(6) ≥ 1.9·10^{-5}（已知显式）
2. **洞数 H 的精确下界**：由 Mertens 显式版本
3. **负相关性的严格证明**：从斜线复用刚性推出 E[X_r X_s] ≤ E[X_r]E[X_s]
4. **LLL 依赖度的精确上界**：需要控制洞对之间的依赖结构
5. **P_0 的显式计算**：使 LLL 条件对 P ≥ P_0 成立
6. **P < P_0 的有限验证**：由 BPN 有限证书覆盖
