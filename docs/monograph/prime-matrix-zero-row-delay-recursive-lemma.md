# 旧筛零行延迟与递推闭合引理

**状态：** `zero_row_delay_supports_but_does_not_replace_q_row_survivor_lemma`

本文接续 `prime-matrix-dec-ospc-exclusion-hardpoint.md`，处理一个新的递推想法：

```text
若旧 p-筛的宽 p 全覆盖零行很晚才出现，
且晚于下一素数 q 的 q×q 覆盖范围，
则 Row(p) 应可递推到 Row(q)。
```

实验见 `docs/monograph/prime-matrix-zero-row-crt-audit.md`。该想法方向正确，但必须区分三种对象：

1. `p` 对齐零行：`[(r-1)p+1,rp]` 无旧 `p`-筛幸存者；
2. 任意滑动宽 `p` 零窗：`[u,u+p-1]` 无旧 `p`-筛幸存者；
3. 真正递推所需的 `q` 行：`[(s-1)q+1,sq]` 含旧 `p`-筛幸存者，且不只含 `q^2`。

第三项才是 `Row(q)` 的直接入口。第一项只是证据，不能单独替代第三项。

## 1. 记号

设 `p<q` 为相邻奇素数，并令

\[
P(p)=\prod_{\ell\le p}\ell.
\]

旧 `p`-筛幸存集合为

\[
\mathcal R_p(I)=\{n\in I:(n,P(p))=1,\ n>1\}.
\]

定义 `q` 行

\[
I_s^{(q)}=[(s-1)q+1,sq]\qquad(1\le s\le q).
\]

## 2. 严格递推引理

**Lemma ZRL-1（旧筛 q 行幸存者推出 Row(q)）。**
若对每个 `1<=s<=q`，

\[
\mathcal R_p(I_s^{(q)})\setminus\{q^2\}\ne\varnothing,
\tag{QSurv}
\]

则 `q×q` 方阵每行含素数，即 `Row(q)` 成立。

**证明。**
取任意 `s`。由 `(QSurv)`，存在

\[
n\in I_s^{(q)},\qquad n\ne q^2,\qquad (n,P(p))=1,\qquad n>1.
\]

若 `n<=p^2`，则 `n` 没有不超过 `p` 的素因子；若 `n` 合成，其最小素因子不超过 `sqrt n<=p`，矛盾。因此 `n` 为素数。

若 `p^2<n<=q^2`，则任何合数 `n` 的最小素因子大于 `p`。由于 `q` 是大于 `p` 的最小素数，所有素因子至少为 `q`，于是合数只能满足 `n>=q^2`；在 `n<=q^2` 下唯一可能是 `n=q^2`。但已排除 `q^2`。故 `n` 仍为素数。

所以每个 `I_s^{(q)}` 都含素数。证毕。

该引理是严格闭合的；它也是 `Annulus-Rough` 的最干净版本。

## 3. p 对齐零行延迟的严格含义

定义首个 `p` 对齐零行为

\[
Z_p=\min\{r>p:\mathcal R_p([(r-1)p+1,rp])=\varnothing\}.
\]

若

\[
Z_p>\left\lceil {q^2\over p}\right\rceil,
\tag{AlignedDelay}
\]

则所有与 `p` 行边界对齐且完全落在 `q^2` 之前的宽 `p` 行都有旧筛幸存者。

这是严格结论，但它只控制 `p` 对齐行。`q` 行的左端点为 `(s-1)q+1`，通常不与 `p` 行边界对齐。一个长为 `q=p+g` 的 `q` 行包含完整 `p` 对齐行，当且仅当它的起点到下一条 `p` 行边界的距离不超过 `g`。当素数间隙 `g` 很小时，这只覆盖约 `(g+1)/p` 比例的 `q` 行。

因此：

```text
AlignedDelay alone
does not imply QSurv.
```

这正是此前 `SEB/ASB` 缝合窗口必须存在的原因。

- 对 `p<=200` 扫描 `p` 对齐零行；
- 对全部 `p<=2000` 检查 `q×q` 内旧筛 `q` 行。

结果：

```text
aligned_zero_inside_q_square_cover = 0
q_square_q_row_failures = 0
min found row / ceil(q^2/p) = 1.5945945945945945
```

关键样本包括：

| ---: | ---: | ---: | ---: | --- |
| 13 | 17 | 23 | 169 | after |

这些数据支持零行延迟直觉：已找到的 `p` 对齐零行均远晚于下一素数平方覆盖。但实验也说明，真正可用于递推的是 `QSurv`，而不是 `AlignedDelay`。

## 5. 与 PDEC-or-SAE 的连接

若 `(QSurv)` 失败，则存在 `q` 行 `I_s^{(q)}` 满足

\[
\mathcal R_p(I_s^{(q)})\subseteq\{q^2\}.
\]

这等价于一个长度 `q` 的短窗口被旧小素数完全覆盖，除可能的 `q^2` 单点外没有旧筛幸存者。按 `prime-matrix-annulus-rough-nonempty-hard-attack.md`，它产生负低模端点亏损；按 `prime-matrix-directed-endpoint-crtdefect-bridge.md`，它进入

```text
Directed Endpoint CRTDefect / OSPC*.
```

因此当前最小硬点可改写为：

```text
QSurv failure
=> DEC/OSPC*
=> PDEC or SAE.
```

其中：

- `PDEC`：若失败行不是孤立现象，则坏行集合产生非零 Fourier/CRT 缺陷；
- `SAE`：若失败行孤立，则必须证明旧核心锚点或壳层幸存者不能被同一单窗端点尖峰全部逃逸。

这给出本路线的正确闭合目标：

```text
Row(p)
+ QSurv(p,q) via PDEC-or-SAE exclusion
=> Row(q).
```

## 5.1 q 零行向 p 阶段反推的精确二分

新增 `docs/monograph/prime-matrix-reverse-zero-row-dichotomy.md` 证明了一个更精确的反推命题。

设 `q=p+g`，若 `2<=s<q` 的 `q` 行是零行，则该整行实际上已经被旧 `p`-筛覆盖：

\[
\mathcal R_p(I_s^{(q)})=\varnothing.
\]

原因是：非 `q` 倍数若旧 `p`-筛幸存，则在 `q^2` 内自动为素数；右端点 `sq`
中 `s<q`，且不存在 `p<s<q` 的素数，所以 `s` 也含有不超过 `p` 的素因子。

令

\[
a_s=(s-1)q\bmod p=(s-1)(q-p)\bmod p.
\]

则出现二分：

1. 若 `a_s>=p-(q-p)`，该 `q` 零行包含一个完整 `p` 对齐零行；
2. 若 `a_s<p-(q-p)`，该 `q` 零行只给出相邻两个 `p` 行的后缀/前缀缝合零窗。

因此用户提出的“反推到第 `k` 个方阵内已有零行”在第一支严格成立；但第二支只反推出
`p` 阶段的滑动/缝合零窗，不能由 `Row(p)` 直接排除。审计
`docs/monograph/prime-matrix-reverse-zero-row-dichotomy-audit.md` 显示，在 `p<=2000`
的假想核心区 `q` 行中，直接包含完整 `p` 行的比例约 `0.00616`，缝合支约 `0.99384`。

所以递推证明若要成功，归纳命题必须从单纯 `Row(p)` 强化为：

```text
Row(p) + SeamSafe/ASB-or-PDEC.
```

这不是转换命题，而是把“q 零行反推 p 阶段矛盾”的唯一缺口定位到缝合零窗排斥。

## 6. CRT 反射配对的正确用法

新增审计见 `docs/monograph/prime-matrix-row-reflection-period-audit.md`。它澄清了一个有用但必须精确使用的对称性。

令

\[
M=\prod_{\ell\le p}\ell,\qquad N={M\over p}.
\]

若 `p` 对齐行 `r` 的非平凡列全部被旧筛覆盖，则镜像行

\[
r^\ast=N-r+1
\]

也全部被覆盖。证明如下：对非平凡列点 `n=(r-1)p+c`，`1<=c<p`，

\[
M-n=(N-r)p+(p-c),
\]

仍是镜像行 `N-r+1` 的非平凡列。若 `ell|n`，则 `ell|(M-n)`。所以覆盖关系被取负映射保持。

但这个反射不是平移周期。行 `r` 与 `r^\ast` 同时为零，只说明零行集合关于周期中点反射对称；它不推出零行集合以 `r` 或 `2r-1` 为周期，也不要求 `r` 或 `2r-1` 整除 `N`。审计样本给出明确反例：`p=23` 时 `r=59` 是零行，`N=9699690`，镜像行也为零；但

\[
N\bmod(2r-1)=9699690\bmod117=39\ne0.
\]

因此“短周期整除”不能作为证明出口。

用户指出的“第二周期复现”可严格写成二面体轨道：

\[
r,\quad N-r+1,\quad N+r,\quad 2N-r+1,\ldots
\]

相邻间隔交替为

\[
N-2r+1,\qquad 2r-1.
\]

其中 `2r-1` 只是镜像行到下一周期同名行的距离，不是覆盖掩码的平移周期。
行平移 `d` 会把所有列值加上 `dp`。对任意旧素数 `ell<p`，由于 `(p,ell)=1`，
要保持模 `ell` 的覆盖相位不变必须有 `ell|d`；若对全部 `ell<p` 同时保持，
则必须有 `N|d`。因此“斜线斜率不变”不等于“截距相位不变”。CRT 保证的平移周期是 `N`，不是 `2r-1`。

审计还直接检查了已知零行：`r+(2r-1)`、`r+2(2r-1)` 和 `r^\ast-(2r-1)` 均不是零行。故短平移周期路线被样本排除。

若把问题放宽为“相位组合可以改变，只要求全覆盖现象复现”，仍不能从反射自动推出 `r`、`2r` 或 `2r-1` 是现象周期。新增审计直接检查了已知零行的这些候选平移：

```text
r+r,\quad r+2r,\quad r+(2r-1)
```

以及后续若干倍，均没有复现全覆盖。正确可保留的是一个条件稳定子引理：

**Lemma ZRL-2（现象周期的必要 gcd 条件）。**
设零行集合 `Z⊂Z/NZ` 对平移 `d` 不变，且 `r` 是首个正零行。则

\[
\gcd(N,d)\ge r.
\]

否则轨道 `r+md (mod N)` 的正代表中存在小于 `r` 的零行，矛盾。特别，对
`d=r,2r,2r-1`，若它们真是现象周期，就必须满足相应强 gcd 限制。审计样本中这些候选平移不仅没有复现零行，而且 `gcd(N,d)<r`，因此被直接排除。

特别地，`p=23` 的首个零行是 `r=59`。逐列审计显示：

- 第 `59` 行区间 `[1335,1357]` 的非平凡列全部被 `<=23` 小素数覆盖；
- 第 `118=2*59` 行区间 `[2692,2714]` 在列 `2,8,10,16,20,22` 留下旧筛幸存者；
- 其中 `2693,2699,2707,2711,2713` 是素数，`2701=37*73` 是双粗合数。

所以第 `118` 行不仅没有复现全覆盖，反而明确含有多个素数。这说明“全覆盖现象周期”必须作为额外可证结构，不能由 `k` 或 `2k` 的数值关系自动推出。

进一步的完整周期审计见 `docs/monograph/prime-matrix-p23-zero-recurrence-audit.md`。在 `p=23` 的 CRT 行周期

\[
N=\prod_{\ell<23}\ell=9699690
\]

中，零行总数为 `3456`，镜像行之前确有 `3454` 次复现，首次复现在第 `2612` 行，平移为 `2553`。这说明“镜像前复现”是真实存在的；但复现集合间隔不规则，最小间隔 `20`、最大间隔 `21789`，且第 `118` 行仍不是零行。因此复现的深层机制不是短周期，而是 CRT 相位空间中存在许多不同覆盖证书点。

每个零行可看成一个相位向量

\[
(r\bmod \ell)_{\ell<23}
\]

使 22 个非平凡列都落入小素数禁类。平移会改变全部截距相位；若新相位向量仍覆盖全部列，就出现复现。第 `59` 行与第 `2612` 行的覆盖证书不同：第 `59` 行由奇偶层覆盖偶列、模 `3,5` 和 `7,11,13,17,19` 补洞；第 `2612` 行奇偶层翻转，模 `3` 保持关键覆盖，其他小素数重新补齐。第 `118` 行虽然也有大量小素数覆盖，但剩余列没有被高层补齐，故失败。

进一步分层审计给出更精确的复现机制。固定第 `59` 行在 `2,3,5,7`
上的低素数骨架，即固定 `r≡59 (mod 210)`，镜像前仍有 `324` 个零行；
其中第一个是 `6569`。第 `59` 行与第 `6569` 行在 `2,3,5,7`
筛后都只剩列 `5,9,15` 三个洞，但第 `59` 行用 `13,17,19`
分别补洞，第 `6569` 行用 `19,13,17` 置换补洞。相反，若继续固定到
`2,3,5,7,11,13,17`，镜像前只剩第 `59` 行本身。因此真实复现不是
单一短周期，而是“低素数粗骨架频繁复现 + 高素数补洞标签偶然闭合”的层级
CRT 证书。

可保留的严格增益是：

```text
若 r0 是首个 p 对齐零行，
则前 r0-1 行和后 r0-1 行都没有 p 对齐零行。
```

这给出两端帽排斥。它能加强零行延迟和端点缺陷账本：任何早期零行都会同步生成一个末端零行；反过来，若坏行集合不能同时承受首端与尾端的对称端点异常，则进入 `PDEC-or-SAE`。但它仍不能单独替代 `(QSurv)`，因为 `q` 行不与 `p` 行边界对齐。

## 6.1. `2p` 短复现猜想的审计结论

新增审计见 `docs/monograph/prime-matrix-short-recurrence-gap-audit.md`。它区分两个命题：

1. 全局短复现禁止：任意两个零行的循环距离都大于 `2p`；
2. 边界短复现禁止：首零行与末零行跨周期距离大于 `2p-1`。

第一项是假的。完整周期扫描显示，`p=19` 时最小零行间隔为 `5`，且有 `24`
对间隔不超过 `2p=38` 的零行；`p=23` 时最小零行间隔为 `20`，且有 `20`
对间隔不超过 `46` 的零行。因此不能用“全局 `2p` 内不复现”闭合行命题。

第二项是正确的边界表述，但它不是独立新引理。若首零行为 `r0`，由反射对称末零行为
`N-r0+1`，所以跨周期首尾间隔为

\[
r_0+N-(N-r_0+1)=2r_0-1.
\]

故

\[
r_0>p\quad\Longleftrightarrow\quad \text{首尾跨周期间隔}>2p-1.
\]

这说明“边界 `2p` 短复现禁止”与目标“前 `p` 行无零行”同强，不能单独作为证明出口。
它的价值在于重写目标：必须证明首端帽/尾端帽的边界相位非覆盖，而不是证明全局短间隔非覆盖。

对 `p=23` 的短复现相位画像还显示，短复现簇发生在周期内部远离边界处。它们不是同一个证书的平移，
而是低素数相位部分同步、高素数标签重新补洞。例如间隔 `20,25,27,35` 的短复现对中，
`2,3,5,7` 骨架后的剩余洞通常只有 `3` 或 `4` 个，再由 `11,13,17,19`
置换补齐。这进一步说明：零行簇是层级 CRT 证书现象，不能作为边界帽的直接反例；边界帽需要单独的
CRT 最小代表下界。

`docs/monograph/prime-matrix-boundary-phase-noncoverage-hard-attack.md` 将这个边界任务进一步压缩为
`BPN-MCR/BPN-RM`：任意完整覆盖证书的 CRT 最小代表必须不小于 `p`；等价地，在前窗口中补掉最后残洞
必释放旧覆盖列。该文件还记录了 Sylvester 大因子弱输入：每个边界行必有某数含 `>p` 大素因子，
但仍需排除“小因子 × 大因子”覆盖全部大因子点的可能。

## 7. 审稿边界

本文严格证明了 `QSurv=>Row(q)`，并证明了 `AlignedDelay` 的精确作用范围。但本文没有证明 `QSurv` 对所有相邻素数无条件成立。

换言之，实验支持递推结构，但不能替代最终证明。若要完成无条件闭合，下一步必须直接攻：

```text
QSurv failure impossible,
```

等价地攻：

```text
DEC/OSPC* bad q-row
=> PDEC-or-SAE contradiction.
```

进一步的等价硬点见 `docs/monograph/prime-matrix-qsurv-grid-gap-hardpoint.md`。该文档把 `QSurv` 改写为 `q` 网格素数荒漠排斥，并说明普通素数间隙上界、`p` 对齐零行延迟和完整 CRT 周期均衡都不能单独替代该排斥。
