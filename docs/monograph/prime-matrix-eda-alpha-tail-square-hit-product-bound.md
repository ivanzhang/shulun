# 小素平方命中重数的乘积上界

**状态：** `alpha_tail_square_hit_product_bound_reduction_open`

本文继续压缩平方删除账本中的 `Hmax`。核心事实是：若同一个整数含有很多不同素数平方因子，则这些素数平方的乘积
必须整除该整数，因此受该整数大小直接限制。

## 1. 单点平方命中上界

令

\[
L_2(z)=\max\left\{L:\prod_{i=1}^{L}p_i^2\le z\right\},
\tag{SHP-1}
\]

其中 `p_i` 是第 `i` 个素数。若 `n<=z`，则 `n` 最多含有 `L_2(z)` 个不同素数的平方因子。

**证明。**  
若 `a_1^2,\ldots,a_L^2` 都整除 `n` 且 `a_i` 为互异素数，则

\[
\prod_{i=1}^L a_i^2\mid n\le z.
\tag{SHP-2}
\]

在所有 `L` 个互异素数中，前 `L` 个素数给最小乘积。因此

\[
\prod_{i=1}^{L}p_i^2\le \prod_{i=1}^{L}a_i^2\le z.
\tag{SHP-3}
\]

故 `L<=L_2(z)`。证毕。

## 2. 多点链 `Hmax` 上界

对 `m` 点链，任意起点 `d` 的平方命中重数为

\[
H(d)=\#\{(a,j):a^2\mid d+jr,\ 0\le j<m\}.
\tag{SHP-4}
\]

若所有点都不超过 `z_m`，则由单点上界逐点求和：

\[
H(d)\le mL_2(z_m).
\tag{SHP-5}
\]

因此

\[
H_{\max}\le mL_2(z_m).
\tag{SHP-6}
\]

代入平方删除账本得到无条件下界

\[
D_m^{\rm sq}\ge {S_1\over mL_2(z_m)}.
\tag{SHP-7}
\]

这一步完全初等，不依赖随机模型。

## 3. 闭合判据

结合粗筛/平方自由分解，若

\[
{S_1\over mL_2(z_m)}\ge \Delta_m^{\rm rough},
\tag{SHP-8}
\]

则

\[
E_m=\Delta_m^{\rm rough}-D_m^{\rm sq}\le0.
\tag{SHP-9}
\]

若 `(SHP-8)` 失败，则只能发生：

1. `S1` 的平方类总质量太低，进入 square-mass `PDEC`；
2. `L_2(z_m)` 上界太粗，需要利用 `m` 个相邻线性点的互质/同余排斥细化；
3. 粗筛端点盈余 `Delta_rough` 过大，回到 rough `PDEC/SAE`。
