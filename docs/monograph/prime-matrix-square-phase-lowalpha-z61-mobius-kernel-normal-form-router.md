# Prime Matrix square-phase low-alpha z=61 Möbius kernel normal form

**状态：** `z61_mobius_slice_balance_reduced_to_one_dimensional_kernel_open`

z=61 的二维边块已经降为一维 squarefree divisor-kernel：`Block_b=sum_m mu(m)K_b(m)R_m`。`K_b(m)` 只由 `m` 的因子拆分落入哪个 balance bucket 决定，且完全非负。因此最终剩余不再是边级双线性枚举，而是证明一维核加权的 `R_m=A_m-N/m` 在 Möbius 奇偶两片内没有超过 `0.221522` 的符号偏斜；若失败，则直接抽取为 one-dimensional kernel PDEC。

## 1. 一维核公式

```text
K_b(m)=sum_{d|m, m/d in supp(lambda), bucket(d,m/d)=b} |lambda_d lambda_{m/d}|
Block_b=sum_m mu(m) K_b(m) R_m,   R_m=A_m-N/m.
```

其中 `m` 为 squarefree，且 `K_b(m)>=0`。这一步把二维边问题降成一维模数核问题。
