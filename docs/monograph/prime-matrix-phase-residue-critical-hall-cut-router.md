# Prime Matrix phase-residue critical-Hall-cut 证书

**状态：** `phase_residue_hall_defect_reduced_to_critical_hall_cut_or_existing_caps_open`

phase-residue Hall defect 给出一个有限非空缺陷族 {S: |S|>|N(S)|}。在该族中按大小、缺陷量和稳定哈希选择规范 S_*；若它可分解，则某个连通分量仍缺陷，故可取连通 core。S_* 的真子集均满足 Hall，剩余缺口被压成 cut boundary B_*=N(S_*) 上的不可再分容量缺口。真正剩余从任意 Hall defect 变为 phase-residue critical-Hall-cut PDEC/cap。

## 1. 临界 Hall 割分解

从有限非空缺陷族 `F={S subset L_zeta: |S|>|N_G(S)|}` 中选择规范临界子集 `S_*`。
选择规则先最小化 `|S|`，再最大化缺陷量，最后用 stable hash 破平局。

```text
S_*=argmin_{S in F} (|S|,-Delta_H(S),stable_hash(S))
B_*=N_G(S_*)
Delta_*=|S_*|-|B_*|>0
for every proper T subset S_*: |T|<=|N_G(T)|
```

因此任意 Hall 缺陷不能匿名保留；它必须落到一个连通、真子集 Hall 正常、边界明确的 critical cut，或回流已有出口。

## 2. critical cut 字段

| field | meaning |
| --- | --- |
| `critical_subset` | 在所有 \|S\|>\|N(S)\| 的负载子集中按 size、defect、hash 选择的规范 S_*。 |
| `connected_core` | 若缺陷分成多个连通分量，至少一个分量仍有正缺陷；S_* 取该分量。 |
| `proper_subset_hall_ok` | S_* 的真子集均不再违反 Hall；否则会更小。 |
| `cut_boundary` | B_*=N(S_*) 是该临界缺陷的全部可支付边界。 |
| `critical_margin` | Delta_*(S_*)=\|S_*\|-\|B_*\|>0，是不可再分的容量缺口。 |
