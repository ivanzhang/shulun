# EDA 对角二次相位锁

**状态：** `diagonal_quadratic_phase_lock_reduction_open`

本文继续专攻 `x=p` 对角端点。对角覆盖相位为

\[
k\equiv -p^2\pmod q,\qquad q<p.
\tag{QPL-1}
\]

因为 `p^2` 是每个 `q<p` 模下的二次剩余，覆盖相位不是任意残基，而是被二次字符锁定。

## 1. 二次字符锁

令 `chi_q` 为奇素数 `q` 的 Legendre 字符。若 `q<p` 且 `q\nmid k`，则

\[
q\mid p^2+k
\quad\Longrightarrow\quad
\chi_q(k)=\chi_q(-1).
\tag{QPL-2}
\]

**证明。**  
由 `q|p^2+k` 得 `k≡-p^2 mod q`。因此

\[
\chi_q(k)=\chi_q(-1)\chi_q(p^2)=\chi_q(-1).
\tag{QPL-3}
\]

证毕。

于是：

- 若 `q≡1 mod 4`，覆盖列必须是模 `q` 的二次剩余类；
- 若 `q≡3 mod 4`，覆盖列必须是模 `q` 的二次非剩余类；
- 但更强的是：不是所有该字符类都覆盖，而是其中唯一残基 `-p^2 mod q` 覆盖。

## 2. 对角幸存列的充分条件

**定理 QPL-1（二次字符避让充分条件）。**  
若存在 `1<=k<p`，使对每个奇素数 `q<p` 都满足：

1. 若 `q|k`，则 `q\nmid p^2+k`；
2. 若 `q\nmid k`，则
   \[
   \chi_q(k)=-\chi_q(-1),
   \tag{QPL-4}
   \]

则 `p^2+k` 没有 `<p` 素因子，从而为素数。

**证明。**  
对 `q=2`，`p^2+k` 被 `2` 整除当且仅当 `k` 为奇数；条件 `(QPL-4)` 只处理奇素数，
因此实际使用时还需取 `k` 为偶数以避开 `2`。

对奇素数 `q<p`，若 `q|k`，则 `p^2+k≡p^2 not≡0 mod q`。若 `q\nmid k` 且 `(QPL-4)`
成立，则由 `(QPL-2)` 的逆否形式，`q` 不可能整除 `p^2+k`。所以没有 `<p` 素因子。
又 `p^2<p^2+k<(p+1)^2` 且 `p\nmid p^2+k`，该数只能是素数。证毕。

这个充分条件很强，可能难以直接构造；它的价值是揭示对角零行必须阻止所有这种字符避让列。

## 3. 精确相位避让

二次字符条件还不是必要条件。真正必要且充分的是：

\[
\forall q<p,\qquad k\not\equiv -p^2\pmod q.
\tag{QPL-5}
\]

**定理 QPL-2（对角精确避让等价）。**  
`U_p(p)>0` 当且仅当存在 `1<=k<p` 满足 `(QPL-5)`。

**证明。**  
`k` 满足 `(QPL-5)` 正是说没有任何 `<p` 素数整除 `p^2+k`。由 DBB-1，该点等价于素数。
证毕。

因此二次字符锁给出两层接口：

```text
强接口：构造满足所有 Legendre 反相条件的偶数 k；
精确接口：构造避开所有单残基 -p^2 mod q 的 k。
```

强接口更结构化但更苛刻；精确接口等价原命题。

## 4. 为什么普通容量仍不足

普通容量估计给出期望级别：

\[
(p-1)\prod_{q<p}\left(1-{1\over q}\right)
\asymp {p\over \log p}.
\tag{QPL-6}
\]

它解释了实验中对角余量与第一行素数计数同量级。但这只是平均启发；在长度 `p`、筛到 `p`
的端点上，普通一维下界筛处于奇偶/端点屏障，不能直接推出正性。

因此对角端点要突破，必须使用 `(QPL-1)` 的固定相位和 `(QPL-2)` 的二次字符锁，而不能只靠
总容量。

## 5. 下一步硬点

对角分支的当前最窄命题可写成：

```text
Diagonal-QPL:
For every odd prime p, the residue classes
k ≡ -p^2 (mod q), q<p,
do not cover [1,p-1].
```

可攻方向：

1. 用二次字符反相构造偶数 `k`；
2. 用固定相位大筛证明单残基覆盖存在正余量；
3. 证明若全覆盖，则二次字符模式在短区间内过度偏置，触发 PDEC/Fourier 缺陷；
4. 将对角 QPL 与内部 PDL 分支合并，形成完整 EDA 分叉证明链。

当前仍不能宣称对角分支闭合；本文完成的是把它从普通覆盖问题压成带二次字符锁的固定相位问题。
