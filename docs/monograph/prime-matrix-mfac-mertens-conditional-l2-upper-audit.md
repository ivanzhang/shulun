# MFAC 全 epsilon Mertens 条件化 L2--Upper 审计

- 单实例：`epsilon=0.1`
- 全称量词：`for_every_positive_epsilon`
- 常数：`C_epsilon` 仅可依赖当前 epsilon，且不要求 epsilon 一致。

```text
mertens_assumption_status=externally_assumed
conditional_l2_upper_status=assumption_chain_registered
unconditional_l2_upper_status=unproved
rh_proved=false
```

互素限制分部求和、带参数尾和界和 Euler--phi L2 聚合仍是开放证明义务；本证书不证明 Mertens 型界、Mass--Lower、Chebyshev 能量桥、Mellin 收缩、零自由区域或 RH。
