# 斜线平方激活与零行覆盖阈值

**状态：** `line_activation_necessary_not_sufficient_reduced_to_small_representative_phase_lock`

本文专门回应“素因子斜线在 `q^2` 前尚未连线，是否能证明 `P` 行以内不可能全覆盖”的几何想法。

## 1. 平方激活引理

固定素数 `P`，研究行窗口

\[
(r-1)P+c,\qquad 1\le c<P.
\]

若某个 `q<P` 命中点 `n`，但

\[
n<q^2,
\]

则 `n=q m` 且 `m<q`。若 `m>1`，它有某个素因子 `<q`，所以该点已经被更小素数斜线覆盖。

因此：

```text
q 在 q^2 之前的命中不是独立覆盖；
q 第一次可能作为最小素因子独立覆盖，是从 q^2 开始。
```

这给出严格的“斜线连线”解释：`q^2` 是 `q` 线从 shadow hit 变成 independent hit 的激活点。

## 2. 激活行

一编号第 `r` 行区间为 `[(r-1)P+1,rP]`。素数 `q` 的平方点落入

\[
r_q=\left\lceil {q^2\over P}\right\rceil.
\]

所有 `q<P` 的激活行均不超过 `P`；`P^2` 位于第 `P` 行右端点，是 `P` 线的最后边界点。

所以用户的几何图像是正确的：

```text
到第 P 行，所有 q<P 的独立斜线都已经至少出现；
P 到 P^2 的竖线是最后的边界连线。
```

但这只给出必要结构，不能单独证明无零行。

解释：

- `P<=11`：即使允许完整 CRT 周期中的任意残基相位，`<P` 素数的一残基类也不能覆盖全部列，所以全周期永无零行。
- `P=13` 起：任意相位覆盖能力首次出现，所以完整 CRT 周期内可以有零行。
- 但 `P=13` 的全部 `<P` 斜线在第 `10` 行已经激活，任意相位也已具备覆盖能力；实际第 `10..13` 行仍不是零行，首零行推迟到第 `169=P^2` 行。

因此：

```text
斜线未激活 => 只能说明某些大 q 尚无独立覆盖能力；
斜线已激活 + 任意相位可覆盖 => 仍不保证早期小代表元行全覆盖。
```

剩余硬点是相位问题，而不是斜线数量问题。

## 4. 首零行标签结构

首零行中，每个列的最小覆盖标签都已经过平方激活。例如：

```text
P=13, row=169:
min-label hist = {2:6, 3:2, 5:2, 7:1, 11:1}

P=23, row=59:
min-label hist = {2:11, 3:4, 5:2, 7:2, 13:1, 17:1, 19:1}
```

这说明真正零行不是依赖 `q^2` 前的 shadow hit，而是所有最后补洞标签都已作为最小素因子独立出现。

## 5. 更新后的证明接口

用户的几何模型给出一条有价值的严格链：

```text
未到 q^2 的 q 命中
=> shadow hit
=> 可归并到更小素数覆盖
=> 零行的独立标签必须来自已平方激活的素数。
```

但行命题需要的最后一步是：

```text
Early Phase-Lock:
对 1<=r<=P，实际小代表元相位
(- (r-1)P mod q)_{q<P}
不能同时实现一个完整覆盖证书。
```

也就是说，最小硬点从“斜线有没有画出来”压缩为：

```text
已激活独立斜线的相位在早期对角段不能同步补齐最后残洞。
```

若这一步失败，则失败不是普通覆盖容量，而是一个早期对角 CRT 相位缺陷，应路由到
`EDA-Dual / PDEC / SAE / ColumnCRT`。
