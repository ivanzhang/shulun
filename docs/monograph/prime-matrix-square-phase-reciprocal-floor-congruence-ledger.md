## 4. 证明边界

已闭合：

```text
q | floor(P^2/ell)+s
iff exists u: floor(P^2/ell)=q*u-s
iff P^2/(q*u-s+1) < ell <= P^2/(q*u-s).
```

未闭合：

```text
这些倒数短区间在素数 ell 上满足足够强的二维 Selberg 分布账本；
或任何违反该账本的持续偏差都被 PDEC/SAE/ColumnCRT 排斥。
```
