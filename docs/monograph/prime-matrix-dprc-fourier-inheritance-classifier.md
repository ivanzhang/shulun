# DPRC Fourier 频率继承分类

**状态：** `audit_and_reduction_not_a_proof`

本文接续 `DPRC层叠轮 Fourier 能量路线`，把

```text
30 -> 210 -> 2310 -> ...
```

中的强 Fourier 频率分成两类：

- `inherited`：该频率的周期已经整除上一层轮，只是旧相位在新轮上的提升；
- `new-layer`：该频率必须使用新增素因子层，因而是新的低模 PDEC 候选方向。

## 1. 分类准则

令当前轮为 `W_j`，上一层轮为 `W_{j-1}`。对单位类中心化偏差 `F_W(a)`，把它延拓为
`Z/WZ` 上非单位处为零的函数，并扫描非零加性 Fourier 频率

\[
\widehat F_W(h)=\sum_{a\in U_W}F_W(a)e^{2\pi iha/W}.
\]

若最强频率 `h` 的周期

\[
R(h,W)={W\over (h,W)}
\]

满足 `R(h,W) | W_{j-1}`，则该频率是 `inherited`。否则令

\[
N(h,W;W_{j-1})={R(h,W)\over (R(h,W),W_{j-1})},
\]

其素因子就是本层新增相位因子。若这些新增因子上仍有大 Fourier 质量，就不能把它解释成旧轮偏斜残留，而必须进入 `new-layer PDEC` 出口。

## 3. 结构解释

这给出比“固定模规律”更合适的表述：

```text
每一层小模连乘轮都会显化真实相位偏斜；
若偏斜只沿旧周期提升，则它不能解释新层同步；
若偏斜进入新增素因子周期，则它是新层 PDEC 证书候选；
若每一层新增频率都不同步，则低模结构不能支付零行覆盖压力。
```

因此，素数在小模连乘同余中的刚性不是单层公式，而是逐层展开的相位谱。零行若想在 `P x P` 方阵内出现，必须让圆柱斜线容量压力、`BES` 正偏差同步、以及这些新增轮层频率同步发生。这个同步越强，就越容易被 Fourier/PDEC 证书捕获。

## 4. 当前最小硬点

当前可攻接口更新为：

```text
Fourier Inheritance Clamp:
  对 W_j = prod_{r<=z_j} r，若最强或累计强频率在新增因子层 N(h,W_j;W_{j-1}) 上持续存在，
  则给出 new-layer W_j-unit PDEC 证书；

  若所有新增层频率都不持续同步，
  则 BES 危险交集不能由低模连乘相位支撑，
  剩余正偏差只能分散到高模斜线，
  并进入对偶大筛/分散估计吸收。
```

这不是最终证明；它把用户提出的“无穷迭代、无穷层叠、无穷缠绕”转成一个可审稿的二分接口：每升一层，要么产生可命名 PDEC 证书，要么证明该层不能为零行全覆盖提供同步容量。

## 5. 新增层能量分散更新

新增 `docs/monograph/prime-matrix-dprc-newlayer-energy-dispersion.md` 与脚本
`experiments/prime_matrix_dprc_newlayer_energy_scan.py` 后，上述继承分类被提升为整层能量恒等式。

对 `W=rW0`，`r|h` 的频率正是旧层继承频率，`r∤h` 的频率正是新增层频率。全扫
`P<=100000`、`P>=10007` 得：

| 层 | 新增因子 | 新增能量占比 min/avg/max | centered peak 最大值 | 高 L1 peak | 高 L2 peak |
|---:|---:|---:|---:|---:|---:|
| `30 -> 210` | `7` | `0.580510 / 0.897118 / 0.997260` | `0.611625` | `0.280206` | `0.271803` |
| `210 -> 2310` | `11` | `0.854837 / 0.926300 / 0.973218` | `0.292146` | `0.170133` | `0.114485` |

因此最新读法是：新增层能量占大头，但它在 `2310` 层分散成高维相位振荡；若这种能量想承担零行覆盖压力，必须先低维集中，而低维集中正是 `new-layer PDEC` 证书。
