**状态：** `cold_product_block_inventory_schema_closed_candidate_bound_projection_open`

`ColdProductDyadicBlockInventoryLedger` 的 schema 与候选集合生成规则已闭合：固定 source tuple、cold key 与 dyadic 产品块后，候选支撑就是通过 cold/no-return guard 的 `d|h0` 产品，且同产品同 key 已商化为一个支撑点。但还没有候选集合计数或 Rankin 可和符号界，也没有 primitive 投影规则；因此最新最窄点是 `ColdProductBlockCandidateCountOrSymbolicBound`。
