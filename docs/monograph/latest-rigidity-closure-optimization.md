# 最新刚性洞见下的闭合优化审查

## 0. 结论先行

本轮把两个最新洞见并入统一矛盾场：

1. **扩展斜线层锁**：`P±t` 圆柱螺旋相位块可系统组织小素因子层；
2. **`q|w` 二禁降一禁**：二点筛中若小素数 `q|w`，禁类 `{0,w}` 合并为单禁类。

它们显著优化结构账本和常数，但仍不能单独完成终局无条件闭合。原因是：

- 行列命题尾段仍需要 `PTA` 的 `1/log P` 素数密度节省；
- 二点筛仍需检查 `BMD=>BST-2=>BST=>TLI` 是否隐藏筛余下界；
- RH 仍需 controlled exits 的独立定理化。

本轮真正推进是把最新刚性转化为更小的待证接口，而不是把未证接口改名为已证。

## 1. 扩展斜线层锁的实际作用

广义斜率锁 `GSL` 已给出：

\[
q|k,\quad q|P\pm t
\quad\Longrightarrow\quad
k+(P\pm t)l
\]

在非绕回段被 `q` 整段标记。

圆柱绕回时，轨道连续延续，但整数值为

\[
n_l=k+(P+t)l-PW_l
\]

或

\[
n_l=k+(P-t)l+PW_l^-.
\]

固定绕回层 `W_l=u` 时，同余相位常数，因此每个满足相位条件的绕回块可整段锁定。

所以扩展斜线层锁的严格结论是：

```text
小素因子层 = 广义斜率锁定块并集。
```

这使反例只能在粗数带中继续存在。

## 2. 对方阵行列命题的优化

### 2.1 小素层已经可完全确定化

取 `Y=P^alpha`。经 `GSL` 删除所有 `q<=Y` 的锁定块后，剩余集合是

\[
G_Y(I)=\{n\in I:P^-(n)>Y\}.
\]

行列反例必须满足：

\[
G_Y(I)\subseteq
\bigcup_{Y<p\le P}\{n:p|n\}.
\]

因此仍需证明：

\[
B_Y(I):=
\sum_{Y<p\le P}\#\{n\in G_Y(I):p|n\}
<|G_Y(I)|.
\tag{RHI}
\]

### 2.2 扩展斜线锁对 `PTA` 的贡献

`PM-R2B` 尾段已经化为粗锚平均素数命中：

\[
T(M)=
\sum_{\substack{m\sim M\\P^-(m)>Y}}
\left(\pi((X+H)/m)-\pi(X/m)\right).
\]

扩展斜线锁可以进一步用于 `p` 变量本身。因为若 `p<=P` 为合数，则存在

\[
q\le\sqrt P
\]

使 `q|p`。若把斜线层锁扩展到 `T>=sqrt P`，则所有合数 `p` 的小因子层也可被几何标记。

这给出一个更强但仍诚实的 PTA 版本：

**PTA-GSL。** 对粗锚 `m`，把候选 `p` 区间先删除所有 `q<=sqrt P` 的广义斜率锁。剩余候选即为素数候选。若这些剩余候选在 `m` 平均上满足 Selberg 上界筛主项，则

\[
T(M)
\le
(1+\varepsilon)
\frac{H}{\log P}
\sum_{\substack{m\sim M\\P^-(m)>Y}}\frac1m
E_M.
\]

### 2.3 仍未自动闭合的点

GSL 可以标记合数 `p`，但要得到 `1/log P` 的平均密度仍需要筛上界或等价相位均衡。具体地：

- GSL 给出“哪些位置被小素因子标记”；
- `PTA` 需要“未被标记的位置在所有粗锚平均中不超过模型主项”。

这正是 Selberg 上界筛/大筛平均的内容。若不引用外部筛定理，就必须从圆柱相位块均衡直接证明。

所以方阵行列无条件化的最小真实接口从 `PTA` 强化为：

```text
PTA-GSL: 扩展斜线锁后的 p-候选平均密度满足 Selberg 主项。
```

## 3. 对二点筛的优化：`q|w` 二禁降一禁

二点筛中局部禁类数为

\[
\nu_q(w)=
\begin{cases}
1,&q|w,\\
2,&q\nmid w.
\end{cases}
\]

因此小素层密度为

\[
V_w(Y)=\prod_{q\le Y}\left(1-\frac{\nu_q(w)}q\right).
\]

相对最硬情形 `q∤w` 的增益为

\[
\prod_{\substack{q|w\\3\le q\le Y}}
\frac{1-1/q}{1-2/q}
=
\prod_{\substack{q|w\\3\le q\le Y}}
\frac{q-1}{q-2}.
\]

几何解释是：两族斜线

\[
x\equiv0\pmod q,\qquad x\equiv w\pmod q
\]

在 `q|w` 时完全重合，所以二禁降为一禁。

### 3.1 对常数的真实改善

这个增益能：

- 增大二点粗候选基数；
- 降低小素同步峰；
- 改善有限阈值和特殊 `w` 的常数；
- 让含多个小奇素因子的 `w` 明显比 `w=2` 容易。

### 3.2 对终局主常数的限制

对固定 `w`，所有 `q|w` 是有限集合。随着 `Y->infty`，奇异因子只改变乘法常数，而不改变大素尾段主项：

\[
2\log(1/\alpha).
\]

因此最硬全称仍是 `w=2`。对 `w=2`，除了 `q=2` 的奇偶骨架外，没有奇素数二禁降一禁增益。

所以该洞见优化常数和局部结构，但不能单独消除二点筛的 parity barrier。

## 4. 二点筛的优化后最小接口

把新洞见纳入后，二点筛链条应改写为：

```text
GSL-w: 二点小素锁，含 q|w 二禁降一禁
=> singular-factor ledger
=> BMD/WBE2 分布接口
=> Buchstab transfer without hidden lower-bound
=> TLI
```

其中新增的可闭合部分是：

\[
V_w(Y)=\prod_{q\le Y}(1-\nu_q(w)/q)
\]

及其奇异因子。

仍未闭合的是：

```text
BMD=>BST-2=>BST=>TLI 是否完全不使用未证筛余下界。
```

这必须作为下一步第二优先级审查。

## 5. 对 RH 矛盾场的优化意义

扩展斜线锁和 `q|w` 降禁对 RH 的直接作用有限，但方法论上有价值：

- 它们说明“局部刚性层”应先全部确定化；
- 剩余异常应统一进入一个总能量或总出口不等式；
- RH controlled exits 也应类似写成可量化的出口容量，而不是继续扩展局部图像。

因此 RH 方向的优化仍是：

```text
controlled exits 四列表
或 正性二次型
```

而不是把方阵小素锁直接移植为 RH 终局证明。

## 7. 诚实闭合状态

当前尚不能写成“命题已完全无条件闭合”。可以写成：

```text
小素锁层已经通过 GSL/GSL-w 几何化；
方阵行列剩余压缩为 PTA-GSL；
二点筛常数通过 q|w 奇异因子优化；
RH 保持 controlled-exit 形式化路线。
```

若要真正升级为无条件闭合，下一步必须证明 `BSI`，从而推出 `PTA-GSL`，或给出可引用的外部解析平均定理，并随后完成 `BMD=>TLI` 的无隐藏下界审查。
