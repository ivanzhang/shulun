# DPRC beta桶能量-同步性硬点

**状态：** `reduction_plus_audit_not_a_proof`

本文接续 `DPRC 相对筛余量接口`。目标不是把实验当证明，而是把剩余硬点从原始行覆盖问题继续压缩成一个更小、更结构化的 beta 桶同步性命题。

## 1. 桶向量归一化

固定 `alpha=0.43`，令

\[
S=|S_Y^\pm(P)|,\qquad
D_B=
\sum_{q\in B}
\left(
\#\{k\in S_Y^\pm(P):q\mid P^2\pm k\}
-
{S\over q}
\right),
\]

其中 `B` 跑过六个 beta 桶：

```text
[0.43,0.50), [0.50,0.60), [0.60,0.70),
[0.70,0.80), [0.80,0.90), [0.90,1.00).
```

归一化正偏差向量为

\[
x_B={D_B^+\over \sqrt S},\qquad D_B^+=\max(D_B,0).
\]

相对筛硬点

\[
D_+\le 3\sqrt S
\]

由更强的

\[
\|x\|_1=\sum_B x_B\le 3
\tag{BES-1}
\]

推出。

## 2. 能量出口

由 Cauchy 不等式，

\[
\|x\|_1\le \sqrt 6\,\|x\|_2.
\]

因此只要

\[
\|x\|_2\le {3\over \sqrt 6}=1.224744\cdots
\tag{BES-2}
\]

就直接得到 `(BES-1)`。

审计显示全范围最大值为

```text
max ||x||_2 = 1.233496
sqrt(6)*max ||x||_2 = 3.021437
```

只比 `(BES-2)` 多约 `0.008752`。所以粗 Cauchy 只差一个极小的同步性修正。

## 3. 新的充分接口

把硬点改写成如下二分：

```text
若 ||x||_1 < 12/5，则已经 < 3；
若 ||x||_1 >= 12/5，证明 ||x||_2 <= 6/5。
```

后一条给出

\[
\|x\|_1\le \sqrt6\,{6\over5}=2.939387\cdots<3.
\tag{BES-3}
\]

因此一个足够闭合 DPRC-RSM 的新目标是：

\[
\boxed{
\|x\|_1\ge {12\over5}
\quad\Longrightarrow\quad
\|x\|_2\le {6\over5}.
}
\tag{BES-4}
\]

这比直接证明 `D_+<=3sqrt(S)` 更小：它只排除“高正和同时高能量”的六尺度同向同步。

同一硬点还有一个更贴近最新审计的对偶写法：

\[
\boxed{
\|x\|_2>{3\over\sqrt6}
\quad\Longrightarrow\quad
\|x\|_1<{12\over5}.
}
\tag{BES-5}
\]

若 `(BES-5)` 成立，则低能量段由 Cauchy 给 `||x||_1<=3`，高能量段直接有
`||x||_1<12/5<3`。因此 `(BES-4)` 与 `(BES-5)` 都是可攻的充分接口；前者从高正和出发，
后者从高能量出发。

## 5. 结构性证明路线

`BES-4` 的失败会同时给出两种强信息：

```text
||x||_1 >= 12/5:
  多个 beta 桶都有正偏差，说明许多 q 尺度同时偏向同一动态粗骨架相位；

||x||_2 > 6/5:
  至少一个桶存在强尖峰，说明某个 q 尺度内有局部异常集中。
```

两者同时发生时，应可抽取以下结构缺陷之一：

```text
PDEC:
  多尺度正偏差由同一低模 CRT 相位支撑；

SAE:
  尖峰集中在短 q 区间或短互补因子窗口；

ColumnCRT:
  高素斜线命中被少数列相位重复承载。
```

因此当前最小硬点可更新为：

```text

+ ModelGap S(1-H)>3sqrt(S)
+ BES 高正和能量同步性命题
=> DPRC-RSM
=> Dynamic-Promoted Rough Capacity
```

这里 `BES` 是新的结构主攻点；它直接表达“小模连乘同余刚性限制多尺度高素斜线同时补洞”的内容。
