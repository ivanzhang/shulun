# H3 余量与方阵第一行素数计数的尺度桥

**状态：** `proved_global_average_scale_bridge_not_pointwise_h3`

本文回答一个关键结构问题：

```text
为什么 H3 余量的自然尺度是 q/log q？
它与 q 方阵第一行内的素数个数有什么本质关系？
```

结论是：二者不是偶然同量级，而是同一个“平方根筛障”在两个尺度上的投影。第一行素数数目为
`\pi(q)~q/log q`；H3 余量在 `q^2` 壳层的行平均为

```text
平均 H3 余量 ~ (1/2) * 第一行素数个数。
```

这个 `1/2` 来自 `log(q^2)=2log q`，不是数据拟合常数。

## 1. 第一行素数计数

令

\[
\Pi_1(q)=\#\{n\le q:n\text{ 为素数}\}=\pi(q).
\]

由素数定理，

\[
\Pi_1(q)\sim {q\over\log q}.
\tag{FR-1}
\]

这就是方阵第一行的素数尺度。

## 2. H3 余量的素数含义

设 `p<q` 为相邻素数，考虑 `q` 方阵的行窗口

\[
I_s=[(s-1)q+1,sq],
\qquad 2\le s\le q.
\]

H3 六轮集合 `A_s` 是 `I_s` 中完整 3 块的唯一 `6` 轮候选。定义

\[
M_{H3}(p,s)=\#\{n\in A_s:P^-(n)>p\}.
\]

由相邻壳层单点性：若 `1<n<q^2` 且 `P^-(n)>p`，则 `n` 必为素数；闭端点唯一合数例外是
`n=q^2`。因此，对非端点部分，

```text
H3 余量 = q 长度行窗口内的素数个数，至多差 O(1) 个 3 块边界点。
```

更精确地，对每一行有

\[
M_{H3}(p,s)
=
\#\{n\in I_s:n\text{ 为素数}\}+O(1),
\tag{FR-2}
\]

其中 `O(1)` 只来自 `I_s` 左右两端不完整 3 块；末行还需排除 `q^2`，但 `q^2≡1 mod 3`，不影响
完整 3 块判据。

## 3. 全局平均尺度桥

对 `2<=s<=q` 求和。由 `(FR-2)`，

\[
\sum_{s=2}^{q} M_{H3}(p,s)
=
\pi(q^2)-\pi(q)+O(q).
\tag{FR-3}
\]

除以行数 `q-1`，得到 H3 行平均

\[
\overline M_{H3}(q)
=
{1\over q-1}\sum_{s=2}^{q}M_{H3}(p,s)
=
{\pi(q^2)-\pi(q)\over q}+O(1).
\tag{FR-4}
\]

由素数定理，

\[
\pi(q^2)\sim {q^2\over 2\log q},
\qquad
\pi(q)=o\left({q^2\over\log q}\right).
\]

所以

\[
\overline M_{H3}(q)
\sim
{q\over 2\log q}.
\tag{FR-5}
\]

结合 `(FR-1)`：

\[
\overline M_{H3}(q)
\sim
{1\over2}\Pi_1(q).
\tag{FR-6}
\]

这就是 H3 余量与第一行素数个数的理论关系。

## 4. 底层本质：同一个平方根筛障

第一行与 H3 壳层的共同结构如下。

### 4.1 第一行

判断 `n<=q` 是否为素数，只需检查不超过 `sqrt(q)` 的素因子。素数定理给出第一行幸存素数数目：

\[
\pi(q)\sim {q\over\log q}.
\]

### 4.2 H3 壳层

H3 行位于 `n≈q^2`，判断 `n<q^2` 是否为素数，只需检查不超过 `q` 的素因子；旧筛上界 `p`
正是 `q` 的前一个素数。因此 H3 是同一个平方根筛障在 `x=q^2` 处的行窗口版本。

素数密度从

\[
{1\over\log q}
\]

变为

\[
{1\over\log(q^2)}={1\over2\log q}.
\]

而窗口长度仍为 `q`。所以 H3 的自然尺度是

\[
q\cdot {1\over 2\log q}
=
{q\over2\log q}.
\]

这说明 `q/log q` 量级来自“窗口长度 = 平方根尺度”，而不是来自某个有限模板或数据拟合。

## 5. Buchstab/Mertens 视角

从粗数筛看，H3 是 `u=2` 的临界问题：

\[
u={\log(q^2)\over\log q}=2.
\]

Mertens 乘积给出六轮候选的自然包络

\[
\#A_s\prod_{5\le r\le p}\left(1-{1\over r}\right)
\asymp {q\over\log q}.
\]

但在 `u=2`，不能把 Mertens 平均直接当作逐窗下界。Buchstab 临界常数与素数定理告诉我们：
平均真实素数余量应是 `q/(2log q)`，而非任意常数倍。此前文稿中的 `e^{-gamma}q/log q`
应理解为粗筛包络尺度；第一行桥接给出更本质的素数尺度解释。

## 6. 为什么这还不自动闭合逐行 H3

`(FR-6)` 是全局平均定理。它说明：

```text
H3 总质量与第一行素数质量同源，并且总量为第一行尺度的一半。
```

但它不能单独推出每一行都有正余量。一个假想反例行会把本应约为 `q/(2log q)` 的局部质量压到
`0`，然后由其他行补偿总平均。

因此逐行 H3 的真正闭合仍需证明：

```text
这种把第一行尺度的质量从某一 q 行完全搬走的行为，
必然产生 D_y 或 F_y 低模缺陷；
而这些缺陷不能在 CRT/方阵刚性中持续存在。
```

这正是 `prime-matrix-h3-unified-defect-criterion.md` 的作用。

## 7. 对全局通用公式的意义

第一行尺度桥给出以下理论解释：

1. `q/log q` 不是经验尺度，而是第一行素数计数与平方根壳层素数密度共同决定的必然尺度；
2. H3 平均常数应与第一行相差 `1/2`，因为壳层高度从 `q` 变为 `q^2`；
3. H3 全阻断不是“小余量波动”，而是把一整份第一行尺度质量在单行内压灭；
4. 因此反例必须外显为低模缺陷，而不是普通随机波动。

所以当前最自然的全局通用定理化目标是：

```text
First-row scale conservation + no persistent low-mod defect
=> every H3 row keeps positive q/log q-scale mass
=> 行命题闭合。
```

第一项已由素数定理和相邻壳层单点性给出；第二项仍是最后统一缺陷排斥输入。
