## 1. 反号信用恒等式

对固定深度格 `C`，设 `L_P(C)` 为来源 `P` 的 profile 线性余项，则

```text
credit(C)=sum_P |L_P(C)|-|sum_P L_P(C)|
         =2*min(sum_{L_P>0} L_P, sum_{L_P<0} |L_P|).
```

这把“跨 P 抵消”改写为可验收的反号质量下界。
