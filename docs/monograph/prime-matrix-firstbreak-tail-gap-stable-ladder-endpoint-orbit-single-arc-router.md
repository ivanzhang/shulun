## 1. 单叶片加权包

上一层给出：

```text
sum_a eta*S_a*W_a >= L,
0 <= W_a <= 1.
```

其中 `W` 是单个三角半圆叶片权重。

## 2. layer-cake 恒等式

逐点有：

```text
W_a = int_0^1 1_{W_a>=t} dt.
```

所以：

```text
sum_a eta*S_a*W_a = int_0^1 H(t) dt,
H(t)=sum_{a: W_a>=t} eta*S_a.
```

若积分至少为 `L`，则存在阈值 `t` 使：

```text
H(t) >= L.
```

## 3. 超水平单弧

对单个三角叶片，超水平集：

```text
A_t={a mod m: W_a>=t}
```

是一个位于同一轴向半圆内的循环弧。因此得到：

```text
sum_{a in A_t} eta*S_a >= L.
```

这就是新的 single-arc signed surplus packet。
