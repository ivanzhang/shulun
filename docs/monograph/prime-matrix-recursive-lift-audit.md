# 相邻素数方阵递推升级审计

**状态：** `recursive_lift_route_analysis_not_a_proof`

本报告审查一个新的递推思路：若 `p=p_k` 的 `p×p` 方阵行命题成立，是否可在升级到 `q=p_{k+1}` 的 `q×q` 方阵时，直接继承旧核心 `[1,p^2]` 的行素数存在性，只需处理 `(p^2,q^2]` 新区间。

## 1. 可以保留的正确部分

- 旧核心 `[1,p^2]` 中已经确定为素数的位置，升级到 `q` 后不会变成合数。
- 新素数 `q` 的整除线在 `q×q` 方阵中是第 `q` 列；低于 `p^2` 的多数 `q` 倍数已带有较小互补因子，真正新增的筛除压力主要从旧平方边界之后开始。
- 因此“递推剥离旧核心、重点处理 annulus `(p^2,q^2]`”是合理的结构视角。

## 2. 不能直接推出的关键点

`p` 行命题只保证每个 `p` 对齐行块

\[
I_t^{(p)}=[(t-1)p+1,tp]
\]

含素数；而升级后需要检查的是 `q` 对齐行块

\[
J_s^{(q)}=[(s-1)q+1,sq].
\]

即使 `J_s^{(q)}\subset[1,p^2]`，它通常也不包含完整的 `p` 行。设 `q=p+g`，`A=(s-1)q`。`J_s^{(q)}` 包含完整 `p` 行当且仅当下一个 `p` 倍数距 `A` 不超过 `g`：

\[
(-A\bmod p)\le g.
\]

由于 `g` 通常远小于 `p`，多数 `q` 行只是跨过两个相邻 `p` 行的尾部和头部，不能从“每个 `p` 行有一个素数”直接继承。

## 4. 正确的递推命题应如何加强

递推路线不能只假设 `Row(p)`。需要加强为一个缝合窗口命题：对每个由 `q` 行边界切出的旧核心窗口

\[
J_s^{(q)}\cap[1,p^2]
\]

必须含有旧核心素数。等价地，需要证明：每个跨越两个相邻 `p` 行的“尾段+头段”窗口含素数。

可定义加强命题 `Seam(p,q)`：对所有相关 `s`，

\[
J_s^{(q)}\cap[1,p^2]\cap\mathbb P\ne\varnothing.
\]

若有

```text
Row(p) + Seam(p,q) + Annulus(p,q) => Row(q),
```

则递推结构成立。其中 `Annulus(p,q)` 只处理 `(p^2,q^2]` 中的新行段。

## 5. 对你的斜线覆盖观察的严格化

- 新素数 `q` 在 `q×q` 方阵中主要表现为第 `q` 列的整除线。
- 对旧核心 `[1,p^2]`，真实素数不会被新增小素数筛消去；但行窗口重分块后，旧素数可能落在新行窗口之外。
- 因此“新斜线不能穿过旧已定素数”不是主要障碍；主要障碍是 `q` 行窗口是否捕获旧素数。
- 一旦 `Seam(p,q)` 成立，新区间 `(p^2,q^2]` 的覆盖压力确实比全局重证更局部，可作为递推剥离路线的核心优势。

## 6. 审稿结论

旧核心中的实际素数在升级筛后不会变成合数；但 p 行命题不能直接推出 q 行命题，因为 q 行边界与 p 行边界发生漂移，多数 q 行不包含完整 p 行。递推路线需要额外的滑动窗口/缝合行引理。

下一步若沿此路线推进，应优先证明 `Seam(p,q)`，而不是直接处理整个 `q×q` 方阵。`Seam` 的本质是滑动长度约 `q` 的旧核心素数窗口命题；它比原始行命题强，但比全局重新证明更局部。

## 7. 后续端点化压缩

后续审计见 `docs/monograph/prime-matrix-seam-endpoint-audit.md`。该文档把 `Seam(p,q)` 进一步压缩成端点屏障 `SEB(p,q)`：设旧 `p` 行的末端无素数段为 `sigma_t`，下一行首端无素数段为 `pi_{t+1}`，若

\[
\max_{1\le t<p}(\sigma_t+\pi_{t+1})<q,
\]

则旧核心中所有新 `q` 行缝合窗口自动含素数。因此递推链条的更窄形式是

```text
Row(p) + SEB(p,q) + Annulus(p,q) => Row(q).
```

该压缩明确了新的最小硬点：`SEB` 仍需独立证明，不能由 `Row(p)` 自动推出。

进一步无条件化审查见 `docs/monograph/prime-matrix-seb-unconditionality-audit.md`。结论是：全局 `SEB` 过强，接近要求 `p^2` 以下的边界素数间隙均不超过 `q`。实际 `Seam` 只需要由新 `q` 行边界采样到的端点条件，因此更精确的递推链条应改为

```text
Row(p) + ASB(p,q) + Annulus(p,q) => Row(q).
```

其中 `ASB` 排斥的是特定残基 `r_s=(s-1)q mod p` 上的端点互补空窗，而不是所有旧行边界上的全局端点屏障。

## 8. 平方壳层筛升级引理

后续严写见 `docs/monograph/prime-matrix-square-annulus-lift-lemma.md`。设 `p<q` 为相邻素数。若

\[
n\in(p^2,q^2],\qquad (n,\prod_{\ell\le p}\ell)=1,
\]

则 `n` 是素数，或 `n=q^2`。证明很短：若 `n` 为合数，最小素因子 `r` 满足 `p<r<=sqrt(n)<=q`，相邻素数性迫使 `r=q`；再由 `n<=q^2` 得 `n=q^2`。

因此升级到 `q` 后，壳层中对旧筛幸存集合真正新增筛掉的点只有 `q^2`。需要特别修正的是：`pq` 虽然在 `(p^2,q^2]` 且是 `q` 的倍数，但它已经被旧素数 `p` 筛掉，不是新增非冗余待定点。

于是 `Annulus(p,q)` 可替换为更窄的接口：

```text
Annulus-Rough(p,q):
每个需要由壳层负责的 q 行段含有旧 p-筛幸存者，且不只含 q^2。
```

一旦该旧筛幸存者存在，它由壳层引理自动为素数。递推链条可相应改写为

```text
Row(p) + ASB(p,q) + Annulus-Rough(p,q) => Row(q).
```

审计 `docs/monograph/prime-matrix-square-annulus-sieve-lift-audit.md` 在 `max_p=2000` 的 `302` 个相邻素数对上验证：壳层幸存合数例外失败数为 `0`，非冗余 `q` 倍数均为 `q^2`，完整壳层 `q` 行旧筛幸存者空段数为 `0`。这不能替代非空证明，但显著压缩了 `Annulus` 的逻辑义务。

## 9. Annulus-Rough 与有符号低模桥接

进一步硬攻见 `docs/monograph/prime-matrix-annulus-rough-nonempty-hard-attack.md`。该文档把递推闭合写成：

```text
Row(p)
+ ASB/RPD-or-positive-lowmod-defect-exit
+ Annulus-Rough-or-negative-lowmod-defect-exit
+ Signed-LowMod-Bridge
=> Row(q).
```

其中 Annulus-Rough 失败等价于某个壳层行段旧 `p`-筛幸存者为空，除可能单点 `q^2`。对该段 `I`，若定义

\[
D_T^{ann}(I)=R_T(I)-|I|\prod_{\ell<T}(1-1/\ell),
\]

则失败在 `T=p^+` 给出

\[
D_{p^+}^{ann}(I)
=-|I|\prod_{\ell\le p}(1-1/\ell),
\]

即量级约 `-|I|/log p` 的负低模端点缺陷。它与 ASB/RPD 中 FAC 尖峰的正低模缺陷属于同一类有符号异常。

当前递推路线的真正统一硬点因此是：

```text
large signed low-mod endpoint defect
=> directed CRTDefect/Tail-anchor/OSPC.
```

在该桥接证明完成前，递推链仍是严格归约，不是无条件闭合证明。
