# q 零行向 p 阶段反推的二分定理

**状态：** `proved_reverse_dichotomy_reduces_to_seam_not_direct_contradiction`

本文处理一个自然递推想法：

```text
若 q=p_{k+1} 方阵中存在行号 s<q 的零行，
能否结合 p 筛幸存者自动为素数的引理，
反推出 p=p_k 方阵内已有零行，从而直接矛盾？
```

结论是：有一个强的反推二分成立；但“直接反推出 p 对齐零行”只在少数相位成立。
多数相位给出的不是 p 对齐零行，而是跨两个 p 行边界的缝合零窗。因此该路线能压缩硬点，
但不能单靠 `Row(p)` 闭合。

## 1. 记号

设 `p<q` 为相邻奇素数，`q=p+g`。旧 `p`-筛幸存集合为

\[
\mathcal R_p(I)=\{n\in I:(n,\prod_{\ell\le p}\ell)=1,\ n>1\}.
\]

第 `s` 个 `q` 行为

\[
I_s^{(q)}=[(s-1)q+1,sq].
\]

写其左端点在 `p` 网格中的偏移为

\[
a_s=(s-1)q\bmod p=(s-1)g\bmod p,\qquad 0\le a_s<p.
\tag{phase}
\]

## 2. q 零行先变成旧 p 筛零窗

**Lemma RZD-1（q 零行的旧筛化）。**
若 `2<=s<q` 且 `I_s^{(q)}` 是 `q` 阶筛零行，则

\[
\mathcal R_p(I_s^{(q)})=\varnothing.
\tag{old-zero}
\]

**证明。**
取 `n∈I_s^{(q)}`。若 `q∤n` 且 `n∈\mathcal R_p`，则 `n<q^2` 且没有不超过 `p`
的素因子。由于 `q` 是大于 `p` 的最小素数，若 `n` 合成则 `n>=q^2`，矛盾；
故 `n` 为素数，也不会被 `q` 筛掉，和 `q` 零行矛盾。

剩下的 `q|n` 在本行只可能是右端点 `n=sq`。因 `2<=s<q` 且不存在
`p<s<q` 的素数，`s` 必有不超过 `p` 的素因子，所以 `sq` 也已被旧 `p`-筛覆盖。
故整行没有旧 `p`-筛幸存者。证毕。

这一步正是用户指出的“`q^2` 内被 `p` 以内筛后都是素数”的严格用法。

## 3. 反推二分

令

\[
(s-1)q=mp+a_s,\qquad 0\le a_s<p.
\]

于是 `I_s^{(q)}` 从第 `m+1` 个 `p` 行的第 `a_s+1` 列开始，长度为 `p+g`。

**Lemma RZD-2（完整 p 行或缝合零窗二分）。**
若 `(old-zero)` 成立，则恰有以下两类结构之一：

1. 若

\[
a_s=0\quad\hbox{or}\quad a_s\ge p-g,
\tag{direct-phase}
\]

则 `I_s^{(q)}` 含有一个完整 `p` 对齐零行：当 `a_s=0` 时为第 `m+1` 个 `p` 行，
当 `a_s\ge p-g` 时为第 `m+2` 个 `p` 行；

2. 若

\[
0<a_s<p-g,
\tag{seam-phase}
\]

则 `I_s^{(q)}` 不含完整 `p` 对齐行，但给出相邻两条 `p` 行的缝合零窗：

\[
[(m+1)p+a_s+1,(m+1)p]
\]

长度为 `p-a_s`，以及

\[
[(m+1)p+1,(m+1)p+a_s+g]
\]

长度为 `a_s+g`，二者均被旧筛覆盖，总长度为

\[
(p-a_s)+(a_s+g)=p+g=q.
\]

**证明。**
从左端点到当前 `p` 行末尾的剩余长度为 `p-a_s`。剩余可覆盖下一行的长度为

\[
q-(p-a_s)=a_s+g.
\]

若 `a_s=0`，当前 `p` 行的非平凡部分已完整包含在 `I_s^{(q)}` 中。若
`a_s+g>=p`，即 `a_s>=p-g`，下一条完整 `p` 行被包含；结合 `(old-zero)`，
该完整行全被旧筛覆盖。若 `0<a_s<p-g`，则没有完整 `p` 行被包含，
但当前行后缀和下一行前缀均被旧筛覆盖，得到缝合零窗。证毕。

## 4. 对“直接反推 p 零行”的审稿判断

若 `I_s^{(q)}` 完全位于旧核心 `[1,p^2]` 内，并且 `a_s=0` 或 `a_s>=p-g`，则 RZD-2 的第一支确实直接矛盾于 `Row(p)`。

但若 `0<a_s<p-g`，即使 `I_s^{(q)}` 完全位于 `[1,p^2]` 内，也只能得到一个滑动宽 `p` 零窗或更强的缝合零窗，而不是 `p` 对齐零行。`Row(p)` 只排除固定对齐行：

```text
[(r-1)p+1,rp],
```

不能排除跨边界窗口：

```text
[up+a+1,up+p] ∪ [up+p+1,up+p+a+g].
```

因此：

```text
q 零行 => p 零行
```

不是普遍真命题。正确命题是：

```text
q 零行 => p 对齐零行 或 p 缝合零窗。
```

这把硬点从 `QSurv` 压缩到 `SeamSafe/ASB/PDEC-or-SAE`。

- q 行样本数：`278444`；
- 核心区 q 行样本数：`274749`；
- 直接包含完整 `p` 行比例：约 `0.00828`；
- 核心区直接包含完整 `p` 行比例：约 `0.00616`；

这说明“直接反推 p 对齐零行”只覆盖极少数相位；真正主分支是缝合零窗。

## 6. 下一步硬点

反推路线最小可攻命题应写为：

**RZD-Seam/PDEC.**
若某个 `q` 零行落入 RZD-2 的第二支，则该缝合零窗必须触发以下之一：

1. `SeamSafe/ASB` 失败，与强化递推假设矛盾；
2. 低模端点亏损，进入 `PDEC`；
3. 尾锚或固定偏移相位集中，进入 `Tail-anchor/WSH-Hall`；
4. 壳层部分失败，进入 `Annulus-Rough` 的负低模缺陷。

所以当前最短闭合链不是：

```text
Row(p) => Row(q)
```

而是：

```text
Row(p)
+ SeamSafe/ASB-or-PDEC
+ Annulus-Rough-or-negative-lowmod-defect
=> Row(q).
```

用户提出的反推思想在第一支给出直接矛盾，在第二支把剩余硬点准确定位为缝合零窗排斥。
