## 1. 端点势能差包

上一层给出：

```text
F(v)-F(u) >= G,
G=L/2.
```

中心化增量为：

```text
Y_j=F(j+1)-F(j),
sum_{j in C_m}Y_j=0.
```

## 2. 有向弧与补弧

令：

```text
I=[u,v),
J=[v,u).
```

则：

```text
sum_{j in I}Y_j = F(v)-F(u) >= G,
sum_{j in J}Y_j = F(u)-F(v) <= -G.
```

## 3. signed variation 负载

由弧和下界得到：

```text
sum_{j in I}(Y_j)_+ >= G.
```

由补弧回落得到：

```text
sum_{j in J}(Y_j)_- >= G.
```

因此端点势能差不再是匿名两端点事件；它强制实际轨道边增量携带正/负 variation 负载。
