# EDA 的 `p±1` 斜率递降：条件下降与确定泄漏

**状态：** `pm1_slope_descent_conditional_leakage_obstruction`

本文分析新的递降想法：

```text
若 1<=x<p 且 px+k 全被 <p 素数覆盖，
利用 p-1 或 p+1 的小因子 pi，把同一零窗改写成 pi-斜率长窗，
是否能递降到 pi<11 的零行并矛盾？
```

结论：该方向有价值，但不能自动推出小 `pi` 零行。严格结果是：

```text
p±1 因子给出 pi-网格长窗；
若其中存在一个对齐 pi 子行且无 <pi 泄漏，则可条件下降；
否则得到大量中高标签泄漏压力。
```

小因子 `2,3` 反而必然泄漏，所以不能直接递降到 `p<11`。

## 1. 两个斜率恒等式

设 `pi|p-1`。则

\[
px+k=x(p-1)+(x+k).
\tag{PSD-1}
\]

若 `p-1=pi m`，则

\[
px+k=pi(mx)+(x+k).
\tag{PSD-2}
\]

因此 `k=1,\ldots,p` 给出一个长度约 `p` 的 `pi`-网格长窗，列参数为 `x+k`。

设 `pi|p+1`。同理

\[
px+k=x(p+1)+(k-x)=pi(mx)+(k-x).
\tag{PSD-3}
\]

列参数变为 `k-x`。

这正是用户提出的 `x(p-1)+x+k` 与 `x(p+1)-x+k` 结构。

## 2. 为什么这不是自动下降

`p`-零行只保证每个 `px+k` 有某个 `<p` 的素因子。要得到 `pi`-零行，需要更强条件：

\[
\forall 1\le j\le pi,\quad piY+j\ \text{有某个 }<pi\text{ 的素因子}.
\tag{PSD-4}
\]

也就是说，`pi`-网格长窗中必须存在一个**对齐的完整 `pi` 子行**，且该子行没有 `<pi`
泄漏。

若某列只有 `[pi,p)` 中的素数覆盖，则它对 `p`-零行有效，但对 `pi`-下降无效。这就是
斜率递降的真实阻塞。

## 3. 条件斜率下降定理

**定理 PSD-1（条件 `p±1` 斜率下降）。**  
设 `p` 为最小早期反例素数，`1<=x<p` 且 `U_p(x)=0`。取 `pi|p-1` 或 `pi|p+1`。
若由 `(PSD-2)` 或 `(PSD-3)` 给出的 `pi`-网格长窗中，存在一个对齐完整子行

\[
\{piY+1,\ldots,piY+pi\}
\tag{PSD-5}
\]

并且该子行每个非平凡列均由 `<pi` 素数覆盖，且 `Y mod M_pi` 的最小正代表不超过 `pi`，
则 `EDA(pi)` 失败，矛盾于 `p` 的最小性。

**证明。**  
无泄漏对齐子行正是一个 `pi`-筛零行乘数 `Y`。零行条件只依赖于 `Y mod M_pi`。若其最小正代表
`<=pi`，则 `pi` 层出现早期零行。由于 `pi<p`，这与 `p` 的最小早期反例性矛盾。证毕。

## 4. 小因子 `2,3` 的确定泄漏

虽然 `p-1` 与 `p+1` 都为偶数，且其中一个被 `3` 整除，但这不能自动下降：

- `pi=2` 时，`<2` 没有素数，所以任意 `2` 子行全部泄漏；
- `pi=3` 时，`<3` 只有素数 `2`，任意对齐 `3` 子行至少有一个奇数列泄漏。

因此 `2` 与 `3` 方向给出的不是小层零行，而是确定泄漏列。它们可以增加泄漏压力，但不能直接
推出 `p<11` 的零行矛盾。

## 6. 可保留的压力不等式

虽然不能直接下降，`p±1` 斜率仍提供强约束。对每个 `pi|p±1`，最小反例必须满足：

```text
每个可对齐 pi 子行
要么有 <pi 泄漏，
要么代表逃逸。
```

若许多 `pi` 和许多对齐子行同时泄漏，则这些泄漏列必须由 `[pi,p)` 中的中高标签补洞。
同一高标签在短 `pi` 子行内复用受列差整除限制，因此可接入已有：

```text
External Leakage Witness Congestion
HighLabel-MinRep
PDEC/SAE
```

## 7. 当前结论

用户的新思路给出了一条新的斜率递降压力链，但严格闭合还需证明：

```text
PM1-Slope Leakage Congestion:
p±1 产生的所有小斜率长窗泄漏不能同时由中高标签补洞，
除非触发 PDEC/SAE 或 MinRep 逃逸矛盾。
```

这应作为内部 `x<p` 分支的增强约束；它不能替代对角 `x=p` 分支，也不能单独推出
`pi<11` 零行矛盾。
