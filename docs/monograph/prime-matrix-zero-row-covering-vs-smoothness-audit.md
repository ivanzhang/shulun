# 零行覆盖与 p-光滑误用审计

**状态：** `zero_row_covering_not_smoothness`

本文复核 `P=23` 第 `59` 行零行结论，并审查把零行问题转化为同余覆盖问题后的新路线。

## 1. 行号约定

旧文档和脚本中的第 `r` 行采用一编号：

\[
[(r-1)p+1,\;rp].
\tag{ZS-1}
\]

用户新记号

\[
px+1,\ldots,px+p
\tag{ZS-2}
\]

中的 `x` 等于旧行号 `r-1`。

因此：

```text
旧第 59 行 = x=58 = [23*58+1, 23*59] = [1335,1357].
```

而

```text
23*59+1 到 23*59+23 = [1358,1380]
```

是旧第 `60` 行，不是旧第 `59` 行。

## 3. 同余覆盖转化是正确的

令

\[
Q_p=\{q:\ q<p,\ q\ \text{prime}\},\qquad M_p=\prod_{q<p}q.
\tag{ZS-3}
\]

对 `1<=k<=p-1`，因为 `p\nmid px+k`，零行条件等价于

\[
\forall k\in[1,p-1]\quad
\exists q<p:\quad q\mid px+k.
\tag{ZS-4}
\]

对固定 `q<p`，由于 `p` 在 `mod q` 中可逆，

\[
q\mid px+k
\quad\Longleftrightarrow\quad
k\equiv -px \pmod q.
\tag{ZS-5}
\]

所以 `x mod q` 选择 `[1,p-1]` 上的一个模 `q` 同余类。由 CRT，完整周期中的零行就是
CRT 环面

\[
\mathbb Z/M_p\mathbb Z
\tag{ZS-6}
\]

上使这些同余类并集覆盖 `[1,p-1]` 的相位点。

## 4. 关键纠错：零行不是连续 p-光滑数

零行只要求每个数至少有一个 `<=p` 的素因子；它不要求所有素因子都 `<=p`。

例如 `p=23,x=58` 的零行中：

```text
1335 = 3*5*89,
1336 = 2^3*167,
1337 = 7*191,
1346 = 2*673.
```

这些数都有小素因子，但都不是 `23`-光滑数。因此以下推理无效：

```text
每个 px+k 有 <=p 小素因子
=> 每个 px+k 是 p-光滑数
=> 可用 Størmer-Lehmer/Pell 连续光滑数下界排除 x<=p.
```

错误发生在第一步。该路线不能闭合行命题。

## 6. 真正剩余命题

完整 CRT 周期内有零行并不矛盾；行命题需要排除的是早期方阵内零行，即

\[
1\le x\le p-1
\quad\text{或按边界约定}\quad
1\le x\le p.
\tag{ZS-7}
\]

因此正确目标不是证明“覆盖方案不存在”。覆盖方案对 `p=13,17,19,23` 已经存在。正确目标是：

\[
\forall 1\le x\le p,\quad
\exists 1\le k\le p-1:\quad
\gcd(px+k,M_p)=1.
\tag{ZS-8}
\]

这可以表述为：

```text
早期对角段 x=1,...,p 不穿过 CRT 覆盖证书集合。
```

完整 CRT 环面中，各 `x mod q` 可独立组合；但早期 `x<=p` 时，所有模 `q` 的残基来自同一个小整数
`x`，不是任意独立相位。这种“小代表元对角刚性”才是可继续硬攻的核心。

## 7. 下一步可攻接口

行命题的新最窄接口应写成：

```text
Early-Diagonal-Avoidance:
the diagonal segment {1,...,p} in Z/M_pZ avoids the zero-row covering set.
```

可用的严格化方向：

1. **精确覆盖证书。** 把零行写成集合覆盖证书 `C(x)`，对 `x<=p` 给出一组必留洞的对偶权重。
2. **小代表元刚性。** 利用 `x<q` 时 `x mod q=x`，以及 `q<x` 时残基只发生一次折返，限制各层禁类的相位独立性。
3. **PDEC/SAE 接口。** 若早期对角段接近覆盖，必产生低模 Fourier/CRT 缺陷或单窗逃逸证书。
4. **计算证书辅助。** 对有限低范围用 CRT 证书确认；全局证明必须转为对角避让不等式，而不是连续光滑数下界。

这一路线保留了用户提出的 CRT 覆盖视角，但移除了“p-光滑”误用，并把行命题重新压缩为一个
更精确的早期对角避让问题。
