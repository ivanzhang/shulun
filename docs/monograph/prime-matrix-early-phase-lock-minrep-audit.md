## 2. 解释

`P<=11` 的无零行是低层容量事实：即使完整 CRT 周期允许任意相位，也没有一残基类覆盖方案。

`P=13` 后情况改变：覆盖方案存在，且所有独立斜线很早已经激活。但早期行的相位不是任意的，
而是同一个小整数 `r-1` 在所有模 `q<P` 下的同步投影：

\[
(-(r-1)P\bmod q)_{q<P}.
\]

因此首零行被推迟到远大于 `P` 的 CRT 最小代表位置。

## 3. 行号因子没有稳定闭合律

首零行行号有时是素数，有时高度合成：

```text
P=13: row=13^2；
P=17: row=7*173；
P=19: row is prime；
P=23: row=59 is prime；
P=29: row=2*5*521。
```

乘数 `x=row-1` 也没有单一粗数模式。它可以是光滑型、半粗型或素数型。因此“首零行行号必为大奇素因子粗数”不能作为证明定律；可保留的结构是：

```text
首零行是完整覆盖证书集合的 CRT 最小正代表。
```

## 4. 当前最小硬点

行命题的早期部分可进一步写为：

```text
MinRep Phase-Lock:
任何完整覆盖证书 tau 的 CRT 最小正代表 r_tau 都满足 r_tau>P。
```

等价地：

```text
早期对角段 r=1,...,P 不命中完整覆盖证书集合。
```

这与短区间素数形式等价，但保留了方阵圆柱几何的特殊输入：

- `q^2` 前 shadow hit 可删除；
- 已激活标签必须作为最小素因子独立补洞；
- 完整覆盖需要所有模 `q<P` 的相位同步，而早期小代表元强烈限制这种同步。

下一步应从这里构造 `EDA-Dual / PDEC / SAE` 证书，而不是继续只数斜线条数。
