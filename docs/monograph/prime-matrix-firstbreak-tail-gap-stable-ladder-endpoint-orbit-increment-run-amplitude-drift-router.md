## 1. increment-run surplus 包

上一层低边界支路给出连续 run `R` 与符号 `sigma`。令：

```text
Z_j=sigma*Y_j>0 for j in R.
```

并有质量下界：

```text
sum_{j in R}Z_j >= H,  H=G/B.
```

## 2. 幅度阈值二分

固定任意幅度阈值 `Lambda>0`。若：

```text
max_{j in R}Z_j >= Lambda,
```

则得到单边大增量 `increment edge-spike` 原子。否则：

```text
0<Z_j<Lambda for all j in R,
```

于是由总质量下界得到：

```text
|R| >= H/Lambda.
```

这就是长的有界增量单调漂移支路。
