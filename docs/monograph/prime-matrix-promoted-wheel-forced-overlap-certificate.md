# 提升轮强制重叠证书

**状态：** `reduction_plus_finite_audit_not_a_proof`

本文把提升轮集合覆盖的下一层硬点从“单线容量”推进到“强制重叠”。核心结论是：剩余 `q` 斜线的总命中数即使超过轮骨架大小，也不能自由使用；CRT 会迫使大量不同 `q` 标签落在同一偏移上，从而消耗覆盖预算。

## 1. 覆盖账本

固定

```text
plus:  P^2+k,  1<=k<P；
minus: P^2-k,  1<=k<P。
```

令 `W` 为已提升轮，`S=S_W^\pm(P)` 为轮骨架，`A_q` 为剩余素数 `q<P, (q,W)=1` 在 `S` 上命中的偏移集合。定义

\[
T=\sum_q |A_q|,\qquad
U=\left|\bigcup_q A_q\right|,
\]

并令每个偏移的标签重数为

\[
m_k=\#\{q:k\in A_q\}.
\]

二重交叉总量为

\[
I_2=\sum_{k\in S}\binom{m_k}{2}.
\tag{FOC-1}
\]

## 2. 强制重叠引理

若每个偏移最多有 `M` 个剩余 `q` 标签，则

\[
T-U=\sum_{m_k\ge1}(m_k-1),
\]

且对 `1<=m<=M` 有

\[
\binom m2\le {M\over2}(m-1).
\]

因此

\[
T-U\ge {2I_2\over M}.
\tag{FOC-2}
\]

所以若

\[
T-\left\lceil {2I_2\over M}\right\rceil < |S|,
\tag{FOC-3}
\]

则剩余 `q` 斜线不可能覆盖整个轮骨架。

这一步不使用概率模型。它只使用集合恒等式、二重交叉数和单点最大重数上界。

## 3. 重数上界来自剩余素数连乘

设剩余素数从

\[
r_1<r_2<\cdots
\]

开始。若某个偏移 `k` 同时被 `m` 条剩余 `q` 斜线命中，则 `P^2\pm k` 被 `m` 个不同剩余素数整除，因此

\[
r_1r_2\cdots r_m\le P^2+P-1.
\tag{FOC-4}
\]

于是 `M` 可取为满足 `(FOC-4)` 的最大 `m`。这给出完全确定的上界，不依赖实际枚举出的最大重数。

例如：

```text
W=9699690=2*3*5*7*11*13*17*19
=> 剩余素数从 23 开始。

P=36739:
23*29*31*37*41*43 <= P^2+P-1，
再乘 47 已超过，所以 M<=6。
```

## 4. 二重交叉也是短单位窗口

对两个剩余素数 `q<r`，交叉条件为

\[
qr\mid P^2\pm k.
\]

写成

\[
P^2\pm k=qr\,t.
\]

因为 `(qr,W)=1`，该交叉仍落在轮骨架当且仅当 `(t,W)=1`。因此

\[
|A_q\cap A_r|
=
\#\{t\in I_{qr}^{\pm}(P):(t,W)=1\},
\tag{FOC-5}
\]

其中平方后行

\[
\left\lceil{P^2+1\over qr}\right\rceil
\le t\le
\left\lfloor{P^2+P-1\over qr}\right\rfloor,
\]

平方前行

\[
\left\lceil{P^2-P+1\over qr}\right\rceil
\le t\le
\left\lfloor{P^2-1\over qr}\right\rfloor.
\]

所以 `I2` 不是抽象碰撞数，而是同一套提升轮单位类短窗口计数的二阶版本。

## 6. 结构意义

提升轮容量阶梯给出第一层刚性：

```text
提升 13 后最大单线转到 17；
提升 17 后最大单线转到 19；
提升 19 后最大单线转到 23；
提升 23 后最大单线转到 29。
```

强制重叠证书给出第二层刚性：

```text
剩余小 q 线越强，彼此交叉也越强；
总容量 T 的超额会被 I2 强制吃掉；
M 由剩余素数连乘给出确定天花板。
```

因此当前最小硬点可升级为：

```text
Promoted-Wheel Forced-Overlap Certificate:
  选择提升轮 W；
  用单位类短窗口给出 T 与 I2 的确定上下界；
  用剩余素数连乘给出 M；
  证明 T-ceil(2I2/M)<|S|。
```

若该不等式失败，则失败不再是“覆盖可能”，而是一个更明确的缺陷证书：

- `I2` 过小：许多 `(q,r)` 互补因子短窗口异常缺少单位类；
- `T` 过大但 `I2` 不随之增大：命中在 CRT 相位中过度分散；
- `M` 超预算：`P^2±k` 具有异常多的剩余小素因子。

三者都可路由到 `PDEC/SAE/ColumnCRT`。
