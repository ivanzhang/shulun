# SEB 无条件化证明审查

**状态：** `seb_too_strong_reduce_to_arithmetic_seam_barrier`

本报告专门审查端点屏障

\[
\mathrm{SEB}(p,q):\qquad
\max_{1\le t<p}(\sigma_t+\pi_{t+1})<q
\]

能否直接无条件化。结论是：`SEB` 是一个非常清晰的充分接口，但它比实际 `Seam(p,q)` 需要的条件更强；直接证明 `SEB` 等价于证明一类接近 Legendre 量级的边界素数间隙上界，不能由当前主稿已有的 `Row(p)`、CRT 均衡或普通筛估计自动推出。下一步应转攻更精确的算术采样屏障 `ASB(p,q)`。

## 1. SEB 的素数间隙含义

令旧 `p` 行边界为 `tp`。设

- `A_t` 为不超过 `tp` 的最大素数；
- `B_t` 为大于 `tp` 的最小素数。

则旧行端点量满足

\[
\sigma_t=tp-A_t,\qquad
\pi_{t+1}=B_t-(tp+1).
\]

所以

\[
\sigma_t+\pi_{t+1}=B_t-A_t-1.
\tag{1}
\]

因此 `SEB(p,q)` 等价于

\[
B_t-A_t\le q
\qquad (1\le t<p).
\tag{2}
\]

也就是说：每个旧行边界 `tp` 两侧相邻素数的跨边界素数间隙必须不超过下一素数 `q`。

## 2. 为什么 Row(p) 不足

`Row(p)` 只说明每个旧行

\[
[(t-1)p+1,tp]
\]

至少含一个素数。因此它只能推出

\[
0\le \sigma_t\le p-1,\qquad
0\le \pi_{t+1}\le p-1,
\]

从而

\[
\sigma_t+\pi_{t+1}\le 2p-2.
\tag{3}
\]

但 `SEB` 要求

\[
\sigma_t+\pi_{t+1}<q=p+g.
\tag{4}
\]

当相邻素数间隙 `g` 小时，`q` 只比 `p` 略大；所以 `(3)` 与 `(4)` 中间仍有近 `p` 的缺口。这个缺口正是端点互补硬点：上一行的素数可能全部偏左，下一行的素数可能全部偏右。

## 3. 与最大素数间隙的关系

若已知强间隙输入

\[
G(p^2):=\max_{\substack{a<b\le p^2\\ a,b\ \mathrm{consecutive\ primes}}}(b-a)\le q,
\tag{5}
\]

则 `SEB(p,q)` 立即成立，因为每个 `B_t-A_t` 都是 `p^2` 内的相邻素数间隙。

反过来，`SEB` 至少给出所有穿过旧行边界 `tp` 的素数间隙上界。由于边界间距为 `p`，任意长度超过 `p` 的长素数间隙都会穿过某个旧行边界；因此若要用统一方式证明 `SEB`，本质上需要控制 `p^2` 以下长度约为 `p=\sqrt{p^2}` 的素数间隙。这是 Legendre 量级的局部素数间隙问题。

当前已知无条件短区间素数定理只能给出长度 `x^\theta` 的区间含素数，其中可用的 `\theta` 仍大于 `1/2`。代入 `x\asymp p^2` 后得到的长度为 `p^{2\theta}`，仍大于 `p`，不足以推出 `(5)` 或 `SEB`。普通 PNT、Bertrand、Dusart 型显式区间也更弱。

因此，直接把 `SEB` 写成无条件定理会在审稿中暴露为“隐含强素数间隙猜想”。

## 4. 实际 Seam 只需要算术采样屏障

`SEB` 检查所有旧行边界 `t`。但实际 `Seam(p,q)` 只检查新 `q` 行边界切出的窗口。

设 `q=p+g`，令

\[
r_s=(s-1)q\bmod p=(s-1)g\bmod p.
\]

若 `r_s\le g`，则对应 `q` 行含完整旧 `p` 行，可由 `Row(p)` 继承。若 `r_s>g`，该 `q` 行只需要检查特定旧行边界

\[
t_s=\left\lfloor{(s-1)q\over p}\right\rfloor+1.
\]

此时 seam 失败当且仅当

\[
\sigma_{t_s}\ge p-r_s,\qquad
\pi_{t_s+1}\ge r_s+g.
\tag{ASB-Fail}
\]

所以真正必要的无条件接口不是全局 `SEB`，而是算术采样屏障

\[
\boxed{
\forall s,\ r_s>g:\quad
\sigma_{t_s}<p-r_s
\ \ \text{or}\ \
\pi_{t_s+1}<r_s+g.
}
\tag{ASB}
\]

`SEB` 推出 `ASB`，`ASB` 推出 `Seam`，但 `ASB` 比 `SEB` 明显更弱，因为它只检查由 `q` 行分块实际访问到的端点阈值。

## 5. 可用矛盾场入口

`ASB-Fail` 同时要求两个方向的端点空段过长：

1. 旧行 `I_{t_s}` 的末端长度 `p-r_s` 全为合数；
2. 下一旧行 `I_{t_s+1}` 的首端长度 `r_s+g` 全为合数；
3. 两段拼合成一个完整新 `q` 行窗口，并且该窗口不含完整旧 `p` 行。

这比任意长素数间隙更有结构：空段必须贴住旧行边界，同时阈值 `r_s` 由乘法漂移序列 `(s-1)g mod p` 决定。可用的矛盾场投影是：

- **CRT 相位投影：** `r_s` 随 `s` 在模 `p` 中按步长 `g` 漂移；端点空段若长期匹配该漂移，会形成可检测的残基相位相关。
- **斜线覆盖投影：** 首尾两段都是短窗口合数段，所有点必须由 `<=p` 的小素数斜线覆盖；若端点段过长，低模覆盖密度与互质不可复用发生冲突。
- **相邻互质投影：** 连续整数的解释因子不能相同；长端点段要求许多小素因子交替补洞，容易产生容量账本。
- **行列对偶投影：** `ASB-Fail` 给出一个新 `q` 行空窗，同时跨越两个旧 `p` 行；它比任意空窗多一个旧/新双分块结构，可接入已有行列矛盾场。

## 6. 下一步最小可证目标

直接证明 `SEB` 目前过强。下一步应改为证明：

```text
Row(p) + ASB(p,q) + Annulus(p,q) => Row(q).
```

其中 `ASB` 的攻坚形式为反证：

```text
假设存在 s 使 ASB-Fail 成立。
则一个长度 q 的新行窗口由两个端点合数段拼成。
所有 q 个位置必须由 <=p 的小素数斜线覆盖。
利用 r_s 的模 p 漂移、相邻互质、低模覆盖容量和旧/新分块双结构，
推出覆盖容量 < q，矛盾。
```

这条路线避免把整个问题退化为全局最大素数间隙上界，保留了方阵/CRT 矛盾场的结构优势。

## 7. 审稿结论

`SEB` 是一个有价值的充分条件和压力诊断工具，但不应作为当前无条件证明的最小目标。它隐含接近 `G(p^2)\le q` 的强素数间隙控制，超出现有无条件输入。真正应无条件化的是 `ASB`：只排斥由 `q` 行漂移实际采样到的端点互补空窗。下一步文稿应把递推路线更新为 `Row(p)+ASB(p,q)+Annulus(p,q)=>Row(q)`，并将 `ASB-Fail` 作为方阵/CRT 矛盾场的具体反例形态。
