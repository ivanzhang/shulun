## 1. 偏差符号二分

沿用上一层固定纤维内的偏差向量：

```text
D_r=M_r-L/q_j,
sum_r D_r=0.
```

上一层给出某个余数 `r` 的绝对偏差阈值：

```text
|D_r|>=delta,
delta=E_a(S)/(N-1).
```

若 `D_r>=delta`，则已经得到正余数过载。

## 2. 亏损到盈余的零和转移

若 `D_r<=-delta`，则：

```text
sum_{s!=r}D_s=-D_r>=delta.
```

共有 `q_j-1` 个其他余数类，因此鸽巢原理给出某个 `s!=r` 满足：

```text
D_s>=delta/(q_j-1).
```

代入 `delta=E_a(S)/(N-1)` 得到统一正过载阈值：

```text
M_s-L/q_j>=E_a(S)/((N-1)(q_j-1)).
```
