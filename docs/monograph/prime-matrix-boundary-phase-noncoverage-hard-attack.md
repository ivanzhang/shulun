# 边界相位非覆盖引理硬攻

**状态：** `reduced_to_min_crt_representative_or_grid_prime_gap_input`

本文专攻前 `P` 行的边界相位非覆盖。结论必须分清：

```text
已严格完成：等价链、反射边界重写、Sylvester 大因子弱输入、实验审计。
尚未完成：对所有 P 证明完整覆盖证书的 CRT 最小代表必 >=P。
```

## 1. 命题形式

设 `P` 为奇素数，根基素数为全部 `ell<P`。令

\[
M_{<P}=\prod_{\ell<P}\ell .
\]

**BPN(P)（Boundary Phase Noncoverage）。**
对每个 `1<=x<P`，存在 `1<=c<P` 使

\[
\gcd(xP+c,M_{<P})=1.
\tag{BPN}
\]

等价地，前 `P` 行中没有 `P` 对齐零行。

## 2. 等价链

### Lemma BPN-1（边界幸存者自动为素数）

若 `1<=x<P` 且 `1<=c<P` 满足 `(xP+c,M_{<P})=1`，则 `xP+c` 是素数。

**证明。**
有

\[
P<xP+c<P^2.
\]

若 `xP+c` 合成，则其最小素因子不超过

\[
\sqrt{xP+c}<P,
\]

这与 `(xP+c,M_{<P})=1` 矛盾。证毕。

因此 `BPN(P)` 等价于：

```text
每个网格区间 [xP+1,xP+P-1], 1<=x<P, 至少含一个素数。
```

这是一个强短素数间隔型命题，只是端点被限制在 `P` 的倍数上。

### Lemma BPN-2（覆盖相位形式）

固定 `x`。列 `c` 被小素数 `ell<P` 覆盖当且仅当

\[
c\equiv -xP\pmod \ell .
\]

故 `x` 是边界零相位当且仅当禁类族

\[
\{c: c\equiv -xP\pmod\ell,\ 1\le c<P\}_{\ell<P}
\]

覆盖全部列 `1,...,P-1`。

### Lemma BPN-3（完整覆盖证书最小代表形式）

一个完整覆盖证书 `S` 是一组同余要求

\[
x\equiv a_\ell\pmod\ell,\qquad \ell\in L_S\subseteq\{\ell<P\},
\]

使这些同余诱导的禁类覆盖全部列。令 `x_S` 为该 CRT 系统的最小非负代表。
则

\[
BPN(P)\quad\Longleftrightarrow\quad x_S\ge P
\]

对每个完整覆盖证书 `S` 成立。

这就是当前最干净的边界相位非覆盖核心。

## 3. 反射边界重写

令完整 CRT 行周期

\[
N=\prod_{\ell<P}\ell .
\]

若首个零行为 `r0`，反射给出末零行 `N-r0+1`。首尾跨周期间隔为

\[
r_0+N-(N-r_0+1)=2r_0-1.
\]

因此

\[
r_0>P\quad\Longleftrightarrow\quad \text{首尾跨周期间隔}>2P-1.
\]

这只是 `BPN(P)` 的等价重写，不是独立证明出口。全局 `2P` 短复现禁止为假：
`prime-matrix-short-recurrence-gap-audit.md` 已给出 `P=19,23` 的周期内部短复现反例。

## 4. 已有刚性输入如何进入

### 4.1 低素数骨架与高标签补洞

`P=23` 的完整周期审计显示，零行不是单一周期现象，而是

```text
低素数粗骨架 + 高素数补洞标签置换。
```

同一 `2,3,5,7` 骨架可在远离边界处复现很多次；但要进入前窗口 `x<P`，
高标签补洞必须同时满足完整覆盖且 CRT 最小代表仍小于 `P`。实验中未出现。

### 4.2 前缀势垒

`front-window-prefix-barrier-scan.md` 显示：对扫描样本，任何根基素数前缀在
`1<=x<P` 中的最小残洞数始终非零。该事实支持：

```text
低素数只形成候选骨架，不会在边界帽内直接闭合。
```

但这仍不足以证明最终命题，因为高素数可以尝试补最后残洞。

### 4.3 残洞迁移

`front-window-completion-cost-scan.md` 显示：局部补洞约束可能有小 CRT 代表；
但若要求补洞后仍保持全部旧列覆盖，最早完整代表回到 `x>=P`。

新增 `prime-matrix-boundary-residual-migration-audit.md` 进一步校正了表述：
局部补洞本身并不困难。固定前窗口最薄行 `x0` 的残洞 `H(x0)`，扫描中常有许多
`y<P` 能覆盖 `H(x0)`。困难在于这些 `y` 会产生新的残洞 `H(y)`。

因此正确目标不是“高素数不能补洞”，而是：

```text
边界残洞迁移守恒：
在 y<P 内补掉旧残洞，必产生至少一个新残洞。
```

若该守恒成立，则完整覆盖证书不能有 `x_S<P`。

### 4.4 Sylvester 大因子弱输入

Sylvester 定理给出一个无条件但不足的输入：任意 `k` 个连续整数，每个都大于 `k`，
其乘积有一个大于 `k` 的素因子。取

\[
k=P-1,\qquad xP+1,\ldots,xP+P-1.
\]

于是该行中至少某个数含有大于 `P-1` 的素因子。又因所有列都非 `0 mod P`，
该大素因子实际上大于 `P`。

这证明：

```text
每个边界行都含有一个带 >P 大素因子的数。
```

但它不证明该数本身为素数；它可能是 `小因子 × 大因子` 的半素数或多因子数。
因此剩余硬点正是：

```text
排除所有大因子点都被小因子共同覆盖。
```

这与此前“大因子短窗口不可复用、半素数补洞、粗数带互斥”的矛盾场一致。

### 4.5 CRT 零/非零解集镜像

`prime-matrix-crt-solution-set-geometry-audit.md` 将 CRT 筛层与数值层分开。
令

\[
N=\prod_{\ell<P}\ell,\qquad
R(r)=\{1\le c<P:\gcd((r-1)P+c,N)=1\}.
\]

则有精确镜像

\[
R(N-r+1)=\{P-c:c\in R(r)\}.
\]

所以零行镜像是严格定理。但这只说明两端对称，不给出边界帽内 `R(r)` 非空。

审计还显示：中区的幸存者可能大量为 `P`-rough 合数，而边界帽 `r<=P` 的幸存者自动为素数。
因此“中区粗合数密集、两侧光滑合数密集”是数值层现象；若要把它用于证明边界零行不存在，
必须先构造连接数值层与 CRT 筛层的势函数。镜像本身不能替代 `BPN-MCR/BPN-RM`。

新增 `prime-matrix-crt-zero-solution-distribution-audit.md` 进一步把零行写成精确方程组：

\[
Z_P=\bigcap_{1\le c<P}\bigcup_{\ell<P}
\{r:r\equiv 1-cP^{-1}\pmod \ell\}.
\]

完整扫描 `P=13,17,19,23` 后，边界帽 `2<=r<=P` 的零行数均为 `0`，而零行在
CRT 周期内按镜像成对分布。关键新信息是：按周期十等分统计时，平均幸存列数在各等分中
基本完全相同；零行不是由某个单调“靠近中区”势能控制，而是由多素数覆盖证书的相位组合
控制。因此可保留的严格路线是：

```text
镜像两端帽 + 覆盖证书最小代表下界 + 残洞迁移势函数。
```

不能使用的路线是：

```text
中区粗合数密集 => 边界帽无零行。
```

新增 `prime-matrix-zero-row-spacing-gradient-audit.md` 专门检验了用户提出的间隔梯度猜想。
结果分为两层：

1. **边界跨周期间隔命题在样本中成立。** 若 `r0` 是首个零行，则镜像给出末个零行
   `N-r0+1`，因此首尾跨周期间隔为

\[
\Delta_{edge}=2r_0-1.
\]

扫描 `P=13,17,19,23` 得到的 `\Delta_{edge}` 分别为
`337,2421,7317,117`，均大于 `2P`。

2. **全局“中心更密、边界更稀”梯度不成立。** 十等分统计中，边缘十等分零行数并不小于
   中心十等分；例如 `P=23` 的零行十等分为
   `[361,337,344,344,342,342,344,344,337,361]`，边缘反而略多。

因此可用于主链的是更窄、更准确的目标：

```text
首尾跨周期间隔 > 2P
⇔ 首个零行 r0>P
⇔ 边界帽 2<=r<=P 无零行
⇔ BPN(P)。
```

这仍是 `BPN(P)` 的等价重写，不能作为独立证明出口；但它给出一个更适合硬攻的
`BPN-Defect` 形式：若边界帽内有零行，则它和镜像尾端零行构成一对距离 `<=2P-1`
的双端完整覆盖证书。下一步应证明这种双端证书必触发低模 CRT 缺陷、Tail-anchor 缺陷
或残洞势函数负值。

## 5. 当前唯一核心硬点

边界相位非覆盖已压缩为以下三类接口。最新审查显示：固定五阶 `BPN-B5`
是有效的低范围证据和缺陷定位工具，但不能作为全局终局；当前最优先攻应升级为
`BPN-BK/Selberg`。

### BPN-BK / Selberg（可变阶筛余正性）

固定奇阶 Bonferroni 截断存在渐近风险。令小素因子个数的自然尺度为

\[
\lambda\approx \log\log(P^2).
\]

固定奇阶 `K` 的独立模型主项包含

\[
\sum_{j=0}^{K}\frac{(-\lambda)^j}{j!},
\]

该多项式对任意固定奇阶 `K` 都会在某个有限 `\lambda` 后变号；而
`\log\log(P^2)` 无界增长。因此固定 `S_5` 不能作为最终无条件证明路线。

新增 `prime-matrix-bpn-bonferroni-order-risk-audit.md` 给出风险表：`P=10007`
样本仍有 `S_5=236>0`，但高重惩罚/素数型点比例已达 `0.532673`，模型五阶部分已为负。
正确升级方向是：

```text
BPN-BK: 取 K≈c log log P 的奇阶 Bonferroni/Brun 截断；
或构造 Selberg/Brun 非负筛权，证明边界行筛余正性。
```

若可变阶/带权筛余正性失败，则失败必须表现为某个高重核心桶过密，并进入
`CoreK-Density-or-TailAnchor` 出口。

新增 `prime-matrix-bpn-bk-weight-model-audit.md` 与
`prime-matrix-bpn-bk-selberg-route.md` 后，这一路线的审稿边界更明确：
普通 Selberg/Brun 非负筛权不能单独给出边界行非空。边界行长度 `H=P`，
筛到 `z=P`；若只用 `A_d=H/d+O(1)` 的普通区间分布，可用 level 至多
`D<=H`，故 `s=log D/log z<=1`，而一维下界筛正性需要 `s>2`。
因此 `BPN-BK/Selberg` 必须写成缺陷二分，而不是直接写成存在性证明：

```text
S_K(r)<=0
=> BK-DEC(K,D,r) 或 CoreK-Density/TailAnchor
=> Directed CRTDefect / Tail-anchor / PDEC-or-SAE
=> 排斥边界零行。
```

其中 `BK-DEC` 是可变阶包含排斥低阶项的端点 sawtooth 异常，`CoreK`
是 `Core6` 在 `K≈c log log P` 下的高重核心升级。

新增 `prime-matrix-bpn-bk-dec-bridge-proof.md` 后，第一条桥接已经严格闭合：
若边界零行存在，且 BK 尾项满足 `|R_{K,>D}|<=T_{K,D}`、主项余量
`(P-1)V_{K,D}>T_{K,D}`，则必有

```text
E_{K,D}(r)<=-((P-1)V_{K,D}-T_{K,D}),
```

再由低模分块鸽巢推出某个块投影异常，即 `Directed Endpoint CRTDefect`。
因此下一步不再是证明“BK-DEC 能不能进入缺陷出口”，而是证明尾项预算与
`Directed Endpoint CRTDefect` 的排斥。

新增 `prime-matrix-bpn-bk-tail-core-dichotomy.md` 后，“尾项预算”也已被结构化：
若边界零行不触发上述 `BK-DEC`，则必有尾关联质量

```text
U_{K,D}(r)=#{(n,d): n in I_r, d|n, omega(d)<=K, d>D}
```

超过预算 `T`。对这些 `(n,d)` 作 dyadic/相位分块，鸽巢立即给出
`TailCoreBucket/CoreK-Density` 过密块。于是当前最小剩余不再是抽象尾项，
而是两个具体出口的排斥：

```text
Directed Endpoint CRTDefect；
TailCoreBucket/CoreK-Density。
```

### BPN-B5（五阶 Bonferroni 正性）

令

\[
S(r)=\#\{1\le c<P:\gcd((r-1)P+c,M_{<P})=1\}.
\]

对 `d|M_{<P}` 定义

\[
A_d(r)=\#\{1\le c<P:d\mid (r-1)P+c\}.
\]

边界帽中 `2<=r<=P` 时，所有格点数都小于 `P^2`，所以 `d>=P^2` 的交集项自动为 `0`。
令 `I_j(r)` 为所有 `j` 个根基素数交集项之和，则五阶 Bonferroni 下界为

\[
S_5(r)=(P-1)-I_1(r)+I_2(r)-I_3(r)+I_4(r)-I_5(r).
\]

若能证明

\[
S_5(r)>0\qquad(2\le r\le P),
\tag{BPN-B5}
\]

则由奇阶 Bonferroni 不等式得 `S(r)>=S_5(r)>0`，从而直接证明 `BPN(P)`。

新增 `prime-matrix-bpn-defect-bonferroni-audit.md` 显示：三阶 `S_3` 在较大样本会失败，
但五阶 `S_5` 在 `P<=199` 的全部边界帽行未失败，最坏样本 `P=199` 的最小 `S_5=12`。
进一步用逐点小素因子个数恒等式扫描 `P=251,503,1009,2003,5003`，最小 `S_5`
分别为 `17,28,49,96,177`，均为正。
因此当前最小硬点不再是抽象残洞势函数，而是明确的五阶交集和不等式：

```text
证明 I1-I2+I3-I4+I5 < P-1。
```

`BPN-B5` 目前应定位为低范围强证据和缺陷探针。若要证明所有 `P`，必须将固定
五阶替换为可变阶 `BPN-BK` 或 Selberg/Brun 权重。

五阶式还有一个更透明的逐点解释。设 `omega_P(n)` 为 `n` 的不同 `<P` 小素因子个数，则

\[
\sum_{j=0}^{5}(-1)^j\binom{\omega_P(n)}j
=
\begin{cases}
1,&\omega_P(n)=0,\\
0,&1\le\omega_P(n)\le5,\\
-\binom{\omega_P(n)-1}{5},&\omega_P(n)\ge6.
\end{cases}
\]

边界帽中 `n<P^2`，所以 `omega_P(n)=0` 等价于 `n` 为素数。因此

\[
S_5(r)
=\#\{n\in((r-1)P,rP):n\ \text{prime}\}
-\sum_{\omega_P(n)\ge6}\binom{\omega_P(n)-1}{5}.
\]

于是 `BPN-B5` 等价于：

```text
每个边界行的素数数目 > 至少六个小素因子的高重合数惩罚。
```

这给出下一步最具体的攻坚对象：高重合数若想压倒素数，必须在长度 `P`
短窗内大量出现含六个以上小素因子的整数；这应触发“小核心乘积过密”或
`Tail-anchor/CRTDefect` 出口。

新增 `prime-matrix-bpn-high-omega-core-audit.md` 后，高重惩罚被进一步核心化。
对每个负贡献数 `n`，取其六个最小 `<P` 小素因子乘积

\[
core_6(n)=q_1q_2q_3q_4q_5q_6<P^2.
\]

审计 `P=503,1009,2003,5003` 的最薄 `S_5` 行显示：惩罚项数量远小于素数项，
并按 `core_6` 桶分布。例如 `P=5003` 最薄行有 `272` 个素数型点、惩罚 `95`，
其中 `core_6<=P^2/4` 的惩罚为 `55`，`core_6<=P^2/2` 为 `13`，
近 `P^2` 桶为 `27`。这说明若未来某行出现 `S_5<=0`，必有以下二分：

```text
小/中 core6 桶过密  -> 固定小核心倍数在长度 P 窗口中过密；
大 core6 桶过密     -> n 几乎等于 core6，形成尾锚/端点集中。
```

两支都应送入 `Tail-anchor/CRTDefect` 或给出统一容量上界。固定五阶的 `Core6`
只是 `CoreK` 的最低非平凡模型；在可变阶路线中，应把六小素核心替换为
`K+1` 小素核心。

### BPN-MCR（最小 CRT 代表）

对任意完整覆盖证书 `S`，

\[
x_S\ge P.
\]

这是最直接、最审稿友好的形式。

### BPN-RM（残洞迁移守恒）

令 `R(x)` 为相位 `x` 的残洞集合：

\[
R(x)=\{1\le c<P:\gcd(xP+c,M_{<P})=1\}.
\]

精确的残洞迁移表述为：若 `1<=x,y<P` 且 `y` 覆盖了 `R(x)`，即

\[
R(x)\cap R(y)=\varnothing,
\]

则

\[
R(y)\ne\varnothing.
\]

换言之，旧洞可以被补掉，但残洞必须迁移到别的列。

`BPN-RM => BPN-MCR => BPN(P)`。

这里有一个审稿级警告：全局形式的 `BPN-RM` 与 `BPN(P)` 几乎同强。若存在
`y<P` 使 `R(y)=∅`，则它会补掉任意 `R(x)` 且没有新洞，`BPN-RM` 失败；
反之若 `BPN(P)` 成立，则任何 `y<P` 都有 `R(y)≠∅`。因此 `BPN-RM`
不是免费更弱命题；要成为证明，必须给出一个独立势函数或单调量，直接排除
`R(y)=∅`。

实验给出的可用结构是残洞迁移图：

```text
x -> y  若 y 覆盖 R(x)。
```

扫描中该图存在大量迁移边和残洞集合互换，但没有空残洞顶点。下一步真正可攻的是：

```text
构造残洞势函数 Phi(R)
使得任何补洞迁移 x -> y 保持 Phi(R(y)) >= 1，
从而排除空残洞。
```

## 6. 审稿级诚实边界

当前不能宣称 `BPN(P)` 已无条件证明。原因是 `BPN(P)` 等价于所有网格短区间
`[xP+1,xP+P-1]` 含素数；这比现有常规短区间素数定理更强。

更具体地：

**Lemma BPN-4（短素数间隔含义）。**
若 `BPN(P)` 对某个 `P` 成立，则区间 `[P+1,P^2-1]` 被长度约 `P`
的网格区间逐段击中；若 `BPN(P)` 对所有大素数 `P` 成立，则素数间隔在平方尺度上满足

\[
g(n)\ll \sqrt n
\]

的网格版本。反过来，若已知对所有 `P<n<P^2` 的每个长度 `P-1` 区间都有素数，
则 `BPN(P)` 立即成立。

这说明边界相位非覆盖不是一个纯局部 CRT 恒等式，而是强短区间素数存在命题的
CRT 表述。任何无条件闭合都必须实质性证明这类短区间输入，或给出比现有短区间理论
更强的方阵专用机制。

```text
全局短复现路线：已排除。
边界反射路线：等价重写。
低骨架/高标签路线：压缩到 BPN-MCR 或 BPN-RM。
Sylvester 路线：给出大因子存在，但剩余小因子覆盖障碍。
```

下一步应直接专攻非循环版 `BPN-RM`：不是重复证明 `R(y)\ne emptyset`，
而是构造可审查的残洞势函数，证明补洞迁移不能把势函数降到 `0`。

## 7. 下一步非循环攻坚目标

当前唯一不循环的目标可写成：

```text
存在显式非负势函数 Phi_P(R)
使 Phi_P(empty)=0，
且对每个边界相位 x<P 有 Phi_P(R(x))>=1。
```

该势函数不能只依赖 `|R|`，因为实验中补洞迁移可保持或增加/减少残洞数量；
也不能只依赖低素数骨架，因为同一低骨架可由高标签置换补洞。它必须同时编码：

1. 残洞列的 CRT 相位；
2. 覆盖这些残洞所需高素数标签的互斥；
3. 新释放列的强制出现；
4. Sylvester 大因子点不能全被小因子解释的容量约束。

若这样的 `Phi_P` 构造失败，则边界相位非覆盖应改为条件输入：

```text
GridPrimeGap(P): 每个 [xP+1,xP+P-1], 1<=x<P, 含素数。
```

这会让主论证保持审稿诚实：方阵矛盾场可在 `GridPrimeGap` 条件下闭合边界帽，
但无条件版本仍需新的短区间素数证明。
