# 结语：圆柱斜线、CRT 刚性与素数不可全遮蔽的图景

本文研究的命题，可以用一个直观画面来概括：把自然数一行一行铺进宽为 `P` 的方阵，再把左右边界粘起来，形成一个圆柱面。每个根基素数就像一束固定斜率的光，沿圆柱面绕行，把与它有同余倍数关系的位置照亮。被这些斜线照亮的位置是合数解释；没有被照亮的位置，就是素数或类素数候选。目标命题说：在 `P×P` 的方阵中，每一行、每一个非第 `P` 列，都不能被这些斜线完全遮蔽，必然留下至少一个素数点。

## 1. 命题的核心直觉

如果只看一条斜线，它似乎可以绕圆柱很远；如果只看很多小素数斜线，它们似乎很密；如果再看双粗合数的大因子锚，它们似乎也能补洞。但本文反复揭示的核心事实是：

> 斜线覆盖能力的增长，追不上方阵行列中由 CRT 非零类、短窗互斥、大因子不可复用和尾部锚削减共同制造出的刚性缺口。

也就是说，合数解释不是可以任意摆放的“涂色”。每一个合数点都必须由真实素因子解释；相邻点不能随便共享大因子；小素数同余类在 CRT 周期中严格均衡；尾部大锚虽然看起来多，却在平均意义下被 Tail-log4 削薄；正反 45 度斜线虽然能制造整条合数斜线，但其贡献被归入小因子锁定层，不能重复算作主体容量。

这使问题从“素数是否随机出现”转化为“合数覆盖是否有足够自由度完成全遮蔽”。本文的答案是：全遮蔽若发生，会被迫形成一个高度结构化的坏配置，而这个坏配置同时违反能量、频率、CRT 均衡与大因子互斥的多重约束。

## 2. 论证思想的几何图像

本文的几何思想可以分成三层。

第一层是圆柱斜线。模 `P` 的列方向被卷成圆周后，同余类不再是孤立的点，而是绕圆柱的螺旋线。一个素因子对应一种斜率；不同素因子对应不同螺旋族。若某行被全覆盖，就意味着许多螺旋线在同一水平截面上精确拼成无缝遮罩。

第二层是 CRT 晶格。把高度延长到根基素数乘积的一个周期，所有非零同余类在非第 `P` 列中严格均衡。这是一种“晶体”结构：每个局部同余条件看似简单，但全部叠加后形成刚性的周期骨架。任何行或列的全覆盖，都不能只在局部解释，还必须与整个 CRT 周期的均衡结构相容。

第三层是能量与频率。若主体双粗锚试图补完所有洞，它们会在倒数相位空间中产生异常偏差。这个偏差若分散，就被 NRC/Weil 型完成和压低；若集中，就形成短簇或高投影增量；若频率反复碰撞，就进入 frequency-closure terminal。无论哪一种，都会被 D 组结构定理捕获。

形象地说：反例不是一块阴影，而是一台必须同时满足几何、同余、频率、能量四套齿轮的机器。本文的工作，就是逐步证明这台机器无法运转。

## 3. 精细构造的作用

本文没有把“素数应该均匀分布”当作直觉口号，而是把每类合数解释拆成可计账对象。

- 小因子锁定层：由根基素数同余类直接解释，是最刚性的部分。
- 尾部锚层：由接近 `P` 的大因子解释，看似危险，但通过 Tail-log4 证明其总贡献可削薄。
- 主体双粗层：真正的难点。它既没有小因子那么周期化，也没有尾部锚那么容易平均削去，必须进入 Structured-EHPD、OMR、CGTP、LSMP、FCT 的结构分析。
- 45 度斜线层：它解释了为什么某些斜对角线上会出现大量合数，但它本质上仍是步长 `P+1` 或 `P-1` 与首项共享因子的同余锁定，不能成为新的自由覆盖容量。

这样的分层使每个合数点都有“账本归属”。一旦全覆盖发生，账本必须平衡；而最终的矛盾正来自账本不可能同时满足所有约束。

## 4. 深层洞见：反例会自我放大为坏配置

真正关键的思想不是直接数某一行有多少素数，而是反过来问：如果没有素数，会发生什么？

如果某行或某列全为合数，那么每个点都必须找到一个素因子解释。剥离小因子和尾部锚后，剩下的主体双粗解释必须覆盖全部剩余候选。此时覆盖不再是普通集合覆盖，而是带有以下刚性的覆盖：

1. 短窗口中大因子不可复用；
2. CRT 非零类骨架不能被任意改变；
3. 覆盖缺口必须超过零频均衡基线；
4. 一阶 Fourier 偏差必须出现；
5. 偏差若继续递推，会消耗平方能量；
6. 频率若共振，会进入低维闭包终端。

因此，反例会被迫升级为 Structured-EHPD 坏配置。这个坏配置越试图隐藏，越会暴露结构；越试图分散，越会被完成和压低；越试图集中，越会触发短簇或投影增量；越试图共振，越会进入频率闭包。反例没有逃逸方向。

## 5. 证明逻辑链条的总览

整篇论文的证明链条可以压缩成一句话：

> 行列反例 `=>` 三层剥离 `=>` 主体双粗坏配置 `=>` 一阶偏差 `=>` OMR/CGTP/LSMP/FCT 结构递推 `=>` 能量或终端矛盾 `=>` 反例不存在。

更细地看：

1. A/B 附录把行反例、非第 `P` 列反例归约为统一的主体双粗坏配置。
2. M5 覆盖缺口说明：全覆盖超过 CRT 零频基线，必然迫出一阶偏差。
3. D 组结构理论说明：一阶偏差不能无限维持；它要么形成高投影增量，要么被 NRC 压低，要么进入频率闭包终端。
4. CGTP 能量账本说明：高投影增量不能无限出现，否则平方能量超过总质量。
5. LSMP 说明：小质量碎片不能逃避能量账本。
6. FCT 说明：共振失败不是漏洞，而是低维终端。
7. Tail-log4 说明：尾部大锚不会填平主缺口。
8. 显式常数与有限验证说明：理论段与小素数段重叠覆盖全部奇素数。

这个链条的意义在于，它把原本看似依赖素数随机性的命题，转化为一个确定性的“覆盖能力不足”命题。

## 6. 最终意义与开放视野

本文尝试建立一种新的视角：素数不是只作为“未被筛掉的随机剩余”出现，而是作为同余斜线覆盖系统无法完全遮蔽的必然空隙出现。这个视角把筛法、CRT、圆柱几何、能量递推和频率分析放到同一个图景中。

从更高维度看，本文的核心不是某一个估计，而是一种原则：

> 当局部同余约束足够刚性，而全局周期结构又足够均衡时，任何试图消灭全部素数空隙的覆盖方案，都会在某个投影中制造不可吸收的结构偏差。

这种原则也许可以继续用于研究更宽的素数网格、短区间筛余、二维同余覆盖、甚至更一般的“局部规则无法完成全局遮蔽”的问题。
