# RH-1 weak 专攻计划：离线零点到 primorial CRT 投影方差

本文件专攻 RH 路线的第一硬点：如何把一个假想的离线零点 `ρ=β+iγ`，`β>1/2`，传递到有限 primorial CRT 系统中的可检测偏差。目标不是直接证明 RH，而是构造一个可攻的弱版桥接命题。

## 1. RH-1 weak 命题

设 `W` 为固定光滑紧支撑非负权，定义

`E(X)=sum_n Λ(n)W(n/X)-X\hat W(1)`。

若存在 zeta 零点 `ρ=β+iγ`，`β>1/2`，则存在 `η>0`、无穷多 `X_j`、以及 `y_j` 满足 `M_{y_j}=prod_{p<=y_j}p <= X_j^θ`，使 primorial CRT 类误差

`E(a;M_y,X)=sum_{n≡a mod M_y} Λ(n)W(n/X)-Main(a;M_y,X)`

的非零类方差满足

`Σ_{a in R(M_y)} |E(a;M_y,X_j)|^2 >= |R(M_y)| X_j^{1+2η}`。

这里 `R(M_y)` 是模 `M_y` 的非零类集合。该命题比“存在单个类超平方根偏差”更弱，但足以通过 Parseval 推出某个 CRT Fourier 模式异常。

## 2. 为什么先攻方差版

单个类偏差可能被相位抵消；方差更稳定。若所有 CRT 模式都平方根随机，则方差约为 `|R|X`。离线零点若能在某个 `M_y` 的非零类系统中留下 `X^β` 级相干信号，则方差应超过 `|R|X`。

方差版还有三个优点：

1. 可用 Parseval 在类空间与角色/频率空间之间转换；
2. 更接近 large sieve 反向问题；
3. 与本文 D 组能量账本天然兼容。

## 3. 显式公式分解

对每个 `a mod M`，写

`1_{n≡a mod M} = 1/φ(M) Σ_{χ mod M} \bar χ(a)χ(n)`

在 reduced residue classes 上成立。于是

`E(a;M,X)=1/φ(M) Σ_{χ mod M} \bar χ(a) E_χ(X)`，

其中

`E_χ(X)=sum_n Λ(n)χ(n)W(n/X)-δ_χ X\hat W(1)`。

Parseval 给

`Σ_{a in R(M)} |E(a;M,X)|^2 = 1/φ(M) Σ_{χ mod M} |E_χ(X)|^2`。

因此 RH-1 weak 等价于证明离线 zeta 零点会迫使某些 `χ mod M_y` 的加权 prime sum 二次平均偏大。

## 4. 第一障碍：zeta 零点只直接进入主角色

zeta 零点 `ρ` 直接出现在主角色 `χ=χ0` 的显式公式里。对非主角色，出现的是 `L(s,χ)` 的零点。若只用 reduced residue class 的 Dirichlet 角色分解，zeta 零点主要留在主角色，而主角色对应的是所有非零类的共同平均，不产生类间方差。

这说明原始 RH-1 weak 不能简单依赖 Dirichlet 角色分解。必须改用能看见 zeta 主误差的投影。

## 5. 关键修正：非互素类/筛余层投影

zeta 主误差反映的是总素数计数波动，而 reduced residue classes 去掉了小素数整除结构后，主误差可能只表现为整体密度变化。要把它转成局部刚性偏差，需要保留筛余层信息，而不是只看 reduced classes。

建议改用 Buchstab 层投影：

`B_d(X)=sum_{n<=X, d|n} Λ(n)W(n/X)` 或 `S_z(X)=sum_{(n,P(z))=1} Λ(n)W(n/X)`。

这些投影直接包含 zeta 主误差，并能通过 Möbius/Buchstab 展开连接到 CRT 非零类。

## 6. RH-1B：Buchstab 层弱投影命题

更可行的弱命题是：若 `β>1/2` 零点存在，则存在 `z=X^α` 的筛层，使

`S_z(X)-Expected_z(X) >= X^{β-o(1)} Π_{p<=z}(1-1/p)`

在某列 `X_j` 上成立，或其 dyadic Buchstab 分层方差超过平方根级。

这个命题避免把 zeta 零点硬塞进非主 Dirichlet 角色，而是让离线零点先进入“筛余总量”。随后再用本文方阵/CRT 的零频基线与覆盖缺口机制，把筛余总量偏差转为局部覆盖缺口。

## 7. 证明 RH-1B 的可能路线

使用 Möbius 截断：

`S_z(X)=Σ_{d|P(z)} μ(d) sum_{d|n} Λ(n)W(n/X)`。

内层约为

`sum_m Λ(dm)W(dm/X)`。

对 `d` 不太大时，显式公式应给出主项和零点项，零点项约为

`(X/d)^ρ` 乘以局部权重。

求和得到零点贡献近似

`X^ρ Σ_{d|P(z)} μ(d)d^{-ρ}`。

Euler product 截断为

`X^ρ Π_{p<=z}(1-p^{-ρ})`。

若 `β>1/2`，该乘积不会小到完全抵消 `X^ρ`；其大小约为负幂对数级。因此筛余层仍保留离线零点贡献：

`≈ X^ρ / log^C z`。

这正是 RH-1B 的核心。

## 8. 第二障碍：Λ(dm) 不是简单 Λ(m)

上述推导忽略了 `Λ(dm)` 的结构。当 `d` 含多个小素数时，`Λ(dm)` 不等于 `Λ(m)`。需要改用 von Mangoldt 与筛条件的恒等式：素数 `n` 若 `(n,P(z))=1` 且 `n>z`，则自动是未被小素数整除的候选。对素数权本身，`(n,P(z))=1` 只是排除 `n<=z` 的小素数，几乎不改变大素数计数。

因此直接筛 `Λ(n)` 的 `S_z` 可能不会产生有用局部结构。更合适的是筛整数候选或合数覆盖函数，再通过 von Mangoldt 显式公式连接素数权。

## 9. 第三修正：用 Chebyshev 波动驱动覆盖缺口

离线零点给 `ψ(X)-X` 的大波动。若 `ψ(X)` 偏大，表示到 `X` 为止素数/素数幂权重异常多。对方阵覆盖语言，素数异常多意味着合数覆盖异常少；若 `ψ(X)` 偏小，表示合数覆盖异常强。两种方向都可能转成覆盖缺口或覆盖过剩。

因此 RH-1 weak 的目标应改写为：

> 离线零点导致某些尺度上的“素数空洞密度”相对 CRT 零频基线异常，从而产生 M5 所需的 `Gap` 或其对偶缺口。

这避免强行要求某个 residue class 大偏差，而是要求筛余空洞密度偏差。

## 10. 最小可攻命题 RH-1C

**RH-1C（筛余空洞投影）。** 若存在 `β>1/2` 零点，则存在无穷多 `X_j` 与 `z_j=X_j^α`，使由小素数 `p<=z_j` 构造的 CRT 筛余集合 `R(z_j)` 中，素数空洞计数相对 CRT 零频基线偏离至少

`X_j^{β-o(1)} / log^C X_j`。

该命题比原 RH-1 更贴近本文局部机器，因为本文的对象正是“哪些位置未被合数斜线覆盖”。

## 11. RH-1C 到局部矛盾场

若 RH-1C 成立，则下一步链条为：

1. 筛余空洞偏差给出 `Gap` 或对偶 `Gap*`；
2. M5+ 迫出一阶 Fourier 偏差；
3. D 组终端处理该偏差；
4. 若无穷多尺度出现，则进入 RH-3 跨尺度排斥。

因此 RH-1C 是比原 RH-1 更自然、更接近当前技术的桥。

## 12. 当前结论

下一步最优专攻不是原始 Dirichlet 角色版 RH-1，而是 RH-1C：

> 离线零点 `β>1/2` 是否必然导致某个小素数 CRT 筛余空洞密度相对零频基线出现超平方根偏差？

这个命题保留 zeta 主误差，又能连接方阵覆盖缺口，是目前最有希望的桥接点。

需要警惕的是：素数权本身与小素数筛条件高度相关，直接 Möbius 投影可能退化。因此必须围绕“合数覆盖函数/素数空洞函数”建立显式公式，而不是只对 `Λ(n)1_{(n,P(z))=1}` 做传统角色分解。
