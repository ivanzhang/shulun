# 统一 Barrier 闭合路线

**状态：** 高维统一攻坚方向。

## 1. 统一转移恒等式

对任意小素数壳 `B` 与相位转移 `x->y`，有

`ΔH = ΔS - ΔC + ΔE`。

这里 `H` 表示洞数，`S` 表示小壳大小，`C` 表示剩余层原始容量，`E` 表示重叠能量。

若旧洞被杀掉数量为

`KILL=|H_P(x)\H_P(y)|`，定义

`Barrier(x,y;B)=ΔE-ΔC+ΔS+KILL`。

由恒等式立刻得到：

`Barrier = |H_P(y)\H_P(x)|`，即新生洞数量。

特别地，若 `y` 全补旧核，即 `H_P(x)∩H_P(y)=empty`，则

`Barrier=|H_P(y)|`。

因此主目标可统一成：

> 任意前窗口全补旧核转移都有 `Barrier>=1`。

## 2. 分情况的统一解释

此前所有分情况只是估计 Barrier 的工具：

- 小壳迁移影响 `ΔS`；
- 容量不足体现为 `-ΔC` 变大；
- 重叠吞噬体现为 `ΔE` 变大；
- 标签互斥限制 `ΔC` 的可实现增长；
- CRT 同步压力限制全补旧核的可行相位；
- 列缺陷流记录 `Barrier` 的列支撑如何在周期中迁移。

因此最终证明不应写成很多零散特例，而应证明统一不等式：

`ΔE-ΔC+ΔS+KILL >= 1`。

## 3. 为什么这是高维本质命题

这个不等式同时包含三种增长量级差异：

1. **小壳维度增长。** 随 `P` 增大，小壳大小仍线性增长；
2. **覆盖容量增长。** 斜线层数增长，但有效覆盖受重叠扣减；
3. **同步复杂度增长。** 多点补洞需要 CRT 模数乘积增长，快于前窗口尺度。

`Barrier` 正是三者差额的局部守恒量。

## 4. 可证明分解

为了证明 `Barrier>=1`，可分解为：

`Barrier = ShellShift + CapacityLoss + OverlapGain + KillCredit`。

其中：

- `ShellShift=ΔS`；
- `CapacityLoss=-ΔC`；
- `OverlapGain=ΔE`；
- `KillCredit=KILL`。

困难在于某些项可为负，但四项总和实验上保持正。

下一步要找稳定下界，例如：

`OverlapGain + KillCredit >= ΔC-ΔS+1`。

## 5. 接入列缺陷流

`Barrier` 不只是数量；它有列支撑：

`New(x,y)=H_P(y)\H_P(x)`。

列缺陷流 `D_c` 记录这些新生洞在 CRT 周期内如何补偿旧洞消失。

若前窗口零行存在，则存在一条转移链把某个极小核杀到空集，即最终 `Barrier=0`。因此列支撑也为空。证明 `Barrier>=1` 等价于说缺陷流不能在前窗口湮灭。

## 6. 下一步证明目标 UB-1

**UB-1。** 设 `H_P(x)` 是前窗口偏序极小核。对任意 `1<=y<P`，若 `H_P(x)∩H_P(y)=empty`，则

`Barrier(x,y;B)>=1`。

这个命题表面上等价于 `H_P(y) nonempty`，但其证明可通过四项分解完成，而不是循环使用目标。

## 7. UB-1 的非循环证明入口

证明时不直接使用 `H_P(y)`，而估计四项：

1. `KILL` 由旧核大小给出；
2. `ΔS` 由小壳 CRT 迁移显式计算；
3. `ΔC` 由剩余层容量上界控制；
4. `ΔE` 由强制重叠、短差标签互斥、CRT 同步给出下界。

只要四项推出 `Barrier>=1`，即得到新洞存在。

## 8. 下一步实际工作

下一步应研究 `ΔE` 的下界，因为这是最能体现结构刚性的项。
