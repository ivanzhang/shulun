# 从搜索证书到无条件证明：H_P 列方向证明的路线图

本文档汇总从 §198 卡在束搜索经验，到 §213 给出"组合-密度严格论证"的完整推进。
读者通过这一文档可以看到 P×P 方阵列方向局部非空刚性的证明骨架是如何被精确化的。

## 1. 元层面框架

按 §206 提出的元层面框架，把研究目标统一为：

> **方阵局部非空刚性**：P×P 方阵 `A_{i,j} = (i-1)P + j` 的某局部子集 R ⊂ [P]×[P] 必含素数。

不同 R 形状对应不同方向：

| R | A 算术结构 | 难度 |
|---|-----------|------|
| 行 R_i | 短区间 | Bertrand（已证）|
| 列 R^j | 等差数列 j+tP | Linnik 型 |
| 对角线 | 等差数列 1+t(P+1) | 类 Linnik |
| 子方阵 | 二维网格 | 多元 BV |

证明工具：

- **CRT 列均匀刚性**：每个 q < P 在 R 上单一同余斜线
- **密度波动结构刚性**：H_holes(q, r) 的稀疏性

## 2. 列方向 R^j 的完整证明骨架（§200-§213）

```

```

### 关键代数公式

**§200.12 r_unkill 公式**：

```
r_unkill(q, P, A_old) ≡ -A_old · P^{-1} (mod q)
```

当 modulus_below > P − A_old（k=10 反例自动满足），每个新 q 至多 1 个不杀候选 r。

**§201 M_kill 全代数公式（无截断）**：

```
M_kill(prefix, P) = Σ_{q ∉ used} min(last_cap, max(0, H_holes(q, r_unkill_q) − 1))
```

仅依赖 holes 几何与 r_unkill 序列，纯有限可计算。

**§202.1 传递性引理**：

> 若 `modulus_k > P_witness`，则 j ≥ k+1 反例 witness 必为 k 反例 witness。

故 witness 集合从 k_low=10 起单调收缩，所有更高 k 强制定理由 k_low 蕴含。

## 7. 双视角统一（§205）

本研究方向（30P 链 + 容量前缀）与 codex 平行方向（rigid-patch 单列模型）是同一组合对象的不同视角：

| 30P 链方向 | 单列方向 |
|------------|---------|
| 单位相位 c mod 2310 | 列 a mod P |
| holes_for_c(c, W) | H_y(a) |

两条路汇合于 holes 命中分布的稀疏性。
