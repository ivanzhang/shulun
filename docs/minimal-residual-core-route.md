# 极小残洞核路线：RCC 的正确修正版

**状态：** 新核心接口；替代过强的朴素 RCC。

## 1. 朴素 RCC 的失败与修正

偏序扫描 `front-window-hole-poset-scan` 表明，前窗口内确实存在

`H_P(y) strictly subset H_P(x)`。

例如 `P=23` 中，`x=4` 的洞集

`[5,9,11,15,17,21]`

可下降到 `x=14` 的洞集

`[9,15]`。

因此，命题不能写成“任意前窗口相位移动都没有净消洞”。

正确修正是：

> 前窗口中允许局部净消洞，但下降过程必须停在非空极小残洞核；不存在空洞极小元。

这与目标命题完全等价：若存在前窗口零行，则空集就是偏序最小洞集；反之若所有极小洞集非空，则每个前窗口行都有洞。

## 2. 极小残洞核命题 MRC

定义前窗口洞集族

`F_P={H_P(x): 1<=x<P}`。

按集合包含关系排序。候选核心命题为：

**MRC(P)：** `empty notin F_P`，并且 `F_P` 的每个极小元都非空。

表面上第一句就是目标命题；真正有用的是第二句的结构化证明路线：

1. 对任意 `x`，若 `H_P(x)` 非极小，则存在下降相位 `y` 消掉一批洞；
2. 下降链因洞集有限必停；
3. 停点是极小残洞核；
4. 证明极小残洞核因结构刚性不可能为空。

这样不再试图用有限模板覆盖所有相位，而是用偏序下降把任意相位归约到极小核，再证明极小核非空。

## 3. 极小核的实验形态

小样本极小/最小洞集为：

- `P=13`: `[10]`
- `P=17`: `[7]`
- `P=19`: `[8]`
- `P=23`: `[9,15]`
- `P=29`: `[12,18,28]`, `[1,19,25]`, `[5,13,23]`
- `P=31`: `[12,22]`
- `P=37`: `[29,35]`
- `P=41`: `[7,9,15]`
- `P=47`: `[17,41,45]`
- `P=53`: `[2,36,42,48]`, `[9,21,29,45]`
- `P=59`: `[25,43,53]`

这些核呈现三类刚性：

1. **短 gap 骨架。** 如 `[9,15]`、`[29,35]`、`[7,9,15]` 保留小间距差。
2. **镜像伴随。** 许多核靠近 `c -> P-c` 的镜像对或镜像缺陷。
3. **补洞高代价。** 局部补掉核很容易，但延拓为全覆盖会回到首个零行相位，通常远超 `P`。

## 4. 极小核非空的矛盾场方程

假设存在前窗口零行 `x0<P`，即 `H_P(x0)=empty`。

对任意极小核下降链终点 `x*`，从 `x*` 到 `x0` 必须净消掉所有核洞且不产生新洞。

于是需要满足：

`Gain(x0;x*) >= |H_P(x*)|` 且 `Release(x0;x*)=0`。

其中

`Gain` 是核洞被新相位覆盖的数量，`Release` 是原非洞列被释放成新洞的数量。

极小性给出强约束：对任意 `y<P`，若 `H_P(y) subseteq H_P(x*)`，则必须 `H_P(y)=H_P(x*)`。因此零行若存在，必须突破极小性，等价于构造一个“全核同步消除且零释放”的相位。

候选矛盾场不等式应写成：

`Release(y;x*) >= 1` 对所有 `y<P` 且 `Gain(y;x*)=|H_P(x*)|`。

这比旧式 `净补洞数<=0` 更准确，也更可能证明。

## 5. 三个可攻证明接口

### 5.1 同因子短差互斥接口

若极小核中存在短差 `d=|c1-c2|`，则同一大根基素数不能同时解释两洞，因为同因子覆盖要求 `q|d`。当 `q>d` 时不可能。

因此短差核需要多个不同补洞因子同步命中，CRT 模数乘积迅速增大，最小代表跨出前窗口的压力增强。

### 5.2 相邻商互质释放接口

若相位移动补掉核洞 `c`，对应因子 `q` 固定了 `y mod q`。相邻列 `c±1` 因不能被同一 `q` 覆盖，必须由其它层保持覆盖。

多个核洞同步补掉时，其邻域保持覆盖形成互质商链。该链越长，释放某一邻域列的风险越不可避免。

### 5.3 CRT 列均衡回流接口

完整 CRT 周期中，除第 `P` 列外，各列类素数计数严格相等。若前窗口存在极小核到空集的零释放消除，则该列族在周期前端产生过强负缺陷。

镜像对称 `A(r)=A(M+1-r)` 会把该缺陷复制到周期末端。于是必须在中部产生补偿过冲。下一步要把这种补偿写成计数不等式，排除“前端零释放消除”。

## 6. 下一步最小闭合任务

最小可证目标不是直接证明全部 MRC，而是先证明：

**短差极小核不可零释放消除。** 若极小核 `K` 含有差 `d<min K` 或 `d<sqrt(P)` 的两点，则不存在 `y<P` 使 `K subseteq covered_y` 且 `H_P(y)=empty`。

这能覆盖当前多数样本，并可继续推广到无短差核的镜像缺陷型。
