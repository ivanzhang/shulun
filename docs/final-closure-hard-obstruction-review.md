# 最终闭合硬障碍审查：与最小等差素数问题的关系

**状态：** 顶级审稿级风险提示；当前不能诚实声称目标命题已无条件闭合。

## 1. 列命题的外部等价障碍

目标列命题要求：对每个奇素数 `P` 与每个 `1<=c<P`，存在 `0<=k<P` 使

`kP+c`

为素数。

这等价于：模 `P` 的每个非零剩余类 `c` 都有一个素数代表小于 `P^2`。

若记 `p(P,c)` 为同余类 `c mod P` 中的最小素数，则列命题正是

`max_{1<=c<P} p(P,c) < P^2`。

这属于“最小等差素数”问题，强接近 Chowla 型猜想。当前公开无条件结果只给 Linnik 型 `p(P,c) << P^L`，已知指数 `L` 大于 `2`；`P^2` 级别不是已知无条件定理。

因此，若本文声称无条件证明列命题，就等价于在素数模数情形证明一个非常强的最小等差素数上界。该点必须作为核心硬障碍处理，不能由局部 CRT 几何或有限参数优化自动越过。

## 2. 行命题的外部等价障碍

行命题要求：每个区间

`[(r-1)P+1, rP]`, `1<=r<=P`,

都含素数。

这意味着在 `P^2` 以下没有长度至少 `P` 的素数空隙，并且要求所有以 `P` 为块长的划分块都命中素数。

这强接近 Legendre/Oppermann/短区间素数间隙类问题。现有无条件素数间隙上界尚不能推出每个长度 `P≈sqrt(x)` 的区间都含素数；RH 级别也通常给 `O(sqrt(x) log x)` 规模，仍不足以直接得到长度 `sqrt(x)`。

因此行命题也不是目前可由标准无条件解析数论直接闭合的简单推论。

## 3. 对当前矛盾场证明链的影响

前面构造的 SFL、KFCI、SLI、SCD、SDL 等结构仍有研究价值，它们说明：

- 短差核心的静默补洞受到平方自由 CRT 同步损耗限制；
- 单大特征零模态被小标签静止无杀伤与边界流出排斥；
- 稀疏分支可由单坐标壳差给出大量释放候选。

但这些结构目前仍没有严格推出“每个剩余类 `c mod P` 在 `P^2` 前有素数”。尤其列命题若闭合，将解决最小等差素数的 `P^2` 界；这需要额外的全局解析输入或一个真正突破性的局部-全局定理。

## 4. 正确的论文状态表述

当前论文应表述为：

1. 已建立一套圆柱筛几何的刚性矛盾场框架；
2. 已闭合若干局部零模态：短差核心、单大特征、小标签静止、壳差稀疏分支；
3. 仍需一个全局定理，把这些局部排斥提升为每个行/列边际非零；
4. 列命题的最终闭合将至少达到 Chowla 型最小等差素数 `P^2` 界的强度。

因此不能写成“已完成无条件证明”。应写成“条件化于全局局部-全局提升引理”或“提出新证明路线并识别剩余核心障碍”。

## 5. 下一步诚实攻坚方向

最有希望且审稿上诚实的下一步不是继续降低形式阈值，而是证明或明确假设以下全局提升引理：

**LG-AP（局部几何到等差素数提升）。** 圆柱筛几何中的 SFL/KFCI/SLI/SCD/SDL 排斥所有可能造成某一剩余类 `c mod P` 在 `[1,P^2)` 中无素数的覆盖方案。

该引理一旦成立，列命题闭合；但它本身就是 Chowla 型强命题的核心，必须独立给出完整证明。

在没有 LG-AP 的无条件证明前，全文应保持为研究纲领/条件证明，而非定稿证明。

## 6. 外部依据备注

公开资料与标准文献中，最小等差素数问题通常记为 `p(a,q)`：满足 `p≡a mod q` 的最小素数。Linnik 定理只给出 `p(a,q) << q^L` 的某个绝对指数界；Chowla 型猜想预期更强的接近 `q^{1+ε}` 级别。本文列命题所需的 `p(a,P)<P^2` 位于这些强猜想/条件结果附近，并非当前初等 CRT 几何可自动推出的已知无条件事实。

因此，后续所有“阈值有限验证”只能验证有限范围，不能替代缺失的全局解析或局部-全局提升引理。
