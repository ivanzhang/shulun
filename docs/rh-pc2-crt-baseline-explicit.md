# PC2：CRT 候选基线与边界误差显式化

本文把 `docs/rh-pc2-li-crt-baseline-match.md` 中的核心输入

`C_z(X)=C_z^0(X)+o(Δ)`

拆成显式可审查引理。目标是证明：当 `z=(log X)^A`, `0<A<1`，CRT 周期 `M=∏_{p<=z}p=X^{o(1)}`，平滑候选总量的周期误差远低于离线零点产生的 `Δ=X^{β-o(1)}`, `β>1/2`。

## 1. CRT 候选计数

令

`M=M_z=∏_{p<=z}p`, `χ_M(n)=1_{(n,M)=1}`。

定义平滑候选计数

`C_z(X)=Σ_n χ_M(n)W(n/X)`。

零频基线为

`C_z^0(X)=φ(M)/M · X\widehat W(1)`。

## 2. 周期分解误差

**Lemma PC2-A（平滑周期计数误差）。** 对任意固定 `W∈C_c^∞((0,∞))`，有

`C_z(X)=C_z^0(X)+O_W(M)`。

更强地，对任意 `J>=1`，可写

`C_z(X)=C_z^0(X)+O_{W,J}(M^J X^{1-J})+O_W(M)`，

但本文只需 `O_W(M)`。

**证明。** 按模 `M` 的剩余类分解：

`C_z(X)=Σ_{a mod M,(a,M)=1} Σ_{n≡a mod M} W(n/X)`。

对固定 `a`，内和是步长为 `M` 的平滑采样。Euler--Maclaurin 或 Poisson 求和给

`Σ_{n≡a mod M} W(n/X)=X/M · \widehat W(1)+O_W(1)`。

对 `φ(M)` 个非零类求和，得主项 `φ(M)X\widehat W(1)/M`，误差 `O_W(φ(M))=O_W(M)`。证毕。

## 3. `M=X^{o(1)}` 显式化

由 Chebyshev 函数 `θ(z)=Σ_{p<=z}log p` 的初等上界 `θ(z)<<z`，有

`log M=θ(z)<<z=(log X)^A`。

因此

`M <= exp(C(log X)^A)=X^{o(1)}`。

对任意固定 `β>0`，特别是 `β>1/2`，有

`M=o(X^{β-o(1)})`。

于是 PC2-A 给

`C_z(X)-C_z^0(X)=o(Δ)`。

## 4. 素数自动位于非零类

若 `p∈supp W(n/X)⊂[cX,CX]` 且 `X` 充分大，则 `p>z`。因此任何 `p<=z` 都不整除该素数 `p`，即

`(p,M)=1`。

故 PC1 产生的素数异常完全发生在 CRT 非零候选集合内部。

## 5. 边界项显式化

候选恒等式写为

`C_z=P_z+B_z+Err_bd`。

在全局平滑窗口中，`Err_bd` 只包括：

1. 支撑端点平滑误差；
2. Chebyshev 权转无权时的固定对数损失；
3. 素数幂项；
4. 若采用硬截断，则端点半开区间约定误差。

对平滑权版本，端点误差已被 `W` 吸收。素数幂贡献满足

`Σ_{k>=2,p^k≈X}1 << X^{1/2+o(1)}`，

Chebyshev 权版本中为 `O(X^{1/2}log^C X)`。由于 `β>1/2`，它是 `o(X^{β-o(1)})`。无权化的对数损失已在 PC1 中并入 `X^{o(1)}`。

因此

`Err_bd=o(Δ)`。

## 6. 基线差分定理

**Theorem PC2-Explicit-Baseline（CRT 基线显式匹配）。** 设 `z=(log X)^A`, `0<A<1`，`Δ=X^{β-o(1)}`, `β>1/2`。则：

1. `C_z(X)=C_z^0(X)+o(Δ)`；
2. PC1 的素数异常位于 CRT 非零候选集合内；
3. 候选恒等式的边界项满足 `Err_bd=o(Δ)`；
4. 因而

   `B_z-B_z^0=-(P_z-P_z^0)+o(Δ)`。

**证明。** 第 1 项由 PC2-A 与第 3 节；第 2 项由第 4 节；第 3 项由第 5 节；第 4 项由恒等式 `C_z=P_z+B_z+Err_bd` 与 `B_z^0=C_z^0-P_z^0` 相减得到。证毕。

## 7. 对总攻框架的影响

本文把 `docs/rh-contradiction-field-final-assault.md` 第 7 节中的第二项“PC2 的 CRT 候选边界误差与权重正规化”定理化。PC2 剩余义务只是在最终投稿中固定平滑权规范，并在 Chebyshev 权/无权版本之间选择统一口径。
