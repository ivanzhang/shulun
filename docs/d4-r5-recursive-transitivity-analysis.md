# D4/R5 层叠剥离递归模型：传递性分析

## 1. 递归状态

令尺度序列 `X_0<X_1<...<X_n`，对应约束素数壳层

```text
Q_j = { q : sqrt(X_{j-1}) < q <= sqrt(X_j) }.
```

旧候选集合 `S_j` 与新壳层满足：

```text
S_j = S_{j-1} ∩ N_j,
```

其中 `N_j` 是避开 `Q_j` 零同余类的集合。

对每个局部窗口/行候选定义状态向量

```text
Z_j = (L_j, E_j, D_j, B_j, C_j)
```

其中：

- `L_j`: 异常层总质量；
- `E_j`: 异常层二次能量；
- `D_j = E_j - L_j^2/20`: Cauchy 缺陷；
- `B_j`: 当前坏度，例如 `max(0, L_j^2/20-E_j)` 或 light 超界量；
- `C_j`: 层分类状态，包括 light/short/transition/highmass。

## 2. 传递性目标

递归剥离要证明一个传递算子 `T_j`：

```text
Z_j = T_j(Z_{j-1}, shell_j)
```

满足三择：

1. **稳定耗散**：若 `C_j=C_{j-1}`，则

```text
D_j >= D_{j-1} + c_j - err_j.
```

2. **坏度回传**：若 `B_j>0` 且无跳变耗散，则存在投影 `pi_j` 使

```text
B_{j-1}(pi_j window) >= B_j - eps_j.
```

3. **跳变吸收**：若 `C_j!=C_{j-1}`，则

```text
B_j <= B_{j-1} - kappa_j
```

或该窗口落入有限危险窗口证书族。

若 `sum(c_j-err_j)` 正向累积，而 `sum eps_j` 可控，则坏结构不能无限向大尺度传递。

## 3. 为什么这能替代有限模板覆盖

有限模板覆盖要求所有尺度都属于固定模板族，这是不现实的；递归传递只要求每一步新壳层满足统一局部不等式。无穷多素数约束被分解为无穷多个局部传递步骤，而不是一次性模板枚举。

## 4. 现有数值证据

`docs/d4-r5-recursive-peeling-probe.json` 显示：

- highmass 型见证 `1088373,1088475` 在所有 `hi` 增量中壳层缺陷均为正；
- low-prefix 型见证 `1088588` 出现一次大跳变，坏度下降后转入 light 超界方向；
- 这支持将 RPL 分为 stable 与 jump 两个引理。

## 5. 下一步核心不等式

### RPL-stable

固定层分类时，新增壳层 `A` 满足

```text
E(A) - L(A)^2/20 >= 0
```

并且交叉项不会使总缺陷下降超过可控误差：

```text
D(S∪A)-D(S) >= d(A) - Cross(S,A).
```

需要证明 `Cross(S,A)` 被同余独立性/CRT 均匀性控制。

### RPL-jump

层分类改变时，必有某个资源阈值被跨越，例如 `tau_sum=60`、`count=20/25`、`U=0.16`、`L=0.35`。跳变集合落在低维边界；需要证明边界窗口总数/总质量有限可控，或被已完成的外向舍入窗口证书覆盖。

## 6. 当前结论

递归模型的传递性方向是合理的，但严格闭合需要两个具体证明：

1. stable 壳层的交叉项上界；
2. jump 边界的有限性/吸收证明。
