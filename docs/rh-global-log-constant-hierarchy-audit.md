# 全局 log 常数层级排序审查

本文补强容量链最后剩余接口：全局所有 `log^C X`、阈值常数、截断高度和低体积余量是否可以按无循环顺序选择。本文不宣称 RH 已证明；它只是把当前文档包中的对数损失统一登记为条件化可审查账本。

## 1. 目标

当前 RH 反例矛盾场文档允许两类损失：

- `log^C X` 多对数损失；
- `X^{o(1)}` 固定复杂度损失。

由于 PC1 异常为 `X^{β-o(1)}` 且 `β>1/2`，任意固定对数损失可被主指数余量吸收。唯一需审查的是：各接口选择的 `C` 是否存在循环依赖。本文给出统一选择顺序。

## 2. 常数层级

按以下顺序选择常数：

1. **结构复杂度常数 `C_struct`**：固定模板、布尔深度、dyadic 层数、Bohr 频率维数；
2. **有限重叠常数 `C_overlap`**：物理窗、dyadic 层、相位盒、SC 短窗覆盖；
3. **截断常数 `C_tail`**：Vaaler/Fourier 截断高度与边界平滑参数；
4. **投影/frame 常数 `C_frame`**：DGap 盒 frame、PI 允许投影有限交；
5. **容量常数 `C_cap`**：DSO/PI/SC/OV2/MLC/FCT/LSMP 容量损失；
6. **触发阈值常数 `C_trig`**：PPI、PI_seed、FCT_seed、SC_seed 的反面阈值；
7. **低体积余量 `B_LV`**：必须大于前面全部对数损失；
8. **主层门槛 `C_0`**：必须大于 NRC、PPI、MLC 所需全部对数损失；
9. **最终余量 `B_final`**：用于有限个 dyadic pigeonhole 和全局 union bound。

选择规则为

`C_struct << C_overlap << C_tail << C_frame << C_cap << C_trig << B_LV << C_0 << B_final`。

这里 `A<<B` 表示先固定 `A`，再取 `B` 足够大以吸收所有依赖 `A` 的有限多项式表达。

## 3. 接口对应表

| 接口 | 使用的常数 | 被谁吸收 |
| --- | --- | --- |
| DGap 盒重叠 | `C_overlap` | `C_frame`, `C_cap` |
| Fourier/Vaaler 尾项 | `C_tail` | `CE/LSMP` 或 `B_LV` |
| DGap 投影 frame | `C_frame` | `C_cap` |
| DSO/PI bridge | `C_frame+C_cap` | `C_trig` |
| PI lacunary/dense | `C_cap` | `C_trig`, `B_final` |
| SC 局部乘积 | `C_overlap+C_cap` | `B_LV`, `B_final` |
| OV2/MLC Uniform | `C_cap+C_trig` | `C_0`, `B_final` |
| FCT/LSMP span 计数 | `C_struct+C_cap` | `B_final` |
| LV 体积吸收 | 前面全部 | `B_LV` |
| 主层门槛压过 NRC | `C_cap+C_trig` | `C_0` |

## 4. 无循环性检查

常数选择无循环，原因是：

1. 结构复杂度只来自固定模板定义，不依赖容量结论；
2. 有限重叠只依赖结构复杂度；
3. 截断高度只依赖结构复杂度和需要的平方可和速率；
4. frame 和容量损失依赖前面三项；
5. 触发阈值只需小于容量可检测下界，故在容量之后选择；
6. LV 余量和主层门槛是最终“大常数”，专门吸收前面所有损失；
7. `B_final` 最后处理有限 pigeonhole、union bound 和文档合并损失。

没有后置常数反过来改变前置模板定义；若某步骤需要改变前置复杂度，则按定义进入 `CE/LSMP`，不参与常数排序。

## 5. 与指数余量的关系

任意固定常数层级给出的总损失为 `log^{C_total}X`。对任意固定 `C_total`，

`log^{C_total}X = X^{o(1)}`。

因此 PC1 的 `X^{β-o(1)}` 异常在经过有限多个接口后仍为 `X^{β-o(1)}`。只要没有接口引入固定正幂损失 `X^ε`，主指数余量保持。若出现正幂损失，该接口必须标记为未闭合，不能被本文吸收。

## 6. 主定理

**Theorem Global-Log-Constant-Hierarchy（条件化）。** 当前正式 RH 反例矛盾场文档中的所有多对数损失可按第 2 节顺序无循环选择，并统一吸收到 `X^{o(1)}`。在该常数层级下，容量矩阵中的 `log^C X` 损失不会破坏 PC1 离线零点异常的指数级主量。

**证明。** 第 3 节逐项登记接口常数。第 4 节说明依赖方向严格从结构、重叠、尾项、frame、容量、触发阈值到最终余量，不存在回边。第 5 节说明有限多对数损失均为 `X^{o(1)}`。证毕。
