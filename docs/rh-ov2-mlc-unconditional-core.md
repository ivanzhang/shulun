# OV2-MLC：主层容量无条件核心

本文把 `docs/rh-ov2-main-layer-capacity-interface.md` 中可无条件化的容量账本抽出：双锚正规形的 dyadic 主/尾层分解、低尾容量吸收、近平方边界吸收、主层门槛条件。不可检测均匀质量的最终吸收仍依赖 PPI/FCT/LV 的终端分解，本文只把纯容量部分定理化。

## 1. Dyadic 双锚容量

由 AAI，无重复解释点进入正规形

`n=q_1q_2r`, `q_1,q_2~Q`, `r~R`, `Q^2R~X`。

对固定 `Q,R`，平凡容量满足

`V_{Q,R} << Q^2R << X`。

更细地，固定 `r` 后，`q_1q_2~X/r` 是乘积薄壳，粗略自由度为 `O(Q)`，故

`V_{Q,R} << RQ · log^C X`。

当 `R` 很小时，这比 `X` 有显著节省。

## 2. 低尾容量吸收

令 `L=log X`。

**Lemma MLC-U1（低尾层容量）。** 若 `R<L^{A_1}`，则

`V_{Q,R} << X^{1/2}L^{A_1/2+C}`。

因此对任意固定 `B`，在充分大 `X` 上有

`V_{Q,R} <= X/L^B`。

**证明。** 由 `Q^2R~X` 得 `Q~(X/R)^{1/2}`。用 `V_{Q,R}<<RQ log^C X`，得

`V_{Q,R}<<R(X/R)^{1/2}log^C X=X^{1/2}R^{1/2}log^C X`。

若 `R<L^{A_1}`，即得第一式；它相对 `X` 有 `X^{1/2}` 幂节省，故强于任意固定对数节省。证毕。

## 3. 近平方边界吸收

**Lemma MLC-U2（近平方边界）。** 若 `Q>X^{1/2}L^{-A_0}`，则

`R=X/Q^2 < L^{2A_0}`，

故该层由 MLC-U1 低尾容量吸收；若质量不按容量分散而集中到少数 `r` 或短 `n` 窗口，则触发短簇终端。

**证明。** 第一式直接由 `Q^2R~X`。低尾吸收由 MLC-U1。若实际 overlap 质量远超过容量均匀估计，只能集中于少数尾因子或短物理窗，这正是短簇定义。证毕。

## 4. 主层定义与门槛

称 `Q,R` 为主层，若：

1. `Q>z` 且 `Q<=X^{1/2}L^{-A_0}`；
2. `R>=L^{A_1}`；
3. 有效层权 `W_Q` 满足

   `W_Q^{1/2}>=K_eff L^{C_0}X^{-ε/4}`。

否则为低容量层、近平方边界层或复杂度不足层。

**Lemma MLC-U3（主层门槛压过 NRC 量级）。** 在主层中，若 PPI 给出偏差下界

`c X^{1/2+ε/2}W_Q^{1/2}/L^C`，

而 NRC 上界为

`C K_eff X^{1/2}L^C`，

则取 `C_0` 足够大后，PPI 下界大于 NRC 上界。

**证明。** 代入主层门槛：

`X^{1/2+ε/2}W_Q^{1/2}/L^C >= K_eff X^{1/2+ε/4}L^{C_0-C}`。

对固定 `C,C_0` 且 `C_0` 足够大，右侧最终超过 `C K_eff X^{1/2}L^C`。证毕。

## 5. Dyadic pigeonhole 定位

**Lemma MLC-U4（大能量定位）。** 若总 overlap 能量 `E_ov` 超过阈值，且低尾层、近平方边界层与低容量层均由 MLC-U1/U2 或 LV 吸收，则存在一个主层 `Q,R` 承载相应大能量比例。

**证明。** dyadic 层数为 `O(log^C X)`。若每个主层均低于总阈值除以该层数，同时尾层已吸收，则总和不能超过阈值。故某主层承载大能量。证毕。

## 6. MLC 无条件核心定理

**Theorem MLC-Unconditional-Core（主层容量无条件核心）。** 对 AAI 双锚正规形 `n=q_1q_2r`，以下纯容量结论无条件成立：

1. dyadic 块满足 `Q^2R~X` 与容量界 `V_{Q,R}<<RQlog^C X`；
2. `R<log^{A_1}X` 的低尾层有强于任意固定对数节省的容量上界；
3. `Q>X^{1/2}log^{-A_0}X` 的近平方边界层归入低尾层或短簇；
4. 若大 overlap 不在尾层/边界层/低容量层，则由 dyadic pigeonhole 定位到主层；
5. 主层门槛可压过 NRC 的平方根量级上界。

**证明。** 分别由 MLC-U1 至 MLC-U4 与 MLC-U3 合并。证毕。

## 7. 仍待无条件化的 MLC 剩余

不可检测均匀质量的最终吸收已单独写入 `docs/rh-ov2-mlc-uniform-absorption.md`。因此第三项覆盖输入中，AAI、PPI 与 MLC 容量核心均已定理化；MLC 的不可检测剩余被转入 FCT、SC/LV、DSO/PI 或零频均匀背景。
