# C5 DGap 内联证明链：过密对偶缺口的三接口定理化

本文补 `docs/rh-merge-unconditional-checklist.md` 的 C5。目标是把 `docs/rh-dgap-maintext-three-interface-chain.md` 从“分支说明”升级为可并入合并稿的编号证明链。本文保持严格口径：C5 的 DGap 内部逃逸已压缩到已命名接口；最终无条件化仍依赖 C6/C9/C10 对终端、尾项和外部定理的放电。

## 1. 与 C3 修正版的入口匹配

采用 C3 修正版账本：

`B_z=ACC_z+Hole_z+o(Δ)`，

其中 `ACC_z` 是至少被允许证书覆盖的粗合数候选数，`Hole_z` 是未被覆盖的粗合数候选数。过密分支 `E_z>=Δ` 给

`ACC_z^0-ACC_z + DGap_z >= Δ-o(Δ)`, `DGap_z:=Hole_z^0-Hole_z`。

若 `ACC_z^0-ACC_z` 承载固定比例异常，则进入 `A` 的覆盖同步分支。C5 只处理剩余主通道：

`DGap_z>=cΔ`。

这说明 DGap 是“基准应有缺口被异常压缩”的对偶事件，而不再依赖旧公式中的 `O_z-O_z^0`。

## 2. Lemma C5.1：盒局部化与有限重叠

**Lemma C5.1（Box localization）。** 若 `DGap_z>=cΔ`，则存在固定复杂度盒族 `𝓑` 与偏差函数 `h`，使 DGap 正质量在盒族上被检测；且除非进入 `LV/SC/CE/LSMP/FCT`，有点态有限重叠

`Σ_{B∈𝓑}1_B(n)<=log^{C_box}X`。

**证明。** DGap 由 `Hole_z^0-Hole_z` 给出，表示基准中存在而实际中被覆盖/消失的缺口质量。按物理窗口、dyadic 锚层、CRT/Bohr 相位窗和平滑边界把该质量分解为有限复杂度盒。若某点被过多盒覆盖，则原因只能是：物理短窗低体积集中、dyadic 层无限细化、相位模板复杂度逃逸或短弧树漂移。它们分别是 `LV/SC`、`CE/LSMP`、`CE/FCT/LSMP` 的定义入口。因此在非命名失败分支中，固定复杂度给点态 `log^{C_box}X` 重叠。证毕。

## 3. Lemma C5.2：frame 下界与常数方向剥离

对盒函数定义

`φ_B=(1_B-E_0 1_B)/||1_B-E_0 1_B||_2`，`V=span{φ_B:B∈𝓑}`。

**Lemma C5.2（DGap projection energy）。** 在 C5.1 的非失败分支中，若 PC2 零频基线成立，则 DGap 正质量给出

`||P_V h||_2^2 >= X^{2β-1-o(1)}`。

**证明。** 点态有限重叠给 Gram/frame 上界

`||Σ_B c_B φ_B||_2^2 <= log^{C}X Σ_B |c_B|^2`。

由对偶 Bessel 不等式，盒相关和满足

`Σ_B |<h,φ_B>|^2 <= log^C X ||P_Vh||_2^2`，

故若 DGap 在盒上有 `Δ` 级线性偏差，则 Cauchy--Schwarz 与盒总质量归一化给 `Σ_B |<h,φ_B>|^2 >= X^{2β-1-o(1)}`，从而得到投影能量下界。`φ_B` 中扣除的常数方向只对应 CRT 零频平均；若常数方向承载主偏差，则违反 PC2 的 `C_z-C_z^0=o(Δ)` 或进入 C2 基线失败。因此在 PC2 成功分支中，下界必须落在非常数投影空间 `V`。证毕。

## 4. Lemma C5.3：逐步正交投影分配

令 `V_PI` 为允许投影空间，`V_low` 为低维/短簇/低体积空间，`V_err` 为剥离前两者后的误差空间。它们不必天然直和，按顺序定义正交剩余：

`h_0=P_Vh`, `h_1=h_0-P_{V_PI}h_0`, `h_2=h_1-P_{V_low}h_1`。

**Lemma C5.3（Orthogonal allocation）。** 若 C5.2 的能量下界成立，则至少一个出口承载固定比例能量：`PI`、`FCT/SC/LV/LSMP`、`CE/CapacityFail`；否则矛盾。

**证明。** Hilbert 空间投影恒等式给

`||h_0||_2^2 = ||P_{V_PI}h_0||_2^2 + ||h_1||_2^2`

以及

`||h_1||_2^2 = ||P_{V_low}h_1||_2^2 + ||h_2||_2^2`。

若第一项承载固定比例，进入 `PI`。若第二层投影承载固定比例，按 `V_low` 的定义进入 `FCT/SC/LV/LSMP`。若剩余 `h_2` 承载固定比例，则它恰为模板复杂度、边界或容量误差，进入 `CE/CapacityFail`。若三者均不承载固定比例，则与 `||h_0||_2^2>=X^{2β-1-o(1)}` 矛盾。证毕。

## 5. Lemma C5.4：低维剩余的频率抽取

**Lemma C5.4（Low-dimensional extraction）。** 在 C5.3 中，若能量落入 `V_low`，且 `SC/LV/LSMP/CE/PI/DSO` 均未触发，则存在固定低维 CRT/Bohr 频率族 `Λ_*`、固定短弧 `I_*` 与无穷成功尺度子列，使该能量给出 `FCT_seed`。

**证明。** 对盒模板作 Fourier/Vaaler 截断，频率高度取 `H=log^A X`。若高频尾项承载固定比例能量，进入 C9 尾项或 `CE/LSMP`。否则低频有限包承载固定比例能量。若承载能量的频率包独立维数沿尺度无界，可贪心抽取新增独立包列；CRT/Bohr 坐标上的新增独立性给 martingale/square-function 能量，进入 `DSO/PI`。故在非 `DSO/PI` 分支中，存在固定维数的关系模板沿无穷子列承载主能量。若该低维模板随尺度漂移，则漂移表现为坐标新增、关系高度增长或短弧无限细化，分别进入 `DSO/PI`、`CE/LSMP` 或 `FCT/SC`。因此可抽取固定 `Λ_*`。固定低维有限相位和若无同向短弧，则长期抵消，不能承载 C5.2 的能量；由 pigeonhole 得固定短弧 `I_*` 与同向子和，即 `FCT_seed`。证毕。

## 6. Theorem C5：DGap 内部出口穷尽

**Theorem C5-DGap-Inline.** 假设 C2 的 CRT 零频基线、C9 的 Fourier/Vaaler 尾项处理、C6 的内部终端吸收和 C10 的外部定理包均可用。若过密分支中 `DGap_z>=cΔ`，则该异常必进入

`A/PI/FCT/SC/LV/LSMP/CE/DSO/NRC`

之一，或触发上述假设中的某个已编号接口失败。特别地，DGap 不产生独立的最终逃逸通道。

**证明。** C5.1 将 DGap 质量局部化到有限重叠盒族；失败已命名。C5.2 将盒相关转成非常数投影能量；常数方向由 PC2 排除。C5.3 用正交投影链把能量分配到 `PI`、低维/短簇/低体积或误差事件。C5.4 进一步处理低维剩余：尾项进入 C9，新增独立包进入 `DSO/PI`，固定低维同向相位进入 `FCT_seed`。所有出口都在合并稿事件表内，故 DGap 内部闭合。证毕。

## 7. 对无条件化清单的影响

C5 可从“待定理化”更新为“内部三接口已定理化，待依赖放电”。剩余不在 DGap 内部，而在：

1. C6：`A/PI/FCT/SC` 终端吸收的逐条证明；
2. C9：Fourier/Vaaler 尾项平方可和内联；
3. C10：`EXT-KL/EXT-Vaaler` 等正式引用；
4. C2：PC2 零频基线最终内联。
