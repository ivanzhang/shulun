# LV/LSMP/CE 主文吸收链：低体积、小质量与复杂度逃逸

本文把 RH 反例矛盾场中的三类外部出口 `LV/LSMP/CE` 合成为可并入主文的吸收链。它们来自 PPI、FCT、PI/DSO、SC、DGap 与 Fourier/Vaaler 尾项链。本文证明的目标是：这些外部出口要么被平凡体积、小质量/coarea 或模板分类吸收，要么只输出已命名 seed，不允许回流为新的 PC4 内部分支。

本文不宣称 RH 已证明；它闭合的是 `LV/LSMP/CE` 外部吸收接口。

## 1. 外部出口的角色

`LV/LSMP/CE` 不是新的结构终端，而是三类“不能继续沿当前主模板推进”的出口。

- `LV`：有效支撑体积低于主误差预算，平凡估计吸收；
- `LSMP`：质量分散到小原子、薄层或频率原子，coarea 与方向筛选吸收；
- `CE`：固定模板条件失败，按失败原因转入已命名事件。

它们不能返回自身，也不能作为最终自由吸收通道。

## 2. LV：低体积平凡吸收

设某 dyadic 块的目标主尺度为 `X`，误差预算为 `X/log^B X`。若有效支撑满足

`Vol_eff <= X/log^{B+C}X`，

且所有 dyadic、Fourier、平滑、divisor 损失至多为 `log^C X`，则平凡估计给

`Contribution <= Vol_eff log^C X <= X/log^B X`。

这就是 LV 吸收。若 LV 条件失败，说明对象并非低体积：

- 短窗或边界集中：转 `SC`；
- 小原子/薄层分散：转 `LSMP`；
- 固定投影可见：转 `PI`；
- 覆盖同步可见：转 `A`。

因此 LV 失败不能继续叫作裸 LV。

## 3. LSMP：小质量与薄层吸收

LSMP 处理小质量原子、薄层族、频率原子分散和不可控尾项。典型输入是一族薄层 `B_a`，满足有限重叠与复杂度控制，并携带同向偏移

`Σ_a σ_a Bias(B_a) >= M/log^C X`。

若这些薄层的总质量低于阈值，则由小质量吸收。若不可吸收，则只有两种输出：

1. 方向筛选/DPI 产生允许窗口偏差，输出 `PI_seed`；
2. 频率原子落入祖先短深度 span，输出 `FCT_seed`。

频率原子版本中，大局部复杂度若既无重 span，又无可控重子集，则 dyadic 层蛋糕和 maximal disjoint 选择把频率原子转成 LSMP 薄层族；若 LSMP 上界失败，仍只输出 `PI_seed` 或 `FCT_seed`。

因此 LSMP 不引用 PI/FCT 的最终闭合作为前提，只输出 seed 交给已建立的 PC4 无循环图。

## 4. CE：复杂度逃逸分类器

CE 不是数学终端，而是固定模板条件失败时的分类器。它包含四类。

1. 频率复杂度逃逸：由 `DSO-E/NRC/FCT/LSMP` 接收；
2. 尾项能量逃逸：由 Fourier/Vaaler 尾项主文链转 `LSMP` 或 `PI_seed`；
3. 旧坐标重写逃逸：转 `LV` 或 `FCT`；
4. 边界体积逃逸：转 `LV/SC/LSMP`。

若 CE 无法分类，说明原模板定义未固定，应视为文档接口缺口，而不是新的数学分支。在当前主文链中，所有 CE 出口均已落入上述四类。

## 5. 与已闭合主链的拼接

当前主文链中的外部出口按如下方式接收。

- PPI 尾项或复杂度逃逸：由本文第 3--4 节接收；
- DGap `V_err` 与尾项：由 CE/LSMP 接收；
- SC 低体积或重复薄层：由 LV/LSMP 接收；
- PI/DSO 误差吞噬、非允许投影、重叠过高：分别进入 CE、LV/LSMP、SC；
- Fourier/Vaaler 尾项失败：进入 CE/LSMP/LV/SC/FCT/DSO/PI；
- NRC 失败：不是本文出口，而是 FCT；
- CapacityFail：必须绑定到具体容量定理，已证明则矛盾，未证明则列入对应容量义务。

因此本文只处理 `LV/LSMP/CE`，其余出口由相应主文链接收。

## 6. LV/LSMP/CE 主文吸收定理

**Theorem LV-LSMP-CE-Maintext-Absorption。** 在固定复杂度模板、有限重叠、全局对数常数层级和已命名 seed 接收口径下，任何进入 `LV/LSMP/CE` 的分支都满足以下之一：

1. 被低体积平凡估计、小质量/coarea 或固定模板尾项平方可和吸收；
2. 输出 `A/PI/FCT/SC` 的 seed；
3. 输出 `DSO/NRC/CapacityFail` 中已由相应主文链接收的命名事件；
4. 暴露为文档接口缺口，而不是新的数学终端。

特别地，`LV/LSMP/CE` 不产生无标记回流，也不构成 RH 反例的独立吸收通道。

**证明。** LV 由第 2 节平凡体积估计吸收，失败转结构事件。LSMP 由第 3 节薄层 coarea、方向筛选和频率原子版本吸收，失败只输出 `PI_seed/FCT_seed`。CE 由第 4 节四分分类，每类转入已命名链条。第 5 节核查这些出口与 PPI、DGap、SC、PI/DSO、Fourier/Vaaler、NRC 和容量链一致。故无自由回流。证毕。

## 7. 对全局无条件化的影响

本文把主要外部吸收口 `LV/LSMP/CE` 主文化。当前剩余压力进一步集中到：

1. PC1 一般 Landau--Ingham 振荡输入；
2. `EXT-*` 外部定理精确引用；
3. 容量常数层级与全文符号/权重/尺度一致性审查；
4. 最终总稿把各主文链合并为单篇定理化证明。
