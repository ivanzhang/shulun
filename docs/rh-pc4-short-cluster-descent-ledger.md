# PC4-SC：短簇递归下降账本与防循环审查

本文补强 `docs/rh-pc4-short-cluster-closure-theorem.md` 中的关键审稿点：`shorter_SC` 递归为什么不能无限进行。核心是为每个短簇状态建立离散长度-体积-相位势函数；每次真正进入更短簇都必须严格下降。若势函数不降，则说明并非新的短簇，而是同一固定短簇模板反复承载偏差，必须转入 PI/A/FCT 或 LV/LSMP。

## 1. 标准短簇状态

短簇状态记为

`S=(I,𝓑,Q,R,κ,σ)`，

其中：

- `I` 是物理短窗，长度为 `L(S)`；
- `𝓑` 是 Bohr/CRT 相位切片，零频测度为 `μ(S)`；
- `Q,R` 是 AAI 正规形 `n=q_1q_2r`, `q_i~Q`, `Q^2R~X` 的 dyadic 层；
- `κ` 是有效锚复用复杂度；
- `σ` 是同相位符号与短弧类型。

规范化约定：`I` 取 dyadic 网格最小覆盖窗，`𝓑` 取不可再删除的切片交，`Q,R,κ,σ` 取固定复杂度层代表。若两个状态只有常数倍边界差异且规范代表相同，视为同一短簇模板。

## 2. 离散势函数

定义短簇势函数

`𝓥(S)=B_1 ℓ(S)+B_2 v(S)+B_3 a(S)+B_4 h(S)`，

其中：

- `ℓ(S)=ceil(log_2 L(S))` 是物理长度层；
- `v(S)=ceil(log_2( μ(S)/μ_min ))_+` 是到低体积阈值的体积层；
- `a(S)` 是尚未固定的锚/相位自由度数；
- `h(S)` 是 dyadic 层高度预算，例如 `ceil(log_2 Q)+ceil(log_2 R)` 的剩余可分裂层数。

取权重

`B_1 >> B_2 >> B_3 >> B_4 >> 1`。

在非终端假设下，LV/LSMP 未触发，所以 `μ(S)>=μ_min`；复杂度逃逸未触发，所以 `a,h` 有统一上界；长度层和体积层为非负整数。因此 `𝓥(S)` 是有下界的离散量。

## 3. shorter_SC 单步表

从 `S_t` 进入 `S_{t+1}` 的更短簇步骤只可能属于四型。

| 类型 | 真变化 | 势函数变化 | 非下降出口 |
| --- | --- | --- | --- |
| 物理缩窗 | `L` 至少跨过一个 dyadic 层下降 | `ℓ` 降低 | 若不降，则同窗重复 |
| Bohr 压缩 | 切片测度跨层下降 | `v` 降低或触发 LV/LSMP | 若不降，则切片冗余 |
| 锚自由度固定 | 可复用锚或相位自由度减少 | `a` 降低 | 若不降，则产生 PI/A 可见投影 |
| dyadic 剥离 | `Q,R` 层被剥离到更薄壳 | `h` 降低 | 若不降，则同层容量重复 |

按权重层级，任何真变化都给

`𝓥(S_{t+1}) <= 𝓥(S_t)-1`。

若四项都不真变，则 `S_{t+1}` 与 `S_t` 是同一规范短簇模板，不是新的 `shorter_SC`。

## 4. 单步下降引理

**Lemma SC-D1（短簇单步下降）。** 在排除 PI/A/FCT、LV/LSMP、CE 与局部乘积容量违反的非终端假设下，任何真正的 `shorter_SC` 步满足

`𝓥(S_{t+1}) <= 𝓥(S_t)-1`。

**证明。** 若下一层短簇来自物理缩窗，则规范 dyadic 覆盖长度下降，`ℓ` 降低；否则不是更短物理窗。若来自 Bohr/CRT 切片压缩，则测度跨过一个 dyadic 体积层，`v` 降低；若低于阈值，则 LV/LSMP 触发。若来自锚复用关系固定，则自由度 `a` 降低；若自由度不降而仍产生同向偏差，则该偏差在固定投影或 ACC 容量账本中可见，转入 PI/A。若来自 dyadic 层剥离，则 `h` 降低；若同层重复过密，则由 SC-LD1 的局部乘积容量界或 PI/A/FCT 分支处理。四种情况穷尽短簇递归来源，故势函数至少下降 `1`。证毕。

## 5. 同一短簇模板重复的出口

**Lemma SC-D2（重复短簇模板出口）。** 若同一规范短簇状态 `S` 在无穷多尺度上反复同向承载离线零点级偏差，则至少触发一项：

1. PC4-PI 高投影增量；
2. PC4-A 覆盖/ACC 同步过剩；
3. PC4-FCT 低维相位闭包；
4. LV/LSMP 低体积或可求和尾层；
5. 局部乘积容量界 SC-LD1 被违反。

**证明。** 固定 `S` 给固定短窗、固定 Bohr 切片、固定 dyadic 层与固定锚复用模板。若偏差在允许 σ-代数中可检测，则它是 PC4-PI 投影增量；若表现为覆盖容量的同向增益，则是 PC4-A；若只依赖低维相位关系，则是 PC4-FCT。若零频体积可求和或集中到低层，则由 LV/LSMP 吸收。若以上均否，则剩余只能是在同一 `Q,R` 层同一短窗内超过 AAI 正规形给出的局部乘积容量，这正是 SC-LD1 的违反。证毕。

## 6. 短簇递归终止定理

**Theorem SC-Descent-Termination。** 在排除 PI/A/FCT、LV/LSMP、CE 且接受 AAI+SC-LD1 局部乘积容量界的非终端假设下，不存在无限 `shorter_SC` 递归链。

**证明。** 对任意无限 `shorter_SC` 链取规范状态序列 `S_0,S_1,...`。若无限多步是真正更短簇，由 SC-D1，离散势函数 `𝓥` 无限严格下降，违背其下界。若只有有限多步真正下降，则从某时刻起规范短簇模板重复；由 SC-D2 触发 PI/A/FCT、LV/LSMP 或容量违反，均被非终端假设排除。因此无限短簇递归链不存在。证毕。

## 7. 接入 PC4-SC

本文把 `docs/rh-pc4-short-cluster-closure-theorem.md` 中的递归终止段落替换为可审查的三步：

`标准短簇状态 -> 离散势函数 -> 真递归下降/重复模板出口`。

因此 PC4-SC 的剩余口径不再是“直观上长度会下降”，而是明确引用 `SC-Descent-Termination`。
