# 近乎完美匹配障碍：锚图像谱与粗候选骨架谱

**状态：** Q_eff 下一硬点；从 gap 谱投影寻找近乎完美匹配矛盾。

## 1. 对象

粗候选集合 `R` 是小筛 CRT 骨架；锚命中集合 `A` 是有非空锚列表的粗候选点。列反例要求

`A=R`。

真实数据中 `A` 是 `R` 的子集，缺失点正是素数。

## 2. 扫描结果

新增脚本：`experiments/near_perfect_matching_spectrum_scan.py`。

实验显示：

- `R` 的 gap 谱高度规则，主要由 `2,4,6,10,12,...` 等小筛轮间隔组成；
- `A` 的 gap 谱继承部分小筛结构，但数量显著减少；
- `R` 在 `sqrt(P)` 阈值下几乎全连通；
- `A` 也多为短 gap，但密度打折；
- 缺失点分布穿插在整个粗候选骨架中，不是单个边界效应。

## 3. 近乎完美匹配假设

若列反例成立，则 `A=R`。这意味着每个小筛骨架点都被某个锚素数图像命中。

锚素数 `q` 的图像为一个长步长等差序列：

`r_q, r_q+q, r_q+2q, ...`。

因为 `q>sqrt(P)`，每条图像在局部小筛轮间隔尺度上非常稀疏。

要使这些稀疏长步长图像并成 `R` 的高密短 gap 骨架，必须大量不同锚图像交错，每个短 gap 都由不同锚颜色接力。

这正是受限列表着色的谱版本。

## 4. 谱缺口不等式目标

令 `G_R(h)` 为粗候选 gap 计数，`G_A(h)` 为锚命中点 gap 计数。真实系统中 `G_A` 是 `G_R` 的削弱版。

列反例要求

`G_A(h)=G_R(h)` 对所有 gap h。

但每条锚图像内部 gap 至少 `q>sqrt(P)`，所以所有小 gap `h<sqrt(P)` 都只能来自不同锚图像之间的交错，而不是同一锚复用。

因此小 gap 计数需要消耗锚图像交错复杂度。候选不等式：

`Σ_{h<sqrt(P)} G_R(h) <= Cross(Q_eff)`。

其中 `Cross(Q_eff)` 是 `Q_eff` 条长步长同余图像在 `[0,P)` 中可产生的小 gap 交错的最大数量。

若能证明

`Cross(Q_eff) < Σ_{h<sqrt(P)}G_R(h)`

则列反例矛盾。

## 5. Cross 上界的刚性

两条锚图像 `q_1,q_2` 产生相邻小 gap，需要存在行号

`k_1≡r_{q_1} mod q_1`, `k_2≡r_{q_2} mod q_2`, `|k_1-k_2|<sqrt(P)`。

这等价于一个二模 CRT 近碰撞：

`r_{q_1}+a q_1 - r_{q_2}-b q_2 = h`, `|h|<sqrt(P)`。

每个近碰撞消耗一对锚坐标。若同一对坐标产生多次近碰撞，则差分给出

`a' q_1-b' q_2 = h'`

的小值关系，迫使 `q_1/q_2` 有短有理逼近。对素数锚集合，这种重复近碰撞应有限。

因此 `Cross(Q_eff)` 应近似线性而非二次。

## 6. 下一步硬攻引理 Cross-linear

**Cross-linear.** 对来自同一列 `c` 的有效锚图像族，长度 `<sqrt(P)` 的相邻交错数满足

`Cross(Q_eff) <= C Q_eff`。

若成立，则列反例要求

`N-1 = Σ_{h<sqrt(P)}G_R(h) <= C Q_eff`。

结合 `Q_eff <= (1-η)N` 或更弱常数，可尝试矛盾；即使不能单独矛盾，也能与二阶复用能量合并。

## 7. 目前边界

Cross-linear 尚未证明；它是对锚图像近碰撞的核心几何数论问题。但它比原始列命题更深入内部：只讨论大因子斜线图像之间能产生多少短 gap 交错。

下一步实验应直接统计锚图像近碰撞对的复用次数，寻找 `Cross` 线性上界的证据。

## 8. Cross-linear 扫描推进

已新增：`docs/anchor-cross-linear-hard-attack.md` 与 `experiments/anchor_cross_collision_scan.py`。

扫描显示同一锚对的近碰撞复用次数极低，`max_pair_reuse` 通常 `3--4`，且 `distinct_pairs≈cross_events`。这支持 Cross-linear。下一步需证明 `Anchor-neighborhood sparsity`：每个锚图像的 `sqrt(P)` 邻域只吸引有界数量的其它有效锚图像。
