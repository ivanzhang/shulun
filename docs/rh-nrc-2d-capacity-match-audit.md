# NRC-2D Capacity-Match 容量门槛审查

本文专攻 `NRC-2D` 剩余的 `Capacity-Match`。结论必须谨慎：从低秩一维 NRC 乘积得到的二维上界是

`|S_2| <= P log^C X`，

所以要推出相对小偏差，确实需要局部容量

`V_Q >= P log^{B+C}X`。

但反方向 `V_Q<Plog^{B+C}X` **不能自动等于** 全局 `LV=o(Δ)`，因为 `P` 可能与 `X` 同阶，而 `Δ=X^{β-o(1)}` 只有 `β>1/2`。因此 Capacity-Match 的严格版本必须是三分，而不是简单“容量不足即 LV”。

## 1. 高容量分支已经闭合

由 `docs/rh-ppi-rank-finite-separation-lemma.md`，二维权重有分离秩 `L<=log^C X`，故

`|S_2| <= L C_0^2 P log^{2A}X + Err <= P log^{C_1}X+Err`。

若

`V_Q >= P log^{B+C_1+2}X`, `Err<=V_Q/log^{B+1}X`,

则

`|S_2| <= V_Q/log^B X`。

所以高容量二维 NRC 包不能承载固定比例 PPI 偏差。该分支无剩余障碍。

## 2. 低容量分支的真实困难

若

`V_Q < P log^{B+C_1+2}X`，

则低秩 NRC 上界不再相对小。但这只说明“平方根乘积法不够强”，并不说明该层一定全局可忽略。要把它转出 NRC，需要额外证明二者之一：

1. **相对异常低体积：** `V_Q log^{C_V}X <= Δ/log^{B_LV}X`，于是进入 `GEE-LV`；
2. **小质量/薄层结构：** 虽然 `V_Q` 可能大于 `Δ/log^B`，但该容量被压在少数 `r`、少数相位原子或少数短簇上，进入 `LSMP/SC/PI/CE`。

没有这一步，不能把 `NRC-2D` 宣称闭合。

## 3. 可证的安全分流定理

**Theorem Capacity-Match-Safe.** 在 PPI 双锚主层、固定模板深度窗口和 `PPI-Rank` 成立的假设下，任一二维加性分离 NRC 包满足以下之一：

1. **高容量相对小：** `V_Q >= P log^{B+C}X`，则 `|S_2|<=V_Q/log^B X`；
2. **全局低体积：** `V_Q log^{C_V}X <= Δ/log^{B_LV}X`，则该包进入 `GEE-LV`，总负担为 `o(Δ)`；
3. **中间容量层：**

   `Δ/log^{B_LV+C_V}X < V_Q < P log^{B+C}X`。

   该层不能由当前 NRC/LV 直接吸收，必须触发新的结构证书：`LSMP/SC/PI/CE`，或另行证明更强的二维相消。

**证明。** 第 1 项由低秩一维 NRC 乘积上界与容量比较得到。第 2 项正是 GEE-LV 的相对主异常定义。剩余即为第 3 项。证毕。

该定理是审稿安全的：它不把中间容量层偷换为 LV。

## 4. 中间容量层的结构含义

中间层同时满足：

`V_Q > Δ/log^A X`, `V_Q < P log^D X`。

它很窄但危险。其含义是：局部容量足以承载离线零点异常的一部分，却又小到无法压过 `P` 级二维低秩 NRC 背景。若这样的层长期存在，必须出现以下结构之一：

- **薄尾因子：** `r` 的有效选择数少，进入 `LSMP/LV`；
- **短簇集中：** 许多质量落在少数 `q_1q_2r` 窗口，进入 `SC`；
- **投影集中：** 相位原子数量少但偏差反复出现，进入 `PI`；
- **复杂度集中：** 需要超固定模板深度才能描述，进入 `CE`。

因此中间容量层是下一步真正硬点，不是 NRC 解析估计硬点。

## 5. 更强闭合所需的新引理

要完全闭合 `Capacity-Match`，需要证明：

**Lemma MidCap-Structure.** 若中间容量层

`Δ/log^A X < V_Q < P log^D X`

承载固定比例 PPI 可检测偏差，则必触发 `LSMP/SC/PI/CE`。

这比原来的 Capacity-Match 更精确，也更可能可证。证明方向应从 `Q^2R~X` 与相位原子数出发：若总容量接近 `Δ` 但小于 `P` 级背景阈值，则自由度被压缩在少数尾因子或少数相位盒中；这种压缩正是 `LSMP/SC/PI/CE` 的定义性结构。

## 6. 当前状态

`NRC-2D` 已完成：

- `PPI-Rank`：有限分离秩；
- 高容量分支：相对小偏差；
- 全局低体积分支：转 `GEE-LV`。

剩余唯一硬点进一步精确为：

`MidCap-Structure`：中间容量层必须触发 `LSMP/SC/PI/CE`，否则 `NRC-2D` 尚不能无条件闭合。
