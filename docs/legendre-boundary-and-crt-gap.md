# 目标命题的强度边界与 CRT 缺口校准

**状态：** `proof_route_must_not_hide_legendre_level_input`

本命题的行版本包含一个非常强的素数分布断言。第 `r` 行是区间

`[(r-1)P+1, rP]`

长度为 `P`，而该区间上端约为 `X≈rP<=P^2`。因此行命题等价于要求在许多长度约 `sqrt(X)` 的区间中存在素数。这与 Legendre 型问题处于同一尺度。

这并不说明几何/CRT 路线无效，但说明：任何声称证明“每行都有素数”的路线，必须真正使用方阵/圆柱/CRT 刚性带来的额外结构，不能只依赖普通筛计数。否则就会等价地偷渡一个当前经典解析数论中非常困难的短区间素数断言。

## 1. 为什么单纯增长缺口不够

小筛后洞数约为

`P Π_{q<=sqrt(P)}(1-1/q) ≈ P/log P`。

但要证明其中至少一个为素数，本质上要证明这些洞不全是含有 `>sqrt(P)` 大因子的合数。普通筛法只给出候选数量，不能排除全部候选为合数。

因此“large_patch < small_holes”若要严格成立，必须引入额外刚性：

- 大因子互斥；
- 同余相位链；
- CRT 周期复现矛盾；
- 或方阵行列双向约束。

## 2. 当前 CRT 路线的真实缺口

我们已经有直觉：若全行被覆盖，覆盖态沿圆柱推进可能诱导短复现；短复现会要求许多互素模数同时约束 `k`，产生矛盾。

但严格证明仍缺一个关键桥：

> 从“一行全覆盖”推出“存在短步长 `k<P` 的覆盖复现或相位链闭合”。

没有这个桥，CRT 周期为 `M=Π_{q<P}q` 本身允许覆盖图案只在巨大周期后复现；这不矛盾。

因此下一步不能直接说“全覆盖导致短周期”；必须证明一个几何动力引理：

> 全行覆盖态在宽度 `P` 的圆柱上，由斜率固定和列宽有限性强迫产生短相位回归。

## 3. 可攻的桥接引理

### 引理 C：相位压缩/鸽巢回归

设第 `r` 行全覆盖。对覆盖每列的某个根基素数选择一个代表 `q(c)`。向下推进 `t` 行后，其覆盖列变为

`c - tP mod q(c)`。

由于列窗口只有 `P` 个位置，而参与大因子集合有许多模数，若在 `1<=t<P` 内存在一个 `t` 使代表覆盖列集合整体仍覆盖 `1..P`，则得到短复现。

难点：必须证明这样的 `t` 存在，而不是假设存在。

### 引理 D：行列双向闭锁

若某一行全覆盖，同时每列也被同一斜线系统限制，则全覆盖行的覆盖选择不能任意漂移。行覆盖与列覆盖叠加可能强迫一个有限相位回路，从而产生短周期。

这可能比单行动力更有希望，因为目标命题同时要求行和列；反例行/反例列在同一方阵内会互相制约。

### 引理 E：满补链不能无回归穿越宽度 P

把全行补洞视为从左到右的一条大因子标签链 `q(c)`。相邻洞距离小于 `sqrt(P)` 时标签不能相同。若链长度约 `P/logP`，标签变化产生大量互素模数。需要证明在圆柱宽度 `P` 内，这样的标签链必存在一个短相位回归。

## 4. 下一步实验应测什么

不要再只测补洞比例，而要测反例假设下的“相位回归压力”：

1. 对每行的小筛洞，记录其大因子标签 `q(c)`；
2. 对 `1<=t<P`，计算标签推进后的列集合覆盖率；
3. 找最大覆盖率和是否出现短复现；
4. 计算若要短复现，需要同时稳定的标签集合及其模数乘积。

如果实验显示高覆盖行总有很强短回归压力，才有希望升级为 CRT 引理。

## 5. 诚实结论

当前最关键缺口不是“数值常数”而是：

> 全覆盖假设如何严格推出短 CRT 周期或短相位回归。

下一步应集中攻这个桥接引理，而不是继续找有限模板或单纯筛估计。
