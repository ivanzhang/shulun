# PC4-FCT：Noether 闭包链终止命题

本文接续 `docs/rh-pc4-fct-phase-drift.md`。相位漂移压力引理把固定低维 FCT 编码的长期成功压成三种结果：零频不足、平方能量压力、或新的低维同步证书。本文处理第三种：证明 FCT 闭包证书链不能无限递归；若不严格降维或耗散，则同一低维 Bohr 交集反复承载偏差，从而转入 PC4-PI 或短簇。

## 1. FCT 闭包状态

定义一个 FCT 闭包状态为三元组

`S=(Ξ,H,𝓑)`,

其中：

- `Ξ={ξ_1,...,ξ_d}` 是低维频率基；
- `H` 是整数 span 高度；
- `𝓑` 是由 `Ξ` 生成的 Bohr/倒数相位切片族。

复杂度记为

`C(S)=d + logH + depth(𝓑)`。

若新的同步证书 `ξ_new=Σ_i m_iξ_i` 不增加 span 维数，只细化 `𝓑` 或降低可用相位自由度，称为闭包细化；若它减少有效基维或把某个自由相位固定到短弧，称为降维闭包。

## 2. Noether 预算

定义剩余秩-体积预算

`N(S)=d_free + A log(μ(𝓑)/μ_min) - B depth(𝓑)`。

这里 `d_free` 是尚未被闭包证书固定的有效自由频率维数，`μ(𝓑)` 是 Bohr 交集在当前 CRT 层的零频测度，`μ_min` 是低体积终端阈值，`A,B` 为固定大常数。只要没有进入 LV/LSMP/短簇，就有 `μ(𝓑)>=μ_min`，所以 `N(S)` 有下界。直观上：

- 新独立频率会增加自由度，但这不是 FCT，而是 NRC/DSO 分支；
- FCT 碰撞不增加自由度，只能固定自由相位、加深 Bohr 条件或重复旧关系；
- 若不断细化而不触发终端，则 `μ(𝓑)` 下降，剩余体积预算减少；到 `μ_min` 以下即转入短簇/LV/LSMP；
- 若不细化，则同一 `𝓑` 反复承载偏差，触发 PC4-PI。

## 3. 单步 Noether 二分

**Lemma FCT-N1（单步闭包二分）。** 给定 FCT 状态 `S_t` 与下一同步证书。若该证书不触发 PC4-PI、短簇、LSMP 或 LV，则产生新状态 `S_{t+1}`，并满足二者之一：

1. 剩余预算严格下降：`N(S_{t+1}) <= N(S_t)-c`；
2. `S_{t+1}` 与 `S_t` 在同一 Bohr 交集上等价，且该交集再次承载同向偏差。

**证明。** 新证书若固定一个相位自由度，则 `d_free` 下降，预算下降。若证书细化 Bohr 条件但仍未进入低体积终端，则 `μ(𝓑)` 下降而 `log(μ(𝓑)/μ_min)` 减小，预算下降。若证书只重复旧关系，则 Bohr 交集等价不变；若它仍能吸收离线偏差，则同一交集再次承载同向偏差。若测度下降到 `μ_min` 以下，则进入短簇/LV/LSMP，已被本引理假设排除。证毕。

## 4. 等价状态反复推出投影增量

**Lemma FCT-N2（等价闭包反复到 PI/短簇）。** 若同一 FCT 状态 `S` 在无穷多尺度上等价出现，并且对应 Bohr 交集 `𝓑` 反复承载同向离线偏差，则触发以下至少一项：

1. `PC4-PI` 高投影增量；
2. 短簇或低体积集中；
3. DSO/CE 容量矛盾。

**证明。** 同一 `𝓑` 反复承载同向偏差，按固定模板抽取可视为一个投影窗口族。若零频测度不可求和，PI-Seed 给平方能量发散，PI-Cap/Dense closure 给容量上界，触发 PC4-PI 矛盾。若零频测度可求和或集中在低体积集合，转入短簇、LV 或 LSMP。若偏差分散到新增坐标，则由 DSO-E/CE 容量控制。证毕。

## 5. FCT-Noether 主命题

**Proposition FCT-Noether（FCT 闭包链终止，条件化）。** 在排除 PC4-PI、短簇、LSMP、LV 与 DSO/CE 容量失败的非终端假设下，FCT 闭包证书链不可能无限延续。

**证明。** 对闭包链 `S_0,S_1,...` 应用 FCT-N1。若无限多步属于预算下降情形，则 `N(S_t)` 严格下降；但在排除低体积终端时 `N(S_t)` 有统一下界，不可能无限。若从某时刻起不再下降，则存在等价状态反复出现；由 FCT-N2 触发 PC4-PI、短簇或容量矛盾，违背非终端假设。故无限 FCT 闭包链不存在。证毕。
