# `Y≈√L` 筛-补洞常数缺口模型

## 1. 链级模型

固定素数 `P`、列 `c`、固定小模 `δ=30` 的允许残基 `r`，考虑链：

`N_n = A + 30Pn,  A=c+rP,  0≤n≤L`。

取：

`L = floor(C log²P / 30)`,

`Y ≈ √L`。

定义：

`U_Y={n≤L : N_n 不被任何素数 q≤Y 整除}`。

定义有效补洞集合：

`B_Y={n_q≤L : q>Y, qh=A+30Pn_q, h≥q, P^-(h)≥q}`。

若前 `L` 项全合数，则每个 `n∈U_Y` 必须由某个有效最小因子 `q>Y` 补洞，因此必须有：

`U_Y ⊂ B_Y`，特别是 `|U_Y|≤|B_Y|`。

所以只要证明：

`|U_Y|>|B_Y|`

就得到矛盾，链中必有素数。

## 2. 小筛剩余 `U_Y` 的主量

每个素数 `q≤Y` 在链坐标中删去一个固定残基类：

`q | A+30Pn ⇔ n≡r_q mod q`。

因此一维小筛给出：

`|U_Y| ≈ L ∏_{7≤q≤Y}(1-1/q)`。

由 Mertens 公式：

`|U_Y| ≈ C_30 · L/logY`。

这里 `C_30` 是冻结 `2,3,5` 后的局部常数。

## 3. 有效补洞 `B_Y` 的主量

若 `q>Y` 命中链，则命中密度约为 `1/q`。但要成为有效最小层补洞，还要求协因子 `h` 满足：

`h≥q`, `P^-(h)≥q`。

这给出额外粗性密度，约为：

`≈ e^{-γ}/logq`

相对于普通命中产生一个约 `e^{-γ}` 的常数损失。

因此预期：

`|B_Y| ≈ e^{-γ}|U_Y|`。

数值实验中 `B_Y/U_Y` 的中位数稳定在 `0.54~0.58`，接近：

`e^{-γ}=0.561459...`

## 4. 新的核心引理

**√L 筛-补洞常数缺口引理。**

存在常数 `c_1>c_2>0`，使得对充分大素数 `P`、所有非平凡列 `c`、所有 `δ=30` 允许残基 `r`，有：

`|U_Y| ≥ c_1 L/logY`,

`|B_Y| ≤ c_2 L/logY`,

其中 `Y≈√L`。

则 `|U_Y|>|B_Y|`，所以链中存在素数。

## 5. 与先前困难的区别

此前倒数 Buchstab 估计需要在 `K/logP` 的素数主项尺度上控制误差。

现在只需证明常数级差距：

`B_Y/U_Y ≤ θ < 1`。

数值显示可以取 `θ≈0.75` 仍非常保守。

这把核心难点从“素数主项级精度”降低为“筛常数差距”。

## 6. 当前未证点

关键仍是严格证明有效补洞上界中的常数 `c_2` 小于小筛下界常数 `c_1`。

粗糙上界筛可能常数不足；需要保留协因子 `q`-粗性的 Mertens/Buchstab 常数，证明其带来不可消除的 `e^{-γ}` 损失。
