# D4/R5 全局路线修正：从有限模板覆盖转向递归剥离

## 核心修正

有限模板覆盖所有尺度并不合理。对数 `X` 的素性由所有 `q<=sqrt(X)` 的非零同余约束共同决定；当 `X` 增大时，约束素数集合增大，模板复杂度不会在绝对意义上稳定为一个固定有限集。

因此，全局证明不应要求“所有尺度都落入同一个有限模板库”，而应寻找递归不变量：当尺度从 `X` 推到更大尺度时，新出现的素数约束可以作为新壳层加入；若出现全覆盖/坏候选，则通过剥离最高壳层，把坏结构投影回较小尺度，或者产生可累积的能量缺陷。

## 新目标：递归剥离闭合

设 `S(X)` 为由 `q<=sqrt(X)` 的非零同余约束定义的候选集合。把约束按壳层分解：

```text
S(X) = S(Y) ∩ New(Y,X),     Y < X, typically Y≈sqrt(X) or dyadic predecessor.
```

目标不是枚举 `S(X)` 的所有模板，而是证明一个递归二择：

1. **剥离回传**：若 `S(X)` 中存在 R5 坏单元，则去掉最高新壳层后，在 `S(Y)` 中产生同类坏单元，且坏度不显著降低；
2. **能量耗散**：若不能回传，则新壳层贡献一个正的能量缺陷 `D(Y,X)>0`，这些缺陷沿尺度递推累积，最终超过可用资源上界。

## 递归变量

建议使用三类变量，而不是绝对模板：

- `M_j`: 第 `j` 层壳的候选质量；
- `E_j`: 第 `j` 层壳的二次能量；
- `D_j = E_j - M_j^2/C`: 相对 Cauchy 阈值的缺陷；
- `B_j`: 边界/相位漂移误差；
- `R_j`: 新壳层和旧候选集合之间的相关残差。

目标递推形态：

```text
D_{j+1} >= (1+eta_j) D_j - B_j - R_j
```

或者在坏单元存在时：

```text
Bad(X_{j+1}) => Bad(X_j) with controlled loss
```

若 `sum eta_j` 发散或 `sum(B_j+R_j)` 可控，则无限尺度坏结构不可能存在。

## 与现有 R5 证书的关系

当前 H80 / finite-window / outward interval 证书不是废弃，而成为递归的局部转移基块：

- 它证明在一个典型危险窗口内，固定成员层泛函没有隐藏内部极值；
- 它给出局部转移中的最小正余量；
- 多窗口模板探针表明极值坏结构集中在少数壳层形态，适合用作递归转移的局部模型。

## 下一硬引理

**递归剥离引理 RPL（Recursive Peeling Lemma）**

给定尺度 `X` 与前一尺度 `Y`，令新壳层为 `sqrt(Y)<q<=sqrt(X)` 的约束。若在 `X` 的 R5 层泛函中存在坏单元（例如违反 `R5global1--4` 的候选极值），则至少发生以下之一：

1. 坏单元在剥离新壳层后投影为 `Y` 上的坏单元，且坏度损失 `<= epsilon_j`；
2. 新壳层与旧候选集合之间产生能量缺陷 `D_j >= c_j`；
3. 坏单元被压缩到有限危险窗口，可由当前外向舍入局部证书排除。

若能证明 `sum c_j` 大于总资源上限，而 `sum epsilon_j` 可吸收，则全局坏单元不存在。
