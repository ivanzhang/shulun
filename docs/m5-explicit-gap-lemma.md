# Lemma M5 覆盖缺口显式化附录

本附录补强 `docs/ab-to-d-interface-match.md` 的 Lemma M5：把“全覆盖迫出一阶偏差”改写为显式覆盖缺口不等式。

## 1. 记号

令 `X` 为 A/B 剥离后剩余的 `D`-粗候选集合，`r=|X|` 或加权总量 `r=sum_X w(x)`。令主体锚窗口族为 `𝓦`，覆盖函数

`C(x)=sum_{W in 𝓦} α_W 1_W(x)`, `0<=α_W<=1`。

全覆盖要求

`C(x)>=1` 对所有 `x in X`，故 `sum_X w(x)C(x)>=r`。

设几何零频基线为

`B_0=sum_{W in 𝓦} α_W μ_geo(W)`。

定义覆盖缺口

`Gap = r-B_0`。

坏配置的主体容量条件要求存在固定 `γ>0` 使

`Gap >= γ r/log^2P`。

该条件正是 A/B 剥离小因子、尾部锚和 45 度锁定后，主体双粗锚仍需超过 CRT 均衡基线来完成全覆盖的数量化表述。

## 2. Fourier 展开上界

**Lemma M5.1（覆盖函数截断）。** 对每个 `W in 𝓦`，取高度 `H` 的 Vaaler 展开。则

`sum_X w(x)C(x) = B_0 + Σ_{0<|ξ|<=H} β_ξ S(ξ) + E_H`,

其中 `S(ξ)=sum_X w(x)e(ξφ(x))`，并有

`Σ_{0<|ξ|<=H}|β_ξ| <= C log^A P`, `|E_H|<=C r/H`。

**证明。** 对每个窗口指标应用 `EXT-Vaaler`。零频项求和为 `B_0`。非零频项按相同频率合并得系数 `β_ξ`。窗口族复杂度与有限重叠给 `l^1` 系数和 `<=Clog^AP`。截断误差逐窗口求和并由有限重叠控制为 `Cr/H`。证毕。

## 3. 小一阶偏差导致覆盖不足

**Lemma M5.2（小 Fourier 偏差上界）。** 若对所有允许频率 `0<|ξ|<=H` 有 `|S(ξ)|<Λr/log^A P`，且 NRC/FCT 误差满足

`Err_NRC <= γr/(4log^2P)`, `Cr/H <= γr/(4log^2P)`,

则

`sum_X w(x)C(x) <= B_0 + γr/(2log^2P)`。

**证明。** 由 Lemma M5.1，非零频总贡献至多

`Σ|β_ξ||S(ξ)| <= Clog^AP * Λr/log^AP`。

选择常数包中的 `Λ` 使该项 `<=γr/(4log^2P)`；NRC/FCT 非共振误差由假设给 `<=γr/(4log^2P)`，截断误差也由 `H` 选择吸收。合并即得。证毕。

## 4. 显式缺口矛盾

**Theorem M5+（显式覆盖缺口版 M5）。** 若 A/B 反例诱导的最小坏配置满足主体覆盖缺口

`Gap=r-B_0>=γr/log^2P`，且常数包保证 Lemma M5.2 的三项误差各不超过 `γr/(4log^2P)`，则必存在允许频率 `ξ` 使

`|S(ξ)| >= Λr/log^A P`。

按 D 组归一化，把 `Λ/log^A P` 重命名为当前节点偏差参数，得到 D 标准形式的一阶偏差条件。

**证明。** 若所有允许频率都小于阈值，Lemma M5.2 给

`sum_X wC <= B_0+γr/(2log^2P)`。

但全覆盖要求 `sum_X wC>=r=B_0+Gap>=B_0+γr/log^2P`，矛盾。故存在一阶偏差频率。证毕。

## 5. 接入说明

本附录把原 Lemma M5 的核心义务压缩为一个显式主体覆盖缺口 `Gap>=γr/log^2P`。该缺口来自 CRT 非零类均衡基线、Tail-log4 尾部削除和主体锚容量上界；在最终主链中由常数吸收表的 `A_star=2` 与 `tail_error_power=4` 保证有余量。
