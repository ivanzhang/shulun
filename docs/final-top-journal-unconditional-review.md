# 顶刊无条件证明标准最终复核判定

本报告对当前归档审稿包作最后一次“顶级数学期刊无条件证明”标准复核。结论必须区分两件事：

1. 仓库是否形成了完整的条件化审稿包、正式附录、引用表、常数表和有限验证证书；
2. 这些材料是否已经达到顶刊可直接接受的无条件逐行证明标准。

## 1. 总判定

**严格判定：当前稿件尚不能诚实表述为“已经达到顶刊无条件证明标准”。**

当前稿件已经远强于早期探索稿：A/B/C/D 均已附录化，A/B 到 D 的接口已经补表，EXT 引用和常数吸收也已归档。但按顶刊审稿标准，仍存在若干“证明草图/接口假设/外部定理适配”性质的义务，不能简单用“已归档”替代逐行证明或精确引用适配。

因此最终可审稿口径应为：

> 当前仓库形成了完整的条件化证明主链与审稿包；若 D 组结构附录中的若干压缩步骤、Tail-log4 中 BG/RKS 输入的精确适配、以及常数吸收表对应的不等式逐行展开均被审稿接受，则两段覆盖推出全部奇素数成立。

不能表述为：

> 本文已经无需额外审查义务而达到顶级数学期刊无条件证明。

## 3. 未达到顶刊无条件标准的核心原因

### 3.1 D 组仍有压缩证明步骤

`docs/d-structure-formal-appendix.md` 已给出 OMR、CGTP、LSMP、FCT 的定理化版本，但其中若干关键步骤仍是高度压缩的数学论证，例如：

- OMR 中“若所有窗口无密度增量，则偏差只能由几何测度误差解释”；
- CGTP 中从一阶投影增量到平方能量增量的常数级转换；
- LSMP 中从小质量能量到同向薄层偏移的方向筛选；
- FCT 中 `log^8K` span 计数对所有递推路径的统一吸收。

这些步骤有清晰证明路线，但顶刊无条件证明需要逐行定义所有窗口族、测度、投影、父子块、停止时刻，并逐项证明常数不丢失。

### 3.2 Tail-log4 的 BG/RKS 输入仍需精确适配

`EXT-BG` 已有引用来源，但当前稿件仍把 Bourgain--Garaev/Baker 输入概括为“固定对数节省”。顶刊审稿会要求：

- 明确 BG 定理的变量范围、区间长度、系数条件；
- 逐项匹配本文 RKS 分区中的每个 Type I/II 块；
- 对未被 Baker prime-variable 显式定理覆盖的多线性区间，给出 BG 原定理的准确编号和条件检查。

### 3.3 常数吸收表是账本，不是逐项证明

`docs/constants-absorption-final-audit.md` 已说明 `32<128`、`tail_error_power=4>A_star=2` 等余量，但顶刊标准还需要把每个 `log^8K`、`log^16K`、`Λ^4` 损失如何进入抽取器不等式逐项写成编号不等式。

### 3.4 A/B 到 D 的一阶偏差引理仍需展开

`docs/ab-to-d-interface-match.md` 的 Lemma M5 是核心桥梁。当前证明使用 Vaaler/Fourier 截断、NRC/FCT 分支和覆盖缺口吸收，但未逐项写出：

- 覆盖缺口的精确定义；
- 零频 CRT 基线与全覆盖需求之间的严格差值；
- `Λ` 与常数包之间的显式关系。

这是从“结构性归约”升级为“顶刊逐行证明”的关键剩余。
