# 扩展矛盾场后续义务清单

**状态：** 当前必须持续关注的刚性接口。

## 1. 已新增进入方程组的变量

1. **周期密度场** `A(r)=|H_P(r-1)|`：负责 CRT 周期与镜像。
2. **列缺陷流** `D_c(I)`：负责列均衡守恒。
3. **镜像列配对场**：负责 `c <-> P-c` 的同步约束。
4. **局部标签场** `L_x(c)`：负责相邻互质、短差大标签不可复用。
5. **层叠壳场** `S_j(x)`：负责小素数逐层衰减。

## 2. 当前应优先证明的三条接口

### E1：小壳迁移释放 + 列缺陷流

若 `x->y` 改变小素数壳签名并补掉旧核，则释放列集合 `H_P(y)\H_P(x)` 非空。

增强目标：释放列集合不能被镜像列配对与列均衡自由吸收，必须形成可检测缺陷流。

### E2：短差标签互异 + CRT 同步

短差核若由大标签补洞，则大标签必须互异。互异标签的同余系统模数乘积迅速增大，前窗口代表稀缺；若代表存在，标签重排释放新洞。

### E3：周期镜像 + 前窗口零行排斥

若前窗口有零行，则周期末端镜像也有零行。列均衡要求中段补偿。需证明层叠场允许的迁移/释放模式无法产生这种精确补偿。

## 3. 不应遗忘的审查边界

- CRT 周期内可以存在零行；只能排除“前窗口零行”。
- 原始覆盖容量可能超过行宽；必须扣除重叠能量与 CRT 同步损耗。
- 有限小素数不能控制无限结构；它们只提供层叠剥离的前缀壳。
- 行命题和列命题尚未统一，列命题需要列壳/缺陷流对偶化。

## 4. 下一步最小可执行任务

继续攻 E1：对小壳迁移 `x->y`，建立释放列集合的结构方程：

`Release_B(x,y)=S_B(y)\S_B(x)`，

并分析其中被剩余素数层覆盖的比例与强制重叠。目标是证明在补掉旧核时：

`Release_B(x,y) \ U_{>B}(y) nonempty`。

这就是 LD-2 的精确集合形式。
