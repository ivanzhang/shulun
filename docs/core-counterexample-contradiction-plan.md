# 面向目标命题的核心反例矛盾构建计划

**状态：** 下一阶段攻坚蓝图。

## 1. 反例的最小形式

行命题反例：存在奇素数 `P` 与 `1<=x<P`，使

`H_P(x)=empty`。

也就是说第 `x+1` 行除第 `P` 列外所有列都被根基素数 `<P` 的斜线覆盖。

在层叠场中，这等价于对每个素数前缀层 `j`：

`|S_j(x)|=C_j(x)-E_j(x)`。

因此反例必须是一个全层零场解。

## 2. 核心矛盾聚焦

把反例分成两类：

### A 类：小壳签名发生迁移

存在小素数前缀 `B_z` 与某个比较相位 `y<P`，通过改变 `a_p(x)` 的小模数禁余类补掉旧核。

要证：小壳迁移必释放新候选点，且这些新候选点不能被剩余层全部覆盖。

对应硬点：LD-2。

### B 类：小壳签名保持，靠中大层补完

小素数壳不变或变化不足以解释补洞，最终需要中大素数同步覆盖残余核。

要证：若残余核含短差，则大层同步产生 CRT 跨窗或释放；若无短差，则进入镜像/列均衡缺陷。

对应硬点：LD-1 与无短差核。

## 3. 数量级差异的精确表达

原始斜线数随 `P/log P` 增长，看似很多；但有效覆盖受三种损耗限制：

1. **壳衰减损耗：** 小素数只是在 CRT 小壳中剥离候选，不提供对剩余壳的无限控制；
2. **重叠损耗：** 多条斜线在同余锁相下重复覆盖同一列；
3. **同步损耗：** 大素数每层至多覆盖少数点，多点同步要求 CRT 模数乘积跨过前窗口尺度。

所以应证明：

`有效覆盖量 <= 行宽剩余壳 - 1`。

即：

`C_j(x)-E_j(x) <= |S_j(x)|-1`。

这就是目标命题在矛盾场中的不等式版本。

## 4. CRT 周期刚性的接入方式

周期刚性不应单独作为“零行不能存在”的断言，因为 CRT 周期内确实可有零行。它应作为反例排斥的补充约束：

- 若前窗口过早零行存在，则镜像周期末端也有零行；
- 列均衡要求每列类素数总量相等；
- 前端零行会制造列缺陷的同步下冲；
- 补偿波必须在中段/镜像段回流；
- 若局部层叠场已证明补偿需要释放新洞，则周期刚性与局部释放共同排斥反例。

换言之，CRT 周期刚性是“全局守恒律”，层叠衰减场是“局部动力学”。二者要通过列缺陷流连接。

## 5. 下一步具体任务

### 5.1 定义列缺陷流

对区间 `I` 定义

`D_c(I)=1_{c in H_P(x), x+1 in I}` 的累计偏差。

完整周期列均衡给出

`D_c([1,M])` 对所有 `c<P` 相等。

前窗口零行给出一段同步低谷，需要证明其无法由层叠场允许的迁移补偿。

### 5.2 建立小壳释放不等式

对 `B_z`，若 `S_B(y)` 与 `S_B(x)` 不同且补掉旧核 `K`，证明

`(S_B(y)\S_B(x))` 中至少一个点逃过剩余层覆盖。

这是 LD-2。

### 5.3 建立大层短差同步不等式

对短差核，证明大层补完全部点需要互异素数同步；若同步模数 `Q>P`，前窗口代表至多一个，并且该代表释放新洞。

这是 LD-1。

## 6. 当前最优顺序

最优顺序应为：

1. 先做 LD-2 的实验增强与可证化；
2. 再做 LD-1 的严格短差同步；
3. 然后把列缺陷流接入 CRT 周期；
4. 最后处理无短差镜像核与列命题。
