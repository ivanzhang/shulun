# OSE-local 补核释放引理：短差核不能在前窗口净消失

**状态：** 候选引理；实验支持，局部事实已严格化。

## 1. 精确目标

设 `K=H_P(x)` 是前窗口 `1<=x<P` 的短差极小残洞核。若某个前窗口相位 `1<=y<P` 覆盖 `K` 的全部列，即

`K subset union_{q<P} A_q(y)`，

则要证明

`H_P(y)\K nonempty`。

这就是补核释放不等式：

`release(y;x)=|H_P(y)\K| >= 1`。

若该不等式对所有短差极小核成立，则短差核只能迁移，不能在前窗口内净消灭。

## 2. 实验事实

`ose-patch-release-scan` 对 `P=23,29,37,41,47,53,67,71,83,97` 的短差最小核做了局部补核扫描。

发现：凡是局部补核 CRT 约束仍有前窗口代表 `y<P`，均满足

`release(y;x)>=1`。

典型例子：

- `P=23, K=[9,15]`，补到 `y=17` 后新洞为 `[6,10,18]`；
- `P=29, K=[1,19,25]`，补到 `y=24` 后新洞为 `[5,13,23]`；
- `P=37, K=[29,35]`，补到 `y=24` 后新洞为 `[19,23,31]`；
- `P=71, K=[3,33,43,49,61]`，补到 `y=42` 后新洞为 `[17,19,29,37,41,55,59,67]`。

这表明局部补洞不是净消灭，而是残洞核迁移。

## 3. 两案证明框架

### 3.1 奇偶翻转案

若 `x not≡ y (mod 2)`，则 `q=2` 覆盖壳翻转。

原核 `K subset O_2(x)` 会被 `q=2` 所在的新覆盖壳吞掉，但旧覆盖壳 `E_2(x)` 变成新反壳 `O_2(y)`。

要使 `release=0`，奇素数层必须覆盖整个 `E_2(x)`。

因此此案归约为奇素数壳重叠能量命题 OSE：

`E_odd(y) >= R_odd(y)-|O_2(y)|+1`。

### 3.2 同奇偶补核案

若 `x≡y (mod 2)`，则 `q=2` 覆盖壳不变，不能帮助补 `K`。补核必须完全由奇素数层完成。

若 `K` 含短差对 `c1,c2`，差 `d=c2-c1`。同一奇素数 `q` 同时补二者必须满足

`q|d`。

因此对 `q>d`，两点必须由不同素数补。短差链越长，需要同步的不同素数越多，CRT 模数乘积越大；若仍存在前窗口代表，则该代表必改变其它奇素数层覆盖，释放新洞。

## 4. 可严格证明的局部子事实

以下事实已经是初等严格结论：

1. **奇偶壳事实。** `H_P(x) subset {c: c not≡x mod 2}`。
2. **短差互斥。** 若 `q>d=|c2-c1|`，则同一 `q` 不能同时覆盖 `c1,c2`。
3. **CRT 同步压力。** 若短差链中 `m` 个点需由互异素数 `q_1,...,q_m` 补，则补核相位被固定在模 `Q=prod q_i` 的一个同余类中。
4. **前窗口代表稀缺。** 若 `Q>>P`，该同余类在 `[1,P-1]` 中至多有一个代表；多数情况下无代表。

剩余待证点是：当这个唯一代表存在时，必释放新洞。

## 5. 下一步最小严证目标

先证明下面的有限形式，但不依赖有限模板：

**PR-1。** 设短差核 `K` 中存在相邻短差对 `c,c+d`，且所有可同时补二者的小因子均属于骨架层 `{3,5,7}`。若 `y<P` 覆盖二者且 `x≡y mod 2`，则 `y` 在同一奇偶壳中至少释放一个不属于 `K` 的新洞。

证明方向：

- 若用骨架小因子补，则该小因子的周期覆盖位置固定，会迫使某个原唯一覆盖列失去唯一解释；
- 若不用骨架小因子，则需两个不同较大素数同步，CRT 模数增长，前窗口代表若存在也会错开骨架层，产生释放。

## 6. 与主命题的连接

偏序下降路线为：

任意前窗口洞集 `H_P(x)` 若非极小，可下降；下降链终点是极小残洞核。若极小核含短差，则由本引理不能净消失。剩余只需处理“无短差镜像缺陷核”。

因此当前主命题被拆成两类极小核：

1. 短差核：走 OSE-local / patch-release；
2. 无短差核：走镜像缺陷与列均衡回流。
