# 行列归约 A/B 短定理化

本文件补强最终主链入口：把 `Column-Closure` 与 `Row-Closure` 的反例归约到 Structured-EHPD 坏配置。这里的目标是明确归约逻辑和仍需核对的几何刚性，避免读者从历史探索段中重构入口。

## 1. 基本分解

令 `D=floor(sqrt(P))`。对方阵点 `n=kP+c`，若 `n` 合数，则至少发生一项：

1. **小因子锁定**：存在素数 `p<=D` 使 `p|n`；
2. **双粗解释**：`n=qm`，其中 `q>D` 且 `m>D`；
3. **尾部锚解释**：双粗解释中有一因子位于 `[τP,P]`，进入 Tail-log4 处理。

相邻或短距离粗合数不能共享同一个 `>D` 的素因子：若 `q>D` 同时整除 `n_1,n_2`，则 `q|n_1-n_2`；当 `0<|n_1-n_2|<D` 时不可能。这是大因子短窗不可复用刚性。

## 2. Theorem A：Column-Closure 归约

**Theorem A（列反例到 Structured-EHPD）。** 固定 `c<P`。若第 `c` 列中所有 `kP+c` 均为合数，则该列诱导的锚覆盖族满足 Structured-EHPD 坏配置假设。

**证明。** 对列中每个 `k`，按第 1 节分配一个解释。小因子锁定层由 CRT 非零同余类排除；因为 `c<P`，第 `P` 列的平凡模 `P` 锁定不出现。剩余点必须由双粗锚 `q>D` 覆盖。对固定大锚 `q`，列条件给出唯一行剩余类

`kP+c≡0 mod q`。

因此每个大锚在列上形成一条稀疏斜线/剩余类轨道。大因子短窗不可复用保证短窗口中不能由同一大锚重复解释相邻粗点。CRT 列均衡保证除第 `P` 列外非零同余类交集的列密度相等，故全列合数不能通过把所有缺口集中到该列来逃逸。

于是列反例给出：小因子锁定已剥离、尾部锚由 Tail-log4 计入误差、主体双粗锚需在无短窗复用的条件下覆盖全部剩余粗候选。这正是 Structured-EHPD 的坏配置输入。证毕。

## 3. Theorem B：Row-Closure 归约

**Theorem B（行反例到 Structured-EHPD）。** 固定行 `k`。若该行所有 `kP+c` 均为合数，则该行诱导的锚覆盖族满足 Structured-EHPD 坏配置假设。

**证明。** 对行中每个列位置 `c`，同样按小因子锁定、双粗解释、尾部锚解释三类分配。小因子锁定由模 `p<=D` 的斜线族给出；相邻列位置不能由同一大因子解释，因为列差小于 `D` 时共享大因子会迫使该大因子整除小列差。

正反 45 度斜线锁定来自 `P+1` 与 `P-1` 的小因子结构：若斜线首项与 `P±1` 有共同小素因子，则整条对应斜线被小因子锁定。这些点归入小因子锁定层；未被此类斜线锁定的剩余点若仍合数，必须由双粗锚或尾部锚解释。

尾部锚 `q∈[τP,P]` 的互补因子 `m` 变化快，不能在行内当作稳定主体容量；该部分正由 Tail-log4 给出 `V_D P/log^4P` 级误差。剥离尾部后，主体双粗锚必须在一行长度 `P` 的窗口内覆盖所有剩余粗候选，并受大因子短窗不可复用、CRT 非零类均衡和斜线相位刚性约束。这正是 Structured-EHPD 坏配置输入。证毕。

## 4. 审稿风险与剩余核对

Theorem A/B 是归约定理，不是 Structured-EHPD 本身。它们的审稿风险集中在三点：

1. 小因子锁定层与双粗主体层是否完全不重叠或有无重复计数；
2. Tail-log4 剥离是否同时覆盖行、列两种尾部解释；
3. 45 度斜线锁定是否只作为小因子锁定层处理，而没有额外假设其能单独证明行命题。

这些风险均为符号与分层核对问题。若第 1 节三分解、Tail-log4 和 Structured-EHPD 输入均成立，则行列反例均归约为同一种坏配置。
