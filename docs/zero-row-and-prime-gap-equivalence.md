# 零行位置与素数间隙的等价关系

**状态：** `front_window_zero_row_is_prime_gap_problem`

零行扫描显示，完整 CRT 周期内的零行可以很早出现，但仍在 `r>P` 后。例如 `P=23` 时最小零行为 `r=59`，对应区间

`1335,1336,...,1356`

这些数都由 `2,3,5,7,11,13,17,19` 中的素数整除。

这说明零行不是罕见异常，而是合数长串在 CRT 覆盖语言中的表现。

## 1. 前 P 行零行的精确含义

第 `r` 行除第 `P` 列外全覆盖等价于：

`(r-1)P+1, ..., (r-1)P+P-1`

全部为合数或被根基素数覆盖。

若 `r<=P`，则这些数都小于 `P^2`。任何合数 `n<P^2` 都有素因子 `<P`。因此：

> 前 `P` 行存在零行，等价于在 `1..P^2` 内存在长度 `P-1` 的连续合数串，且起点与 `P` 的行分割对齐。

这与 Legendre 型命题高度接近。

## 2. 为什么完整 CRT 零行不矛盾

在完整 CRT 周期中，零行可以出现在 `r>P` 后。此时对应数可能远大于 `P^2`，合数可以完全由 `<P` 的素数覆盖，但这不违反“每个 `n<P^2` 的合数有小因子”的高度约束。

因此目标不是排除 CRT 零行，而是排除前窗口零行：

`min Z_P > P`。

## 3. 对证明路线的约束

任何证明 `min Z_P>P` 的方法，实质上都在证明一种素数间隙上界：在每个区间

`[xP+1, xP+P-1]`, `0<=x<=P-1`

中存在素数。

这正是 `P^2` 以下相邻素数间隙小于约 `P` 的断言。

所以如果不使用方阵额外结构，就会落入经典困难问题。我们必须使用：

- 与行分割对齐的结构；
- 列均衡守恒；
- 圆柱斜线相位；
- 相邻大因子互斥；
- gap 多标签复杂度；
- CRT 补偿流。

## 4. 当前可保留的突破点

虽然完整证明仍缺桥，但以下事实是可用的：

1. 完整 CRT 零行集合 `Z_P` 可存在；
2. 目标只需证明 `Z_P` 不进入 `[1,P]`；
3. 前窗口内具有高度约束 `n<P^2`；
4. 该高度约束使每个被覆盖数的最小因子与补因子形成递归商约束；
5. 若全行覆盖，则产生一段对齐的合数串，其因子标签链必须满足相邻互斥和 gap 刚性。

## 5. 下一步真正可攻点

应把“前窗口”作为额外刚性，而不是只看 CRT 周期：

### 引理 H（高度受限标签链）

设 `0<=x<=P-1`，若所有 `xP+c, 1<=c<P` 均合数，则选择每个数的最小素因子 `p_c<P`。则标签链 `p_c` 必须满足：

- 相邻小距离内大标签不重复；
- 小标签覆盖形成高度周期；
- 大标签对应商 `m_c=(xP+c)/p_c < P^2/p_c`；
- 高频 gap 的标签-商对不能同时满足互质和高度限制。

该引理比纯 CRT 更接近目标，因为它直接使用 `x<P`。
