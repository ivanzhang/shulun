# Anchor Cross-linear 硬攻稿

**状态：** 锚图像近碰撞谱的核心线性上界。

## 1. Cross 事件定义

固定列 `c`。对有效锚 `q`，其命中行号集合为

`K_q={k: q|kP+c, k in R}`。

两个锚 `q_1,q_2` 产生一个 Cross 事件，若存在

`k_1 in K_{q_1}`, `k_2 in K_{q_2}`

满足

`0<|k_1-k_2|<D=sqrt(P)`。

这些 Cross 事件正是锚图像产生粗候选小 gap 的来源。

## 2. 扫描事实

新增脚本：`experiments/anchor_cross_collision_scan.py`。

代表列扫描显示：

- `cross_events` 与 `Q_eff` 同阶；
- `distinct_pairs` 几乎等于 `cross_events`；
- 同一锚对的复用次数 `max_pair_reuse` 很小，通常 `3--4`；
- 绝大多数锚对只产生一次近碰撞。

这强烈支持：

`Cross <= C Q_eff`。

## 3. 单锚对近碰撞方程

若同一锚对 `(q_1,q_2)` 产生两次近碰撞，则存在整数 `a,b,a',b'` 与小差 `h,h'`，满足

`r_1+a q_1 - r_2-b q_2 = h`,

`r_1+a' q_1 - r_2-b' q_2 = h'`,

其中 `|h|,|h'|<D`。

相减得

`(a-a')q_1 - (b-b')q_2 = h-h'`,

且 `|h-h'|<2D`。

由于 `q_1,q_2>D`，这是一条强 Diophantine 近关系。若 `|a-a'|`、`|b-b'|` 不小，则左侧通常远大于 `D`；若它们很小，则只能有有限多次。

## 4. 复用次数上界候选

**Pair-collision bound.** 对任意不同锚素数 `q_1,q_2>D`，在 `[0,P)` 中满足

`|r_1+a q_1-r_2-b q_2|<D`

的近碰撞次数至多为绝对常数 `C_0`。

实验提示 `C_0=4` 可能成立于有效锚图像相邻 Cross 统计；保守可取更大常数。

单独 `C_0` 只给 `Cross <= C_0 Q_eff^2`，还不够。需要更强：每个锚只与有界多个锚发生近碰撞。

## 5. 锚邻接度上界

固定锚 `q_1`。若它与许多 `q_2` 产生近碰撞，则许多锚图像点落在 `K_{q_1}` 的 `D` 邻域内。

但 `K_{q_1}` 在 `[0,P)` 中只有约 `P/q_1` 个点，每个点的 `D` 邻域总长度约 `D P/q_1`。

另一个锚 `q_2` 命中该邻域的概率约该长度除以 `P`，即 `D/q_1`，再乘粗候选过滤密度。

对 `q_1>D`，这是小量。求和应给每个锚平均邻接度有界。

## 6. Cross-linear 候选证明路线

1. 对每个锚 `q`，其命中点数 `n_q<=1+P/q`。
2. 每个命中点的 `D` 邻域长度为 `2D`。
3. 所有邻域总长度 `<=2D n_q`。
4. 其它锚图像命中这些邻域的次数，按同余分布应不超过

   `Σ_{q'} (2D n_q/q' + O(1))`。

5. 小筛粗候选过滤再降低常数。

若能控制 `O(1)` 累加，得到每个锚平均 Cross 度 `O(1)`，即

`Cross <= C Q_eff`。

## 7. 当前未闭合点

关键困难是第 4 步的 `O(1)` 对所有 `q'` 累加可能太大。必须利用“有效锚”而不是所有锚：只有实际命中粗候选的 `q'` 才参与，且有效锚数 `Q_eff≈P/log P`。

需要证明有效锚 residues 不会全部集中到某个锚邻域。这又回到小筛 CRT 均匀性，但现在是在锚图像邻域尺度上。

## 8. 下一步硬点

专攻：

**Anchor-neighborhood sparsity.** 对任意锚 `q`，其它有效锚图像落入 `K_q` 的 `D` 邻域的次数为 `O(1)` 或至多 `O(log P)`，且总和为 `O(Q_eff)`。

若该引理成立，Cross-linear 成立；再与二阶复用能量和 Q_eff 损耗合并，可形成明确矛盾不等式。

## 9. 邻域稀疏扫描修正

已新增：`docs/anchor-neighborhood-sparsity.md` 与 `experiments/anchor_neighborhood_sparsity_scan.py`。

扫描表明 Cross-linear 的常数版可能过强：平均邻域吸引度随 `P` 缓慢增长，`P=2003` 可到约 `15`。因此应修正为 `Cross-log`，并把 Cross 作为联合能量的一部分，而不是单独闭合矛盾。
