# 前窗口分支势函数：保持 x<P 的代价

**状态：** `front_window_branches_keep_residual_holes`

`P=23` 的递归分支树显示：按根基素数逐步加入同余约束时，只要要求 CRT 最小代表仍满足 `x<P`，就无法消灭所有洞。

即使加入全部根基素数后，`x<P` 分支仍保留洞：

- `x=0` 保留特殊洞 `[1]`；
- 正行最佳如 `x=14` 保留 `[9,15]`。

完整覆盖首次出现在 `x=58>P`。

## 1. 分支势函数

定义对一个部分同余方案 `S_k`：

- `x(S_k)`：CRT 最小非负代表；
- `H(S_k)`：在该代表下尚未覆盖的列洞集；
- 势函数 `Ψ(S_k)=|H(S_k)|`。

实验显示存在前窗口势垒：

`x(S_k)<P => Ψ(S_k)>=1`。

完整覆盖 `Ψ=0` 只能在 `x>=P` 的分支出现。

## 2. 保持前窗口的代价

每次加入新素数 `q`，若选择使 `x` 仍在前窗口的余类，往往只能补某些早期洞，同时会错过与后续模数兼容的必要洞。

换言之：

> 小 `x` 分支可以局部降低洞数，但会保留一个不可补的残洞核。

该残洞核随模数加入而变化，但不会为空。

## 3. 对 MC-2 的解释

MC-2 中的“早期洞不可延拓”可解释为：

- 早期相位 `x<P` 的确命中洞；
- 但命中后得到的分支仍有残洞核；
- 若选择可延拓为无洞的必要列，则 CRT 代表必须跳到 `x>=P`。

因此证明 MC-2 可转化为证明前窗口势垒：

`min_{S: x(S)<P} |H(S)| >= 1`。

## 4. 一般化候选引理 PB（Potential Barrier）

对任意奇素数 `P`，任意部分或完整覆盖方案 `S`，若其 CRT 最小代表 `x(S)<P`，则对应覆盖列集合不能等于全部 `1..P-1`。

特别地，对完整根基模数集合：

`x<P => A(x+1)>=1`。

这与行命题等价，但分支势函数给出了递归证明路线：证明每个保持 `x<P` 的扩展步骤都保留残洞核。

## 5. 下一步

把 `P=23` 的有限分支树压缩成一般不等式：

- 小模数骨架留下的洞数下界；
- 中模数早期相位最多消除部分洞；
- 若要消除残洞核，CRT 步长必须跨过 `P`；
- 因而 `Ψ=0` 分支不可能留在前窗口。

## 6. 多 P 正行前窗口扫描

排除 `x=0` 第一行特殊洞后，多 P 扫描显示：

- `P=13,17,19`：正行最佳残洞数为 `1`；
- `P=23,31,37`：正行最佳残洞数为 `2`；
- `P=29,41`：正行最佳残洞数为 `3`。

因此前窗口势垒不是由第一行特殊值 `1` 造成，而是真正在 `1<=x<P` 中存在。

最终残洞核通常很小，说明反例若要发生，只差最后 1 到 3 个洞；这些洞正是中大素数相位延迟的核心。

## 7. 势垒不等式的新形式

令

`B_P(x)=#` 未被所有根基素数 `<P` 覆盖的列数，`1<=x<P`。

实验支持：

`min_{1<=x<P} B_P(x) >= 1`。

更细地，前缀势函数

`B_{P,k}(x)`

随加入素数前缀单调下降，但在前窗口内不触底：

`min_{1<=x<P} B_{P,k}(x) >= 1` 对所有前缀 `k`，特别是完整前缀。

## 8. 证明目标 PB-2

证明：对任意素数前缀 `Q_k={q_1,...,q_k}`，若 `x<P`，则 `Q_k` 的禁余类覆盖不能覆盖全部列。

完整情形即目标命题；前缀版本更适合归纳：

- 加入新素数 `q` 只能覆盖一个同余类；
- 若它消灭当前残洞核，则 CRT 代表必须跨过 `P`；
- 若保持 `x<P`，则残洞核转移但不消失。

这就是“残洞核守恒/迁移”观点。
