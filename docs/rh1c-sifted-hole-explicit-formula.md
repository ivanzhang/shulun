# RH-1C 专攻：筛余空洞函数与显式公式桥接

本文件继续推进 `docs/rh1-weak-attack-plan.md` 的结论：原始 Dirichlet 角色版 RH-1 会把 zeta 主零点困在主角色中，难以产生非零 CRT 类方差。因此更自然的桥接对象不是单纯的 reduced residue class prime sums，而是“筛余空洞函数”：小素数斜线覆盖后仍未被解释的位置密度。

## 1. 筛余空洞函数定义

固定筛层 `z`，令

`P(z)=prod_{p<=z}p`。

定义整数筛余指示

`R_z(n)=1_{(n,P(z))=1}`。

在方阵语言中，`R_z(n)=1` 表示点 `n` 没有被小素数斜线覆盖，是“小因子锁定层”剥离后的候选空洞。素数大于 `z` 时自动满足 `R_z(n)=1`，但 `R_z` 还包含双粗合数候选。因此真正的空洞函数不是 `Λ(n)R_z(n)`，而是

`H_z(n)=R_z(n)-C_z(n)`，

其中 `C_z(n)` 是由允许的大因子主体锚与尾部锚给出的合数覆盖权。理想情况下，`H_z(n)` 支持在未被任何合数解释覆盖的位置，即素数或类素数候选。

RH-1C 的目标是：若 zeta 有离线零点，则某些尺度上 `H_z` 的加权总量或 CRT 投影相对零频基线出现超平方根偏差。

## 2. 为什么只看 `Λ(n)R_z(n)` 不够

对素数权，若 `n=p>z`，则 `R_z(p)=1`。因此

`sum_n Λ(n)R_z(n)W(n/X)`

与 `ψ(X)` 只差小素数和素数幂的低阶项。它确实保留 zeta 零点波动，但它没有表达“合数覆盖能力”。它看到的是素数权，而方阵反例矛盾场需要的是：合数斜线能否覆盖筛余候选。

所以必须引入 `C_z(n)`，把问题从“素数有多少”改写为“筛余候选中有多少被合数覆盖解释”。这正是本文局部机器的语言。

## 3. 覆盖函数的 Buchstab 展开

筛余候选 `R_z(n)` 可用 Buchstab 分解：若 `n` 没有小因子，则要么是素数，要么有最小素因子 `q>z`。形式上，候选集合分解为

`R_z = Prime_z + Σ_{q>z} Anchor_q + higher overlaps`。

在方阵证明中，这对应：

1. 素数空洞；
2. 主体双粗锚覆盖；
3. 尾部锚覆盖；
4. 多重解释的重叠修正。

因此定义加权缺口

`Gap_z(X)=Σ_n W(n/X)R_z(n) - Σ_n W(n/X)C_z(n)`。

若 `Gap_z(X)` 大，则筛余候选中存在合数覆盖无法解释的空洞；若 `Gap_z(X)` 小或负，则合数覆盖异常强。

## 4. 显式公式输入的位置

zeta 零点通过 `ψ(X)` 进入素数权：

`ψ(X)-X ≈ -Σ_ρ X^ρ/ρ`。

要让它进入 `Gap_z`，需要一个覆盖恒等式：

`Σ_n W(n/X)R_z(n) = Prime_z(X)+CompositeCover_z(X)+Overlap_z(X)`。

于是

`Prime_z(X)=Σ_n Λ(n)R_z(n)W(n/X)/log n` 的波动，会迫使 `CompositeCover_z` 或 `Gap_z` 出现相反波动，除非 overlap 项精确吸收。

本文局部刚性正是为了排除 overlap 项无限自由吸收：大因子短窗互斥、尾部锚削薄、CRT 均衡和 D 组能量终端都限制 overlap 的调节能力。

## 5. RH-1C 精确弱命题

**RH-1C weak。** 若存在零点 `ρ=β+iγ`，`β>1/2`，则存在 `α>0`、无穷多 `X_j`，令 `z_j=X_j^α`，使筛余空洞缺口满足至少一个方向：

`|Gap_{z_j}(X_j)-ExpectedGap_{z_j}(X_j)| >= X_j^{β-o(1)}/log^A X_j`。

这里 `ExpectedGap_z` 是 CRT 零频基线加 Tail-log4 平均覆盖项。

该命题比 RH-1 原版更贴近方阵证明，因为它直接产生 M5 所需的覆盖缺口。

## 6. 可能证明路线：三项不可同时吸收

由显式公式，离线零点给 `Prime_z(X)` 一个 `X^β/log^A X` 级波动。覆盖恒等式给

`R_z - C_z = Prime_z + Error_overlap`。

若 `Gap_z` 没有同级波动，则必须由 `C_z` 或 `Error_overlap` 吸收素数波动。

但：

1. **尾部锚不能吸收**：Tail-log4 给 `P/log^4P` 级平均削薄；
2. **主体锚不能自由吸收**：大因子短窗互斥与 D 组能量限制主体覆盖偏差；
3. **重叠项不能无限吸收**：多重解释会增加局部能量或进入 FCT 低维闭包。

因此，若能把这三项的吸收能力都压到 `o(X^β)`, 就得到 RH-1C weak。

## 7. 关键断点：覆盖恒等式的权重化

最大困难是把集合恒等式变成带 `Λ` 或素数权的解析恒等式。`R_z(n)` 是整数候选，`Prime_z(X)` 是素数权，`C_z(n)` 是合数覆盖权；它们不是同一权重体系。

需要构造一个统一权重，例如：

`ω(n)=log p` 若 `n` 的最小未解释素因子为 `p`，或使用 Buchstab 权 `1/log n` 把 `Λ` 转成素数计数。

只有权重统一，显式公式的 zeta 零点波动才能进入覆盖缺口账本。

## 8. 可先证明的 toy theorem

**Toy RH-1C。** 假设存在一个权重 `ω_z(n)` 满足：

1. 对素数 `p>z`，`ω_z(p)=Λ(p)+O(1)`；
2. 对双粗合数，`ω_z(n)` 可分配给其主体锚，且满足短窗互斥容量；
3. 总权重有 Buchstab 分解，overlap 项满足 Tail-log4/D 组吸收。

则离线零点 `β>1/2` 推出某些 `Gap_z` 出现 `X^{β-o(1)}` 级偏差。

这个 toy theorem 把 RH-1C 的困难集中到权重构造，而不是同时处理所有问题。

## 9. 下一步最优目标

下一步应专攻 **Buchstab 覆盖权构造**：找到一个权重 `ω_z(n)`，同时满足：

- 对素数保留 zeta 显式公式波动；
- 对合数可按最小大因子或主体锚分配；
- 对重叠解释有正性或能量控制；
- 与 CRT 零频基线兼容。

若这个权重存在，RH-1C 就有可能从显式公式接入方阵矛盾场。

## 10. 结论

RH-1C 的本质不是“找一个同余类偏差”，而是“把 zeta 零点波动翻译为筛余空洞覆盖缺口”。这比 Dirichlet 角色方差路线更贴近本文已建立的局部刚性机器。

真正的下一硬点是权重统一：如何让素数权、筛余候选权、合数覆盖权处在同一个可加账本中。解决它，才可能把离线零点传递到 M5/D 组矛盾场。
