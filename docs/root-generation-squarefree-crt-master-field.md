# 根基生成—平方自由 CRT—均衡镜像总场

**状态：** 高维统一框架；用于寻找最终矛盾显化不等式。

## 1. 三个投影其实是同一个对象

用户指出的三类刚性：

1. `X` 以内素数由 `sqrt(X)` 内已确定素数的非零同余类约束生成；
2. 根基素数 CRT 周期内，除第 `P` 列外列分布严格均衡，行密度镜像；
3. 根基素数在 CRT 模数中一次出现，周期模数平方自由，即无根基素数平方整除 CRT 周期。

它们不是分散事实，而是同一筛结构的三个投影：

- 生成投影：谁是候选；
- 周期投影：候选如何在 CRT 周期中分布；
- 平方自由投影：各根基同余方向独立、无重根退化。

## 2. 根基生成场

对任意 `X`，素数判定由根基集合

`Q_X={q prime: q<=sqrt(X)}`

的非零同余类决定。

在本问题中，第 `x+1` 行列 `c` 的数为

`N=xP+c`，且 `N<P^2`。因此若 `N` 为合数，则必有素因子 `<P`。

所以行内候选洞恰是

`H_P(x)={c<P: xP+c not≡0 mod q, all q<P}`。

这说明目标命题不是外加素数猜测，而是根基生成场在前窗口中的非零性。

## 3. 平方自由 CRT 场

令

`M=prod_{q<P} q`。

这是平方自由模数。每个根基素数 `q` 在 CRT 中贡献一个独立坐标。

平方自由性给出三点刚性：

1. 每个根基斜线族只切除一个坐标超平面；
2. 不存在 `q^2` 造成的重复权重或重根吸收；
3. CRT 坐标变换可逆，局部相位改变会在每个 `q` 坐标线性平移。

因此小壳动力方程

`a_q(y)-a_q(x)=-(y-x)P mod q`

本质上是平方自由 CRT 环上的线性流。

## 4. 周期均衡镜像场

在完整周期 `M` 内定义二维候选矩阵

`Z(r,c)=1_{c in H_P(r-1)}`。

CRT 给出：

- 列均衡：`sum_{r=1}^M Z(r,c)` 对所有 `1<=c<P` 相等；
- 镜像：`Z(r,c)=Z(M+1-r,P-c)`；
- 周期：`Z(r+M,c)=Z(r,c)`。

这些是全局守恒律。

## 5. 层叠缺陷流场

对根基前缀 `B` 定义壳

`S_B(x)`。

剩余层有效覆盖为

`U_{>B}=C_{>B}-E_{>B}`。

主方程：

`|H_P(x)|=|S_B(x)|-C_{>B}(x)+E_{>B}(x)`。

转移方程：

`Barrier(x,y;B)=ΔE-ΔC+ΔS+KILL=|H_P(y)\H_P(x)|`。

这是局部动力律。

## 6. 总场一致性条件

若前窗口存在行反例或列反例，则必须同时满足：

1. 根基生成场允许候选完全消失；
2. 平方自由 CRT 线性流可把缺陷集送到空集；
3. 层叠 Barrier 为 `0`；
4. 周期列均衡仍能补偿该缺陷湮灭；
5. 镜像场同步复制该湮灭而不破坏补偿。

因此反例不是一个局部事件，而是五个投影同时闭合的高维零模态。

## 7. 反例矛盾显化不等式的目标形态

我们要找的不等式应同时含局部与全局项：

`LocalBarrier + GlobalBalanceDefect + MirrorDefect >= 1`。

其中：

- `LocalBarrier=ΔE-ΔC+ΔS+KILL`；
- `GlobalBalanceDefect` 衡量列均衡要求的补偿是否可由当前转移支撑实现；
- `MirrorDefect` 衡量镜像列配对是否可同时满足。

若存在反例，则三项必须同时为 `0`。证明其和至少为 `1` 即排斥反例。

## 8. 平方自由性的关键作用

平方自由 CRT 使每个根基坐标只出现一次。因此：

- 同一根基素数复用两个短差点要求 `q|d`，否则不可能；
- 多点补洞必须使用多个独立 CRT 坐标；
- 独立坐标的同步模数乘积快速增长；
- 这正是 `SyncLoss` 的来源。

如果 CRT 模数含平方，可能出现高阶吸收；但这里没有，这增强了互斥与同步压力。

## 9. 下一步核心命题 Master Inequality

**MI。** 对任意奇素数 `P` 与任意前窗口反例候选转移链，存在某一步 `x->y` 与某个根基前缀 `B`，使

`ΔE-ΔC+ΔS+KILL + BalanceDefect + MirrorDefect >= 1`。

特别地，若只考虑行反例，先证明局部版：

`ΔE-ΔC+ΔS+KILL >= 1`。

若处理列反例，则需要加入 `BalanceDefect + MirrorDefect`。

## 10. 证明路线

1. **局部闭合：** 用平方自由短差互斥与重叠能量证明 `LocalBarrier>=1`，排除行零边际。
2. **列支撑扩散：** 若 `LocalBarrier` 产生新洞，则其列支撑在 CRT 小壳流下不可长期避开固定列。
3. **全局闭合：** 用列均衡与镜像守恒排除列零边际。

## 12. 四投影统一刚性矛盾场方程组（新增）

本节把根基生成、平方自由 CRT、列均衡镜像、前窗口高度约束写成同一组场方程。目标是避免把反例看成孤立覆盖事件，而把它看成四个投影同时为零的高维零模态；证明策略就是证明该零模态不存在。

### 12.1 基本场变量

令

`N_x(c)=xP+c, 0<=x<P, 1<=c<P`，

根基素数集合为

`Q(P)={q prime: q<P}`，

完整 CRT 模数为

`M_P=prod_{q<P} q`。

定义候选场

`Z_P(x,c)=1_{N_x(c) not≡0 mod q for every q<P}`。

前窗口中有 `N_x(c)<P^2`，因此 `Z_P(x,c)=1` 等价于 `N_x(c)` 为素数或 `N_x(c)=1` 的边界例外。对 `x>=1` 而言，行命题即

`R_P(x):=sum_{c=1}^{P-1} Z_P(x,c) >= 1, 1<=x<P`。

列命题即

`C_P(c):=sum_{x=0}^{P-1} Z_P(x,c) >= 1, 1<=c<P`。

反例是某个行边际或列边际为零。

### 12.2 根基生成投影：上界随 `X` 增长，根基随 `sqrt(X)` 增长

对任意 `X`，素性由 `sqrt(X)` 内已确定素数的非零同余约束决定。前窗口中特别有

`xP+c<P^2 => sqrt(xP+c)<P`。

所以全部合数解释都必须来自 `Q(P)`。这给出第一条刚性：前窗口反例不是“缺少根基”，而是要求所有 `P-1` 个位置都被同一有限根基族精确击中。

这个投影给出高度函数

`h_x(c,q)=(xP+c)/q`，当 `q|N_x(c)` 时定义。

若 `q>sqrt(P)`，则

`h_x(c,q)<P^{3/2}`；若 `q` 接近 `P`，则 `h_x(c,q)<P+O(1)`。

因此大斜率覆盖不是免费容量：它把覆盖任务递归压回更小商尺度。统一矛盾场必须记录这一高度损耗。

### 12.3 平方自由 CRT 投影：独立坐标与无重根吸收

因为 `M_P` 是平方自由乘积，每个 `q<P` 只贡献一个 CRT 坐标。第 `x` 行在 `q` 坐标上的禁列为

`a_q(x)=-xP mod q`。

行移动 `x -> x+t` 满足线性流方程

`a_q(x+t)-a_q(x)=-tP mod q`。

平方自由性带来两条不可替代的约束：

1. **短差互斥。** 若 `q>D` 且 `0<|c-d|<D`，同一 `q` 不可能同时覆盖 `c,d`，因为否则 `q|(c-d)`。
2. **同步乘积损耗。** 若一个核中 `m` 个短差互斥点必须由互异大根基素数 `q_1,...,q_m` 补掉，则对应行相位需落在一个模

   `Q=q_1...q_m`

   的 CRT 剩余类中。平方自由性保证这里没有 `q_i^2` 的重根吸收，也没有坐标复用折扣。

因此“斜线覆盖能力”的真实增长不是根基数目的简单相加，而是受短差核迫使的乘积同步约束削弱。

### 12.4 周期列均衡与行密度镜像投影

在完整周期内，候选场满足

`Z_P(x+M_P,c)=Z_P(x,c)`。

除第 `P` 列外，各列总量严格均衡：

`T_c:=sum_{x=0}^{M_P-1} Z_P(x,c)` 与 `c` 无关，`1<=c<P`。

同时镜像给出

`Z_P(x,c)=Z_P(M_P-1-x,P-c)`，

等价于行密度

`R_P(x)=R_P(M_P-1-x)`。

这说明零行可以在完整周期内存在，但必须成镜像势阱并由列均衡补偿。前窗口反例若存在，则不是单个低谷，而是在周期守恒场中插入一个过早触底的深势阱；该势阱必须同时满足短差互斥、同步乘积、高度商链和列补偿。由此形成全局排斥接口。

### 12.5 层叠壳—有效覆盖—释放方程

取根基前缀 `B subset Q(P)`，定义小壳

`S_B(x)={c: xP+c not≡0 mod b for all b in B}`。

剩余层 `Q(P)\B` 对 `S_B(x)` 的覆盖容量记为 `C_{>B}(x)`，覆盖重叠能量记为 `E_{>B}(x)`。则有精确恒等式

`R_P(x)=|S_B(x)|-C_{>B}(x)+E_{>B}(x)`。

对行移动 `x -> y`，定义旧核杀灭量

`KILL=|H_P(x)\H_P(y)|`。

局部释放/新洞势垒为

`LB_B(x,y)=ΔE_{>B}-ΔC_{>B}+Δ|S_B|+KILL`，

并有恒等式

`LB_B(x,y)=|H_P(y)\H_P(x)|`。

因此若旧核被完全补掉却没有新洞释放，则必须有 `LB_B(x,y)=0`。这就是行反例需要穿过的局部零势垒。

### 12.6 统一矛盾场不等式

把四个投影合成一个缺陷泛函：

`Xi_B(x,y)=LB_B(x,y)+SyncLoss_B(x,y)+HeightLoss_B(x,y)+BalanceDefect(x,y)+MirrorDefect(x,y)`。

各项含义如下。

- `LB_B`：层叠壳迁移中的新洞释放量；它已经是精确非负整数。
- `SyncLoss_B`：短差核被互异大根基补洞时的平方自由 CRT 同步损耗；当同步乘积超过前窗口可容纳尺度而仍要求短代表时取正。
- `HeightLoss_B`：大根基补洞后商 `h_x(c,q)` 落入更低尺度所产生的递归约束损耗；它防止用无限多“大斜线”无代价填满有限窗口。
- `BalanceDefect`：若某列或某组列在前窗口亏损，而可达新洞列支撑无法在完整周期中提供均衡补偿，则取正。
- `MirrorDefect`：若亏损/补偿结构不能与 `c <-> P-c`、`x <-> M_P-1-x` 镜像同时兼容，则取正。

目标主不等式为

`Xi_B(x,y)>=1`

对任意可能产生前窗口行反例或列反例的关键转移成立。

若存在行反例，则可沿极小残洞核转移链选择一步，使旧核被杀灭且没有新洞释放；这会强迫 `LB_B=0`。主不等式说明此时至少有同步、高度、均衡或镜像缺陷显化，矛盾。

若存在列反例，则即使每个局部转移都有释放，释放列支撑也必须长期避开某固定列；列均衡和镜像使这种长期避让不可能，因此 `BalanceDefect+MirrorDefect>=1`。

### 12.7 当前最小可攻证明义务

为了把总方程组变成严格证明，下一步不应再做有限模板覆盖，而应证明以下三个结构命题。

**SFL（平方自由同步损耗）。** 设残洞核含一个短差连通块 `K`。若 `K` 中 `m` 个点均需由大于块直径的根基素数补洞，则这些补洞素数两两不同，且同步模数为平方自由乘积 `Q`。当 `Q>P` 时，前窗口 `[0,P-1]` 内同一补洞方案至多有一个相位代表；若该代表存在，则壳迁移必产生新洞释放，即 `LB_B>=1` 或 `HeightLoss_B>=1`。

**HCL（高度商链损耗）。** 在 `0<x<P` 的前窗口中，任意大根基覆盖 `q|xP+c` 都产生商 `h=(xP+c)/q<P^2/q`。若一个完整行反例需要大量大根基覆盖，则这些商构成更低尺度的互斥链；递归剥离后，所需独立约束数增长快于行宽可提供的自由度，故 `HeightLoss_B>0`。

**GBM（均衡镜像补偿）。** 若某列前窗口边际为零，或某行前窗口边际为零并诱发全列同步亏损，则完整周期列均衡要求的补偿列支撑必须与镜像配对同时存在。极小核迁移的可达新洞支撑若试图避开某列，会破坏列均衡；若试图镜像配对，则产生短相位回路，进入 SFL。故 `BalanceDefect+MirrorDefect>0` 或 `SyncLoss>0`。

这三个义务正好对应用户强调的三个投影：根基生成给 HCL，平方自由 CRT 给 SFL，列均衡与行密度镜像给 GBM。三者合并后，反例必须让 `Xi_B=0`，而三个结构命题迫使 `Xi_B>=1`。
