# Fourier/Vaaler 尾项统一平方可和审查

本文补强 `docs/rh-dgap-lowdim-extraction-line-by-line-audit.md` 的剩余接口：DGap 盒模板中的 Fourier/Vaaler 截断尾项为何要么平方可和并可吸收，要么转入 `CE/LSMP/LV/SC` 等已命名终端。本文是 RH 反例矛盾场的接口无条件化推进，不宣称 RH 已证明。

## 1. 模板原子清单

当前正式 DGap/PC4 模板只允许以下原子：

1. 物理平滑窗 `W(n/X)` 或 dyadic Whitney 窗；
2. dyadic 层标签 `Q,R`；
3. CRT 字符原子；
4. 倒数环带 `ξx^{-1} mod p ∈ I`；
5. Bohr 短弧/短区间原子；
6. 有限并、交、差和有限线性组合。

若出现依赖无界多坐标、无界高阶布尔复杂度、无界关系高度或非 dyadic 端点堆叠，则不属于固定模板族，直接进入 `Complexity-Escape/LSMP`。

## 2. 单原子尾项界

### 2.1 平滑窗

平滑物理窗的 Mellin/Fourier 系数快速衰减。取截断高度 `H_k>=k^4`，尾项满足

`||Tail_k||_2 <= C_A H_k^{-A}`

任取固定 `A`。故平方可和。

### 2.2 硬边界物理窗

硬边界先用宽度 `η_k` 平滑。边界层贡献为 `O(η_k^{1/2})`，截断尾为 `O((H_kη_k)^{-1})`。取

`η_k=k^{-4}`, `H_k=k^8 log^C k`,

得 `||Tail_k||_2=O(k^{-2})`，平方可和。若边界层质量异常大，则它是低体积/边界拥挤事件，进入 `LV/LSMP`。

### 2.3 倒数环带与 Bohr 短弧

倒数环带和 Bohr 短弧的指标用 Vaaler 多项式逼近。平滑后尾项满足

`||Tail_k||_2 <= C(H_k^{-1}+η_k^{1/2})`。

同样取 `η_k=k^{-4}`、`H_k=k^8log^Ck`，得到平方可和。若短弧数量或边界数量随尺度超过 `log^C`，则转入 `CE`；若短弧边界集中承载固定比例能量，则转入 `SC/LV`。

### 2.4 CRT 字符原子

CRT 字符原子本身是精确 Fourier 基元素，无尾项。有限个字符的线性组合也无尾项；若字符数量无界，则不是固定复杂度模板，进入 `CE` 或 DSO/PI 新增频率包分支。

## 3. 有限布尔组合的尾项稳定性

设每个原子写成 `a_i=m_i+r_i`，其中主项 `m_i` 是有限频率组合，尾项 `r_i` 满足

`Σ_k ||r_{i,k}||_2^2 < ∞`。

对固定数量原子的并、交、差，可用乘法和加法展开。由于所有指标和主项在 `L^∞` 中有固定界，含至少一个尾项的误差由

`C_T Σ_i ||r_{i,k}||_2`

控制。用 Cauchy 和固定原子数得

`Σ_k ||R_k||_2^2 <= C_T Σ_i Σ_k ||r_{i,k}||_2^2 < ∞`。

因此固定复杂度布尔闭包保持平方可和。若布尔深度或原子数增长，则进入 `CE/LSMP`。

## 4. 与 DGap 盒有限重叠的兼容

DGap 盒是

`B=I ∩ Layer(Q,R) ∩ Ω`。

其中 `Layer(Q,R)` 只是 dyadic 外标签，不产生 Fourier 尾项；`I` 与 `Ω` 的尾项已由第 2--3 节控制。盒族有限重叠给

`Σ_B 1_B(n) <= log^C X`。

因此所有盒尾项在能量估计中最多多损失 `log^C X`，仍保持平方可和或 `X^{o(1)}` 可吸收。若有限重叠失败，则按 `docs/rh-pc4-dual-box-overlap.md` 进入 `LV/LSMP/FCT/CE`。

## 5. 截断高度与“固定复杂度”的兼容

尾项证明允许截断高度 `H_k` 随层增长；主项频率数因此增长为 `k^O(1)`。这不破坏固定模板链条，原因是：

1. 固定模板指原始几何/CRT 规则固定，不要求近似多项式的截断项数固定；
2. 截断项数的多项式增长只作为误差控制工具，不作为新的自由频率证书；
3. 若某个高频尾项本身承载固定比例异常，则它不再是尾项，而是进入 `CE/LSMP` 或新增独立频率包，由 DSO/PI 桥接处理。

因此平方可和截断方案与固定复杂度模板不冲突。

## 6. 统一尾项定理

**Theorem Fourier-Vaaler-Tail-Uniform（条件化统一尾项定理）。** 对正式 RH/PC4/DGap 审稿包中使用的任一固定复杂度盒模板，存在一组平滑参数 `η_k` 与截断高度 `H_k`，使该模板分解为有限频率主项与尾项：

`ψ_k = ψ_{k,main}+ψ_{k,tail}`，`Σ_k ||ψ_{k,tail}||_2^2 < ∞`。

若该分解失败，则失败必然属于以下已命名终端之一：`Complexity-Escape`、`LSMP`、`LV`、`SC`、或新增独立频率包的 `DSO/PI` 分支。

**证明。** 模板原子由第 1 节列出。平滑窗、硬边界、倒数环带、Bohr 短弧和 CRT 字符分别由第 2 节处理。固定布尔组合由第 3 节保持平方可和。DGap 盒的有限重叠由第 4 节保证能量求和中只损失多对数因子。第 5 节说明增长截断高度只属于近似工具，不改变原始模板复杂度。若任一条件失败，其失败类型正是第 1、2、4、5 节列出的已命名终端。证毕。

## 7. 对总攻割集的影响

本文消除了 DGap 低维抽取中“Fourier/Vaaler 尾项平方可和或进入 CE/LSMP”的跳步。当前 DGap 外部接口主要剩下：

1. `FCT phase drift/closure` 的无无限递归排除；
2. 上游解析输入、外部引用和容量常数的最终标准化。
