# 锚因子二阶复用能量硬攻稿

**状态：** 深入锚列表内部矛盾场；目标是形成复用供需不等式。

## 1. 基本复用方程

固定列 `c` 与锚因子 `q`。若 `q` 同时锚定两个粗候选行号 `k_i,k_j`，则

`q | k_iP+c` 且 `q | k_jP+c`。

相减得

`q | (k_j-k_i)P`。

因 `(q,P)=1`，所以

`k_j-k_i = m q`。

因此同一锚因子的复用行号严格构成步长 `q` 的等差子序列。

在粗候选短邻域中，由于 `q>sqrt(P)`，复用必须跨越至少 `sqrt(P)`；实验进一步显示最小复用比值常为 `2q`，这是因为同一列同一锚下相邻命中若间隔 `q`，中间乘积商结构经常被小素数阻断。

## 2. 复用冷却定理

严格可证版本：

**Cooling-1.** 每个锚 `q>sqrt(P)` 在行方向复用后，需要至少 `q` 的冷却距离。即在任意长度 `<q` 的窗口中最多命中一次。

因此在长度 `T` 的区间中，锚 `q` 最多命中

`1+T/q`

个粗候选点。

## 3. 扫描结果

新增脚本：`experiments/anchor_reuse_energy_scan.py`。

代表列中观察到：

- 粗候选数约 `P/log P`；
- 空锚列表数量占相当比例；
- 锚出现次数 `anchor_occ` 与粗候选数同阶但小于粗候选数；
- 锚复用能量存在，但复用次数通常很低，最大复用约 `5--8`；
- 复用间距比 `gap/q` 的最小值为 `2.0`。

这说明真实系统远未达到“所有粗候选列表非空”的反例要求。

## 4. 列反例下的供需方程

令 `R` 为粗候选集合，`N=|R|`。令锚列表大小为 `a_k=|L(k)|`。

列反例要求

`a_k>=1` 对所有 `k in R`，

故

`A:=Σ_{k in R} a_k >= N`。

真实扫描中 `A<N`，缺口正是素数数量；但证明不能直接使用真实素数。

把总锚出现按锚因子分组：

`A=Σ_q n_q`，

其中 `n_q` 是锚 `q` 命中的粗候选数。

Cooling-1 给

`n_q <= 1+P/q`。

## 5. 一阶上界不足

求和得

`A <= Σ_{sqrt(P)<q<P} (1+P/q)`，

该量太大，因为包含大量没有命中粗候选的锚 `q`。真实可用锚必须满足某个命中值 `k≡r_q(c)` 本身是粗候选。

因此需要二阶筛掉不可用锚：锚 `q` 可用不仅要求命中列，还要求命中点避开所有小素数，即落在粗候选骨架中。

## 6. 可用锚密度修正

对固定 `q`，其命中行号为

`k=r_q + nq`。

这些点落入粗候选集合的概率/密度约为

`δ_D=prod_{p<=sqrt(P)}(1-1/p) ≈ 1/log P`。

所以锚 `q` 的有效命中数应约为

`δ_D(1+P/q)`。

若能无条件证明上界

`n_q <= C δ_D(1+P/q)+error_q`

并求和，则

`A <= C δ_D Σ_{q>D}(1+P/q)`。

这仍约为 `C P/log P`，与 `N≈δ_D P` 同阶。需要常数上严格小于 `N` 才能矛盾，难度很高。

## 7. 二阶复用能量缺口

考虑复用能量

`E=Σ_q binom(n_q,2)`。

若列反例成立且 `A>=N`，在可用锚种类数 `Q_eff` 不足时，必须有复用：

`E >= (A^2/Q_eff - A)/2`。

另一方面 Cooling-1 与粗候选密度给上界：

`E <= Σ_q binom(δ_D(1+P/q)+error_q,2)`。

目标是证明下界大于上界。

实验中真实 `E` 很小，说明复用不足以填补空列表缺口。

## 8. 显式矛盾不等式候选

令

`N=|R|`, `Q_eff=# {q>D: q hits at least one rough candidate}`。

列反例要求 `A>=N`。由 Cauchy，

`E >= (N^2/Q_eff - N)/2`。

若能证明

`Q_eff <= (1-η)N`

且同时

`E <= η' N`

其中参数满足

`(N^2/Q_eff - N)/2 > η'N`，

则矛盾。

扫描中 `Q_eff=distinct_anchor` 明显小于 `N`，而 `E` 约为 `O(N)`。这条路线有希望。

## 9. 下一步可证义务

需要证明两条：

1. **有效锚种类不足：** `Q_eff <= (1-η)N`。直觉：许多粗候选是素数，反例假设下这条不能直接用；必须由锚可用同余与粗候选骨架证明。
2. **复用能量线性上界：** `E <= η'N`，来自 Cooling-1 与粗候选间隔谱。

若两者闭合，则列反例的锚列表非空假设产生二阶能量矛盾。

## 10. 当前诚实边界

目前已严格证明 Cooling-1 与短邻域互斥；已实验支持 `Q_eff<N` 与 `E=O(N)`。但无条件证明 `Q_eff <= (1-η)N` 仍是核心硬点，它本质上要求说明锚因子同余命中不能覆盖全部粗候选。

下一步应专攻 `Q_eff` 上界，从锚因子 `q` 的命中点也必须避开小素数的 CRT 约束出发，证明有效锚种类有固定比例损耗。

## 11. Q_eff 损耗推进

已新增：`docs/qeff-loss-hard-attack.md` 与 `experiments/qeff_loss_structure_scan.py`。

扫描中最难列仍有明显 `Q_eff/N` 损耗，例如 `P=503` 最难约 `0.57`，`P=251` 最难约 `0.63`。这支持二阶能量路线。

下一步不再只看数量，而是攻“近乎完美匹配不可能”：若 `Q_eff≈N` 且列反例成立，则几乎每个粗候选必须由唯一锚颜色单次命中，形成小筛粗候选骨架到锚素数同余图像的近乎完美匹配。需要证明这种匹配与粗候选 gap 谱/CRT 小筛骨架不兼容。
