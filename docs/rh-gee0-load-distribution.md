# GEE-0 负担分配不等式：从异常账本到出口负担

本文专攻 `docs/rh-global-exit-exclusion-target.md` 中的第一步 GEE-0。目标不是证明各出口上界，而是严格证明：PC1--PC2--C3--C4/C5 后剩下的 `Δ` 级同向异常，必须被有限出口集合的负担量覆盖。

## 1. 统一权重原子

固定成功尺度 `X`、平滑权 `W` 与 PC1 给出的符号 `σ`。所有账本均使用同一 Chebyshev 权

`w_X(n)=Λ(n)W(n/X)`

或由它诱导的粗合数候选权。对任一事件集合 `S`，写

`Mass(S)=Σ_{n∈S} |w_X(n)|`，

`Bias(S)=σΣ_{n∈S}(w_X(n)-w_X^0(n))`。

这里 `w_X^0` 是对应 CRT 零频基线权。统一权重后，所有 dyadic pigeonhole、Vaaler 截断与证书分解只允许产生 `log^C X` 损失，归入 `X^{o(1)}`。

## 2. 异常原子集合

由 PC1 和 PC2，存在同向粗合数候选异常账本 `𝓐_X`，满足

`Bias(𝓐_X) >= c_0Δ-o(Δ)`。

更具体地：

- 过疏分支中，`𝓐_X` 是 `B_z-B_z^0` 的正异常原子；
- 过密分支中，`𝓐_X` 是 `ACC^0-ACC` 或 `DGap=Hole^0-Hole` 的正异常原子；
- 边界、素数幂、平滑尾项、CRT 残周期误差合并为 `Err_0=o(Δ)`。

GEE-0 的任务是对 `𝓐_X` 构造一个路由映射到出口集合。

## 3. 出口集合与路由映射

出口集合固定为

`𝓔={A,PI,FCT,SC,LV,LSMP,CE,DSO,NRC}`。

定义部分路由映射

`R: 𝓐_X -> 𝓔 ∪ {Abs}`，

其中 `Abs` 表示已经由平凡误差、尾项平方可和或 CRT 边界吸收的原子。路由规则：

1. `ACC` 正向过剩原子路由到 `A`；
2. `Hole` 正向异常原子路由到 `LV/LSMP/CE` 或基线/证书完备接口；
3. `OV` 复用原子先经 AAI 双锚正规形；低体积/边界/复杂度失败路由到 `LV/LSMP/CE/SC`，稳定可检测主层路由到 PPI 输出 `NRC/FCT/PI/SC/DSO/LV/LSMP/CE`；
4. `DGap` 原子经盒局部化和投影分配，路由到 `A/PI/FCT/SC/LV/LSMP/CE/DSO/NRC`；
5. Fourier/Vaaler 尾项若平方可和，路由到 `Abs`；若承载固定比例异常，按 C9 路由到 `CE/LSMP/LV/SC/FCT/DSO/PI`。

这些规则正是 C3、C4、C5、C9 的合并事件表。

## 4. 负担量定义

令 `𝓐_E={a∈𝓐_X:R(a)=E}`。定义出口负担

`Load(E;X)=Σ_{a∈𝓐_E} |bias(a)|`。

若某原子按多个模板被重复记录，按归一化拆分权重 `θ_{a,E}>=0`，满足

`Σ_E θ_{a,E} <= log^{C_route}X`，

并定义

`Load(E;X)=Σ_a θ_{a,E}|bias(a)|`。

为了得到无对数污染的最终 GEE-0，可把 `log^{C_route}X` 吸收到 `X^{o(1)}`，即允许

`Σ_E Load(E;X) >= c_0Δ/log^{C_route}X`。

由于 `Δ=X^{β-o(1)}`，这仍可重写为 `X^{β-o(1)}` 级异常。若最终出口上界均为 `o(X^{β-o(1)})`，矛盾仍成立。

## 5. GEE-0 分配定理

**Theorem GEE-0-Load-Distribution（负担分配定理）。** 假设 PC1 同向异常、PC2 基线、C3 覆盖划分、C4 过疏路由、C5 过密路由和 C9 尾项路由均成立，并且所有路由有限重叠损失为 `log^{C_route}X`。则存在常数 `c_1>0`，使无穷成功尺度上

`Σ_{E∈𝓔} Load(E;X) >= c_1 Δ/log^{C_route}X - o(Δ)`。

等价地，按 `X^{o(1)}` 记号，

`Σ_{E∈𝓔} Load(E;X) >= X^{β-o(1)}`。

**证明。** PC1 与固定符号子列给 `Δ` 级同向素数异常；PC2 把它转成粗合数候选异常，边界误差为 `o(Δ)`。C3 把粗合数异常分解到 `ACC/Hole/OV` 或对偶 `DGap`。C4 证明过疏 `OV` 原子必经 AAI/MLC/PPI 路由到出口集合；C5 证明过密 `DGap` 原子必经盒/投影/低维抽取路由到出口集合；C9 证明尾项要么平方可和吸收，要么同样进入出口集合。除 `Abs` 中 `o(Δ)` 误差外，每个异常原子至少被一个出口接收，至多被 `log^{C_route}X` 个模板重复记录。按第 4 节定义的拆分负担求和，即得结论。证毕。

## 6. GEE-0 的剩余审稿义务

GEE-0 已把“分支覆盖”变成明确负担分配不等式，但顶刊闭合仍需补两个量化细节：

1. **PC2 边界误差完全内联**：必须把 `Err_0=o(Δ)` 逐项写出，而不能只引用“CRT 基线”。
2. **路由有限重叠常数表**：需要对 C4/C5/C9 中每个 dyadic、盒、频率包、短弧模板给出统一 `C_route`。

这两个义务比九个出口上界简单；它们属于 bookkeeping 和常数管理，不是新的结构分支。

## 7. 对 GEE 总目标的影响

GEE-0 证明后，最终 RH 反例矛盾场只剩九个出口上界。下一步最优攻坚为：

1. `GEE-LV`：逐入口列出 `Vol_eff` 并证明低体积负担为 `o(Δ)`；
2. `GEE-NRC`：完成 `EXT-KL` 参数匹配，证明非共振倒数和负担为 `o(Δ)`。
