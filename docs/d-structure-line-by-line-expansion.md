# D 组压缩证明逐行展开附录

本附录专门补强 `docs/d-structure-formal-appendix.md` 中被最终复核标出的四个压缩点：OMR 几何误差归因、CGTP 平方能量增量、LSMP 方向筛选与薄层偏移、FCT 短深度 span 计数。本文仍保留诚实边界：本附录完成组合与能量部分的逐行展开；解析输入仍由 `EXT-KL` 与 NRC 附录承担。

## 1. 公共定义

令 `(X,w)` 为有限加权集合，`r=sum_X w(x)`。一个节点 `v` 带有有限分割 `𝓟_v`。对 `A in 𝓟_v`，记

`μ(A)=sum_{x in A}w(x)`, `μ_geo(A)` 为对应几何模型质量，`ρ(A)=μ(A)/μ_geo(A)`。

允许窗口族 `𝓦_v(K)` 满足三条闭包性质：

1. 有限并差闭包：至多 `K` 个基本窗口的并差仍属于复杂度 `Klog^C K`；
2. 有限重叠选择：任意窗口族有 disjoint 子族，其固定扩大覆盖原族且重叠度 `<=C`；
3. Fourier 可测：每个窗口指标有高度 `H<=Klog^C K` 的 Vaaler 逼近，误差 `O(H^{-1})`。

高投影增量定义为：存在 `W in 𝓦_v(K')` 使

`μ(W) >= (1+δ) μ_geo(W)`, `δ >= κΛ^2/log^8K`。

短簇定义为：存在允许尺度以下的弧或 Bohr 交集承载 `>=cΛr/log^C K` 的偏差质量。frequency-closure terminal 定义同 `docs/fct-tree-wfe-theoremization.md`。

## 2. OMR 几何误差归因展开

**Lemma D10（偏差分解恒等式）。** 对任一允许窗口 `W`，实际偏差可分解为

`μ(W)-μ_geo(W)=E_alg(W)+E_geom(W)`,

其中 `E_alg(W)` 是非零 Fourier 频率贡献，`E_geom(W)` 是 Vaaler 截断和边界误差。

**证明。** 用 Vaaler 多项式 `1_W=P_W+R_W`，其中 `P_W` 含零频与非零频，`sum_X w R_W` 与 `int R_W dμ_geo` 组成边界误差。零频项正是 `μ_geo(W)`；非零频项为 `E_alg(W)`；余项为 `E_geom(W)`。逐项相减得到恒等式。证毕。

**Lemma D11（无增量推出点态偏差上界）。** 若没有高投影增量，则对所有 `W in 𝓦_v(K')`，有

`μ(W)-μ_geo(W) < δ μ_geo(W)`, `δ=κΛ^2/log^8K`。

**证明。** 这是高投影增量定义的否定。若某 `W` 违反该不等式，则它本身就是高投影增量窗口。证毕。

**Lemma D12（分散偏差必须进入代数误差）。** 设有限重叠窗口族 `𝓤` 满足

`sum_{W in 𝓤}|μ(W)-μ_geo(W)| >= B`, `mult(𝓤)<=C0`。

若无高投影增量且 `sum_W |E_geom(W)| <= B/4`，则

`sum_{W in 𝓤}|E_alg(W)| >= B/4`。

**证明。** 由 Lemma D10，`|偏差|<=|E_alg|+|E_geom|`。求和得 `B<=sum|E_alg|+sum|E_geom|`。代入几何误差上界 `B/4`，得到 `sum|E_alg|>=3B/4`，特别大于 `B/4`。证毕。

**Lemma D13（NRC 吸收代数误差）。** 在非共振背景下，对复杂度 `K'` 的有限重叠窗口族 `𝓤`，有

`sum_{W in 𝓤}|E_alg(W)| <= C K' P^{1/2} log^C P`。

**证明。** 每个 `E_alg(W)` 是有限个非零频率倒数相位和。窗口复杂度给频率个数 `<=K'log^C P`，有限重叠防止同一质量重复超过常数次。对每个非共振频率调用 NRC，即 `EXT-KL` 完成和界；求和得到所述上界。证毕。

**Proposition D14（OMR 逐行输出）。** 若一阶偏差产生总层偏差 `B>=cΛr/log^C K`，且无短簇、无高投影增量、无 frequency-closure terminal，则矛盾；因此 OMR 必输出三终端之一。

**证明。** 无短簇时，Vitali 选择给有限重叠窗口族 `𝓤`，仍承载 `B` 量级偏差。无高投影增量给 Lemma D11。Vaaler 截断高度取入常数包，使几何误差和 `<=B/4`。由 Lemma D12，代数误差和 `>=B/4`。若非共振，Lemma D13 给上界 `C K'P^{1/2}log^CP`，被主吸收条件压到 `<B/4`，矛盾。若不非共振，则进入 FCT，违背无 frequency-closure terminal。故三终端之一必须发生。证毕。

## 3. CGTP 平方能量展开

**Lemma D15（两子块方差公式）。** 父块质量为 `M`，几何子块比例为 `α in (0,1)`。若子块密度为 `ρ(1+δ)`，总父密度为 `ρ`，则细分后的归一化平方能量增量为

`ΔE = ρ^2 M * αδ^2/(1-α)`。

**证明。** 子块质量为 `αM`，密度 `ρ_1=ρ(1+δ)`。质量守恒给互补密度 `ρ_2=ρ(1-α(1+δ))/(1-α)=ρ(1-αδ/(1-α))`。能量增量等于

`αM(ρ_1-ρ)^2+(1-α)M(ρ_2-ρ)^2`。

代入 `ρ_1-ρ=ρδ` 与 `ρ_2-ρ=-ραδ/(1-α)`，化简得公式。证毕。

**Lemma D16（投影增量给能量下界）。** 若 `α<=1/2` 且 `αM=m`，则

`ΔE >= ρ^2 m δ^2`。

若 `α>1/2`，则改用互补窗口得到同阶下界，至多损失绝对常数。

**证明。** 当 `α<=1/2` 时，由 Lemma D15，`α/(1-α)>=α`，故 `ΔE>=ρ^2Mαδ^2=ρ^2mδ^2`。当 `α>1/2`，互补块比例 `<1/2`，密度下降幅度为 `ραδ/(1-α)`，其方差贡献仍为 `>=cρ^2Mδ^2`，而 `m` 与 `M` 同阶。证毕。

**Proposition D17（CGTP 有限步逐行版）。** 若每个非终端步骤提供窗口质量 `m_j>=c r_j/log^8K` 与增量 `δ_j>=κΛ^2/log^8K`，且 `ρ_j` 归一化后有统一下界，则路径长度满足

`T <= C log^16K/Λ^4`。

**证明。** 由 Lemma D16，每步能量增量

`ΔE_j >= c r_j Λ^4/log^16K`。

生成树只在剩余质量子块上继续，归一化账本把 `r_j` 计入当前节点能量单位；沿单路径求和时，父子能量增量正交相加，不重复计数。总能量由 martingale `L^2` 上界不超过初始 `r`。若步数超过右端，下界和超过 `r`，矛盾。证毕。

## 4. LSMP 方向筛选展开

**Lemma D18（能量到同向偏移）。** 设小质量原子族的平方能量贡献 `E_small` 超过 `A`。则存在符号选择 `σ in {±1}` 与子族 `𝓐_σ`，使其线性偏移总量至少 `c A^{1/2} M^{1/2}`；在 D 组参数归一化下，若 `E_small>CΛ^2r/log^8K`，则同向偏移 `>=cΛr/log^C K`。

**证明。** 写每个原子的密度偏移为 `u_A`。平方能量为 `sum μ(A)u_A^2`。按符号分成正负两族，至少一族承载一半平方能量。Cauchy--Schwarz 的逆用法给 `sum_{A in 𝓐_σ} μ(A)|u_A| >= (sum μ(A)u_A^2)^{1/2}(sum μ(A))^{1/2}`。代入参数归一化即得。证毕。

**Lemma D19（同向偏移到薄层族）。** 若同向偏移总量 `>=B`，则存在 dyadic 厚度层与有限重叠薄层族 `𝓑`，使该族仍承载 `>=cB/logK` 的同向偏移。

**证明。** 按厚度 dyadic 分层，层数 `O(logK)`。平均原理给一层承载 `>=B/O(logK)`。对该层取 maximal disjoint 子族并固定扩大，有限重叠只损失绝对常数，得到结论。证毕。

**Proposition D20（LSMP 逐行吸收）。** 在无短簇、无高投影增量、无 frequency-closure terminal 且 NRC 可吸收时，`E_small<=CΛ^2r/log^8K`。

**证明。** 反设 `E_small` 超界。Lemma D18 给同向偏移 `>=cΛr/log^C K`。Lemma D19 抽出薄层族并保留 `>=cΛr/log^C K` 的偏移。若薄层质量集中在允许尺度以下，则为短簇。若某薄层实际密度超过几何密度 `1+κΛ^2/log^8K`，则为高投影增量。否则所有薄层偏移只能来自非零频代数误差；非共振时由 NRC 吸收，共振时进入 FCT。四种可能均与非终端假设矛盾。证毕。

## 5. FCT span 计数展开

**Lemma D21（短深度 span 复杂度）。** 设每层最多新增 `B0` 个频率，允许整数倍频高度 `H<=log^C K`，短记忆深度 `h<=ClogK`。则单节点可见 span 描述复杂度至多 `log^{C'}K`。

**证明。** 单节点只保存最近 `h` 层的生成元，但递推规则把低维闭包基约化为秩 `d<=d0` 的基；每个新频率若独立则增加秩，若相关则记录整数系数。秩超过 `d0` 时由 Parseval/能量账本触发高投影或短簇终端，故非终端路径上 `d<=d0`。每个系数大小 `<=H`，描述数至多 `(2H+1)^{d0}`，即 `log^{C'}K`。证毕。

**Lemma D22（碰撞累积触发闭包）。** 若连续 `M>C log^8K` 次 NRC 失败且未产生独立新频率，则这些频率落在同一低维 span，路径进入 frequency-closure terminal。

**证明。** NRC 失败按定义表示当前频率属于短深度祖先 span。若没有独立新频率，则低维基不变，只是系数记录增加。Lemma D21 给非终端可记录的不同系数型数量 `<=Clog^8K`。超过该数量后，鸽巢原理给同一低维 span 内的重复闭包模式；按 frequency-closure terminal 定义，后续频率均由该 span 控制，触发终端。证毕。

**Proposition D23（FCT 逐行闭合）。** NRC 失败分支不能无限延续而不产生短簇、高投影增量或 frequency-closure terminal。

**证明。** 每次 NRC 失败，要么产生独立新频率，要么发生碰撞。独立新频率次数受 Parseval 能量约束，否则多个正交方向的一阶能量和超过 `r`，给高投影增量或矛盾。碰撞次数由 Lemma D22 控制，过多则触发 frequency-closure terminal。因此失败分支有限，且必进入合法终端。证毕。

## 6. D 组强化闭合定理

**Theorem D+（D 组逐行展开闭合）。** 在 `EXT-KL` 与 NRC 附录成立、A/B 到 D 标准形式匹配成立、Tail-log4 削尾成立、常数吸收表成立的前提下，D 组非终端坏配置不存在。

**证明。** 一阶偏差由 OMR 输入给出。Proposition D14 说明若无短簇和 FCT，则必有高投影增量。高投影增量由 Proposition D17 在有限步内耗尽平方能量。小质量逃逸由 Proposition D20 吸收。NRC 失败由 Proposition D23 进入 FCT。于是任何非终端路径都不可能无限延续；若假设坏配置无三终端，则得到能量矛盾。证毕。

## 7. 对最终复核的影响

本附录补强了最终复核中列出的 D 组四个压缩点，但仍不自动解决另外三类义务：

1. Lemma M5 覆盖缺口的全显式不等式；
2. Tail-log4 中 BG/RKS 分区与外部定理编号的逐块匹配；
3. 常数吸收表到抽取器不等式的逐项编号化。

因此本轮推进应更新复核状态为“D 组压缩证明已进一步逐行展开；顶刊无条件标准剩余集中于 M5、BG/RKS 和常数编号化”。
