# 离线零点、素数计数超界波动与方阵/CRT 矛盾场

本文件专门展开一个更直接的 RH 反例入口：若存在离线零点，则 `π(x)-Li(x)` 或短区间素数计数必然出现超平方根级波动。`Li(x)` 是平滑确定基线，故这种波动意味着实际素数集合出现过密或过疏。问题是：能否把这种过密/过疏投影到本文方阵与 CRT 刚性系统中，压制出直观可见的矛盾？

结论先行：离线零点确实会通过显式公式造成 Chebyshev/prime counting 的超界振荡；但要形成本文式矛盾，还必须证明这种全局过密/过疏不能被均匀摊到所有 CRT 类中，而必在某些有限方阵/CRT 投影中形成覆盖缺口或覆盖过剩。这正是 RH-1C/ACC 路线的核心。

## 1. 离线零点到素数计数超界

若 `ζ(s)` 有零点 `ρ=β+iγ`，`β>1/2`，显式公式给

`ψ(x)-x = -Σ_ρ x^ρ/ρ + lower terms`。

通过选择一列 `x_j` 使该零点相位相干，可得到

`|ψ(x_j)-x_j| >= x_j^{β-o(1)}`。

在适当平滑或通过 partial summation 后，通常也会反映到 `π(x)-Li(x)` 的异常振荡：存在过密区间或过疏区间，使实际素数个数偏离平滑基线超过 RH 允许的平方根级。

直观上：

- 若 `π(x)-Li(x)` 大正，素数过密，合数覆盖留下的空洞过多；
- 若 `π(x)-Li(x)` 大负，素数过疏，合数覆盖过强，必须有异常多的合数解释填满候选。

两种方向都应能进入覆盖矛盾场。

## 2. 从全局区间到方阵截面

把区间 `[1,x]` 或短区间 `[x,x+H]` 切成宽为 `P` 的方阵行列，等价于按模 `P` 和行号分层。若某区间素数过疏，则许多局部窗口中素数少于 CRT 零频基线；若过密，则许多窗口中素数多于基线。

方阵行列定理提供一个硬下界：每个 `P×P` 方阵的每行和每个非第 `P` 列都至少有一个素数。这说明素数不能完全消失在任何行/列截面中。虽然这只是很弱的局部存在性，但它排除了极端过疏的局部集中方式。

更强的是论文中形成的结构体系：若某窗口接近全合数覆盖，就会触发 A/B -> M5 -> D 组矛盾场。因此过疏不能通过“局部全遮蔽”实现，只能分散为许多接近临界的覆盖增强；这种分散又会产生能量账本压力。

## 3. 过疏情形的矛盾场

假设存在短区间 `I=[x,x+H]`，素数数量比 `Li` 基线少

`Δ(I) >= H^{1/2+η}`。

这意味着筛余候选中有额外 `Δ(I)` 个位置被合数覆盖解释占据。将这些位置投影到宽 `P≈H^{1/2}` 或某个根基尺度的圆柱方阵中：

1. 小因子锁定层由 CRT 基线决定，不能任意增加；
2. 尾部锚由 Tail-log4 削薄，不能承担 `H^{1/2+η}` 级同步过剩；
3. 主体双粗锚若承担过剩，会在某些行/列/斜截面上产生高覆盖密度；
4. 高覆盖密度超过零频基线后，由 M5 迫出一阶偏差；
5. D 组终端排斥该偏差的稳定存在。

因此，过疏反例需要大量合法合数覆盖容量同步增加。ACC 不同步引理正是要证明这种同步增加不可能。

## 4. 过密情形的矛盾场

若素数过密，表示合数覆盖留下过多空洞。投影到方阵后，有许多截面素数数量异常高。这本身不违反“每行至少一个素数”，但它会违反 CRT 周期内类素数密度的刚性波动结构：非零同余类交集在列方向均衡，局部高峰必须由其他位置的低谷补偿。

若高峰来自 zeta 离线零点的长程相干波动，则补偿低谷也应在相邻尺度出现。于是过密情形会转化为过疏情形：全局振荡有正峰必有负峰。只要负峰可被排斥，正峰也被排斥。

因此 RH 反例的核心可集中处理过疏峰值。

## 5. Li(x) 平滑基线与 CRT 零频基线

`Li(x)` 是连续平滑基线；CRT 零频基线是有限同余系统中的离散平滑基线。要连接二者，需要证明：在尺度匹配 `P,z,M_y` 后，

`Li` 的局部期望 ≈ CRT 非零类零频期望 + 可控边界误差。

这不是自动的。它需要一个 **Li-to-CRT baseline lemma**：平滑素数主项在方阵/CRT 分解中按非零类均匀分布，误差小于目标超界波动。

若该引理成立，`π-Li` 的超界波动就能转化为 CRT 覆盖缺口或覆盖过剩。

## 6. 可见矛盾点在哪里

最直观的矛盾点不是“某行没有素数”，因为 RH 反例造成的波动可能远弱于制造整行无素数。真正可见的矛盾点是：

> 若过疏波动超过平方根级，则合数覆盖容量必须在许多局部截面中同步高于 CRT 零频基线；但合法覆盖容量由小因子均衡、尾部削薄、大因子互斥和 D 组能量递推共同限制，无法产生同相位的长程同步过剩。

也就是说，方阵行列存在性提供最底层的“不可全遮蔽”刚性；更重要的是它背后的证明机制提供“不可长期接近全遮蔽”的能量约束。

## 7. 下一步可证命题

### PC-1：离线零点到短区间过疏

若 `β>1/2`，则存在平滑短区间权 `W((n-X)/H)`，使素数权偏差 `<=-H^{1/2+η}` 或 `>=H^{1/2+η}`。

这是显式公式与平滑权选择问题。

### PC-2：Li-to-CRT baseline

平滑主项 `Li` 在 primorial CRT 非零类分解中给出零频基线，误差小于 `H^{1/2+η}`。

这是连续基线到离散基线的桥。

### PC-3：过疏到 ACC 过剩

若某区间素数过疏，则 `AllowedCompositeCover` 必须超过其期望至少同阶。

这是素数计数缺口到合数覆盖过剩的翻译。

### PC-4：ACC 过剩排斥

`AllowedCompositeCover` 不能在无穷多尺度上产生离线零点相位的超平方根过剩。

这是 ACC 不同步引理。

PC-1 到 PC-4 串联，即给出 RH 反例矛盾场。

## 8. 当前最优攻坚点

在四个命题中，PC-1 属经典显式公式，PC-4 是本文局部刚性机器的延伸。最关键的新桥是 PC-2 与 PC-3：

- PC-2 确保 `Li(x)` 的平滑基线真的对应 CRT 零频基线；
- PC-3 确保素数过疏真的要求合数覆盖容量过剩，而不是被权重转换误差吞掉。

下一步应优先攻 PC-3，因为它最贴近 Buchstab 覆盖权 `ω_z^B` 与 `AllowedCompositeCover` 的构造。

## 9. 结论

用户提出的直觉是正确的方向：离线零点若存在，必然表现为实际素数计数相对 `Li(x)` 的超界过密/过疏；而 `Li(x)` 是平滑确定基线。这种超界波动应当在有限方阵/CRT 模型中表现为筛余空洞或合数覆盖容量的异常。

但可见矛盾不一定是某个方阵行或列直接无素数，而更可能是许多截面的合数覆盖容量必须同步超出合法范围。本文已有行列存在性是底层刚性；真正通向 RH 的，是把这种底层刚性升级为跨尺度覆盖容量不能同步模拟离线零点波动的定理。
