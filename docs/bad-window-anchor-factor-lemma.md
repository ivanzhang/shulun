# 坏窗口锚因子引理：关于“两个因子 > P”的修正与强化

**状态：** 回应并转化用户提出的关键直觉。

## 1. 首先严格澄清尺度

在 `P×P` 方阵内，任意数

`N=kP+c`, `0<=k<P`, `1<=c<P`

满足

`N<P^2`。

因此若 `N=ab` 且 `a>P`、`b>P`，则

`ab>P^2`，矛盾。

所以在方阵内不可能存在“双因子都 `>P`”的合数。

这说明命题“坏窗口中必存双大因子 `>P` 的粗合数”不能作为证明目标；它若为真会直接矛盾，但事实上该对象不存在。

## 2. 正确的可用版本：双因子都大于 `sqrt(P)`

粗合数的真实结构是：所有素因子都大于 `sqrt(P)`，但至少一个因子必须小于 `P`。例如

`N=uv<P^2`, `u>sqrt(P)`, `v>sqrt(P)`。

此时 `u` 或 `v` 可以大于 `P`，但不可能二者都大于 `P`。

因此每个粗合数必有至少一个锚因子

`sqrt(P)<u<P`。

称这样的 `u` 为列覆盖锚因子。

## 3. 锚因子覆盖方程

若 `u` 是 `N=kP+c` 的锚因子，则

`u | kP+c`，即

`k ≡ -c P^{-1} mod u`。

因为 `u>sqrt(P)`，在任意长度 `<sqrt(P)` 的坏窗口中，该锚因子最多命中一个行号。

因此坏窗口内 `m` 个粗合数需要至少 `m` 个互异锚因子。

这正是大因子受限着色模型的颜色。

## 4. 锚因子的上界也很强

由于 `N<P^2` 且 `u>sqrt(P)`，配对因子

`v=N/u < P^2/u < P^{3/2}`。

若进一步 `u>P/λ`，则

`v<λP`。

所以越靠近 `P` 的锚因子，配对因子越被压到 `O(P)` 尺度。这给乘法匹配带来高度约束。

## 5. 坏窗口不存在的错误强形式

坏窗口存在的实验已经明确：例如 `P=1009` 有长度 `31` 窗口含 `8` 个粗候选且全为粗合数。

所以不能证明“坏窗口在 `P` 方阵内不存在”。正确目标是：

> 坏窗口可以存在，但坏窗口不能串接覆盖整个粗候选大簇；否则锚因子资源与局部不可复用约束矛盾。

## 6. 锚因子资源不等式目标

设粗候选大簇 `R_c` 全部为粗合数。为每个 `k in R_c` 选择一个锚因子 `u(k)`，满足

`sqrt(P)<u(k)<P`, `u(k)|kP+c`。

局部刚性：若 `|k-l|<sqrt(P)`，则

`u(k)≠u(l)`。

同余刚性：固定 `u` 只能覆盖行号

`k≡r_u(c) mod u`。

因为 `u>sqrt(P)`，在整列 `[0,P)` 内每个 `u` 覆盖至多 `ceil(P/u)<sqrt(P)+1` 个点，且这些点间距为 `u`。

目标是证明不存在这样的选择函数 `u(k)` 覆盖整个粗候选大簇。

## 7. 下一步最硬点：受限列表着色

把每个粗候选点 `k` 的可用锚因子集合定义为

`L(k)={u: sqrt(P)<u<P, u|kP+c}`。

若 `kP+c` 是素数，则 `L(k)=empty`；若是粗合数，则 `L(k)` 非空。

列反例等价于：每个粗候选点 `k` 都有非空列表 `L(k)`。

而局部互斥说：距离 `<sqrt(P)` 的点不能选择同一颜色。

所以要证明列命题，等价于证明：粗候选大簇中必有某个 `k` 的列表为空。

这仍是原命题，但现在内部结构已被压成列表着色/锚因子资源问题。下一步应证明列表非空假设导致锚因子资源过密。

## 8. 锚列表压力推进

已新增：`docs/anchor-list-coloring-pressure.md` 与 `experiments/anchor_coloring_pressure_scan.py`。

关键等价：在粗候选集合上，`L(k)=empty` 当且仅当 `kP+c` 为素数。因此列反例等价于所有粗候选锚列表非空。

扫描显示真实列中空列表很多，且局部窗口空列表常占多数。简单一阶锚容量与粗候选数量同阶，不能直接矛盾；下一步必须攻二阶复用能量：若所有列表非空，锚因子必须复用，但复用间距至少为锚因子本身且受粗候选大簇位置限制。
