# PC1 Landau--Ingham 主文链：离线零点到平滑素数窗口异常

本文把 PC1 中剩余的 Landau--Ingham 振荡接口写成可并入主文的链条。PC1 的目标是：若 ζ 存在离线零点 `ρ_0=β+iγ`, `β>1/2`，则存在平滑权 `W`、符号 `σ` 与无穷尺度 `X_j`，使

`σ(Ψ_W(X_j)-X_j\widehat W(1)) >= X_j^{β-o(1)}`。

本文不宣称 RH 已证明；它闭合的是总攻链条的上游解析输入口径。有限边界零点情形给文内证明；一般上确界或无限边界族情形精确归入经典 `EXT-PC1-LI`。

## 1. 平滑显式公式输入

取 `W∈C_c^∞((0,∞))`，Mellin 变换为 `\widehat W(s)`。平滑 Chebyshev 和

`Ψ_W(X)=Σ_n Λ(n)W(n/X)`

满足文内已证显式公式：

`Ψ_W(X)=X\widehat W(1)-Σ_ρ X^ρ\widehat W(ρ)+低阶项`。

若 `ρ_0=β+iγ` 是离线零点，可选取 `W` 使 `\widehat W(ρ_0)≠0`。令

`R_W(X)=Ψ_W(X)-X\widehat W(1)`, `u=logX`。

则 `R_W(e^u)` 含有可见项 `c_0e^{(β+iγ)u}`。

## 2. 有限边界零点：文内振荡证明

假设可见零点的最大实部为 `β`，且实部等于 `β` 的可见零点有限。显式公式给

`e^{-βu}R_W(e^u)=T(u)+o(1)`，

其中

`T(u)=Σ_{Reρ=β} c_ρe^{iγ_ρu}`

是非零有限三角多项式。

非零有限三角多项式满足均方平均

`liminf_{U→∞} U^{-1}∫_0^U |T(u)|^2du >0`。

因此存在 `η>0` 与无穷 `u_j→∞`，使 `|T(u_j)|>=η`。取实部或虚部中较大者，并取固定正负号子列，得到某个 `σ∈{±1}` 使

`σ R_W(e^{u_j}) >= c e^{βu_j}`。

这给出 `X_j^β` 级平滑窗口异常。

## 3. 一般情形：LI-General 精确接口

若同实部可见零点无限，或 `β` 是可见离线零点实部的上确界，有限三角多项式不能覆盖。此时使用经典奇点振荡定理。

**Theorem LI-General / EXT-PC1-LI（经典 Landau--Ingham 奇点振荡）。** 设误差项 `R(X)` 的 Mellin/Laplace 变换在边界 `Re s=β` 有不可消除奇点，且测试权不湮灭该边界奇点族。若不存在更右侧可见奇点，则 `R(X)` 不可能在所有大尺度上为 `o(X^β)`；若 `β` 由一列奇点实部逼近，则存在无穷多尺度满足

`|R(X)| >= X^{β-o(1)}`。

该定理是标准外部解析输入，可引用 Landau oscillation theorem、Ingham 振荡定理或 Titchmarsh 中 ζ 零点推出 Chebyshev 函数振荡的标准推论。本文只使用其平滑 Mellin 版本。

## 4. 固定符号子列

LI-General 给出无穷多尺度的绝对值下界。将这些尺度按 `R_W(X_j)` 的实数符号分成正负两类，至少一类无限。取该类，即得固定符号 `σ` 满足

`σ R_W(X_j) >= X_j^{β-o(1)}`。

若显式公式先给复值振荡，则取实部或虚部的非零线性投影；这只改变平滑权的有限线性组合，不改变紧支撑平滑性。

## 5. 素数幂与权重口径

显式公式自然作用于 von Mangoldt 权。素数幂贡献满足

`Σ_{m>=2,p^m≈X} logp · W(p^m/X) = O(X^{1/2}log^C X)`，

而 `β>1/2`，故这是 `o(X^{β-o(1)})`。因此异常落到素数 Chebyshev 权上。若后续链条使用无权素数计数，在固定 multiplicative 窗口内 `logp=logX+O(1)`，除以 `logX` 只产生对数损失，吸收到 `X^{o(1)}`。

## 6. PC1 主文定理

**Theorem PC1-Landau-Ingham-Maintext。** 若 ζ 存在离线零点 `ρ_0=β+iγ`, `β>1/2`，则存在平滑紧支撑权 `W`、符号 `σ` 与无穷尺度 `X_j`，使

`σ(Ψ_W(X_j)-X_j\widehat W(1)) >= X_j^{β-o(1)}`。

有限边界零点情形由本文第 2 节文内证明；一般上确界或无限边界族情形由 `EXT-PC1-LI` 提供。

**证明。** 第 1 节由平滑显式公式给出可见零点项，并选取不湮灭权。若边界可见零点有限，第 2 节给三角多项式振荡。否则第 3 节调用 LI-General，随后第 4 节取固定符号子列。第 5 节去除素数幂并统一权重口径。证毕。
