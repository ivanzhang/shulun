# CRT 密度势函数与相位延迟路线

**状态：** `density_potential_added_to_phase_delay_framework`

用户指出的现象——CRT 周期中部附近高类素数密度、末端附近高合数密度——应作为相位势函数加入矛盾场。实验进一步发现一个精确镜像刚性：

`A(r)=A(M+1-r)`。

这说明密度剖面不是随机波动，而是由 CRT 对称性控制。

## 1. 势函数定义

令

`A(r)=# {1<=c<P : N(r,c) 对所有 q<P 非零 mod q}`。

列均衡给出列方向守恒；镜像引理给出行方向对称：

`A(r)=A(M+1-r)`。

定义势函数

`Φ(r)=A(r)-mean(A)`。

则 `Φ` 关于周期中点为偶函数。

## 2. 零行与势阱

零行是 `A(r)=0` 的深势阱。完整 CRT 周期中可以存在零行，但它们成镜像对出现。

前窗口 `[1,P]` 没有零行，说明前端存在高度约束屏障；远端/中后段可以出现零行，说明纯 CRT 允许势阱，但高度约束延迟了第一个势阱的位置。

## 3. 与相位延迟结合

首个零行 `r_*` 是覆盖同余系统第一次完全对齐的位置。前窗口排斥即

`r_*>P`。

势函数语言中：

- 小素数同余类制造周期性低谷；
- 大素数补洞相位决定低谷是否触底为零；
- 高度约束阻止低谷在前 `P` 行触底；
- CRT 镜像保证触底后在末端出现镜像触底。

## 4. 候选引理 DP（Density Potential Barrier）

在前窗口 `1<=r<=P`，高度约束给出势函数下界：

`A(r)>=1`。

等价于目标行命题。

要证明该下界，可分解为：

`A(r)=small_sieve_survivors(r)-large_patch(r)`。

需要证明：

`small_sieve_survivors(r) > large_patch(r)`。

但这不能靠普通筛独立完成；必须加入相位延迟：大素数补洞相位在 `r<=P` 尚未完全对齐。

## 5. 下一步具体任务

围绕“最后洞相位延迟”建立可证明不等式：

1. 对每个 `x<P` 的洞集 `H(x)`，定义补洞同余集合；
2. 证明补齐 `H(x)` 的最小 CRT 解 `x_*` 满足 `x_*>=P`；
3. 将 `A(r)>=1` 解释为势垒；
4. 用镜像引理解释为什么完整周期后段允许对应势阱。

这把用户指出的中点/末端密度现象纳入了主证明框架。
