# Fourier/Vaaler 尾项主文链：固定模板平方可和与逃逸出口

本文把 RH 反例矛盾场中 DGap、PPI 与 PC4 模板使用的 Fourier/Vaaler 截断尾项写成可并入主文的统一链条。目标是证明：固定复杂度模板的尾项可以平方可和吸收；若不能吸收，则必进入 `CE/LSMP/LV/SC/DSO/PI` 等已命名出口，而不是成为新的误差通道。

本文不宣称 RH 已证明；它闭合的是 Fourier/Vaaler 尾项接口。外部 Vaaler 定理的精确引用仍需在最终参考文献中给出。

## 1. 固定模板原子

正式总攻链只允许以下模板原子：

1. 平滑物理窗或 dyadic Whitney 窗；
2. 硬边界物理窗的平滑替代；
3. dyadic 层标签 `Q,R`；
4. CRT 字符原子；
5. 倒数环带 `ξx^{-1} mod p in I`；
6. Bohr 短弧或短区间原子；
7. 固定次数的有限并、交、差和有限线性组合。

若出现无界多坐标、无界布尔深度、无界关系高度或非 dyadic 端点堆叠，则不属于固定模板族，直接进入 `CE/LSMP`。

## 2. 单原子尾项控制

平滑物理窗的 Fourier/Mellin 系数快速衰减。取截断高度 `H_k>=k^4`，尾项满足

`||Tail_k||_2 <= C_AH_k^{-A}`，

故平方可和。

硬边界先以宽度 `η_k` 平滑。边界层贡献为 `O(η_k^{1/2})`，截断尾为 `O((H_kη_k)^{-1})`。取

`η_k=k^{-4}`, `H_k=k^8log^Ck`，

得 `||Tail_k||_2=O(k^{-2})`，平方可和。若边界层承载固定比例异常，则进入 `LV/LSMP/SC`。

倒数环带和 Bohr 短弧用 Vaaler 多项式逼近。平滑后尾项满足

`||Tail_k||_2 <= C(H_k^{-1}+η_k^{1/2})`，

同样平方可和。若短弧或边界数量超过固定复杂度，则进入 `CE`；若边界集中承载异常，则进入 `SC/LV`。

CRT 字符原子是精确 Fourier 基元素，无尾项。若字符数量无界，则进入 `CE` 或新增独立频率包的 `DSO/PI` 分支。

## 3. 布尔组合稳定性

设每个原子写为

`a_i=m_i+r_i`，

其中 `m_i` 为有限频率主项，`r_i` 满足

`Σ_k||r_{i,k}||_2^2<∞`。

固定数量原子的并、交、差可由加法和乘法展开。所有指标与主项在 `L^∞` 中有固定界，含至少一个尾项的总误差满足

`||R_k||_2 <= C_TΣ_i||r_{i,k}||_2`。

由 Cauchy 与固定原子数，

`Σ_k||R_k||_2^2 <= C_TΣ_iΣ_k||r_{i,k}||_2^2<∞`。

故固定复杂度布尔闭包保持平方可和。

## 4. 与 DGap 盒有限重叠兼容

DGap 盒形如

`B=I ∩ Layer(Q,R) ∩ Ω`。

其中 dyadic 标签无 Fourier 尾项，`I` 与 `Ω` 的尾项已由前两节控制。盒族有限重叠给

`Σ_B1_B(n)<=log^C X`。

因此盒尾项在能量估计中最多多损失 `log^C X`，仍为 `X^{o(1)}` 可吸收。若有限重叠失败，则由 DGap 主文链进入 `LV/LSMP/FCT/CE/SC`。

## 5. 截断高度不产生新自由度

截断高度 `H_k` 可随层增长，多项式数量的主项频率只是近似工具，不改变原始几何/CRT 模板的固定复杂度。若某个高频尾项自身承载固定比例异常，则它不再被当作尾项，而按其结构进入：

- `CE/LSMP`：复杂度或小质量逃逸；
- `DSO/PI`：新增独立频率包；
- `FCT`：频率落入祖先短深度 span；
- `SC/LV`：边界或短窗集中。

## 6. 尾项主文定理

**Theorem Fourier-Vaaler-Tail-Maintext。** 对本文总攻链中任一固定复杂度 PPI/DGap/PC4 模板，存在平滑参数 `η_k` 与截断高度 `H_k`，使

`ψ_k=ψ_{k,main}+ψ_{k,tail}`, `Σ_k||ψ_{k,tail}||_2^2<∞`。

若该分解不能保持平方可和，则失败必然进入 `CE/LSMP/LV/SC/FCT/DSO/PI` 中的已命名出口。

**证明。** 第 1 节列出所有允许原子。第 2 节逐个处理平滑窗、硬边界、倒数环带、Bohr 短弧和 CRT 字符。第 3 节证明固定布尔组合保持平方可和。第 4 节说明 DGap 盒有限重叠只造成多对数损失。第 5 节处理截断高度增长和高频尾项异常的命名出口。故结论成立。证毕。
