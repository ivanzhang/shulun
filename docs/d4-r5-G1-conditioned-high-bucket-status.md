# D4/R5 G1 条件化高桶补偿状态

**状态：** `high_bucket_compensation_alone_insufficient_need_low_high_coupling`

本轮对 `low_sum>3/5` 分支做了条件化 QP 分族：

- B 类：`tau_33_59` 非空、`heavy_short` 为空；
- C 类：`heavy_short` 非空；
- 近危险族中暂未出现 A 类 `tau_33_59=heavy=0`。

## 发现

实际数据中高桶密度补偿很强：

- B 类观测到 `d5/d4 >= 1.47799`；
- C 类观测到 `d6/d4 >= 2.00115`。

但严格 QP 松弛显示：只加入高桶补偿仍不足。原因是优化器会继续把质量在低三桶中摊平，同时只给高桶保留很小质量；因此能量仍可能低于 `1/64`。

## 已排除

- `low>=3/5 + d4/d3>=8/5` 不足。
- `low>=3/5 + d4/d1>=5` 不足。
- B 类加入 `d5/d4>=7/5` 或 `3/2` 仍不足。
- C 类仅靠远程高桶补偿也不足。

## 新的核心接口

需要证明低高耦合，而不是单独密度斜率：

> 当 `low_sum>3/5` 时，高桶质量不能只是“密度高但质量极小”；必须有一个高桶质量下界，或低三桶内部不能按 Cauchy 最优比例摊平。

候选形式：

- B 类：`m5 >= beta_B * (low_sum-3/5)` 或 `m5 >= beta'_B`；
- C 类：`m6 >= beta_C * (low_sum-3/5)` 或 `m6 >= beta'_C`；
- 低桶反摊平：`d2/d1` 与 `d3/d2` 至少一段严格大于 `3/2`，且增强量与 `low_sum-3/5` 成正比。

## 下一步

反解最小耦合常数：

- 对 B 类，在 QP 中加入 `m5 >= beta`，反解最小 `beta`；
- 对 C 类，在 QP 中加入 `m6 >= beta`，反解最小 `beta`；
- 再比较实际数据中 `m5,m6` 的最小值，寻找可证明的有理安全常数。
