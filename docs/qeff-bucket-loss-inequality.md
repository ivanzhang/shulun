# Q_eff 分桶损耗不等式攻坚稿

**状态：** 有效锚种类不足的分桶机制。

## 1. 分桶定义

令 `D=sqrt(P)`。按锚大小分桶：

`B_j={q prime: 2^j D < q <= 2^{j+1}D}`。

对每个桶定义：

- `Possible_j`：该桶中在列窗口 `[0,P)` 至少命中一次的潜在锚数；
- `Effective_j`：其中实际命中粗候选骨架的有效锚数；
- `Occ_j`：该桶锚命中粗候选的总出现次数。

## 2. 扫描事实

新增脚本：`experiments/qeff_bucket_loss_scan.py`。

典型结构：

- 低桶 `j=0,1`：有效率接近 `1`，但桶内锚数量很少；这些锚复用次数较高；
- 中桶：有效率开始下降；
- 高桶：潜在锚数量多，但有效率显著低，且每个有效锚几乎只出现一次。

例如 `P=2003`：

- `j=0`: `9/9` 有效；
- `j=1`: 约 `16/17` 有效；
- `j=3`: 约 `24--34 / 56` 有效；
- `j=4`: 约 `29--42 / 96` 有效；
- `j=5`: 约 `19--23 / 81` 有效。

所以 `Q_eff` 损耗来自高桶；低桶虽高效但数量不足。

## 3. 分桶机制解释

锚 `q` 在列中命中约 `P/q` 次。若 `q` 在第 `j` 桶，则

`P/q ≈ sqrt(P)/2^j`。

命中点要成为粗候选，还要避开所有 `p<=D` 的小素数，密度约 `δ≈1/log P`。

所以期望有效命中数约

`λ_j≈ P/(q log P) ≈ sqrt(P)/(2^j log P)`。

当 `λ_j>>1`，该桶锚几乎都有效；当 `λ_j<1`，有效率约 `λ_j`，显著小于 1。

临界桶满足

`2^j ≈ sqrt(P)/log P`。

高于临界桶，锚很多但多数无效。

## 4. 候选上界

对桶 `j`，有效锚数应满足

`Effective_j <= Possible_j * min(1, C sqrt(P)/(2^j log P))`。

而

`Possible_j≈ #B_j≈ 2^j D / log(2^jD)`。

因此高桶贡献约

`Effective_j <= C P/(log P log(2^jD))`，

但受桶数和区间上界限制。求和后得到

`Q_eff <= β N`

其中 `N≈δP≈P/log P`，`β<1` 需要精细常数。

## 5. 为什么可能有固定比例损耗

粗候选数 `N` 由所有行点经过小筛得到，密度约 `δ`。

锚颜色则还要经过额外条件：某个素数 `q>D` 的同余命中点落入粗候选骨架。高桶锚大多只有 0 或 1 个行命中，因此要有效必须“命中即落入粗候选”，概率约 `δ`。这造成大量潜在颜色丢失。

低桶锚虽然多次命中，几乎有效，但低桶素数总量约 `D/log D`，只占 `N≈P/log P` 的 `1/sqrt(P)` 量级，无法填满 `Q_eff`。

固定比例损耗来自两端夹击：低桶数量少，高桶有效率低。

## 6. 待证分桶上界 QBL

**QBL.** 对任意列 `c`，有效锚种类数满足

`Q_eff <= β N + O(sqrt(P))`

其中存在绝对常数 `β<1`。

证明路线：

1. 用线性筛给 `N` 下界；
2. 对低桶直接用素数计数给数量上界；
3. 对高桶用小筛过滤给有效率上界；
4. 优化分界点得到 `β<1`。

## 7. 当前硬点

第 3 步需要一个上界筛：锚命中点落入粗候选骨架的次数不能超过期望常数倍。也就是对序列

`r_q+nq`

避开所有小素数的计数做上界。该序列长度约 `P/q`，模小素数仍均匀，因为 `(q,p)=1`。

这是标准筛上界型问题，比原始最小等差素数弱得多，可能可用 Brun/ Selberg 上界筛闭合。

## 8. 筛上界审查与修正

已新增：`docs/qeff-sieve-upper-bound-route.md`。

结论：单纯用上界筛证明 `Qeff<=βN` 可能过硬。分桶筛显示：

- 低桶数量少但有效率高，且复用高；
- 高桶有效率低，可由筛上界控制；
- 中桶需要用复用能量付费。

因此更自然的目标是联合分桶不等式：

`Qeff - τE <= βN`

或等价地，低/中桶若贡献很多 `Qeff`，必须同时贡献复用能量 `E`；高桶则由筛损耗控制。
