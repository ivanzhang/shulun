# PC4-SC-Seed：短簇跨尺度排斥种子命题

本文转攻 PC4 剩余主分支 `PC4-SC`。短簇表示覆盖偏差、overlap、低体积尾项或投影能量集中在少数短窗口/低维 Bohr 交集中。PC4-SC 的目标是证明离线零点级短簇不能在无穷多尺度保持同相位相干。本文先写种子命题：若无穷多短簇作为最终通道，则可抽取固定短簇形状、固定锚层/相位类型与同相位子列。

## 1. 单尺度短簇输入

在现有主链中，短簇可由多处产生：

- OV2/MLC 中低容量尾层或不可检测正交质量集中；
- PC4-PI 中小质量窗口族承载高投影增量；
- PC4-FCT 中低维 Bohr 交集反复承载偏差；
- PC4-A 中 `low/tail` 或低体积分支承载 ACC 过剩。

统一抽象为：存在短窗口或低维 Bohr 交集 `S_X`，使

`Mass(S_X) >= c X^{β-o(1)}`, `β>1/2`,

并且该质量与离线零点相位同向。

## 2. 短簇类型

短簇类型由以下有限数据描述：

1. 物理短窗长度 `L_X` 的相对阶；
2. dyadic 锚层 `Q,R` 或尾层参数；
3. 低维 Bohr/倒数相位切片的频率类型；
4. 允许覆盖组件来源：ACC、PI、FCT、OV2 或 LV；
5. 平滑权与边界厚度。

若短簇复杂度无界，则按 Complexity-Escape/FCT/LSMP 处理，不作为 SC 主通道。

## 3. 固定短簇类型抽取

**Lemma SC-1（短簇类型 pigeonhole）。** 若无穷多尺度出现离线零点级短簇，且复杂度不逃逸，则存在无穷子列与固定短簇类型 `𝓢_*`，使每个短簇都是 `𝓢_*` 的自然缩放实例。

**证明。** 按短窗长度相对阶、锚层、Bohr 频率类型、来源组件与边界厚度分层。固定复杂度预算内类型有限；无穷多个尺度落入有限类型之一。若类型复杂度无法固定，则进入 CE/FCT/LSMP。证毕。

## 4. 同相位短簇抽取

**Lemma SC-2（短簇同相位抽取）。** 若短簇质量由固定离线零点频率 `γ` 驱动，则存在无穷子列，使

`γlogX_j mod 2π`

落入固定短弧，且短簇偏差符号同向。

**证明。** 圆周有限分割。短弧足够小时，同一零点项的符号稳定；若多零点相干主导，则进入 PC4-Dual/多频接口。证毕。

## 5. SC 种子命题

**Proposition PC4-SC-Seed（固定短簇同步种子）。** 若短簇可作为 RH 反例链条的最终逃逸通道，并排除 PC4-PI、PC4-FCT、PC4-A、LSMP/LV 与复杂度逃逸，则存在：

1. 固定短簇类型 `𝓢_*`；
2. 固定离线相位短弧 `I_*`；
3. 无穷尺度子列 `X_{j_k}`；
4. 固定短窗/Bohr 交集模板 `S_*`；

使 `S_*` 的自然缩放实例在这些尺度上同向承载 `X^{β-o(1)}` 级偏差。

**证明。** 由 SC-1 固定短簇类型；由 SC-2 固定离线相位短弧。若无法固定模板，则进入复杂度逃逸、FCT 或 LSMP；若短簇偏差转为可检测投影或 ACC/FCT 结构，则进入已闭合的 PC4-PI/PC4-A/PC4-FCT。排除这些分支后得到固定短簇同步种子。证毕。

## 6. 下一步核心排斥方向

PC4-SC-Seed 把短簇分支压缩为：固定短窗/低维 Bohr 交集在无穷尺度上同向承载离线零点级偏差。

下一步最优专攻是 `SC-Mass-Balance`：证明固定短簇若在无穷多尺度承载 `X^β` 级质量，则要么其零频体积可求和而由 LV/LSMP 吸收，要么不可求和并产生投影能量/ACC 同步/FCT 闭包，转入已闭合分支。
