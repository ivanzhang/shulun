# OV2-PPI：相位推送无条件化定理

本文把 `docs/rh-ov2-phase-pushforward-interface.md` 中可无条件化的部分抽成代数/傅里叶定理：双锚正规形 `n=q_1q_2r` 在固定局部模数和投影方向下产生倒数相位；有限复杂度窗口检测可用 σ-代数层蛋糕完成；窗口指标可由有限 Fourier/Vaaler 截断展开为倒数指数和。NRC 上界、主层容量和不可检测质量控制不在本文证明范围内，仍分别由 NRC/MLC/FCT 接收。

## 1. 双锚到倒数相位的代数推送

设 AAI 给出同层双锚正规形

`n=q_1q_2r`, `q_i~Q`, `r~R`, `(q_1q_2,p)=1`。

固定一个局部工作素模 `p` 与线性投影方向。由同余约束解列相位时，得到形如

`Θ(q_1,q_2;r)=a(r)q_1^{-1}+b(r)q_2^{-1}+γ(r) mod p`。

**Lemma PPI-U1（倒数相位正规形）。** 在固定 `r` 与投影方向后，双锚相位是两个倒数坐标的仿射函数；若 `a(r),b(r)` 不全为零，则该相位在 D 组倒数环带窗口族中非退化可见。

**证明。** 覆盖条件是线性同余。解含有锚变量的线性同余时，因 `(q_i,p)=1`，锚变量以逆元 `q_i^{-1}` 出现；固定尾因子和投影方向后，其余项并入系数 `a,b,γ`。若两系数不全为零，至少有一个倒数坐标实际影响相位。证毕。

## 2. 有限窗口检测

令 `ν` 为双锚原子推送到相位空间后的有限正测度，`ν^0` 为零频基线。令 `𝓦(K')` 为由倒数环带、短弧、Bohr 切片及其有限并差生成的复杂度 `K'` 窗口族。

**Lemma PPI-U2（有限复杂度检测）。** 若某个由 `𝓦(K')` 生成的有限 σ-代数原子集合承载总偏差 `B`，则存在窗口 `A∈𝓦(K'')`，`K''<=K'log^C X`，使

`|ν(A)-ν^0(A)| >= cB/log^C X`。

**证明。** 将该 σ-代数的偏差集合分解为有限个基本原子。若每个可由 `𝓦(K'')` 表示的并差窗口偏差都小于右侧，则所有原子的偏差总和小于 `B`，矛盾。Vitali/有限重叠选择只损失 `log^C X`。证毕。

## 3. Fourier/Vaaler 展开

对短弧或环带窗口 `A`，取截断高度 `H` 的 Vaaler 展开：

`1_A(t)=|A|+Σ_{0<|h|<=H} c_h e_p(ht)+Rem_H(t)`。

代入 `t=Θ(q_1,q_2;r)` 得非零项

`e_p(h a(r)q_1^{-1}) e_p(h b(r)q_2^{-1}) e_p(hγ(r))`。

**Lemma PPI-U3（窗口偏差的倒数和展开）。** 对任意 `A∈𝓦(K')`，偏差 `ν(A)-ν^0(A)` 可写成有限线性组合的单/双变量倒数指数和，加上截断误差。若 `a,b` 中一者为零，则退化为单变量倒数和；若二者均为零，则该窗口对当前方向不可见。

**证明。** 对每个基本短弧/Bohr 条件作 Fourier/Vaaler 展开；有限并差由有限线性组合和乘积展开处理。将 PPI-U1 的相位代入即可。截断误差由 Vaaler 余项给出。证毕。

## 4. 共振/非共振分流

**Lemma PPI-U4（相位窗口三分）。** 若 PPI-U2 给出可见窗口 `A`，则 PPI-U3 的倒数和展开必落入以下之一：

1. 非零频率不在祖先短深度 span 中，进入 NRC/EXT 完成和接口；
2. 非零频率落入祖先短深度 span，进入 FCT；
3. 截断误差或窗口复杂度不可控，进入 CE/LSMP 或 MLC 的低容量接口。

**证明。** 对 Fourier 频率集合按是否属于祖先短深度 span 分类。非共振部分正是 NRC 处理对象；共振部分定义上就是 FCT 证书；若需要无限复杂度或不可控尾项才能表示窗口，则不属于固定复杂度 PPI，而进入复杂度/低体积逃逸。证毕。

## 5. PPI 无条件主定理

**Theorem PPI-Unconditional-Core（相位推送无条件核心）。** 在 AAI 双锚正规形和固定复杂度窗口族下，以下结论无条件成立：

1. 双锚 overlap 原子可推送为单/双倒数相位；
2. 任一 D 组可检测偏差给出有限复杂度窗口偏差；
3. 任一窗口偏差可展开为单/双变量倒数指数和；
4. 该倒数和按非共振、FCT 共振、复杂度/截断逃逸三分。

**证明。** 第 1 项为 PPI-U1；第 2 项为 PPI-U2；第 3 项为 PPI-U3；第 4 项为 PPI-U4。证毕。

## 6. 与 OV2 的边界

PPI 已无条件化的是“相位推送的代数与有限 Fourier 检测”。仍待无条件化的部分是：

1. **MLC**：证明大 overlap 能量必处于 PPI 可检测主层，或转入 LV/SC/FCT；
2. **NRC/EXT**：对 PPI 产生的非共振倒数和给出完成和上界；
3. **D 组终端**：将窗口偏差最终送入 OMR/CGTP/LSMP/FCT。

因此 PC3-OV2 的 AAI 与 PPI 两块已降为代数/傅里叶定理；下一步应继续攻 MLC 主层容量接口。
