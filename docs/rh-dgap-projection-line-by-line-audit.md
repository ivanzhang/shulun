# DGap 投影正交化逐行强度审查

本文专攻 `docs/rh-pc4-dual-projection-orthogonalization.md` 的最硬接口：从分散 `DGap` 正质量盒族推出允许投影能量，或转入低维频率/短簇/低体积/误差逃逸。重点修补两点：Gram 下界的 frame 形式，以及 `V_PI/V_low/V_err` 不是天然正交直和时如何用正交投影链处理。

## 1. 盒函数 frame 上界

设归一化盒函数为

`φ_B=(1_B-E_0 1_B)/||1_B-E_0 1_B||_2`。

有限重叠给 Bessel/frame 上界：对任意系数 `c_B`，

`||Σ_B c_B φ_B||_2^2 <= L_X Σ_B |c_B|^2`, `L_X=log^C X`。

**证明。** 扣除常数方向后只会减小点态重叠主项的贡献，并增加一个秩一项；该秩一项由 `Σ|c_B|^2` 控制。盒指标满足 `Σ_B1_B(n)<=L_X`，故乘法算子族的 Gram 矩阵行和由 `L_X` 控制。Schur 或 Cotlar 型估计给算子范数 `<=L_X`。证毕。

## 2. Frame 下界到投影能量

由 frame 上界可得对任意 `h`：

`||P_V h||_2^2 >= L_X^{-1} Σ_B |<h,φ_B>|^2`。

**证明。** 令分析算子 `T h=(<h,φ_B>)_B`。第 1 节说明 `T^*T` 在 `V` 上算子范数 `<=L_X`。由于 `T h=T(P_Vh)`，有

`Σ|<h,φ_B>|^2=||T(P_Vh)||_2^2<=L_X||P_Vh||_2^2`。

移项即得。证毕。

## 3. 常数方向剥离

`<h,1_B>` 与 `<h,φ_B>` 的差异来自常数方向 `E_0 1_B`。若常数方向贡献主导，则

`|<h,1>|` 或对应 CRT 零频基线误差达到 `cΔ`，这违反 PC2 基线 `C_z-C_z^0=o(Δ)` 或进入已命名基线接口失败。

因此在非基线失败假设下，存在子族仍满足

`Σ_B |<h,φ_B>|^2 >= log^{-C}X Σ_B H(B)_+^2/μ^0(B)`。

该步骤把原文中的“常数方向已由 PC2 排除”改为可审查的二分。

## 4. Cauchy 能量下界

若 `Σ_B H(B)_+>=cΔ` 且 `Σ_B μ^0(B)<=X^{1+o(1)}`, 则

`Σ_B H(B)_+^2/μ^0(B) >= c^2Δ^2 / X^{1+o(1)}`。

结合第 2、3 节，得到

`||P_Vh||_2^2 >= X^{2β-1-o(1)}`。

该下界只用有限重叠、PC2 常数方向剥离和 Cauchy，不依赖 PI/FCT closure。

## 5. 非正交三分的正确处理

原文写 `V=V_PI⊕V_low⊕V_err`。严格地说，这三者不必天然正交。应改为按闭子空间逐步正交投影：

1. 先投影到 `V_PI`。若 `||P_{V_PI}h||_2^2` 承载固定比例，进入 PI；
2. 否则令 `h_1=P_Vh-P_{V_PI}P_Vh`，在 `V∩V_PI^⊥` 中继续；
3. 投影到低频/低体积闭包 `V_low`。若承载固定比例，按类型进入 FCT/SC/LV/LSMP；
4. 剩余部分定义为 `V_err`，由模板尾项、复杂度逃逸或边界误差组成，进入 CE/CapacityFail。

由于每步都是正交投影，能量不会被重复计算；有限多步后若没有任一部分承载固定比例，则总能量与第 4 节下界矛盾。

## 6. 逐行补强定理

**Theorem DGap-Projection-LineByLine。** 在 DGap 盒有限重叠、PC2 常数方向剥离、固定复杂度模板一致性和非 SC/LV 假设下，分散 `DGap` 正质量必满足以下至少一项：

1. `V_PI` 承载 `X^{2β-1-o(1)}` 级投影能量，触发 PI；
2. `V_low` 承载固定比例能量，触发 FCT/SC/LV/LSMP；
3. `V_err` 承载固定比例能量，触发 CE/CapacityFail；
4. PC2 常数方向基线失败。

**证明。** 第 1--4 节给 `||P_Vh||_2^2` 下界。第 5 节用逐步正交投影把该能量分配到 `V_PI`、`V_low`、`V_err` 或常数方向。四种情形穷尽。证毕。

## 7. 对无条件化路线图的影响

本审查把 DGap 投影正交化中最弱的“直和分解”表述替换为 frame 上界 + 逐步正交投影。剩余硬点从“投影正交化是否成立”缩小为：

1. `V_low` 中低维频率抽取到 FCT 的强度；
2. `V_err` 中复杂度/尾项是否全部由 CE/CapacityFail 绑定；
3. DGap 盒有限重叠的 dyadic/Bohr 模板假设是否足够统一。
