# Q_eff 有效锚种类损耗硬攻稿

**状态：** 二阶锚复用能量的关键子问题。

## 1. 定义

固定列 `c`，粗候选集合为 `R`，`N=|R|`。对每个粗候选 `k` 定义锚列表

`L(k)={q: sqrt(P)<q<P, q|kP+c}`。

有效锚种类集合为

`Q_eff={q: q in L(k) for some k in R}`。

记 `Q=|Q_eff|`，锚出现总数 `A=Σ_k |L(k)|`，复用能量

`E=Σ_q binom(n_q,2)`。

列反例要求所有 `L(k)` 非空，因此 `A>=N`。

## 2. 扫描事实

新增脚本：`experiments/qeff_loss_structure_scan.py`。

代表输出显示：

- `P=251` 中最难列 `Q/N≈0.63`；
- `P=503` 中最难列 `Q/N≈0.57`；
- 空列表数量与 `N-Q` 同量级；
- 可命中的潜在颜色很多，但大量未实际命中粗候选。

这提示存在固定比例的有效锚种类损耗。

## 3. 损耗来源一：空列表等价素数

真实数据中 `N-Q` 很大，主要来自空列表点，即素数。但列反例假设下不能直接使用空列表。因此必须从锚颜色侧解释损耗：为什么锚颜色无法覆盖全部粗候选。

## 4. 损耗来源二：锚颜色命中需过小筛

每个锚 `q` 在列中命中的行号是

`k=r_q+nq`。

要成为有效锚，至少一个命中点还必须属于粗候选，即避开所有 `p<=sqrt(P)` 的禁余类。

因此 `q` 的有效性受到一组小素数同余条件过滤。虽然 `q` 本身很多，但命中点落入粗候选骨架的概率约 `δ≈1/log P`。

## 5. 损耗来源三：锚颜色之间的碰撞

若一个粗合数有两个锚因子，则它贡献两个颜色但只覆盖一个顶点。这种多锚点造成颜色效率损失：

`A-Q` 是复用/碰撞总量，

而覆盖顶点数最多为非空列表点数。列反例若要求所有顶点非空，需要颜色命中几乎无浪费；但实际多锚与复用都制造浪费。

## 6. 候选 Q_eff 上界

目标证明存在 `η>0`，使

`Q_eff <= (1-η)N`

在列反例假设下也成立。

一个可能路径：

1. 对潜在锚 `q`，有效命中数约 `δ P/q`；
2. 多数大 `q` 只有 0 或 1 次有效命中；
3. 小锚 `q` 可多次命中，但复用冷却与短邻域互斥产生二阶能量；
4. 若 `Q_eff` 接近 `N`，则大部分颜色只能单次命中且每个顶点只有一个颜色，这迫使乘法匹配近乎完美；
5. 近乎完美匹配与粗候选小素数 CRT 骨架不兼容，因为粗候选 gap 谱高度规律，而锚命中 residue 随 `q` 分散。

## 7. 显式矛盾不等式接口

与二阶能量合并：

若 `Q_eff <= (1-η)N`，则

`E >= (N^2/Q_eff - N)/2 >= ηN/(2(1-η))`。

若 Cooling 与粗候选间隔谱给

`E <= η' N`

且 `η'<η/(2(1-η))`，则矛盾。

当前要硬攻的是两边常数：

- 从有效锚小筛过滤得到 `η`；
- 从复用冷却得到 `η'`。

## 8. 下一步

专攻“近乎完美匹配不可能”：假设 `Q_eff≈N` 且所有列表非空，则几乎每个粗候选对应唯一锚，且锚几乎不复用。这会把粗候选集合嵌入锚素数集合的同余图像。证明该图像不能等于小筛 CRT 粗候选骨架。

## 9. 谱缺口推进

已新增：`docs/near-perfect-matching-obstruction.md` 与 `experiments/near_perfect_matching_spectrum_scan.py`。

近乎完美匹配若成立，则锚命中图像的 gap 谱必须等于粗候选小筛骨架的 gap 谱。由于每条锚图像自身步长 `>sqrt(P)`，所有小 gap 都来自不同锚图像的近碰撞交错。下一步核心引理是 `Cross-linear`：有效锚图像族能产生的小 gap 交错数至多线性于 `Q_eff`。

## 10. 分桶损耗推进

已新增：`docs/qeff-bucket-loss-inequality.md` 与 `experiments/qeff_bucket_loss_scan.py`。

有效锚损耗具有清晰分桶结构：低桶锚几乎全有效但数量少；高桶锚数量多但有效率低且几乎只命中一次。候选上界为

`Effective_j <= Possible_j * min(1, C sqrt(P)/(2^j log P))`。

下一步用上界筛证明该分桶估计，并优化求和得到 `Q_eff <= βN`。
