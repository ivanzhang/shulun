# PC1 平滑显式公式文内证明附录

本文把 `EXT-PC1-EF` 改写为可直接放入论文的文内证明接口。这样 PC1 剩余外部解析输入主要压缩为 `EXT-PC1-LI` 的 Landau--Ingham 振荡定理。本文不证明 RH；只证明离线零点一旦存在，就在平滑 Chebyshev 和中出现对应零点项。

## 1. 设置

取 `W∈C_c^∞((0,∞))`，Mellin 变换

`\widehat W(s)=∫_0^∞ W(t)t^{s-1}dt`。

因 `W` 平滑紧支撑，`\widehat W(s)` 整且在任意竖线快速衰减。定义

`Ψ_W(X)=Σ_{n>=1}Λ(n)W(n/X)`。

## 2. Mellin 反演

由 Mellin 反演，对任意 `c>1`，

`W(n/X)=1/(2πi)∫_{(c)} \widehat W(s)(X/n)^s ds`。

绝对收敛允许交换求和与积分，得

`Ψ_W(X)=1/(2πi)∫_{(c)} -ζ'(s)/ζ(s) · \widehat W(s)X^s ds`。

## 3. 移线与留数

将积分线从 `Re s=c` 移到 `Re s=-A`。矩形水平边由 `\widehat W(s)` 快速衰减控制。穿过的极点包括：

1. `s=1`，来自 `-ζ'/ζ` 的简单极点，留数为 `X\widehat W(1)`；
2. 非平凡零点 `ρ`，留数为 `-X^ρ\widehat W(ρ)`；
3. 平凡零点 `-2m`，贡献为 `-X^{-2m}\widehat W(-2m)`。

因此

`Ψ_W(X)=X\widehat W(1)-Σ_ρ X^ρ\widehat W(ρ)+E_W(X)`，

其中 `E_W(X)` 包括平凡零点和新竖线积分。对固定 `W`，这些项在需要的尺度上低于任意指定主零点项 `X^β`，只贡献 `X^{o(1)}` 或更小误差；若需要完全严格形式，可保留为标准收敛误差项。

## 4. 零点项可见性

若存在离线零点 `ρ_0=β+iγ`，并取 `W` 使 `\widehat W(ρ_0)≠0`，则显式公式中含有非零项

`-X^{ρ_0}\widehat W(ρ_0)`。

权函数非湮灭由测试函数分离分布给出：若 `\widehat W(ρ_0)=0` 对所有 `W∈C_c^∞((0,∞))` 成立，则分布 `t^{ρ_0-1}` 为零，矛盾。

## 5. 显式公式命题

**Proposition PC1-Smooth-Explicit-Formula.** 对任意 `W∈C_c^∞((0,∞))`，平滑 Chebyshev 和满足

`Ψ_W(X)=X\widehat W(1)-Σ_ρ X^ρ\widehat W(ρ)+E_W(X)`，

其中零点和按平滑权收敛，平凡零点与移线误差由 `\widehat W` 的快速衰减控制。若 `\widehat W(ρ_0)≠0`，则离线零点 `ρ_0` 在误差项中产生非零 `X^{ρ_0}` 贡献。

**证明。** 第 2 节给 Mellin 反演表达，第 3 节移线取留数，第 4 节给非湮灭零点项。证毕。

## 6. 剩余外部输入

本文替代 `EXT-PC1-EF`。PC1 仍需要 `EXT-PC1-LI` 或等价的 Landau--Ingham 奇点振荡原理，用于从非零零点项推出无穷多尺度的 `X^{β-o(1)}` 大振荡。
