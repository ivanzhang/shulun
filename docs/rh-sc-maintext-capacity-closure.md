# SC 主文闭合链：短簇局部乘积容量与递归终止

本文把 RH 反例矛盾场中的 `SC` 短簇分支合成为可并入主文的闭合链。它接收来自 PPI、FCT、PI/DSO、LV 边界和 PC4 事件图中的短窗集中或高重叠输出，并证明：在 AAI 双锚正规形、局部乘积容量和已命名终端吸收口径下，SC 不能形成无限递归或独立容量黑箱。

本文不宣称 RH 已证明；它闭合的是 SC 内部递归与局部乘积容量接口。下游 `A/PI/FCT/LV/LSMP/CE` 仍需按总稿事件图接收。

## 1. SC 输入状态

短簇状态写为

`S=(I,𝓑,Q,R,κ,σ)`，

其中 `I=[x_0,x_0+L]⊂[X/2,2X]` 是物理短窗，`𝓑` 是 Bohr/CRT 相位切片，`Q,R` 是 AAI 双锚正规形

`n=q_1q_2r`, `q_1,q_2~Q`, `r~R`, `Q^2R≈X`

的 dyadic 层，`κ` 记录锚复用复杂度，`σ` 记录同相位符号和短弧类型。状态按 dyadic 网格、不可删切片、固定层代表规范化；规范代表相同的常数倍边界差异视为同一短簇模板。

## 2. 局部乘积容量

在固定短窗 `I` 与 dyadic 层 `(Q,R)` 中，双锚复用点满足

`q_1q_2r in I + boundary`。

固定 `r` 后，条件变为 `q_1q_2 in I/r`。对每个 `q_1~Q`，`q_2` 被限制在长度约 `L/(RQ)` 的短区间内，故端点和平滑损失外，固定 `r` 的候选数受

`Q(1+L/(RQ))log^C X`

控制。

全局同层双锚容量为 `RQlog^C X`。短窗只占物理尺度比例 `L/X`，因此零频比例主项为

`(L/X)RQlog^C X`。

每个 `r` 的乘积壳端点只造成多对数损失，总端点项为

`Rlog^C X`。

于是得到局部乘积容量界

`Vol_eff(I;Q,R) << (L/X)RQlog^C X + Rlog^C X`。

若比例均衡失败、端点损失集中或边界误差失控，则分别进入 `PI/A/FCT`、`SC/LV/LSMP` 或 `CE`，不作为自由 `CapacityFail`。

## 3. 低体积吸收

若

`(L/X)RQlog^C X + Rlog^C X <= X/log^B X`

且 `B` 大于后续 dyadic、Fourier、divisor 和平滑损失，则由 LV 低体积原则吸收。若该量不低，却仍承载离线零点级超额，则超额必须在固定短簇模板中表现为结构事件：`PI/A/FCT/SC` 或局部容量违反。

## 4. 短簇势函数

定义短簇势函数

`𝓥(S)=B_1ℓ(S)+B_2v(S)+B_3a(S)+B_4h(S)`，

其中：

- `ℓ(S)=ceil(log_2 L(S))` 是物理长度层；
- `v(S)=ceil(log_2(μ(𝓑)/μ_min))_+` 是到低体积阈值的体积层；
- `a(S)` 是尚未固定的锚/相位自由度；
- `h(S)` 是 dyadic 层高度预算。

取 `B_1>>B_2>>B_3>>B_4>>1`。在非终端假设下，`LV/LSMP/CE` 未触发，所有项为有下界的整数。

## 5. 更短簇单步下降

真正的 `shorter_SC` 步只可能来自四类真变化。

1. 物理缩窗：`L` 跨 dyadic 层下降，`ℓ` 降低；
2. Bohr/CRT 压缩：切片测度跨层下降，`v` 降低或触发 `LV/LSMP`；
3. 锚/相位自由度固定：`a` 降低，否则偏差在 `PI/A` 可见；
4. dyadic 剥离：`Q,R` 层变薄，`h` 降低，否则同层重复由局部乘积容量或 `PI/A/FCT` 处理。

故任何非终端真 `shorter_SC` 步都满足

`𝓥(S_{t+1}) <= 𝓥(S_t)-1`。

若四类真变化都没有发生，则新状态与旧状态是同一规范短簇模板，并非新的递归步。

## 6. 重复短簇模板出口

若同一规范短簇状态在无穷多尺度上反复同向承载离线零点级偏差，则固定短窗、固定 Bohr 切片、固定 dyadic 层和固定锚复用模板同时重复。于是必发生以下之一：

1. 偏差在允许投影 σ-代数中可检测，进入 `PI`；
2. 偏差表现为覆盖容量同向增益，进入 `A`；
3. 偏差只依赖低维相位关系，进入 `FCT`；
4. 零频体积可求和或集中到底层，进入 `LV/LSMP`；
5. 同一短窗同一 dyadic 层超过第 2 节局部乘积容量，形成容量矛盾或回到 `SC` 真变化。

因此重复短簇模板不是自由吸收通道。

## 7. SC 主文闭合定理

**Theorem SC-Maintext-Capacity-Closure。** 在 AAI 双锚正规形、dyadic 固定复杂度、局部乘积容量界、LV 低体积原则和已命名终端吸收口径下，不存在无限 `SC` 短簇递归链。任何 SC 质量若不能由局部容量或 LV 吸收，则必进入 `A/PI/FCT/LV/LSMP/CE` 或触发局部容量矛盾。

**证明。** 局部双锚复用由第 2 节容量界控制；低体积情形由第 3 节吸收。若仍发生短簇递归，则规范化状态并使用第 4 节势函数。无限链若有无限多真 `shorter_SC` 步，则由第 5 节势函数无限下降，矛盾。若只有有限多真变化，则从某时刻起重复同一短簇模板，由第 6 节触发 `A/PI/FCT/LV/LSMP/CE` 或容量矛盾，违背非终端假设。证毕。

## 8. 对全局无条件化的影响

本文把 `SC` 从剩余主硬点降为主文闭合链：短簇局部容量由显式 dyadic 乘积壳计数给出，短簇递归由离散势函数排除。下一步剩余压力主要集中到：

1. DGap 三接口的主文化合并；
2. Fourier/Vaaler 尾项平方可和；
3. `LV/LSMP/CE` 外部吸收总链；
4. PC1 一般 Landau--Ingham 输入与所有 `EXT-*` 精确引用。
