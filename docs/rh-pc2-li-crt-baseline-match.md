# PC-2：连续零频基线与 CRT 筛余零频基线匹配

本文专攻 RH 反例矛盾场路线中的 PC-2：把 PC-1 中的连续显式公式零频主项，与 PC-3 使用的 CRT 筛余候选零频基线精确对齐。核心问题是量纲匹配：`Ψ_W^0(X)=X\widehat W(1)` 是 Chebyshev 素数权主项，而 `C_z^0(X)=X\widehat W(1)φ(M)/M` 是筛余候选整数主项。二者不能直接相等，必须通过“素数自动属于筛余非零类”和“候选恒等式”连接。

## 1. 三个零频基线

取 `z=(log X)^A`, `0<A<1`，`M=P(z)=∏_{p<=z}p`。

### 1.1 Chebyshev 零频

PC-1 的 Chebyshev 权主项为

`Ψ_W^0(X)=X\widehat W(1)`。

这是 `Σ_n Λ(n)W(n/X)` 的连续零频基线。

### 1.2 无权素数零频

无权素数计数的平滑主项为

`P_z^0(X)=\widehat W(1) X/log X`

加上可选的低阶 `Li` 平滑修正。若使用 Chebyshev/Buchstab 加权接口，则保留 `Ψ_W^0`，不需要除以 `log X`。

### 1.3 CRT 候选零频

筛余候选计数为

`C_z(X)=Σ_n 1_{(n,M)=1}W(n/X)`，

其零频基线为

`C_z^0(X)=X\widehat W(1)φ(M)/M`。

由 PC3-1，

`C_z(X)=C_z^0(X)+X^{o(1)}`，

故该误差小于任意 `X^β`, `β>0`。

## 2. 素数与筛余候选的兼容性

**Lemma PC2-1（素数自动位于 CRT 非零类）。** 对充分大 `X`，若 `p∈[X/2,2X]` 为素数，则 `(p,M)=1`。

**证明。** 因 `M` 只含 `q<=z=(log X)^A` 的素因子，而 `p>X/2>z`。素数 `p` 不可能被任何 `q<=z` 整除。证毕。

因此 PC-1 的素数波动可以视为发生在 CRT 筛余候选集合内部，而不是发生在被小素数删去的类中。

## 3. 候选恒等式的基线匹配

候选集合分解为

`C_z(X)=P_z(X)+B_z(X)+Err_bd(X)`，

其中 `P_z` 为窗口内素数计数，`B_z` 为 `z`-粗合数计数，边界误差包含素数幂、端点与正规化差异。

对应零频基线定义为

`B_z^0(X)=C_z^0(X)-P_z^0(X)`。

**Lemma PC2-2（基线差分一致）。** 若 `P_z(X)-P_z^0(X)=-Δ`，且 `C_z(X)-C_z^0(X)=o(Δ)`、`Err_bd=o(Δ)`，则

`B_z(X)-B_z^0(X)=Δ-o(Δ)`。

**证明。** 直接相减：

`B_z-B_z^0=(C_z-C_z^0)-(P_z-P_z^0)-Err_bd`。

代入假设即得。证毕。

这说明 PC-2 不要求 `P_z^0=C_z^0`；正确关系是候选总基线减素数基线等于粗合数基线。

## 4. Chebyshev 权与无权基线转换

PC-1 最自然输出 Chebyshev 权异常：

`Σ_p (log p)W(p/X)-X\widehat W(1)=±X^{β-o(1)}`。

若转为无权素数计数，在 multiplicative 子窗口上 `log p=log X+O(1/log^C X)`，故

`P_z(X)-P_z^0(X)=±X^{β-o(1)}/log X`

或更保守地 `±X^{β-o(1)}/log^C X`。

由于 PC3-OV2 只要求指数超过 `1/2`，固定对数损失不改变 `β>1/2` 的性质。

**Lemma PC2-3（权重转换保持超平方根指数）。** 若 Chebyshev 权异常为 `X^{β-o(1)}`, `β>1/2`，则无权化后得到异常 `X^{β-o(1)}` 量级，允许吸收固定 `log^C X` 损失。

**证明。** 除以 `log X` 或有限子窗口 pigeonhole 只产生固定对数因子，写入 `X^{o(1)}`。证毕。

## 5. Li/连续主项到 CRT 零频的正式命题

**Theorem PC2（Li-to-CRT baseline match）。** 设 PC-1 给出某平滑窗口中的素数过疏或过密异常，幅度为 `Δ=X^{β-o(1)}`, `β>1/2`，可为 Chebyshev 权或无权版本。取 `z=(log X)^A`, `A<1`。则：

1. 该素数异常完全发生在 CRT 非零候选集合 `(n,M)=1` 内；
2. CRT 候选总量满足 `C_z=C_z^0+o(Δ)`；
3. 因而素数过疏 `P_z<=P_z^0-Δ` 等价地迫使粗合数基线差 `B_z>=B_z^0+Δ-o(Δ)`；
4. Chebyshev 权版本可接入 PC3-B，无权版本可接入 PC3-U，固定对数损失不改变 `β>1/2`。

**证明。** 第 1 项由 Lemma PC2-1。第 2 项由 PC3-1 的 CRT 候选基线，因为 `M=exp((log X)^A)=X^{o(1)}`。第 3 项由 Lemma PC2-2。第 4 项由 Lemma PC2-3。证毕。

## 6. 与 PC1、PC3-OV2 的拼接

PC-1 输出：

`离线零点 => 平滑素数异常窗口`。

PC-2 输出：

`平滑素数异常窗口 => CRT筛余候选内部的素数过疏/过密相对零频异常`。

PC3-OV2 对过疏分支给出：

`素数过疏 => 覆盖容量过剩 或 D组终端`。

过密分支有两种处理方式：若主导离线零点贡献沿反相位子列给出过疏，则回到 PC3-OV2；若存在多零点相干导致当前构造只稳定给过密，则需要另行发展“覆盖缺口过剩”对偶版本。PC-2 本身只负责基线匹配，不承担符号选择的最终矛盾。

## 7. 诚实边界

PC-2 本身是基线匹配与量纲整理，不证明最终矛盾，也不单独解决过密分支。完成 RH 路线仍需 PC-4：证明 PC3-OV2 的两个输出——覆盖容量过剩或 D 组终端——无法与 RH 反例场共存，并补齐过密对偶分支或严格反相位选择。
