# Small-label insufficiency 攻坚稿

**状态：** KFCI 最小剩余硬点；新增关键压缩：“静止小标签不能杀旧核”。

## 1. 当前剩余模型

由 KFCI 与 Boundary-orbit 推进，若仍存在静默反例，则必须是单大特征零模态：

1. 待补集合 `W=K∪R` 只有一个大特征点 `w_*`；
2. 其它点由小标签覆盖；
3. 小壳细化无释放，即 `ρ_B=0`；
4. 所有参与小标签 `l` 满足 `l<=|W|` 或 `l|(y-x)`。

记

`m=|W|, t=y-x`。

## 2. 静止小标签无杀伤引理

设 `l<P` 是小素数且 `l|t`。因为 `P` 与 `l` 互素，有

`a_l(y)-a_l(x)=-(y-x)P ≡ 0 mod l`。

所以第 `x` 行与第 `y` 行的 `l`-禁余列完全相同。

若 `c in K=H_P(x)`，则

`xP+c not≡0 mod l`。

由于禁余列不变，也有

`yP+c not≡0 mod l`。

因此：

> 任意满足 `l|t` 的小标签，不能在新行 `y` 杀灭旧核 `K` 中的任何点。

这条引理非常关键：Boundary-orbit 中允许的“`l|t` 大小标签”只是不产生边界流出，但它们也没有杀伤旧核的能力。

## 3. 剩余小标签必须全部很小

在单大特征模型中，除 `w_*` 外，旧核点 `K\{w_*}` 必须由小标签杀灭。由静止小标签无杀伤引理，这些杀核小标签不能满足 `l|t`。

而 Boundary-orbit 判据又说明，若 `l>|W|=m` 且 `l∤t`，则必有边界流出 `ρ_B=1`。

所以在静默零模态中，所有实际杀灭旧核的非大标签都必须满足

`l<=m`。

这就是小标签不足的第一层严格压缩。

## 4. 小杀核集合的容量上界

令

`L_m={l prime: l<=m}`。

静默单大特征模型要求：

`K\{w_*}` 被 `L_m` 的禁余类在行 `y` 中覆盖。

对每个 `l in L_m`，行 `y` 中只有一个禁余类

`c ≡ a_l(y) mod l`。

因此在长度为 `P-1` 的列窗口中，小杀核集合是

`U_m(y)=⋃_{l<=m} {c: c≡a_l(y) mod l}`。

旧核点同时满足

`c not≡a_l(x) mod l` 对所有 `l<=m`。

于是可杀核位置必须落在差集

`D_m(x,y)=⋃_{l<=m} A_l(y) \  ⋃_{l<=m} A_l(x)`。

其中 `A_l(z)` 是模 `l` 禁余列。

若 `l|t`，则 `A_l(y)=A_l(x)`，无贡献；因此只剩 `l<=m, l∤t`。

## 5. 小骨架边界事实

对每个 `l<=m, l∤t`，模 `l` 的禁余类从 `A_l(x)` 移到 `A_l(y)`。这不是单向删除，而是等量交换：

- 旧禁余类释放为候选；
- 新禁余类吞掉旧候选。

在一个完整模 `l` 周期中，释放数与吞噬数相等。若静默要求只吞掉 `K\{w_*}` 而不释放新洞，则每个释放类必须被其它小标签或大标签继续覆盖。

但在单大特征模型中只有一个大标签可用，其余覆盖仍来自 `L_m`。于是所有释放边界必须在小 primorial 骨架内自我吸收。

## 6. 小 primorial 骨架闭合条件

令

`M_m=prod_{l<=m} l`。

如果所有小标签释放边界都被 `L_m` 自吸收，则在 `Z/M_m Z` 上，待补/释放集合必须是小骨架平移的不变块。

换言之，`W` 必须接近 `M_m` 的完整轨道并。

但 `W` 只有 `m` 个点，而一旦 `M_m>m`，完整非平凡轨道长度超过 `m`，不可能由 `W` 承载。

对 `m>=3`，已有

`M_m=prod_{l<=m} l > m`。

因此只要小骨架迁移在 `M_m` 上非零，就必须有边界流出，即 `ρ_B=1`。

## 7. 例外：小骨架整体静止

若小骨架迁移在 `M_m` 上为零，则

`M_m | t`。

这时所有 `l<=m` 的禁余类都不变。根据静止小标签无杀伤引理，`L_m` 不能杀灭旧核任何点。

于是单大特征模型中只能由唯一大标签杀灭至多一个旧核点，无法杀灭 `K\{w_*}`。除非旧核大小为 `1`。

若旧核大小为 `1`，则行反例不是通过短差块形成，需转入列均衡/镜像或极小核基例处理；它不属于当前 SFL 短差硬点。

## 8. 得到的 Small-label insufficiency 版本

**SLI。** 设 `W=K∪R` 是 KFCI 失败模型的待补集，`m=|W|>=3`，且只有一个大特征点。若 `ρ_B=0`，则所有杀灭旧核的非大标签必须属于 `L_m`。若 `M_m∤t`，小骨架迁移非零，必有边界流出，矛盾；若 `M_m|t`，小骨架静止，不能杀旧核，仍矛盾。

因此在 `m>=3` 的短差核心中，单大特征静默零模态不可能。

## 9. 剩余小基例

SLI 还留下 `m=1,2` 的极小基例。

- `m=1`：只有一个待补点，不能构成全行反例的短差核心；需由全局列均衡或相邻块扩展处理。
- `m=2`：若只有一个大特征点，另一个点需由 `l<=2` 即 `l=2` 杀灭。若 `2|t`，奇偶相位不变不能杀旧核；若 `2∤t`，奇偶翻转产生边界流出。故 `m=2` 也闭合。

于是 SLI 对所有 `m` 闭合，前提是 `W` 确实是短差核心的完整待补/释放集合。

## 10. 对 KFCI 的影响

结合前面结果：

1. `χ_B>=2`：SFL 同步损耗启动；
2. `χ_B=0`：纯小标签静默杀核不成立；
3. `χ_B=1`：由 SLI 排除。

因此 KFCI 在短差核心模型下闭合：

`χ_B(x,y)>=2 or ρ_B(x,y)=1`。

剩余要审查的是定义层面：`W=K∪R` 是否总能选成短差核心的完整待补/释放集合。若能，SFL 唯一代表陷阱闭合；若不能，需要把全行反例分解为若干短差核心并逐块应用 KFCI。
