# 全局归一化主文闭合链：常数、尺度、符号与权重口径

本文把 RH 反例矛盾场总攻链中最后的全局归一化义务合成为主文审查链：对数常数层级、尺度变量、符号传递、Chebyshev/无权权重、`o(Δ)` 误差和事件入口。本文目标是确认：此前各主文链可以在同一套符号和常数口径下拼接，不产生循环依赖或尺度错配。

本文不宣称 RH 已证明；它完成的是全局一致性与常数层级的审稿闭合。

## 1. 全局变量约定

统一使用以下符号。

| 符号 | 含义 |
| --- | --- |
| `X` | 平滑窗口中心尺度，支撑在 `[X/2,2X]` 或固定倍区间 |
| `z` | 根基素数截断，`z=(log X)^A`, `0<A<1` |
| `M` | CRT 周期 `M=∏_{p<=z}p=exp((1+o(1))z)=X^{o(1)}` |
| `β` | 假设离线零点实部，`β>1/2` |
| `Δ` | 主异常尺度 `X^{β-o(1)}` |
| `E_z` | 素数异常 `P_z-P_z^0` |
| `B_z` | 粗合数候选账本 `C_z-P_z` |
| `ACC_z,O_z,Gap_z` | 允许覆盖、overlap 扣重、缺口账本 |
| `DGap_z` | 对偶缺口压缩 `Gap_z^0-Gap_z` |

所有固定倍平滑支撑、dyadic 层数、CRT 边界和有限重叠损失均允许进入 `X^{o(1)}`。

## 2. 符号传递

定义 `E_z=P_z-P_z^0`。PC2 给出 CRT 候选总量刚性

`C_z-C_z^0=o(Δ)`。

因此

`B_z-B_z^0=(C_z-P_z)-(C_z^0-P_z^0)=-E_z+o(Δ)`。

于是：

- 过疏 `E_z<=-Δ` 推出粗合数候选过剩 `B_z-B_z^0>=Δ-o(Δ)`，进入 PC3/OV2；
- 过密 `E_z>=Δ` 推出粗合数候选不足，进入 Dual/DGap。

统一覆盖场方程为

`-E_z=(ACC_z-ACC_z^0)-(O_z-O_z^0)+(Gap_z-Gap_z^0)+o(Δ)`。

过密时等价写为

`(ACC_z^0-ACC_z)+(O_z-O_z^0)+DGap_z>=Δ-o(Δ)`。

这固定了全稿正负号口径。

## 3. Chebyshev 权与无权口径

PC1 自然输出 Chebyshev/von Mangoldt 权。素数幂项为 `O(X^{1/2}log^C X)`，相对 `β>1/2` 的主异常可吸收。若某节使用无权素数计数，则在固定 multiplicative 窗口内

`log p=log X+O(1)`，

从 Chebyshev 权除以 `logX` 只产生固定对数损失。故全文可采用以下规则：主证明保留 Chebyshev 权；需要无权表述时，显式声明“除以 `logX`，损失并入 `X^{o(1)}`”。

## 4. 全局对数常数层级

所有接口只允许两类损失：`log^C X` 与固定复杂度 `X^{o(1)}`。常数按无循环顺序选择：

`C_struct << C_overlap << C_tail << C_frame << C_cap << C_trig << B_LV << C_0 << B_final`。

含义如下：结构复杂度、有限重叠、截断高度、frame 投影、容量损失、触发阈值、低体积余量、主层门槛、最终 pigeonhole/union-bound 余量。

依赖方向严格从左到右：后置常数只吸收前置损失，不反过来改变模板定义。若某步骤要求提高前置复杂度，则转入 `CE/LSMP`，不参与常数排序。

## 5. `o(Δ)` 稳定性

有限多个接口累计产生的总损失为 `log^{C_total}X` 或 `X^{o(1)}`。因此

`Δ/log^{C_total}X = X^{β-o(1)}`。

由于 `β>1/2`，NRC 平方根型背景、素数幂项、CRT 周期 `M=X^{o(1)}`、平滑端点和 dyadic 边界均不会吞噬主异常。任何接口若需要固定正幂损失 `X^ε`，必须列为未闭合接口；当前主文链不允许这类损失作为已吸收项。

## 6. 事件入口归一化

事件入口统一为：

- `A`：`|ACC_z-ACC_z^0|>=cΔ` 的固定模板同步；
- `PI`：允许投影窗口上有 `X^{2β-1-o(1)}` 级平方能量或等价投影增量；
- `FCT`：频率落入固定低维短深度 span 并同相位承载异常；
- `SC`：短物理窗、短 Bohr 原子或少数盒承载 `cΔ` 级质量；
- `LV`：有效体积低于主误差预算；
- `LSMP`：小质量原子/薄层族或频率原子分散；
- `NRC`：非共振完成和输入，失败转 `FCT`；
- `CE`：固定模板失败分类器；
- `DSO`：新增正交频率包 square-function；
- `CapacityFail`：必须绑定具体容量定理。

这些入口分别由当前新增主文链接收，不再允许自由回流。

## 7. 全局归一化定理

**Theorem Global-Normalization-Maintext-Closure。** 采用第 1--6 节约定后，PC1--PC2--PC3/OV2--PC4--Dual/DGap 的尺度、符号、权重、误差和常数层级一致。任一离线零点异常 `|E_z|>=Δ` 经 PC2 反号账本后，过疏进入 PC3/OV2，过密进入 Dual/DGap；两路所有后续输出均落入已命名主文链或外部引用标签，不产生尺度错配、符号反转或未登记对数损失。

**证明。** 第 1 节统一尺度，且 `M=X^{o(1)}`。第 2 节给 PC2 反号关系和覆盖场方程，固定过疏/过密入口。第 3 节统一 Chebyshev 与无权口径。第 4--5 节说明所有多对数损失按无循环层级吸收到 `X^{o(1)}`，不破坏 `Δ=X^{β-o(1)}`。第 6 节逐项登记事件入口，并由此前主文链接收。故全局拼接一致。证毕。
