# OV-2 专攻：overlap 大能量到 D 组终端的严格接口

本附录专攻 `docs/rh-pc3-formal-theoremization.md` 中留下的唯一深层接口 `OV-2`。目标是把

`E_ov(X)>X^{1+ε}`

转写为 D 组 `短簇 / 高投影增量 / FCT / NRC` 终端之一。本文给出可审查的结构化证明链条，并诚实标记最后仍需外部完成和输入的位置。它不是 RH 证明，而是 PC-3 后续最小硬点的定理化压缩。

## 1. Overlap 窗口族

沿用 PC-3 设置：`z=(log X)^A`，`M=P(z)`，`z<Q<=X^{1/2+o(1)}`。对 dyadic 锚层 `Q<q<=2Q`，真实最小锚账本只允许

`n=qm`, `q=P^-(n)`, `P^-(m)>=q`, `n~X`。

这一本账没有重复；若把同一条件同时施加到两个不同锚上，则 overlap 恒为零。因此 OV-2 必须研究的是**允许覆盖模型**的重复解释：一条斜线/一个根基锚只要求 `q|n`，不要求 `q=P^-(n)`。定义允许层重数

`ρ_Q^{allow}(n)=#{q in (Q,2Q] prime : q|n and q is an admissible covering anchor at n}`，

以及相对于真实唯一锚账本的扣重函数

`o_Q(n)=max(ρ_Q^{allow}(n)-ρ_Q^{min}(n),0)`，

其中 `ρ_Q^{min}(n)` 至多为 `1`，且仅当 `P^-(n) in (Q,2Q]` 时为 `1`。

平滑层 overlap 为

`O_Q(X)=Σ_n o_Q(n)W(n/X)`。

正规化能量为

`E_ov(X)=Σ_Q |O_Q(X)|^2/W_Q`，

其中 `W_Q` 是该层零频容量尺度。直观上，`O_Q` 大表示许多候选点被同层多个大锚重复解释；`E_ov` 大表示这种重复不是普通均匀噪声，而是集中或相干的结构异常。

## 2. OV-2 目标命题

**Proposition OV2（overlap 大能量终端）。** 假设 D 组外部输入 `NRC` 与 `FCT` 可用，且层容量满足

`Σ_Q W_Q <= Xlog^C X`。

若

`E_ov(X)>X^{1+ε}`，

则至少发生以下 D 组终端之一：

1. **短簇终端**：某个短窗口内 overlap 质量超过 D 组短簇阈值；
2. **高投影增量终端**：某个允许倒数/斜线投影窗口产生密度增量 `>=κΛ^2/log^C X`；
3. **FCT 终端**：重复解释频率落入祖先短深度 span，触发 frequency-closure；
4. **NRC 终端**：非共振频率的完成和界不足以吸收该能量，从而暴露非共振异常。

更准确地说，在 D 组排斥定理的语境中，若四种终端都被排除，则 `E_ov(X)<=X^{1+ε}`。

## 3. 第一步：dyadic 能量 pigeonhole

**Lemma OV2-1（大能量层抽取）。** 若 `E_ov(X)>X^{1+ε}`，则存在 dyadic 层 `Q` 使

`|O_Q(X)| >= X^{1/2+ε/2} W_Q^{1/2} / log^C X`。

**证明。** dyadic 层数为 `O(log X)`。若所有层均小于右侧适当常数倍，则

`Σ_Q |O_Q|^2/W_Q <= X^{1+ε}/2`，

矛盾。证毕。

该层 `Q` 以下固定。所有后续分析都在 `Q` 层内完成。

## 4. 第二步：同层 overlap 转为双锚关联

`o_Q(n)>0` 意味着 `n` 除真实最小锚外，还至少有一个额外允许锚；若同层内出现两个允许锚，则存在不同素数 `q_1,q_2 in (Q,2Q]` 使

`n=q_1m_1=q_2m_2`。

因此 `O_Q` 由允许双锚关联控制：

`O_Q(X) <= Σ_{q_1≠q_2 in (Q,2Q]} Σ_{m_1,m_2} 1_{q_1m_1=q_2m_2} W(q_1m_1/X)+O_Q^{cross}`。

其中 `O_Q^{cross}` 是“一个真实最小锚在本层、另一个额外允许锚在邻层或尾层”的交叉项。由于 `q_1,q_2` 为不同素数，等式强迫

`m_1=q_2r`, `m_2=q_1r`。

于是同层允许 overlap 的核心形态为

`n=q_1q_2r`, `q_1,q_2~Q`。

这里不再要求 `P^-(r)>=max(q_1,q_2)`；若要求该条件，就会退回真实最小锚账本并消灭 overlap。正确的刚性来自另一点：同一个 `n` 同时含有两个可用大锚，必然消耗乘积容量 `q_1q_2`，从而把 `r` 压入短尾 `r~X/Q^2`。

**Lemma OV2-2（允许双锚正规形）。** 同层允许 overlap 的主项由三因子正规形 `q_1q_2r` 控制；所有非正规项只来自跨层扣重、端点、素数幂或 dyadic 边界。跨层项要么进入相邻层同型正规形，要么作为低容量尾层吸收。

**证明。** 上述整除等式给出正规形。`q_1=q_2` 不产生重复解释。dyadic 边界通过半开区间或相邻层重分配处理。若一个锚是真实最小锚、另一个是额外允许锚，则仍得到 `n=q_1q_2r`，只是 `q_1,q_2` 可能落在相邻层；细分 dyadic 层后仍归入同型项。若 `r=1`，则 `n=q_1q_2` 是边界双素数层，容量受 `Q^2~X` 的薄层约束，低于主能量门槛或触发短簇终端。证毕。

## 5. 第三步：短簇 / 分散二分

把 `n` 轴分成长度 `H_Q` 的短窗口 `I`，其中 `H_Q` 取 D 组允许的最小投影尺度。记

`O_Q(I)=Σ_{n in I} o_Q(n)W(n/X)`。

**Lemma OV2-3（短簇二分）。** 若存在窗口 `I` 使

`O_Q(I) >= τ_Q H_Q`

超过 D 组短簇阈值，则触发短簇终端；否则 overlap 质量必须分散在至少

`N_Q >= |O_Q|/(τ_QH_Q)`

个窗口上。

**证明。** 第一项正是短簇定义。若不发生，则每个窗口质量小于 `τ_QH_Q`，覆盖总质量 `|O_Q|` 至少需要所述数量窗口。证毕。

这一步把“集中异常”排除后，迫使 overlap 成为大范围分散相干异常。

## 6. 第四步：分散 overlap 到投影增量

对允许双锚正规形 `n=q_1q_2r`，固定 `r` 或固定比值相位，可把 `(q_1,q_2)` 投影到倒数相位

`Φ(q_1,q_2;r)=a(r)q_1^{-1}+b(r)q_2^{-1} mod p`

或其方阵圆柱版本的斜线相位。D 组允许窗口族 `𝓦(K)` 正是这些倒数环带、斜线相位窗及其有限并差。

**Lemma OV2-4（分散质量给投影偏差）。** 在无短簇条件下，若 `|O_Q|` 满足 Lemma OV2-1 的大层下界，则存在一个允许投影窗口 `A in 𝓦(K')`，使

`|μ_Q(A)-μ_Q^0(A)| >= c |O_Q|/log^C X`。

**证明。** 把每个 overlap 点按其相位 `Φ` 推送到投影空间。若所有允许窗口的偏差均小于右侧，则由有限复杂度 VC/Vitali 分解，所有分散窗口上的总偏差至多为 `O(|O_Q|/2)`，无法承载 Lemma OV2-1 的大质量。故至少有一个窗口承载相干偏差。证毕。

这一步是纯组合测度步骤；它只使用有限重叠选择、层蛋糕分解和 D 组窗口族对相位空间的覆盖。

## 7. 第五步：投影偏差的三终端分解

对 Lemma OV2-4 得到的窗口 `A`，D 组 OMR/CGTP 机制给出三分支：

1. 若偏差来自真实局部质量集中，则是高投影增量；
2. 若对应相位频率落入祖先短深度 span，则是 FCT；
3. 若频率非共振，则由 NRC 完成和界给出上界。

**Lemma OV2-5（OMR 接入）。** 若无短簇且存在 Lemma OV2-4 的投影偏差，则或者触发高投影增量，或者触发 FCT，或者偏差满足 NRC 上界

`|μ_Q(A)-μ_Q^0(A)| <= C K_eff X^{1/2}log^C X`。

**证明。** 这是 `docs/d-structure-formal-appendix.md` 中 Proposition D3 的 overlap 实例化：层相位窗口是倒数环带的有限并差；非共振时引用 `NRC`，共振失败时按 `FCT` 进入频率闭包。证毕。

## 8. 第六步：非终端假设推出能量上界

**Theorem OV2-Closure（非终端能量上界）。** 若短簇、高投影增量、FCT 与 NRC 异常四类终端均不发生，则

`E_ov(X)<=X^{1+ε}`。

**证明。** 反设 `E_ov>X^{1+ε}`。Lemma OV2-1 抽取大能量层 `Q`。若短簇发生，矛盾于非终端假设；否则由 Lemma OV2-3 得分散质量。Lemma OV2-4 将分散质量转化为某允许窗口的大投影偏差。Lemma OV2-5 表明该偏差只能给高投影增量、FCT 或 NRC 异常；三者均被非终端假设排除。剩余的 NRC 上界为

`C K_eff X^{1/2}log^C X`，

而 Lemma OV2-1 与 Lemma OV2-4 给出的偏差下界为

`c X^{1/2+ε/2}W_Q^{1/2}/log^C X`。

在 D 组常数吸收条件 `W_Q^{1/2}>=K_eff log^C X · X^{-ε/4}` 的主层范围内，下界超过 NRC 上界，矛盾。低容量尾层由 Tail-log4 或 PC-3 边界项吸收。故反设不成立。证毕。

## 9. 仍需严查的两个接口

OV-2 的主逻辑已经压缩为 D 组同型链条，但仍有两个必须在后续逐行补强的接口：

1. **允许锚语义接口**：已在 `docs/rh-ov2-admissible-anchor-interface.md` 中定理化。关键结论是：overlap 必须定义为允许覆盖锚相对真实最小锚账本的扣重；整除上包络只能用于非终端能量上界的单调下传，不能把上包络终端逐点下传。
2. **相位推送接口**：从允许双锚正规形 `q_1q_2r` 到 D 组倒数环带窗口 `𝓦(K)` 的映射需逐项写出，尤其要说明圆柱斜线相位与模素数倒数相位的同构范围。
3. **主层容量接口**：Theorem OV2-Closure 中 `W_Q` 的主层下界与低容量尾层吸收要接入 Tail-log4 常数账本。

完成后两点后，OV-2 可以从“深层输入”升级为“D 组实例化定理”。当前文档的贡献是把 OV-2 的真正硬点缩小到两个可审查接口，而不是泛泛保留为黑箱。

## 10. 与 PC-3 的闭合关系

`docs/rh-pc3-formal-theoremization.md` 证明：素数过疏若不被小 overlap 吸收，则产生覆盖容量过剩；若 overlap 大，则需要 OV-2。本附录证明：大 overlap 若不触发短簇、高投影增量、FCT 或 NRC，则能量必被压回 `X^{1+ε}` 以下。因此 PC-3 与 OV-2 合并后形成以下二分：

`素数过疏 => 覆盖容量过剩 或 D组终端`。

这正是 RH 反例矛盾场路线中 PC-3 所需的结构输出。后续最优攻坚不是再转换命题，而是严写相位推送和主层容量两个接口，把允许双锚正规形完全接入既有 D/Tail-log4 附录。
