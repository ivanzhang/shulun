# FCT_seed 与低维相位证书同型匹配审查

本文补强 `docs/rh-dgap-lowdim-extraction-line-by-line-audit.md` 的最后外部接口：固定低维谱族与同相位短弧为何严格等同于 `docs/rh-pc4-fct-seed.md` 所需的 `FCT_seed`。本文只消除“定义是否匹配”的跳步，不宣称 RH 已证明。

## 1. 两侧证书格式

### 1.1 DGap 低维相位证书

`DGap-LowDim-LineByLine` 输出以下数据：

1. 固定低维 CRT/Bohr 频率族 `Λ_* = span_Z{λ_1,...,λ_d}`；
2. 固定整数关系模板，系数高度 `Σ|m_i| <= H_*`；
3. 无穷成功尺度子列 `X_j`；
4. 固定短弧 `I_*`；
5. 固定符号方向，使 `u` 的固定比例能量在该短弧上同向承载离线异常；
6. 逃逸排除清单：非 `PC4-PI/DSO/SC/LV/LSMP/CE/Err`。

### 1.2 FCT_seed 需要的数据

`FCT-Seed` 需要以下数据：

1. 固定 FCT 类型 `𝓕_*`；
2. 固定低维 span 类型；
3. 有界整数系数证书；
4. 固定倒数/Bohr 相位窗口；
5. 固定离线相位短弧；
6. 同向吸收离线零点项的符号信息；
7. 排除 Complexity-Escape、LSMP、LV、PC4-PI 等外部终端。

因此唯一需审查的是：DGap 证书的 `Λ_* + I_* + 同向能量` 是否逐项给出 FCT 的 `𝓕_* + Bohr 窗 + 离线相位短弧 + 符号吸收`。

## 2. 字段匹配表

| DGap 输出字段 | FCT_seed 字段 | 匹配理由 | 失败出口 |
| --- | --- | --- | --- |
| `Λ_*` 固定低维 CRT/Bohr span | 固定低维 span 类型 | 二者都是有限 CRT 字符、Bohr 倒数相位和 dyadic 标签生成的有界维整数 span | 若维数或标签无界，转 `CE/LSMP` |
| 有界整数关系模板 `m` | 有界整数系数证书 | FCT 单尺度证书 `ξ_v=Σm_iξ_i` 正是低维 span 中的整数关系 | 若系数高度增长，转 `CE` 或 FCT 树加深 |
| 无穷尺度子列 `X_j` | 跨尺度固定类型实例 | 自然缩放实例沿子列保持组合类型不变 | 若类型漂移，转 DSO/PI 或 `CE/LSMP` |
| 固定短弧 `I_*` | 固定离线相位短弧 | 短弧 pigeonhole 给同一相位窗口，正是 FCT 相位窗口 | 若无限换弧，转相位漂移分支 |
| 同向固定比例能量 | 同向吸收离线零点偏差 | 能量符号与离线项符号一致，构成吸收证书 | 若不同向，则抵消，不能承载异常 |
| 非 PI/SC/LV/LSMP/CE/Err | 外部终端排除 | 两侧排除清单一致，差异仅名称细化 | 若触发任一项，则不进入 FCT_seed |

## 3. 自然缩放与固定类型

DGap 低维证书中 `Λ_*` 的“固定”是组合类型固定：频率由同一有限规则从尺度 `X_j` 的 CRT 模数、dyadic 层和 Bohr 参数生成。FCT-Seed 中 `𝓕_*` 的“固定”也是组合类型固定，而非要求数值频率在不同模数下字面相同。

因此定义映射为：

`𝓕_*(X_j) :=` 由 `Λ_*` 的生成规则、整数关系模板 `m`、短弧 `I_*`、符号方向 `σ` 组成的自然缩放实例。

若某尺度不能用该自然缩放实例表达，则必然出现以下之一：

1. 新增独立坐标未被 `Λ_*` 吸收，回到 `DSO/PI`；
2. 关系高度增长，回到 `CE/LSMP`；
3. 相位窗口细化或漂移，回到 `FCT phase drift`；
4. 支撑局部拥挤，回到 `SC/LV`。

所以在当前非逃逸分支中，DGap 低维证书给出固定 FCT 类型。

## 4. 同向性匹配

DGap 输出的是 `u` 的固定比例能量同相位承载。FCT_seed 需要的是离线零点项 `γlogX` 被同一低维模型同向编码。两者之间的桥接来自总场方程：`u` 是 DGap 剩余盒能量，是离线异常在 Dual/DGap 分支中的投影残差。若 `u` 的固定低维部分与离线相位不同向，则它只能抵消主异常，无法在无穷成功尺度上承载固定比例 `E_X`。

因此，在成功尺度子列上可取符号 `σ∈{+,-}`，使

`σ Re(e^{iγlogX_j} P_{Λ_*}u_j) >= cE_{X_j}`。

短弧 pigeonhole 固定 `I_*` 后，这正是 FCT_seed 的“同向吸收离线零点偏差”。

## 5. 同型定理

**Theorem FCT-Seed-Isomorphism（条件化定义匹配）。** 在 `DGap-LowDim-LineByLine` 的非逃逸假设下，其输出的固定低维频率族、固定整数关系模板、固定短弧与同向能量证书，逐项构成 `FCT-Seed` 所需的固定 FCT 类型、低维 span、有界整数证书、相位窗口和同向离线偏差吸收证书。若任一字段不能匹配，则该失败必然进入 `DSO/PI`、`CE/LSMP`、`FCT phase drift`、`SC/LV` 或误差终端。

**证明。** 字段匹配由第 2 节表格给出。固定类型含义由第 3 节统一为“组合规则固定、数值随模数自然缩放”。同向性由第 4 节的总场方程投影符号给出。若匹配失败，则失败只能表现为新增坐标、关系高度增长、相位漂移、局部拥挤或误差吞噬，分别进入已命名终端。故 DGap 低维证书与 FCT_seed 同型。证毕。

## 6. 对剩余割集的影响

本文消除了 `FCT_seed` 定义匹配这一接口跳步。当前 DGap 外部剩余主要剩下：

1. Fourier/Vaaler 尾项平方可和在全部固定盒模板上的统一证明；
2. FCT phase drift 与 FCT closure 的最终无无限递归排除；
3. 若要走到 RH 无条件证明，还需上游解析输入、容量定理和外部定理引用的完全标准化。
