# 方阵覆盖反例的矛盾场方程框架

**状态：** `rigidity_constraints_unified_into_contradiction_field`

本框架把当前已发现的几类刚性统一起来，用于排斥“某行或某列全覆盖”的反例。重点不再是有限模板，而是建立全局矛盾场：局部相邻互斥、同余商互质、CRT 周期性、列均衡、增长量级差距同时作用，迫使反例结构无法存在。

## 1. 行内覆盖方程

第 `r` 行第 `c` 列为

`N_c = (r-1)P+c`。

若第 `r` 行全覆盖，则对每个 `c` 存在根基素数 `q_c<P` 使

`q_c | N_c`。

对小筛洞集合 `H`，每个 `c in H` 必须由大因子 `q_c>sqrt(P)` 覆盖。

于是得到标签场

`c -> q_c`。

## 2. 相邻刚性：相邻点因子必须不同

若 `c,d in H` 且 `0<|c-d|<sqrt(P)`，并且 `q_c=q_d=q>sqrt(P)`，则

`q | N_c` 且 `q | N_d`，故

`q | (N_d-N_c)=d-c`。

但 `0<|d-c|<sqrt(P)<q`，矛盾。

因此：

> 在任意长度 `<sqrt(P)` 的列段内，大因子标签必须两两不同。

这不是概率现象，而是确定性几何刚性。

## 3. 同余商互质刚性

若同一根基素数 `q` 在同一行命中两个位置 `c_1,c_2`，则

`c_2-c_1 = q m`。

两个命中数满足

`N_{c_2}=N_{c_1}+qm`。

除去共同因子 `q` 后的商为

`A=N_{c_1}/q, B=N_{c_2}/q=A+m`。

若存在另一个根基素数 `p` 同时整除 `A` 与 `B`，则 `p|m`，并且两个原数共享 `pq` 的结构。特别在短距离或粗筛洞链中，这会受到 `pq` 与距离尺度的双重限制。

因此同余命中序列不仅间距固定为 `q`，其商序列还携带互质/低重叠约束。该约束防止同一斜线在局部高密度补洞。

## 4. Gap 转移刚性

设小筛洞补洞链为

`c_1<c_2<...<c_m`，标签为 `q_i=q(c_i)`，gap 为

`g_i=c_{i+1}-c_i`。

若 `g_i<sqrt(P)`，则 `q_i != q_{i+1}`，并且任意短窗口内所有相邻参与标签高度互异。

重复 gap `g` 的转移族

`T_g={(q_i,q_{i+1}): c_{i+1}-c_i=g}`

形成一个多模数转移场。由于同一个 `g` 的两端标签不能相同，且标签在短窗口内不能复用，`T_g` 的模数复杂度随出现次数增长。

这给出 gap 级增长压力：

`complexity(T_g) ≳ exp(Σ_{q in Q_g} log q)`。

若反例要求这些 gap 转移在圆柱推进中保持连续覆盖，则必须压缩这些多模数相位，触发 CRT 矛盾。

## 5. CRT 周期场

令根基周期

`M=Π_{q<P} q`。

覆盖场在行方向以 `M` 为周期。对每个 `q<P`，第 `r+t` 行中同一斜线的列相位移动为

`-tP mod q`。

若某个局部或全局覆盖态以短步长 `t<P` 复现，则对参与复现的标签集合 `Q_*` 必须满足相位兼容：

` tP ≡ Δ_q mod q`。

若兼容要求对多个 `q` 给出同一个短差，则 CRT 迫使

`Π_{q in Q_*} q <= |tP+v|`

否则矛盾。

由于每个大因子 `q>sqrt(P)`，两个独立大因子乘积就超过 `P`，多个大因子乘积迅速超过任何短差尺度。

## 6. 列均衡刚性

在 CRT 周期长方形内，除第 `P` 列外，各列中的类素数数量严格相等。这里类素数指对所有根基素数 `q<P` 均处于非零同余类的元素。

若某一行在 `P x P` 方阵中全覆盖，则该行在类素数分布中形成一个长度 `P` 的零洞横截面。由于列均衡要求每列在完整 CRT 周期内有相等的非零同余类交集数量，局部全覆盖行必须由其他行对每一列进行精确补偿。

但补偿受斜线相位固定控制：

- 同一根基素数的零类在列间按固定螺旋移动；
- 相邻列/行的补偿不能任意重排；
- 若一整行消失，则补偿必须在所有列同步发生；
- 同步补偿会诱导短相位相关，进入 CRT 矛盾场。

因此列均衡提供的是全局守恒律：

`column_mass_j = constant`。

全行覆盖则产生局部亏损场：

`defect_j(r)=1` 对所有 `j`。

守恒要求存在补偿流 `flow_{r'->j}`，但斜线系统只允许沿同余螺旋流动。若补偿流无法满足散度方程，则反例排除。

## 7. 矛盾场方程

把覆盖反例写成场方程：

- `D(r,c)=1` 表示该格点是小筛洞；
- `L(r,c)=q` 表示洞由大因子 `q` 补掉；
- `U(r,c)=1` 表示未被任何根基素数覆盖，即素数/类素数。

反例全覆盖要求：

`U(r,c)=0` 对某整行或整列成立。

但同时必须满足：

1. **局部互斥**：若 `|c-d|<sqrt(P)`，则 `L(r,c) != L(r,d)`；
2. **gap复杂度增长**：高频 gap 的标签集合乘积快速增长；
3. **CRT相位约束**：短复现要求标签集合共同约束 `tP+v`；
4. **列均衡守恒**：完整 CRT 周期内各列 `Σ_r U(r,c)` 相等；
5. **补偿流限制**：亏损只能沿固定斜线相位由根基素数零类产生。

矛盾场目标是不等式化：

`required_compensation_complexity > allowed_CRT_phase_capacity`。

或：

`required_large_factor_product > max_short_difference`。

## 8. 下一步最小证明任务

最值得攻的是“亏损-补偿流”版本，因为它直接使用列均衡刚性：

### 引理 F（全行亏损不可补偿）

若某行全覆盖，则在 CRT 周期内该行对每列造成一个单位类素数亏损。列均衡要求存在跨行补偿，使每列总量恢复相等。由于每条斜线的相位流由单一模数 `q` 决定，补偿流的散度必须满足一组 CRT 同余方程。该方程若有解，则产生短相位回路；短相位回路由大因子互斥给出模数乘积矛盾。

证明链：

1. 全行覆盖 -> 均匀列亏损；
2. 列均衡 -> 必有均匀补偿流；
3. 固定斜率 -> 补偿流分解为根基素数螺旋流；
4. 均匀补偿 + 螺旋流 -> 存在短闭合回路；
5. 短闭合回路 + 大因子互斥 -> CRT 矛盾。

这是当前最接近完整闭合的总路线。
