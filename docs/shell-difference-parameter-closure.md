# Shell-difference 参数闭合修正稿

**状态：** 修正前缀 `M_B` 过大漏洞；给出更稳健的单坐标壳差闭合。

## 1. 发现的参数漏洞

上一稿建议取 `B` 为直到最小不整除 `t=y-x` 的素数 `b_*` 的前缀。虽然这保证小壳非静止，但会带来问题：

`M_B=prod_{b<=b_*}b`

可能已经大于 `P`。此时区间 `[1,P)` 内不包含完整 CRT 周期，公式

`|S_B(y)\S_B(x)|=(P/M_B)D_B+O(M_B)`

的误差 `O(M_B)` 可能大于主项，不能用于推出线性释放。

因此不能直接用大前缀壳闭合参数点。

## 2. 单坐标壳差替代方案

不必取完整前缀。只要存在一个小素数 `b` 使 `b∤t`，单独取

`B={b}`。

则

`S_B(x)={c: c not≡a_b(x) mod b}`，

`S_B(y)={c: c not≡a_b(y) mod b}`。

若 `b∤t`，则 `a_b(y)≠a_b(x)`。于是

`S_B(y)\S_B(x)={c: c≡a_b(x) mod b}`

在列区间 `[1,P-1]` 中的数量为

`floor((P-1+O(b))/b) = P/b + O(1)`。

这是无须完整 CRT 周期的大前缀误差的精确单坐标下界。

## 3. 选择最小不整除素数

令 `b_*` 为最小素数使 `b_*∤t`。则取 `B={b_*}`，得到

`|S_B(y)\S_B(x)| >= P/b_* - 2`。

因为所有素数 `q<b_*` 都整除 `t`，有

`prod_{q<b_*} q | t`，且 `0<|t|<P`，故

`prod_{q<b_*}q < P`。

用 Chebyshev 函数 `θ(u)=sum_{q<=u} log q`，这等价于

`θ(b_*^-)=log prod_{q<b_*}q < log P`。

由显式 Chebyshev 下界可推出

`b_* <= C log P`

对充分大 `P` 成立。

于是

`|S_B(y)\S_B(x)| >= P/(C log P)-2`，

该量对充分大 `P` 大于 `2sqrt(P)`。

## 4. 显式阈值接口

选择任意可引用的显式 Chebyshev 下界，例如存在绝对常数 `u0,Cθ>0` 使

`θ(u) >= Cθ u, u>=u0`。

若 `b_*>u0+1`，则

`Cθ(b_*-1) <= θ(b_*^-) < log P`，

所以

`b_* <= 1 + (log P)/Cθ`。

因此

`|S_B(y)\S_B(x)| >= Cθ P/(2 log P)`

对足够大 `P`，吸收常数后成立。

要压过稀疏上界 `sqrt(P)+1`，只需

`Cθ P/(2 log P) - 2 > sqrt(P)+1`。

等价于

`sqrt(P) > (2/Cθ) log P + O(1)`。

这给出完全显式的充分大阈值 `P0`：取满足

`sqrt(P0) >= (4/Cθ) log P0`

且 `P0` 大于有限初始常数的奇素数上界。

## 5. 为什么单坐标足够

有人可能担心只取 `B={b_*}` 太弱。实际上在稀疏分支中，我们只需要证明释放差数量超过 `O(sqrt(P))`。单坐标壳差已经给

`≈P/b_*`。

而 `b_*=O(log P)`，所以

`P/b_* >> sqrt(P)`。

因此单坐标壳差足以排除全单点稀疏分支，无需使用完整前缀壳。

## 6. 静止情形

若对某个选定小素数 `b` 有 `b|t`，则单坐标壳静止，不能杀旧核中原本避开该禁余类的点。

但选择 `b_*` 保证 `b_*∤t`，所以不会落入静止情形。静止无杀伤仍用于说明：所有小于 `b_*` 的小素数虽然可能参与骨架，但由于相位静止，它们不能杀灭旧核。

## 7. 闭合结论

SDL 参数点可用以下形式闭合：

**SDL-param.** 对任意 `0<|t|<P`，存在素数 `b_*<P`，使 `b_*∤t` 且 `b_*<=1+(log P)/Cθ`（充分大时）。取 `B={b_*}`，若小壳迁移用于静默杀核，则释放差满足

`|S_B(y)\S_B(x)| >= P/b_* - 2 >= c P/log P`。

对充分大 `P`，该量大于 `sqrt(P)+1`，故全单点稀疏分支不可能静默。

小于阈值的 `P` 由有限验证处理。
