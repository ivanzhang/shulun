# Shell-difference lower bound 闭合稿

**状态：** 闭合 SCD 稀疏分支的当前最小审查点；修正释放规模为密度级下界。

## 1. 目标与修正

此前写作目标为

`|S_B(y)\S_B(x)| >= c(B) P/M_B - O(M_B)`。

这个形式过弱且不够准确。因为 `S_B(x)` 是避开每个 `b in B` 一个禁余类的集合，其密度是

`δ_B=prod_{b in B}(1-1/b)`，

而不是 `1/M_B`。

若小壳相位发生非零迁移，两个壳 `S_B(x),S_B(y)` 的对称差在一个完整 `M_B` 周期内通常是 `δ_B` 的固定比例。因此正确目标应为

`|S_B(y)\S_B(x)| >= η_B P - O(M_B)`，

其中 `η_B>0` 只依赖于发生迁移的 `B`-相位。

这比 `P/M_B` 更强；只要 `B` 取到 `M_B=o(P)`，释放差就是线性级。

## 2. CRT 单元计数

令

`M_B=prod_{b in B} b`。

在 `Z/M_B Z` 中定义

`Ω(a)= {r mod M_B: r not≡ a_b mod b for all b in B}`，

其中 `a=(a_b)_{b in B}` 是禁余相位。

则

`|Ω(a)|=M_B δ_B=prod_{b in B}(b-1)`。

行 `x` 的小壳 `S_B(x)` 是区间 `[1,P-1]` 中落在 `Ω(a(x))` 的列。

设 `a'=a(y)`。在一个完整 CRT 周期内，壳差大小为

`D_B(a,a')=|Ω(a')\Ω(a)|`。

于是区间计数给出

`|S_B(y)\S_B(x)| = (P/M_B) D_B(a,a') + O(M_B)`。

误差来自长度 `P` 区间两端不完整 CRT 块；粗略界 `O(M_B)` 足够。

## 3. 壳差非零的精确常数

若 `a'=a`，则 `D_B=0`。

若 `a'!=a`，存在至少一个 `b0 in B` 使 `a'_{b0}!=a_{b0}`。

要构造属于 `Ω(a')\Ω(a)` 的 CRT 单元，只需满足：

- 在模 `b0` 上取 `r≡a_{b0}`，这样 `r notin Ω(a)`；
- 同时因为 `a'_{b0}!=a_{b0}`，该坐标不会违反 `Ω(a')`；
- 对每个其它 `b in B`，取任意非禁余坐标 `r_b != a'_b`。

CRT 独立性给出至少

`prod_{b in B, b!=b0} (b-1)`

个单元。

因此

`D_B(a,a') >= prod_{b!=b0}(b-1) = M_B δ_B/(b0-1)`。

令

`η_B(a,a')=D_B(a,a')/M_B`。

则只要相位非静止，

`η_B(a,a') >= δ_B/(b0-1) >= δ_B/(max B-1)`。

## 4. Shell-difference lower bound

**SDL。** 若 `a_B(y)!=a_B(x)`，即存在 `b in B` 使 `b∤(y-x)`，则

`|S_B(y)\S_B(x)| >= [δ_B/(max B-1)] P - O(M_B)`。

更精确地，

`|S_B(y)\S_B(x)| = (P/M_B)D_B(a(x),a(y)) + O(M_B)`。

其中 `D_B>0`，并有上面的显式下界。

## 5. 与稀疏分支比较

稀疏全单点分支给出

`|W| <= sqrt(P)+1`。

若静默无释放，则小壳迁移释放差必须被待补/交换集合吸收；无短差核心时它也必须表现为 `sqrt(P)`-分离，因此规模不能超过 `O(sqrt(P))`。

但 SDL 给出释放差至少为

`η_B P - O(M_B)`。

只要选择 `B` 使

`η_B P - O(M_B) > C sqrt(P)`，

稀疏分支矛盾。

## 6. 如何选择 B

为了保留线性释放，不能让 `δ_B/(max B-1)` 过小。最稳妥的局部选择是小固定壳，例如：

- `B={2}`：若奇偶相位翻转，`η_B=1/2`；
- `B={2,3}`：任一坐标迁移给 `η_B>=1/6`；
- `B={2,3,5}`：`δ_B=4/15`，`η_B>=1/15`。

固定小壳足以给出 `η_B P >> sqrt(P)`。若固定小壳相位全静止，即所有 `b in B` 都整除 `t=y-x`，则这些小标签不能杀旧核，需加入下一个不整除 `t` 的小素数。

由于 `0<|t|<P`，`t` 不能被所有小素数 `<P` 整除。因此必存在最小根基素数 `b_*<P` 使 `b_*∤t`。

取 `B` 为直到 `b_*` 的小素数前缀，则小壳非静止。但要保证 SDL 超过 `sqrt(P)`，需要控制该前缀的 `η_B` 不太小。这是剩余参数点。

## 7. 参数残余与解决路线

若 `b_*` 很大，则 `t` 被所有小素数 `<b_*` 整除，所以

`prod_{b<b_*} b | t`。

但 `0<|t|<P`，故

`prod_{b<b_*} b < P`。

因此 `b_*` 不可能太大；它至多是使 primorial 仍小于 `P` 的下一个素数，约 `O(log P)` 量级。

对这样的前缀，Mertens 型估计给

`δ_B ≈ e^{-γ}/log b_*`，

于是

`η_B >= c/(b_* log b_*)`。

若 `b_*=O(log P)`，则

`η_B P >= c P/(log P log log P) >> sqrt(P)`。

所以对充分大 `P`，SDL 足以排除稀疏分支；小 `P` 可有限验证。

## 8. 当前闭合状态

SDL 的 CRT 壳差计数已严格。剩余只需把第 7 节的参数估计显式化：

1. 由 `prod_{b<b_*}b | t<P` 推出 `b_*` 的上界；
2. 由 Mertens/初等乘积下界推出 `η_B P >> sqrt(P)`；
3. 小 `P` 有限验证。

这比之前的模糊 `P/M_B` 下界更强，也更贴合小壳动力本质。

## 9. 初等参数闭合方案

为了避免过度依赖深估计，可用非常粗的初等界。

设 `b_*` 是最小不整除 `t` 的素数。则所有素数 `b<b_*` 都整除 `t`，所以

`Prim(b_*)=prod_{b<b_*} b <= |t| < P`。

只需使用一个显式初等事实：存在常数 `A`，使对所有 `u>=A`，

`prod_{b<u} b > 2^u`。

于是充分大时有

`2^{b_*}<P`，故

`b_*<log_2 P`。

另一方面，

`δ_B=prod_{b<=b_*}(1-1/b)`。

可用粗下界

`δ_B >= 1 / prod_{b<=b_*} b`。

但该下界太弱，只给 `δ_B>1/(P b_*)`，不够。必须使用 Mertens 型下界或等价的欧拉乘积初等下界：

存在显式常数 `c0>0`，使

`prod_{b<=u}(1-1/b) >= c0/log u`。

这可由 Rosser-Schoenfeld 型显式 Mertens 不等式给出，属于标准初等可引用工具。

因此

`η_B >= c0 / ((b_*-1) log b_*) >= c1/(log P log log P)`。

于是

`η_B P >= c1 P/(log P log log P)`。

该量最终大于 `2 sqrt(P)`。等价于

`sqrt(P) >= (2/c1) log P log log P`。

这给出一个可显式计算的充分大阈值。

## 10. 小 P 有限验证接口

理论上只需验证

`P < P_0`

的奇素数，其中 `P_0` 由上一节显式常数给出。验证目标不是重新证明全部结构，而是检查目标命题本身：每个 `P×P` 前窗口行列均有素数。

可复用或新增脚本：

`experiments/verify_finite_p_grid.py`。

这使 SDL 参数残余可闭合为：

1. 标准显式 Mertens 下界给充分大；
2. 有限验证覆盖小素数。

注意：这里的有限验证阈值可能很大，但这是技术常数问题，不影响结构证明链条。

## 11. 参数闭合修正

已新增：`docs/shell-difference-parameter-closure.md`。

重要修正：不再取到 `b_*` 的完整前缀壳，因为 `M_B` 可能超过 `P`，导致 CRT 周期误差压倒主项。改用单坐标壳 `B={b_*}`。

若 `b_*` 是最小不整除 `t=y-x` 的素数，则

`|S_{b_*}(y)\S_{b_*}(x)| >= P/b_* - 2`。

所有素数 `<b_*` 都整除 `t<P`，故其 primorial `<P`。由显式 Chebyshev 下界 `θ(u)>=Cθ u` 得

`b_* <= 1+(log P)/Cθ`。

于是释放规模至少为 `cP/log P`，充分大时超过 `sqrt(P)+1`。例如用保守常数 `Cθ=0.1`，条件 `sqrt(P)>=(4/Cθ)log P` 从约 `P=246639` 后成立；更强标准常数会显著降低阈值。
