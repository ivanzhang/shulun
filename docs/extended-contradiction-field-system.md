# 扩展矛盾场方程组：接入周期、列均衡、镜像与标签链刚性

**状态：** 方程组接口；用于后续证明闭合。

## 1. 基础层叠场

已有主方程：

`|H_P(x)| = |S_j(x)| - C_j(x) + E_j(x)`。

其中：

- `S_j(x)`：前 `j` 个根基素数剥离后的候选壳；
- `C_j(x)`：剩余层原始覆盖容量；
- `E_j(x)`：剩余层重叠能量；
- `H_P(x)`：最终残洞集。

扩展场要把此前未完全进入的刚性作为附加约束，而不是替代主方程。

## 2. 周期密度场

令完整 CRT 周期

`M=prod_{q<P} q`。

定义行残洞数场

`A(r)=|H_P(r-1)|`，`1<=r<=M`。

周期与镜像刚性：

`A(r+M)=A(r)`，

`A(r)=A(M+1-r)`。

若前窗口反例存在，即 `A(r0)=0` 且 `2<=r0<=P`，则镜像也有

`A(M+1-r0)=0`。

该事实本身不矛盾，但它要求零点在周期波形中成镜像对出现，并受列均衡守恒约束。

## 3. 列均衡缺陷流

对列 `1<=c<P`，定义周期列残洞计数

`T_c = # {1<=r<=M: c in H_P(r-1)}`。

CRT 列均衡给出

`T_1=T_2=...=T_{P-1}`。

对任意行区间 `I`，定义列缺陷流

`D_c(I)=# {r in I: c in H_P(r-1)} - |I| * T_c/M`。

则完整周期守恒：

`D_c([1,M])=0`。

若前窗口出现零行，则该行对所有列同时贡献 `-T_c/M` 的下冲。列均衡要求这些同步下冲在周期其它位置回补。

后续要证明：这种回补必须经过小壳迁移或大层补洞；而二者分别受 LD-2、LD-1 限制。

## 4. 镜像列配对场

镜像映射为

`r -> M+1-r`，`c -> P-c`。

因此有列级镜像关系：

`1_{c in H_P(r-1)} = 1_{P-c in H_P(M-r)}`。

于是列缺陷流也满足

`D_c(I)=D_{P-c}(Mirror(I))`。

这使前窗口零行产生的缺陷不仅需要周期补偿，还要与镜像列配对一致。

## 5. 局部标签场

若列 `c` 被覆盖，定义标签集合

`L_x(c)={q<P: q | xP+c}`。

若选择一个解释标签 `ell_x(c) in L_x(c)`，则相邻列有强制约束：

- `ell_x(c) != ell_x(c+1)`，因为同一素数不能整除相邻整数；
- 若同一标签 `q` 覆盖两列 `c1,c2`，则 `q | (c2-c1)`；
- 对短差 `d<certain threshold`，大标签不能复用。

定义标签冲突能量：

`G_x = # {短差对 (c1,c2): L_x(c1),L_x(c2) 需要互异大标签}`。

反例零行要求每列至少一个标签，且所有短差/相邻标签约束同时满足。`G_x` 越大，CRT 同步压力越大。

## 6. 扩展矛盾场方程组

前窗口反例必须同时满足：

1. **层叠零场：** 对所有 `j`，`|S_j|=C_j-E_j`；
2. **周期镜像：** `A(r0)=A(M+1-r0)=0`；
3. **列均衡守恒：** `D_c([1,M])=0` 且前窗口同步下冲可回补；
4. **镜像列配对：** `D_c(I)=D_{P-c}(Mirror(I))`；
5. **标签链合法：** 相邻列标签互异，短差大标签不可复用；
6. **CRT 同步可行：** 所有补洞标签同余系统有前窗口代表。

证明策略是：不必单独用某一个约束排除反例，而是证明这些约束不能同时满足。

## 7. 当前最可攻的组合矛盾

最可攻组合是：

**小壳迁移 + 列缺陷流。**

若通过改变小素数禁余类补掉前窗口核，则新壳释放点造成 `D_c` 在若干列上回升。列均衡与镜像要求这些回升按列配对分布；但小壳迁移的释放列由 CRT 小模数决定，通常不满足任意配对自由度。

第二可攻组合是：

**短差标签互斥 + CRT 同步。**

若保持小壳签名，短差核必须用互异中大标签补；同步模数乘积超过前窗口尺度，若偶然有代表，则标签重排释放新洞。
