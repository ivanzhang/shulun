# PPI-Rank 有限分离秩引理

本文补齐 `NRC-2D` 的第一项剩余义务：从 PPI-U2/U3 的窗口语义推出二维权重 `W(q_1,q_2)` 的分离秩至多为 `log^C X`；若不能推出，则该失败不是 NRC 内部事件，而是 `CE/SC/PI/LSMP` 出口。

## 1. 问题背景

在双锚主层，PPI 相位为

`Θ(q_1,q_2;r)=a(r)q_1^{-1}+b(r)q_2^{-1}+γ(r) mod p`。

窗口检测后，二维非共振包形如

`S_2=Σ_{q_1,q_2~Q} W(q_1,q_2;r)e_p(aq_1^{-1}+bq_2^{-1})`。

`NRC-2D` 的低秩容量路线要求

`W(q_1,q_2;r)=Σ_{ℓ<=L}u_ℓ(q_1;r)v_ℓ(q_2;r)+Err`, `L<=log^C X`。

本文证明：这正是固定复杂度 PPI 窗口族的内在含义。

## 2. 允许原子的分离秩

固定 `r` 后，允许窗口由下列原子生成：

1. `q_1` 或 `q_2` 的 dyadic/区间平滑权；
2. 固定小模数同余条件；
3. 单个相位短弧/Bohr 条件 `1_A(Θ(q_1,q_2;r))`；
4. 有限个上述条件的交、并、差和有限乘积。

前两类本来就是单变量权或两个单变量权的乘积，分离秩为 `1`。

第三类经 Vaaler 截断高度 `H<=log^C X` 展开为

`1_A(t)=c_0+Σ_{0<|h|<=H}c_h e_p(ht)+Rem_H(t)`。

代入 `t=Θ` 后每个非零频率项为

`c_h e_p(hγ(r)) e_p(ha(r)q_1^{-1}) e_p(hb(r)q_2^{-1})`，

是一个 `q_1` 权与一个 `q_2` 权的乘积。因此单个短弧/Bohr 原子在截断后分离秩 `<=2H+1<=log^C X`，余项由 Fourier/Vaaler 尾项出口接收。

## 3. 有限布尔组合的秩增长

设两个窗口权重分别有分离秩 `L_1,L_2`：

`W_i=Σ_{ℓ<=L_i}u_{i,ℓ}(q_1)v_{i,ℓ}(q_2)+Err_i`。

则：

- 和/差的分离秩至多 `L_1+L_2`；
- 乘积的分离秩至多 `L_1L_2`，因为

`(u_1v_1)(u_2v_2)=(u_1u_2)(v_1v_2)`；

- 补集 `1-W` 只增加一个常数分离项；
- 有限并差可用和、差、乘积表达。

这里必须区分两种复杂度。若模板布尔深度 `d` 是固定常数，且每个原子截断高度 `H<=log^{C_1}X`，则所有布尔组合后的分离秩满足

`L<= (2H+1)^d <= log^{C_2}X`。

若允许 `d` 随 `X` 增长到 `log^c X`，则 `(2H+1)^d` 通常不再是固定对数幂，不能留在 PPI 主层；这正是复杂度逃逸事件，必须转入 `CE` 或 `LSMP/SC/PI`。因此本文的 `PPI-Rank` 只适用于固定模板深度的 PPI 主层。

## 4. 误差归属

Vaaler 余项、硬边界误差和平滑替换误差若总量满足

`Err<=V_Q/log^B X`，则直接并入 `NRC-2D-LowRank-Capacity` 的误差项。

若误差承载固定比例 PPI 偏差，则它不是 NRC 项，而由既有 Fourier/Vaaler 尾项链进入：

- `CE`：截断高度或窗口复杂度失控；
- `LSMP/LV`：误差集中在低体积或低质量原子；
- `SC/PI`：误差在短簇或投影窗口中重复承载。

因此误差不会形成新的 NRC 逃逸通道。

## 5. Theorem PPI-Rank

**定理 PPI-Rank（二维权重有限分离秩）。** 在固定 `r`、固定 dyadic 主层、固定投影方向与固定模板深度 PPI 窗口族下，任一由 PPI-U2/U3 产生的二维非共振窗口权重满足以下二者之一：

1. 存在展开

   `W(q_1,q_2;r)=Σ_{ℓ<=log^C X}u_ℓ(q_1;r)v_ℓ(q_2;r)+Err`

   且 `Err` 由 Vaaler/平滑尾项控制；
2. 分离秩、截断高度或尾项误差承载主偏差，因而该事件进入 `CE/SC/PI/LSMP/LV`，不计入 NRC。

**证明。** 允许原子中，单变量区间、同余与 dyadic 权秩为 `1`；相位短弧/Bohr 原子由 Vaaler 展开后成为 `O(H)` 个分离项。有限交、并、差和乘积只按加法或乘法规则增加分离秩。固定模板深度保证总秩仍为 `log^C X`。若深度增长导致秩超过固定对数幂，则按定义进入复杂度出口。所有截断和平滑误差若小则并入 `Err`；若大则按 PPI 输出链的尾项/复杂度分支进入命名出口。故二者之一必然成立。证毕。

## 6. 接入 NRC-2D

把 `PPI-Rank` 代入 `docs/rh-gee-nrc-2d-bilinear-hardpoint.md` 的 `NRC-2D-LowRank-Capacity`，得到：

- 若主层容量满足 `V_Q>=Plog^{B+C}X`，二维加性分离 NRC 包相对偏差为 `<=V_Q/log^B X`；
- 若容量不足，转 `LV/LSMP`；
- 若有限秩失败，转 `CE/SC/PI/LSMP`。

因此 `NRC-2D` 剩余硬点从两个降为一个：`Capacity-Match`。
