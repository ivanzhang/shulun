# 奇素数壳重叠能量路线：PSG 的下一接口

**状态：** 候选证明路线；基础等式严格，重叠下界待证。

## 1. 剥离 q=2 后的覆盖账本

固定前窗口相位 `1<=x<P`。由奇偶壳剥离，残洞只可能位于

`S_x={1<=c<P: c not≡ x (mod 2)}`。

其大小为 `(P-1)/2`。

奇素数层 `q=3,5,...,P-1` 在该壳上覆盖集合

`A_q(x)={c in S_x: xP+c≡0 (mod q)}`。

于是

`H_P(x)=S_x \ union_q A_q(x)`。

若存在前窗口零行，则必须有

`|union_q A_q(x)|=|S_x|`。

## 2. 容量不是瓶颈，重叠才是瓶颈

定义原始容量

`R(x)=sum_q |A_q(x)|`，

重叠能量

`E(x)=R(x)-|union_q A_q(x)|`。

则残洞数为严格恒等式：

`|H_P(x)|=|S_x|-R(x)+E(x)`。

实验 `odd-shell-capacity-scan` 与 `odd-shell-layer-ledger` 显示：

- `R(x)` 通常已经大于 `|S_x|`；
- 但 `E(x)` 同时增长，并吞掉最后覆盖余量；
- 最优前窗口相位仍有 `|H_P(x)|>=1`。

所以目标应从“覆盖容量不足”改为：

> 前窗口内奇素数层的强制重叠至少抵消全部容量盈余后还保留一个洞。

即需证明

`E(x) >= R(x)-|S_x|+1`。

## 3. 重叠能量的 CRT 来源

两层 `q1,q2` 在壳内重叠，等价于存在列 `c` 满足

`xP+c≡0 (mod q1 q2)`。

在长度约 `P/2` 的奇偶壳内，这种重叠不是随机事故，而由小素数层的高频同余格强制产生。

尤其是小素数 `3,5,7` 先覆盖大块周期骨架；后续中大素数的单点覆盖若落在壳内，常落入已覆盖骨架，于是边际新增覆盖下降。

账本中典型现象：

- `P=23,x=14`：原始容量 `11` 等于壳大小 `11`，但重叠 `2`，留下 `[9,15]`；
- `P=47,x=46`：容量 `29` 对壳大小 `23` 有盈余 `6`，但重叠 `9`，留下 `3` 洞；
- `P=97,x=82`：容量 `66` 对壳大小 `48` 有盈余 `18`，但重叠 `24`，留下 `6` 洞。

## 4. 可证的局部重叠下界方向

把奇素数分成三层：

1. **骨架层** `B={3,5,7}`：产生高密度周期格；
2. **中层** `M={q: 11<=q<=sqrt(P)}`：每层覆盖多个壳点，且与骨架层有强重叠；
3. **大层** `L={q: sqrt(P)<q<P}`：每层至多覆盖一个壳点。

大层看似可用于补最后洞，但它有两个硬约束：

- 若补两个短差洞 `c1,c2`，同一个大素数不可能同时命中，因为 `q>|c2-c1|`；
- 大层单点命中必须满足 CRT 相位，多个大层同步补洞会使模数乘积迅速跨过前窗口。

因此最后洞若全由大层唯一覆盖，需要大量互异大素数同步；这正是 FSC/CRT 跨窗压力的局部版本。

## 5. 下一候选命题 OSE

**OSE：奇素数壳重叠能量命题。** 对任意奇素数 `P` 与 `1<=x<P`，有

`E(x) >= R(x)-|S_x|+1`。

等价地，奇素数层在反奇偶壳内不能全覆盖。

该命题与行命题等价，但更适合攻击，因为它把问题转化为：

- 小素数骨架制造强制重叠；
- 中层无法避免骨架重叠；
- 大层补最后洞需要 CRT 同步跨窗。

## 6. 下一步最小可证版本

先证明弱化版：

**OSE-local。** 若某相位 `x<P` 的最后残洞集 `K` 含短差 `d<sqrt(P)`，则大层不能唯一覆盖 `K` 的全部点而不产生跨窗 CRT 约束；中小层若补 `K`，则必与骨架层重叠并释放新洞。

这将直接覆盖短 gap 极小核路线 PSG。
