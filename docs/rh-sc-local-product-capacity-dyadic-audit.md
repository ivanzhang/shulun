# SC 局部乘积容量全 dyadic 层核验

本文补强 `docs/rh-pc4-short-cluster-local-density.md` 的 `SC-LD1`：在固定短窗 `I` 与 dyadic 层 `Q,R` 内，双锚正规形 `n=q_1q_2r` 的局部容量为何只有

`Vol_eff(I;Q,R) << (L/X)RQ log^C X + R log^C X`。

本文仍是条件化无条件化推进；它把 SC 局部容量接口拆成可审查的 dyadic 层计数与失败出口。

## 1. dyadic 层模型

固定尺度 `X`、短窗 `I=[x_0,x_0+L]⊂[X/2,2X]`，以及 dyadic 层

`q_1,q_2~Q`, `r~R`, `Q^2R≈X`。

AAI 正规形要求候选复用点满足

`n=q_1q_2r+O(boundary)`，`n∈I`。

边界和平滑误差若超过 `log^C X` 可控范围，按定义进入 `LV/LSMP/CE`，不属于本文主层。

## 2. 固定 r 的乘积壳计数

固定 `r` 后，条件变为

`q_1q_2 ∈ I/r`，

其中 `I/r` 是长度约 `L/r`、中心约 `X/r≈Q^2` 的乘积短区间。对 `q_1~Q` 固定，`q_2` 被限制在长度

`≈ L/(rq_1) ≈ L/(RQ)`

的区间中。因此每个 `q_1` 给出的 `q_2` 数量至多

`1 + L/(RQ)`

再乘固定 divisor/平滑损失 `log^C X`。于是固定 `r` 的候选数至多

`Q(1+L/(RQ))log^C X = (Q + L/R)log^C X`。

对 `R` 个 `r` 求和得到粗界

`RQ log^C X + L log^C X`。

该粗界还未利用“短窗占全局比例”的均衡；下一节给出零频比例修正。

## 3. 零频比例项

全局同层双锚容量为 `RQ log^C X`。在 CRT 非零类均衡和物理平滑窗有限重叠下，长度 `L` 的短窗只占 `[X/2,2X]` 的比例 `L/X`，故零频期望贡献为

`(L/X)RQ log^C X`。

若某短窗长期超过该比例期望，则超额不能记入零频容量，必须表现为下列结构之一：

1. 锚/相位在允许投影窗口中可检测，转 `PI`；
2. 覆盖容量同步，转 `A`；
3. 低维相位锁定，转 `FCT`；
4. 物理或 Bohr 支撑低体积，转 `LV/LSMP/SC`。

因此在“非结构超额”分支中，主项必须是比例项。

## 4. 端点与薄壳余项

比例均衡可能在每个 `r` 的乘积壳端点处损失。对固定 `r`，短区间 `I/r` 的两端各可贡献一个不完整 `q_2` 壳；对所有 `q_1` 的端点累积用 divisor bound 吸收为 `log^C X`。因此每个 `r` 的端点损失为 `log^C X`，总计

`R log^C X`。

若端点损失在少数 `r` 或少数短窗上集中超过该量级，则它正是更短簇或低体积端点事件，进入 `LV/LSMP/SC`。

## 5. dyadic 层容量界

合并第 3 节比例项与第 4 节端点项，得到

`Vol_eff(I;Q,R) << (L/X)RQ log^C X + R log^C X`。

该界在所有 dyadic 层上统一成立；层数只有 `O(log^2 X)`，可并入 `log^C X`。

## 6. 低体积吸收阈值

若

`(L/X)RQ log^C X + R log^C X <= X/log^B X`

且 `B` 大于后续 dyadic/Fourier 损失，则由 `docs/rh-lv-low-volume-principle.md` 吸收。特别地：

- 当 `L<=X/log^B X` 时，比例项有对数余量；
- 当 `R` 很小或端点项主导时，端点族是低体积薄层；
- 当二者都不小，却仍出现离线零点级超额，必须进入 `PI/A/FCT/SC` 结构分支。

## 7. 主定理

**Theorem SC-Local-Product-Capacity-Dyadic（条件化）。** 在 AAI 双锚正规形、dyadic 层固定、CRT/物理零频比例均衡和非低体积假设下，短窗 `I` 中同层双锚复用容量满足

`Vol_eff(I;Q,R) << (L/X)RQ log^C X + R log^C X`。

若该界不能用于吸收对应短簇质量，则失败必然进入 `PI/A/FCT/LV/LSMP/SC`，不形成独立 `CapacityFail`。

**证明。** 固定 `r` 和 `q_1` 后，`q_2` 被短乘积壳限制；全局容量由零频比例给 `(L/X)RQ`，端点不完整壳对每个 `r` 只贡献多对数损失，总计 `Rlog^C X`。dyadic 层数并入多对数。若比例均衡、端点控制或低体积吸收失败，则按第 3、4、6 节分别转入已命名结构事件。证毕。

## 8. 对容量矩阵的影响

本文把 `SC 局部乘积容量` 的“全 dyadic 层逐行证明”从剩余硬点降为条件化可审查接口。仍需在最终论文中与 AAI 正规形和 LV 体积阈值的常数层级统一排序。
