# GEE-SC 负担上界审查：短簇容量、递归转移与 seed 去重

本文专攻 `GEE-SC`。现有 SC 主文链已经证明：短簇局部乘积容量可显式计数，短簇递归不能无限下降；若重复短簇模板仍承载偏差，则转入 `A/PI/FCT/LV/LSMP/CE` 或触发局部容量矛盾。GEE 需要把这转写为出口负担口径。

## 1. SC 的正确 GEE 口径

SC 输入是短窗集中或高重叠结构。它可分为：

- `Load_abs(SC;X)`：局部乘积容量低于相对异常阈值，可由 LV/低体积或平凡容量吸收的短簇项；
- `Seed_rec(SC;X)`：短簇递归中产生的更短簇状态，作为内部转移；
- `Seed_out(SC;X)`：重复模板或容量失败输出的 `A/PI/FCT/LV/LSMP/CE` seed。

最终 GEE-SC 只登记不能再转移、不能吸收的终态短簇负担。SC 主文链说明这种终态不存在。

## 2. 可吸收短簇项

固定短窗 `I` 与 dyadic 层 `(Q,R)`，局部容量为

`Vol_eff(I;Q,R) << (|I|/X)RQlog^C X + Rlog^C X`。

若

`Vol_eff(I;Q,R)log^{C'}X <= Δ/log^{B_SC}X`，

则该短簇项由平凡容量估计给 `o(Δ)`，并可并入 `LV/SC_abs`。有限 dyadic 层、短窗网格和模板重叠只造成固定对数损失。

## 3. 非吸收短簇的递归/转出

若局部容量不低但仍承载固定比例异常，则 SC 主文链给出二分：

1. **真短簇递归：** 物理长度、Bohr 体积、锚自由度或 dyadic 高度之一严格下降；这是内部转移，不登记最终 `Load(SC)`；
2. **重复短簇模板：** 固定短窗/Bohr/dyadic/锚模板反复承载偏差，转入 `A/PI/FCT/LV/LSMP/CE` 或局部容量矛盾。

由短簇势函数 `𝓥` 有下界，真递归有限；终止时若没有吸收，必为重复模板，从而转出。

## 4. Theorem GEE-SC-Transfer

**Theorem GEE-SC-Transfer.** 假设 SC 局部乘积容量界、短簇递归下降账本、Seed-Transfer 去重账本成立。则可以重定义 GEE 路由，使：

1. 可吸收短簇项满足 `Load_abs(SC;X)=o(Δ)`；
2. 真 `shorter_SC` 步作为内部路由，不计入最终 `Load(SC)`；
3. 重复短簇模板与容量失败转入 `A/PI/FCT/LV/LSMP/CE` 或容量矛盾；
4. seed 转出不再重复计入 SC；
5. 最终留在 SC 的未处理负担为零。

因此在该路由定义下，

`Load(SC;X)=o(Δ)`。

**证明。** 对每个进入 SC 的异常原子，先检查局部容量阈值。满足阈值者由第 2 节吸收。否则沿规范短簇状态递推。每个真递归步使势函数下降，故只有有限多步。若递归不能继续且未吸收，则同一规范短簇模板重复承载偏差，由 SC 重复模板出口转入 `A/PI/FCT/LV/LSMP/CE` 或容量矛盾。Seed-Transfer 确保转出项从 SC 删除且有限重叠计入目标出口。故 SC 无最终未处理负担。证毕。

## 5. 审稿口径

`GEE-SC` 的结论不是“短簇不存在”，而是“短簇不是最终自由出口”。短簇要么低容量吸收，要么递归到更短状态，最终转入 `A/PI/FCT/LV/LSMP/CE` 或容量矛盾。

因此 `GEE-SC` 可标记为“容量吸收 + 内部递归转移闭合”。剩余压力主要集中到 `GEE-A` 与所有已转出目标出口的最终合成审查。
