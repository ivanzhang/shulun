# PC4-FCT：新增 CRT 坐标相位漂移引理

本文接续 `docs/rh-pc4-fct-seed.md`。FCT-Seed 已把无穷多 FCT 吸收归约为固定低维 CRT 频率模型长期编码离线相位 `γlogX`。本文建立下一层“相位漂移压力”引理：每当 CRT 模数新增素数坐标，固定低维 span 必须重新预测一个独立局部相位；若它长期成功，则产生平方能量集中，从而转入 PC4-PI 或短簇。本文仍不是 RH 证明；它把 PC4-FCT-Core 的硬点压缩为一个明确的同步排斥接口。

## 1. 固定低维编码模型

由 FCT-Seed，取无穷子列 `X_j`、对应新增素数层 `p_j` 与固定类型低维模型

`Φ_j = Σ_{i<=d} m_i ξ_i(X_j) mod p_j`, `Σ_i |m_i|<=H_*`, `d,H_*` 固定。

FCT 吸收离线零点项意味着存在固定短弧 `I_*`，使局部编码误差

`Err_j = phase(Φ_j) - γlogX_j mod 2π`

反复落入 `I_*`，并且在允许窗口上给同向偏差。

## 2. 新增坐标漂移量

当尺度从 `X_j` 推进到 `X_{j+1}`，CRT 模数新增或细化若干素数坐标。对一个新增坐标 `p`，定义局部漂移

`Δ_p = phase(Φ_{j+1}|_p) - phase(Φ_j|_{old projection}) - γ(logX_{j+1}-logX_j)`。

直观上，`γ(logX_{j+1}-logX_j)` 是连续相位漂移；`phase(Φ_{j+1}|_p)` 是由有限整数关系和新增 CRT 坐标生成的离散相位。若固定低维 span 长期编码成功，则 `Δ_p` 必须反复落入短弧。

## 3. 单新增坐标正交压力

**Lemma FCT-D1（新增坐标短弧命中平方压力）。** 固定低维模板 `𝓕_*` 与短弧 `I`。若在一组新增素数层 `𝓟` 上，局部漂移 `Δ_p` 命中 `I` 的次数超过其零频期望一个固定比例，即

`Σ_{p∈𝓟} (1_I(Δ_p)-|I|) >= η |𝓟|`,

则存在同一 FCT-Bohr 模板上的非主局部偏差 `b_p`，满足

`Σ_{p∈𝓟} ||b_p||_2^2 >= c(η,I)|𝓟|`。

**证明。** 用 Vaaler/Fourier 截断表示短弧指标 `1_I-|I|`。命中超额给出某个非零 Fourier 频率 `h` 的相关和下界。该频率正是新增 CRT 坐标上的非主局部因子。Parseval 给平方能量下界。证毕。

## 4. 漂移压力到 PI 或短簇

**Lemma FCT-D2（漂移压力转终端）。** 在无 FCT 新闭包、无 LSMP、无 LV 且 NRC/EXT 输入可用时，若 FCT 编码在无穷多新增坐标上保持同向短弧命中超额，则触发以下至少一项：

1. `PC4-PI` 高投影增量；
2. 短簇/低维 Bohr 交集集中；
3. DSO-E 非主局部因子平方和超过容量，矛盾。

**证明。** Lemma FCT-D1 把短弧命中超额转为非主局部偏差平方能量。若能量集中在可检测窗口，按 `docs/rh-pc4-pi-closure-theorem.md` 转入 PC4-PI；若集中在低维 Bohr 交集的小体积集合，转入短簇或 LV/LSMP；若分散，则由 `docs/rh-pc4-dso-euler-decorrelation.md` 与 `docs/rh-pc4-pi-dense-closure-theorem.md` 的平方容量界控制，不能长期超额。证毕。

## 5. 相位漂移主引理

**Proposition FCT-Drift（相位漂移压力引理，条件化）。** 若 FCT-Seed 的固定低维编码在无穷多尺度上同向吸收 `γlogX`，则至少发生一项：

1. 新增坐标短弧命中只按零频期望发生，因而不能解释离线零点级同向偏差；
2. 命中超额产生平方能量压力，触发 PC4-PI、短簇、LSMP/LV 或 DSO-E 容量矛盾；
3. 有一个更低维的相位同步关系反复出现，进入新的 FCT 闭包证书。

**证明。** 若固定低维编码长期成功，则每个成功尺度对应新增坐标漂移命中短弧。若命中无超额，则贡献仅为零频背景，不能吸收 FCT-Seed 中同向离线偏差。若有超额，由 FCT-D1 产生平方能量压力，再由 FCT-D2 转入终端或容量矛盾。若 FCT-D2 的非共振条件失败，则按 NRC/FCT 口径得到新的低维同步证书，即第 3 项。证毕。

## 6. 剩余核心同步排斥

本文把 PC4-FCT-Core 缩小为一个更窄的问题：排除第 3 项无限递归，即排除固定低维同步关系不断降维/闭包却永不触发 PI 或短簇的情形。

`FCT-Noether` 已在 `docs/rh-pc4-fct-noether.md` 中写出：FCT 闭包链若不严格降低剩余秩-体积预算，则同一 Bohr 交集反复承载偏差，触发 PC4-PI 或短簇。下一步最优攻坚是合并为 `PC4-FCT-Closure`。
