# LG-AP 硬攻稿：列反例覆盖方案的刚性排斥

**状态：** 真正核心方向；不再转换命题，而是直接攻击列反例覆盖方案。

## 1. 列反例的原始覆盖方程

固定奇素数 `P` 与非零列 `1<=c<P`。列反例为：

`c, P+c, 2P+c, ..., (P-1)P+c`

全部合数。

因为每个数 `<P^2`，其合数性必须由某个根基素数 `<P` 解释。于是存在标签函数

`q: {0,1,...,P-1} -> {prime q<P}`

使

`q(k) | kP+c`。

等价地，对每个标签素数 `q`，它能覆盖的行号满足唯一同余类

`k ≡ -c P^{-1} mod q`。

因此列反例等价于区间 `[0,P-1]` 被根基素数的行同余类覆盖：

`[0,P-1] subset ⋃_{q<P} R_q(c)`，

其中

`R_q(c)={k: k≡r_q(c) mod q}`。

这是列方向的斜线覆盖方程。

## 2. 第一刚性：小标签静止与大标签稀疏

对固定列，素数 `q` 的覆盖行是步长为 `q` 的等差序列。在长度 `P` 的行窗口中，它最多覆盖

`ceil(P/q)`

个点。

- 小 `q` 覆盖多，但只覆盖一个固定余类；
- 大 `q>sqrt(P)` 覆盖少，最多约 `sqrt(P)` 个；
- 若 `q>P/2`，最多覆盖一个点。

所以列反例需要一个多层覆盖账本：小素数形成粗骨架，大素数补小素数骨架的洞。

## 3. 第二刚性：小骨架残洞量级

取小素数集合 `B`。被 `B` 覆盖后的剩余行集合为

`H_B(c)={0<=k<P: kP+c not≡0 mod b for all b in B}`。

在完整 `M_B=prod_{b in B}b` 周期中，密度为

`δ_B=prod_{b in B}(1-1/b)`。

因此在长度 `P` 窗口中，粗略有

`|H_B(c)| = δ_B P + O(M_B)`。

若 `B` 取到 `M_B<sqrt(P)`，则误差小于主项，残洞仍为线性量级 `≈δ_B P`。

这些残洞必须由 `q notin B` 补掉。

## 4. 第三刚性：大标签补洞的短差互斥

若两个残洞行 `k_1,k_2` 被同一大标签 `q` 覆盖，则

`q | (k_2-k_1)P`。

因 `(q,P)=1`，得

`q | k_2-k_1`。

所以若 `0<|k_2-k_1|<q`，同一 `q` 不可能覆盖二者。

特别地，对于 `q>sqrt(P)`，在任意长度 `<sqrt(P)` 的行段内，同一大标签最多补一个残洞。这是列版本的大因子互斥。

## 5. 第四刚性：残洞局部密度迫使多个大标签

若小骨架残洞 `H_B(c)` 在某个长度 `L<sqrt(P)` 的行段中含 `m` 个点，而这些点都不能由中小标签补掉，则至少需要 `m` 个互异大标签。

于是同步模数乘积至少为

`prod_{i=1}^m q_i`。

但列反例固定了同一个列 `c`，不同 `q_i` 的覆盖同余是对行号 `k` 的不同限制；若这些限制共同服务于同一短段的覆盖，它们不能形成周期复用，只能作为孤立补点。多个孤立补点又会在相邻段产生释放/缺口。

这与行方向 SFL 是同一机制的转置。

## 6. 第五刚性：小骨架洞不能全部孤立

关键要证明：对某个可选 `B`，集合 `H_B(c)` 中必存在短差核心，即在长度 `<sqrt(P)` 的窗口内有至少两个需要大标签补洞的点。

若否，则 `H_B(c)` 是 `sqrt(P)`-分离集，故

`|H_B(c)| <= sqrt(P)+1`。

但当 `M_B<sqrt(P)` 且 `δ_B P - O(M_B)>sqrt(P)+1` 时矛盾。

因此小骨架残洞必含短差核心。

## 7. 第六刚性：中标签层不能无代价吸收全部短差核心

可能的反驳是：短差核心中的点不一定需要 `>sqrt(P)` 的大标签，可能由 `B<q<=sqrt(P)` 的中标签覆盖。

对此采用层叠剥离：逐步扩大 `B` 到 `z`，直到短差核心中剩余点若再补就必须用 `q>sqrt(P)`。每扩大一次小壳，残洞密度乘以 `(1-1/q)`，但只要 `M_B` 控制在 `sqrt(P)` 以下，残洞仍超过稀疏上界并产生新短差核心。

若扩大到所有 `q<=sqrt(P)`，则剩余残洞是 `sqrt(P)`-粗数行。若列反例成立，这些粗数必须由 `q>sqrt(P)` 补掉，于是 SFL/KFCI 直接启动。

## 8. 核心硬攻引理 LG-AP-core

**LG-AP-core。** 对任意奇素数 `P`、任意 `1<=c<P`，若列反例成立，则存在一个根基分界 `B` 与一个短差核心 `W subset H_B(c)`，满足：

1. `diam(W)<sqrt(P)`；
2. `|W|>=2`；
3. `W` 中所有点在下一层必须由 `q>sqrt(P)` 的互异大标签补掉，或小壳迁移产生释放；
4. 因而触发 KFCI/SFL 矛盾。

证明关键是第 3 点：要严密说明中标签层不能无限吸收短差核心而不产生新的短差核心或释放。

## 9. 可能的突破路径：递归剥离不变量

定义层 `B_z={q<=z}`，残洞集

`H_z(c)={k<P: kP+c not≡0 mod q for all q<=z}`。

若列反例成立，则对每个 `k in H_z(c)`，必有某个 `q>z` 覆盖它。

取 `z` 从小增长到 `sqrt(P)`。设

`N_z=|H_z(c)|`，

`G_z` 为 `H_z(c)` 的 `sqrt(P)` 短差图。

若 `G_z` 无边，则 `N_z<=sqrt(P)+1`。但筛密度给

`N_z≈P prod_{q<=z}(1-1/q)`。

当 `z` 不太大时，该量大于 `sqrt(P)`，故有边。

当 `z` 接近 `sqrt(P)` 时，密度约

`P / log sqrt(P)`，仍远大于 `sqrt(P)` 对充分大 `P` 成立。

所以直到 `z=sqrt(P)`，残洞仍应有短差核心。这是关键量级差距：

`P/log P >> sqrt(P)`。

若能把误差控制到低于主项，就得到真正闭合。

## 10. 误差控制接口

需要一个区间筛余下界：对模数为所有 `q<=z` 的非零类交集，在长度 `P` 的区间中，

`N_z >= c P/log z - error(z,P)`。

如果取 `z<=sqrt(P)`，希望有

`N_z > sqrt(P)+1`。

这类似粗筛下界。可由 Legendre 筛/Brun 下界给出，但必须注意：这是对单个算术进列 `kP+c` 的筛余集合；因为 `P` 与所有 `q<P` 互素，余类均匀，可按普通区间筛处理。

若该筛余下界无条件成立，则列反例必须在 `H_{sqrt(P)}(c)` 中留下短差核心，而这些点只能由 `q>sqrt(P)` 补，触发 SFL。

## 11. 当前真正硬点

因此 LG-AP 的核心已压到一个经典但可攻的筛下界：

**Rough-residue lower bound.** 对任意 `P` 与 `c`，集合

`{0<=k<P: kP+c has no prime factor <=sqrt(P)}`

的大小应大于 `sqrt(P)+1`。

若这成立，则其中必有两个行号距离 `<sqrt(P)`，而列反例要求它们由 `>sqrt(P)` 的因子补掉，短差互斥迫使互异大标签，进入同步/高度矛盾。

但要注意：`kP+c<P^2`。若它没有 `<=sqrt(P)` 的因子，则它可能是素数或两个都大于 `sqrt(P)` 的因子之积。后者仍小于 `P^2`，可能存在。

因此还需结合半素数层容量，证明这些粗合数不足以覆盖所有粗筛残洞。

## 12. 下一步最小硬攻点

专攻：

`rough candidates > rough composites capacity`

即证明在列 `c mod P` 的前 `P` 个数中，避开 `<=sqrt(P)` 小因子的候选数量，大于可由两个 `>sqrt(P)` 因子组成的合数数量。

这是真正不转换命题的硬攻：直接在列反例覆盖方程内部比较“粗候选数量”和“粗合数容量”。

## 14. 新硬攻方向：粗合数匹配刚性

粗合数在前窗口中形如

`kP+c = uv`，其中 `u,v>sqrt(P)` 且 `u,v<P`。

这给出双曲匹配方程

`uv ≡ c mod P`, `uv<P^2`。

列反例若成立，则每个粗候选都必须被这种双大因子匹配吸收。

关键不是粗合数数量，而是它们的匹配结构：

1. 固定 `u`，`v≡c u^{-1} mod P`，且 `v<P`，所以 `v` 基本唯一；
2. 因 `u,v<P`，所有因子都落在同一个有限乘法群 `F_P^*`；
3. 粗合数层对应乘法超曲线 `uv=c` 在方形 `(sqrt(P),P)^2` 内的格点；
4. 若这些格点覆盖整列粗候选，则乘法匹配必须在行号 `k=(uv-c)/P` 上填满筛余残洞；
5. 相邻行差对应

   `u_1v_1-u_2v_2 = (k_1-k_2)P`。

短差核心中 `|k_1-k_2|<sqrt(P)`，右侧小于 `P^{3/2}`，而左右因子都大于 `sqrt(P)`，这迫使强近似关系。

## 15. 乘法匹配能量引理 MME

下一步真正硬点应改为：

**MME（multiplicative matching energy）。** 在固定非零列 `c mod P` 中，双大因子匹配集合

`M_c={(u,v): sqrt(P)<u,v<P, uv≡c mod P}`

映到行号

`k=(uv-c)/P`。

其像集不可能覆盖粗筛残洞中的每个短差核心而不产生：

- 两个匹配共享因子导致短差整除矛盾；
- 或乘法能量过高导致多个 `uv` 落入过短区间；
- 或 CRT 列均衡/镜像补偿失衡。

这才是粗合数层必须攻克的本质，而不是简单数量不足。

## 18. MME-1：短差粗合数互因子引理

设同一列 `c mod P` 中两个数

`N_i=k_iP+c`, `N_j=k_jP+c`

都是粗合数，且共享某个根基因子 `q>sqrt(P)`。则

`q | N_i-N_j = (k_i-k_j)P`。

因 `q<P` 且 `q≠P`，得

`q | k_i-k_j`。

所以若

`0<|k_i-k_j|<sqrt(P)<q`，

矛盾。

因此：

> 同一列中，距离 `<sqrt(P)` 的两个粗合数不能共享任何 `>sqrt(P)` 的因子。

这说明粗合数短差核心虽然数量不少，但每个点必须使用完全不同的大因子坐标；其乘法匹配没有局部复用能力。

## 19. MME-2 目标：短差粗合数核心的乘法能量

若一个短差核心中有 `m` 个粗合数点，则它们需要至少 `2m` 个大因子出现次数，且任意两点之间不能共享因子。

要让这些点都落在同一列 `c`，每个点满足

`u_i v_i ≡ c mod P`。

这给出 `m` 个独立乘法匹配。下一步需证明：当这些匹配在行号上挤入长度 `<sqrt(P)` 的短窗口时，乘法差

`u_i v_i-u_j v_j=(k_i-k_j)P`

迫使某种能量下界，不能覆盖所有粗筛残洞短差核心而不产生素数。

这就是 MME 的下一硬点。
