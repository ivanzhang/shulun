# Gap 级闭锁候选引理

**状态：** `promising_multimodulus_gap_locking_interface`

上一轮 RCL 同因子短差扫描显示：只看同一个大因子 `q` 在两个格点重复出现，模数乘积不足以超过短差。这个方向不够强。

新的标签链相邻差分扫描显示更有希望的结构：行内大因子补洞点的相邻洞距 `gap` 会大量重复，而同一个小 `gap` 涉及许多不同的大因子标签。其模数乘积远远超过 `gap` 本身。

## 1. 观察

在固定行中，经过小筛后的大因子补洞点形成链

`c_1 < c_2 < ... < c_m`，对应标签

`q_i | (r-1)P+c_i`。

相邻洞距

`g_i = c_{i+1}-c_i`

经常取小值，如 `2,4,6,12`，且同一个 `g` 在一行中重复多次。

实验中同一 `g` 的相关标签集合 `Q_g` 往往很大，例如 `P=1601` 时 `g=6` 可涉及三十多个大因子，`log ΠQ_g` 远大于 `log g`。

## 2. 为什么这可能产生 CRT 矛盾

单个相邻关系给出：

`(r-1)P+c_{i+1} - ((r-1)P+c_i) = g_i`。

两个相邻点通常由不同大因子 `q_i,q_{i+1}` 分别解释，所以并不直接要求 `q_i q_{i+1}|g_i`。

因此 gap 级矛盾不能是简单整除矛盾；必须使用“全覆盖/满补链”的选择刚性：

- 若同一 gap 重复出现很多次，标签对 `(q_i,q_{i+1})` 形成一个转移族；
- 这些转移族在行推进时按各自模数产生不同漂移；
- 若全覆盖链要在有限宽度圆柱内保持无洞，就必须让这些转移在后续行中继续拼接成覆盖链；
- 这会迫使多个不同 `q` 对同一 gap 转移保持相位兼容；
- 多模数兼容最终产生 CRT 矛盾。

## 3. 候选引理 GL（Gap Locking）

设某行全覆盖，且小筛洞均由大因子补掉。令 `G` 为补洞链中出现次数最多的相邻 gap，`Q_G` 为参与该 gap 两端的所有大因子标签集合。

若 `|Q_G|` 足够大，则全覆盖链向下推进时，存在 `1<=t<P` 使得至少两个以上互素标签必须同时保持 gap `G` 的拼接兼容，导致

`q | tP + O(G)`

对多个 `q in Q_G` 同时成立。

当这些 `q` 的乘积超过 `tP+O(G)` 的可用尺度时矛盾。

## 4. 需要严化的桥

当前还不能直接证明多个 `q` 同时整除同一个短量。真正要证明的是：

> 重复 gap 的多标签转移，在全覆盖链的圆柱推进中不能完全自由漂移；若它们都自由漂移，则下一行/若干行会产生洞；若不产生洞，则存在短闭锁。

这就是新的核心桥接命题。

## 5. 下一步实验

对每个高频 gap `G`：

1. 记录所有转移 `(q_i,q_{i+1})`；
2. 推进行号 `t=1..P-1`；
3. 检测这些转移是否在新行仍能以 gap `G` 或邻近 gap 拼接；
4. 找出需要同时稳定的标签子集；
5. 计算其模数乘积与短差尺度。

若高频 gap 转移确实表现出短闭锁压力，则 GL 引理比原 RCL 更可能闭合。
