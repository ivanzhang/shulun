# D4/R5 递归剥离探针状态

## 探针对象

对三个窗口极值见证 `1088373,1088475,1088588`，按 `hi=80,120,...,400` 逐层加入壳层，记录 `L,E2,potential` 与新增壳层缺陷。

证书：`docs/d4-r5-recursive-peeling-probe.json`

## 观察

1. 对 `x=1088373` 和 `x=1088475`，每个新增壳层的 `new_shell_defect` 均为正。
2. `x=1088475` 的 potential 随壳层整体增强，说明 high-mass 见证更像“能量耗散型”而不是回传型。
3. `x=1088588` 在 `160->200` 出现 `L` 与 `E2` 的大幅下降，说明存在层重分类跳变；不能简单用单调壳层递推处理。

## 下一引理分裂

递归剥离引理 RPL 应分成两类：

1. **固定层壳引理 RPL-stable**：若层标签不变，则新增壳层提供非负二次缺陷，且可定量下界。
2. **重分类跳变引理 RPL-jump**：若层标签改变，则坏结构要么被削弱，要么落入有限危险窗口，由外向舍入证书处理。

这比“有限模板覆盖所有尺度”更符合无穷素数约束逐层增长的本质。
