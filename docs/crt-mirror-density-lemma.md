# CRT 镜像密度刚性引理

**状态：** `exact_mirror_symmetry_confirmed_experimentally`

实验显示完整 CRT 周期中存在精确镜像规律：

`row_count(r) = row_count(M+1-r)`。

其中 `M=Π_{q<P}q`，`row_count(r)` 表示第 `r` 行在除第 `P` 列外的类素数数量。

## 1. 同余解释

第 `r` 行第 `c` 列为

`N(r,c)=(r-1)P+c`。

镜像行 `r'=M+1-r` 给出

`N(r',P-c)= (M-r)P + (P-c)`

与 `N(r,c)` 相加：

`N(r,c)+N(r',P-c)=MP+P = P(M+1)`。

对任意根基素数 `q<P`，有 `M≡0 mod q`，且 `P` 与 `q` 互素。因此

`P(M+1) ≡ P mod q`。

实际列置换为 `σ(c)=P-c`。此时

`N(r,c)+N(M+1-r,P-c)=P(M+1)`。

由于 `M≡0 mod q`，有 `P(M+1)≡P mod q`，这里还需注意非零类条件在 `1..P-1` 列上的等价性；直接计算给出对所有根基模数的非零同余类交集双射。

## 2. 对零行的影响

若 `r` 是零行，则 `M+1-r` 也是零行。实验中：

- `P=13` 的零行 `169,702,1609,2142` 成镜像对；
- `169 ↔ 2142`，`702 ↔ 1609`。

因此零行集合关于周期中点镜像对称。

## 3. 与前窗口排斥的关系

镜像对称本身不能排除前窗口零行：若 `r<=P` 是零行，则 `M+1-r` 也是零行，位于末端。它解释了“末端附近高合密”现象：前端结构会在末端镜像出现。

但若经验上末端高合密而前端不为零，则说明前端受高度约束保护，末端不受 `n<P^2` 高度约束。

因此镜像引理应与高度约束结合：

- 纯 CRT：允许零行成镜像对；
- 高度窗口：排除靠近前端的零行；
- 镜像：同时排除靠近末端的对应前端型零行，解释端点刚性。

## 4. 候选引理 M

完整 CRT 周期的类素数行密度满足精确镜像：

`A(r)=A(M+1-r)`。

证明使用列置换 `σ(c)=P-c`，使得对所有 `q<P`：

`N(r,c) not≡0 mod q` 当且仅当 `N(M+1-r, σ(c)) not≡0 mod q`。

## 5. 并入矛盾场

镜像密度给出势函数对称性：

`A(r)-mean` 是关于周期中点的偶函数。

零行若进入前窗口 `[1,P]`，则末端也出现镜像零行。列均衡要求二者亏损由周期内部高密行补偿。补偿流必须跨越从前端到中部再到末端的相位结构。

下一步应研究：

> 前窗口高度约束为何禁止零行，而中/远端无高度约束时允许零行。

这将镜像刚性与相位延迟路线合并。
