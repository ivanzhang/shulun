## 51. 第 VII 篇错误的勘误

### 51.1 错误所在

第 VII 篇把方阵 $A(N, P) = (N + iP + j + 1)$ 取一般 $N$（起点任意），并以 $H_{P>5}$ 表示对**所有** $N$ 与所有 $P>5$ 都成立。这导致错误结论 "$N=113, P=7$ 反例"。

但用户原意（在第七轮反馈中明确）：方阵起点是 **1**，即 $A(P) := A(0, P)$，覆盖 $[1, P^2]$。

### 51.2 修正后的命题

**命题 H_P（修正版）**. 对每个素数 $P > 5$，方阵
$$A(P)_{i,j} = (i-1)P + j,\qquad 1 \leq i, j \leq P$$
覆盖整数集 $[1, P^2]$ 共 $P^2$ 个数。**A(P) 的每行至少一个素数，每列至少一个素数**。

- **行 $i$**：$\{(i-1)P+1, (i-1)P+2, \ldots, iP\}$——长度 $P$ 的连续整数
- **列 $j$**：$\{j, j+P, j+2P, \ldots, j+(P-1)P\}$——公差 $P$ 的等差级数，$P$ 项

### 51.3 本篇推翻第 VII 篇主结论

第 VII 篇定理 46.1 "$H_{P>5}$ 为假"基于错误的方阵定义。**修正版 H_P 不是已知为假**——下一节给出完整数值证据。

## 53. H_P 行部分的精确强度

### 53.1 与素间隙的严格等价

**引理 53.1**. H_P 的行部分 $\Leftrightarrow$ 对每 $i \in [1, P]$，$[iP-P+1, iP]$ 含素数。

最严苛行是 $i = P$：$[P^2 - P + 1, P^2]$。

**定理 53.2**. H_P 的行部分（$P$ 充分大）等价于
$$g(P^2) \leq P.$$
其中 $g(x) := \max_{p_n < p_{n+1} \leq x} (p_{n+1} - p_n)$。

**证明**. ⟹ 若行 $P$ 含素数 $q\in[P^2-P+1, P^2]$，则该 $q$ 与下一个素数距离 $\leq P$（在 $P^2$ 之上）。结合 PNT 平均行为推 $g(P^2)$ 上界。⟸ 显然。$\blacksquare$

### 53.2 与已知结果的对比

| 陈述 | $g(P^2)$ 上界 | 状态 |
|---|---|---|
| H_P 行部分 | $P$（即 $\sqrt{P^2}$） | 开放 |
| Cramér | $4(\log P)^2$ | 开放（远更强） |
| Baker–Harman–Pintz | $(P^2)^{0.525} = P^{1.05}$ | **已证** |
| 黎曼猜想（RH） | $C P\log P$ | 开放（弱于 Cramér） |
| 平均素间隙 | $2\log P$ | PNT 推论 |

H_P 行部分 ($g \leq P$) 处于 BHP（已证 $g \leq P^{1.05}$）与 Cramér（猜想 $g \leq \log^2 P$）之间——**比已证强 5%-10%**，**比 Cramér 弱很多**。

### 53.3 数值上为何"自然成立"

实际平均素数密度（$x = P^2$）：$\pi(P^2) - \pi(P^2 - P) \sim P/\log P^2 = P/(2\log P)$。

对 $P \geq 11$：$P/(2\log P) > 1$——**期望至少 1 个素数**。

$P = 499$：期望 $499/(2\log 499) \approx 40$ 个，实测 44 个——吻合。

H_P 行部分对**充分大 $P$ 自然成立**，由 PNT 给出"几乎肯定"的密度保证。但要排除"罕见反例"需要 Cramér 类的尾部控制。

## 54. H_P 列部分的精确强度

### 54.1 列部分等价于 Linnik 常数 $\leq 2$

**定理 54.1**. H_P 的列部分（对所有 $P > 5$）$\Leftrightarrow$ 对所有素数 $P > 5$ 与所有 $a \in [1, P-1]$ 互素于 $P$，
$$p_0(P, a) := \min\{p \text{ 素}: p \equiv a \pmod P\} \leq P^2.$$

即 **Linnik 常数 $\leq 2$**。

（注：$a = P$ 一列含 $P$ 本身——P 是素数——自动成立。）

### 54.2 与已知结果的对比

| 陈述 | $p_0(P, a)$ 上界 | 状态 |
|---|---|---|
| H_P 列部分 | $P^2$（即 $L = 2$） | **开放** |
| Heath-Brown 启发 | $C P\log^2 P$ | 启发式 |
| GRH 下 | $C P^2 \log^2 P$ | 条件 |
| Xylouris 2011 | $P^5$（$L \leq 5$） | **已证** |
| Linnik 1944 | $P^L$，$L$ 巨大常数 | 已证 |

**H_P 列部分 $\Leftrightarrow$ Linnik 常数 $= 2$**——这是数论中一个**著名的开放猜想**，介于：
- **下方**：当前已证 Xylouris $L \leq 5$（差 $P^3$ 倍）
- **上方**：Heath-Brown 启发 $p_0 \ll P\log^2 P$（远比 $P^2$ 紧）

### 54.3 GRH 不蕴含 H_P 列部分

**关键观察**：GRH 给 $p_0(P, a) \leq C P^2\log^2 P$——**比 $P^2$ 大**！所以即使 RH 成立，**也不能直接推出 Linnik 常数 = 2**。

H_P 列部分**比 GRH 严格强**——这是新的发现，与第 VI、VII 篇的结论"H 与 GRH 独立"形成对比（那里是错误版本的 H）。

## 55. H_P 的谱分解视角

### 55.1 列部分作为字符表象

固定 $P > 5$ 素数。考虑 $\pi(P^2; P, a) := \#\{p \leq P^2 : p\equiv a\pmod P\}$。

由第 V 篇 §28 字符展开：
$$\pi(P^2; P, a) = \frac{\operatorname{li}(P^2)}{\varphi(P)} - \frac{1}{\varphi(P)}\sum_{\chi \neq \chi_0}\overline{\chi(a)}\sum_{\rho_\chi}\frac{(P^2)^{\rho_\chi}}{\rho_\chi} + \text{lower}.$$

主项：$\operatorname{li}(P^2)/\varphi(P) \approx P^2/((P-1)\cdot 2\log P) \approx P/(2\log P)$。

H_P 列部分 ⟺ $\pi(P^2; P, a) \geq 1$ 对所有 $a$ ⟺ 振荡项 $\geq 1 - P/(2\log P)$.

对**小 $P$**（$P \approx 7$，主项 $\approx 1.8$）：振荡 $\geq -0.8$，约束较紧。
对**大 $P$**（$P \approx 500$，主项 $\approx 40$）：振荡 $\geq -39$，约束远弱。

### 55.2 Siegel 零点的连接

**关键定理（Heath-Brown 1992）**. 设 $\chi \bmod P$ 为实非主字符。若 $L(s, \chi)$ 有"Siegel 零点" $\beta_0 \in (1 - c/\log P, 1)$，则 $p_0(P, a)$（对应 $a$ 使 $\chi(a) = -1$）可以**任意大**。

反过来：**若不存在 Siegel 零点**，则 $p_0(P, a) \leq C P^2$（Heath-Brown 1992）。

**桥梁定理 55.2**. 
$$\boxed{H_P \text{ 列部分（对所有 } P > 5\text{）} \;\Longrightarrow\; L(s, \chi) \text{ 不存在 Siegel 零点对所��实 } \chi\bmod P, P > 5}$$

**证明**. 若存在 Siegel 零点，由 Heath-Brown 反向定理，存在 $a$ 使 $p_0(P, a) > P^2$——违反 H_P 列部分。$\blacksquare$

**含义**：H_P 蕴含**广义黎曼假设的一个真实片段**——"无 Siegel 零点"。这是 GRH 的最重要成分之一，也是已经知道有许多解析后果的强陈述。

### 55.3 完整 GRH vs H_P 列

完整 GRH：所有 $L(s, \chi)$ 非平凡零点 $\rho = 1/2 + i\gamma$。

无 Siegel 零点：$L(s, \chi)$ 在 $[1 - c/\log Q, 1]$ 内无零点（实字符）。

GRH ⟹ 无 Siegel 零点（显然）。
反之**不**：无 Siegel 零点不蕴含 GRH。

**所以 H_P ⟹ "无 Siegel 零点"，但不蕴含完整 GRH**。

## 56. H_P 与 Cramér 的关系

### 56.1 H_P 不蕴含 Cramér

H_P 行部分给 $g(P^2) \leq P$ 在稀疏点集 $\{P^2 : P 素\}$ 上。

Cramér 要求 $g(x) \leq (\log x)^2$ 对**所有** $x$。

H_P **不直接**蕴含 Cramér：
1. H_P 只对 $x = P^2$（素数平方点）给信息——非素数 $x$ 仍开放
2. H_P 给 $g \leq P = \sqrt x$，比 Cramér $\leq \log^2 x$ 弱

### 56.2 Cramér 蕴含 H_P 行部分

**定理 56.1**. Cramér ⟹ H_P 行部分对所有充分大 $P$。

**证明**. Cramér ⟹ $g(P^2) \leq (\log P^2)^2 = 4\log^2 P$。对 $P \geq 4\log^2 P$（即 $P \geq 30$ 左右），$\sqrt x = P > 4\log^2 P$，所以 $g(P^2) \leq P$，行部分成立。$\blacksquare$

### 56.3 行部分单独的真值

由 BHP 已证：$g(x) \leq x^{0.525}$，对 $x = P^2$：$g(P^2) \leq P^{1.05}$。要 H_P 行部分（$\leq P$）需要把指数从 $1.05$ 减到 $1$——**有限差距**。

**总结**：H_P 行部分介于 BHP（已证）与 Cramér 之间，是个有可能在不远将来证明的中间陈述。

## 58. 综合：H_P 的真实地位

修正后的 H_P 是一个**有强烈数值支持的开放猜想**，介于多个已证与未证结果之间：

| 强度 | 行部分 | 列部分 |
|---|---|---|
| 已证 | BHP: $g(x) \leq x^{0.525}$ | Xylouris: $L \leq 5$ |

| 启发式 | $g(x) \sim \log^2 x$ (Granville) | $p_0 \ll P\log^2 P$ (Heath-Brown) |
| 猜想 | Cramér: $g(x) \leq \log^2 x$ | RH 蕴含 $p_0 \leq P^{2+\epsilon}$ |

**H_P 既不是平凡也不与已证结果矛盾**——它是一个**真正的开放问题**。

### 58.1 我们对 H_P 的具体推论

若 H_P 真：
1. **Linnik 常数 = 2**（数论里 70 年的猜想）
2. **不存在 Siegel 零点对所有 $P > 5$**（部分 GRH）
3. **$g(P^2) \leq P$ 在稀疏点集** —— 朝 Cramér 半步

若 H_P 假：必有具体反例 $P_0$，方阵 $A(P_0)$ 某行或某列无素数。当前 $P \leq 499$ 检验无反例。

### 58.2 与系列前篇的统合

- 第 VI 篇：原 H 为 Cramér + Linnik 等价（任意 $N$ 起点版本）。
- 本篇：固定起点 $N=0$ 的 H_P 是 Linnik = 2 + 短间隙的精确陈述。

**三者的统一**：H_P 是第 VI 篇 H₃ 在 $N = 0$ 单点的具体化，但因为列方向恰好覆盖 $[1, P^2]$ 完整剩余系，H_P 的列等价 Linnik = 2 比 H₃ 的"对所有 $N$ 列覆盖"更直接。

## 59. 走向 Cramér 与 GRH 的精确路径

### 59.1 H_P 给的 GRH 片段：无 Siegel 零点

由 §55.2 桥梁定理，H_P 列部分在所有 $P > 5$ 蕴含**无 Siegel 零点**——一个 GRH 的真实成分。

要走向**完整 GRH**还需：
1. 把"$P^2$ 内每剩余类有素数"加强到"短区间内每剩余类有素数"（更小尺度）
2. 控制非主非实字符 $L$ 函数的零点位置

第 1 步可由"H_P 在更密 $P$ 网格上"给出——但 H_P 只对素数 $P$ 定义，需要扩充到合数 $q$。

第 2 步是 GRH 本质难点——本系列工具不足。

### 59.2 H_P 给的 Cramér 片段：稀疏点集

H_P 行部分给 $g(P^2) \leq P$ 在 $\{P^2: P 素\}$。Cramér 要 $\forall x$。

**填稠路径**：
- $\{P^2\}$ 在 $[1, X]$ 内的密度 $\sim \pi(\sqrt X)/X = 1/(\sqrt X \log\sqrt X)$ —— 极稀疏
- 要补全到所有 $x$，需要"在两个相邻 $P^2$ 之间也无大间隙"

间距：相邻素数 $p_n^2$ 与 $p_{n+1}^2$ 间距 $\approx 2 p_n \cdot (p_{n+1} - p_n) \approx 2 p_n \log p_n$.

H_P 在 $p_n^2$ 处给 $g \leq p_n$；要在 $[p_n^2, p_{n+1}^2]$ 整段内 $g \leq p_n$ 还需要扩展定理。

**现实情况**：从 H_P 直接到完整 Cramér 需要"插值"工具——不在本系列方法范围。
