# PC4-A：ACC 同步账本与事件图防循环审查

本文补强 `docs/rh-pc4-acc-sync-pressure.md` 中的审稿接口：ACC 同步压力不能把问题循环地推回自身。核心是给固定 ACC 覆盖模板建立容量-相位账本；若模板真变化，则复杂度/容量势函数下降或触发 CE/LV/LSMP；若模板不变而同向过剩重复出现，则由固定模板偏差分解强制转入 PI/FCT/SC 或 DSO 容量矛盾。

## 1. ACC 状态规范化

ACC 状态记为

`A=(𝓒,𝓐,Q,R,𝓑,ω)`，

其中：

- `𝓒` 是 Tail/Body/Overlap/Boundary 等覆盖组件类型；
- `𝓐` 是有限复杂度覆盖模板，包含锚语义、倒数相位和允许类条件；
- `Q,R` 是 dyadic 层；
- `𝓑` 是模板依赖的 CRT/Bohr 切片；
- `ω` 是离线零点短弧相位方向。

规范化规则：同一覆盖组件、同一 dyadic 层、同一 Bohr 切片和同一有限锚语义的常数倍缩放实例视为同一 ACC 模板。若模板复杂度无界，则不是 A 分支，而是 CE/FCT/LSMP 出口。

## 2. ACC 势函数

定义离散势函数

`𝓐pot(A)=C_1 cplx(A)+C_2 b(A)+C_3 h(A)+C_4 v(A)`，

其中：

- `cplx(A)` 是覆盖模板复杂度层；
- `b(A)` 是 Bohr/CRT 切片剩余体积层；
- `h(A)` 是 dyadic 层高度预算；
- `v(A)` 是尚未解释的 ACC 过剩容量账本层。

权重取 `C_1 >> C_2 >> C_3 >> C_4 >> 1`。在排除 CE/LV/LSMP 后，各层均为有界或非负整数，故 `𝓐pot` 有下界。

## 3. ACC 同步步的四型

从一个 ACC 同步状态到下一状态只有四种非终端变化。

| 类型 | 真变化 | 下降/出口 | 不降含义 |
| --- | --- | --- | --- |
| 模板复杂度增加 | 新锚语义或新相位切片 | CE/FCT/LSMP，或固定层内不允许 | 非 A 真步 |
| Bohr/CRT 细化 | 切片体积下降 | `b` 下降或 LV/SC | 切片冗余 |
| dyadic 剥离 | `Q,R` 层更窄 | `h` 下降或 LV | 同层重复 |
| 过剩容量解释 | ACC 过剩被某可见组件吸收 | `v` 下降 | 同一模板重复过剩 |

因此，若 A 分支试图通过不断换模板逃逸，要么进入 CE/FCT/LSMP，要么势函数严格下降。若没有真变化，则它就是固定 ACC 模板在无穷尺度上重复同向过剩。

## 4. 固定模板重复压力

**Lemma A-L1（固定 ACC 模板重复出口）。** 若同一规范 ACC 状态 `A` 在无穷多尺度上产生同相位 `X^{β-o(1)}` 级过剩，`β>1/2`，则至少触发一项：

1. PC4-PI 高投影增量；
2. PC4-FCT 频率闭包；
3. PC4-SC 短簇；
4. LSMP/LV 低质量或低体积逃逸；
5. DSO/CE 容量矛盾。

**证明。** 固定 `A` 给固定偏差函数 `a_X=1_{𝓐(X)}-E_0 1_{𝓐(X)}`。按 `docs/rh-pc4-acc-sync-pressure.md` 的 `low/osc/tail` 分解：`low/tail` 主导则进入 LV/LSMP 或短簇；`osc` 主导时，若某可检测窗口承载固定比例，进入 PI；若非共振失败，进入 FCT；若全部非共振且分散，则 DSO/CE 平方容量界排除 `X^β` 级同向过剩。证毕。

## 5. ACC 防循环定理

**Theorem ACC-Sync-No-Cycle。** 在排除 PC4-PI、PC4-FCT、PC4-SC、LV/LSMP、CE 与 DSO 容量失败的非终端假设下，ACC 同步分支不能形成无限逃逸链。

**证明。** 若无限链中有无限多次真 ACC 状态变化，则由第 3 节分类，或触发 CE/FCT/LSMP/LV/SC，或离散势函数 `𝓐pot` 严格下降；后者因有下界不可能无限。若真变化只有有限多次，则从某时刻起同一规范 ACC 模板重复同向过剩；由 A-L1 触发 PI/FCT/SC/LV/LSMP/CE/DSO，违背非终端假设。故 ACC 同步不能作为无限最终逃逸通道。证毕。

## 6. 接入 PC4-A 与总事件图

本文的作用是把 `ACC-Sync-Pressure` 从“转入若干分支”的压力命题升级为无循环事件图接口：

`真模板变化 -> 势函数下降或 CE/LV/LSMP`；

`固定模板重复 -> PI/FCT/SC/DSO 容量出口`。

因此 PC4-A 在总事件图中只输出边，不引用自身 closure，避免 A--SC--PI--FCT 之间的循环证明。
