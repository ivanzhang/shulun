# D4/R5 G1 容量界攻坚路线

## 1. 本轮审计结论

脚本 `experiments/d4_r5_G1_capacity_audit.py` 从现有局部窗口证书中抽取容量数据，输出 `docs/d4-r5-G1-capacity-audit.json`。

在完整危险窗口 `[1088200,1088600)` 内，已验证的最大总容量为

```text
L_max,resource = 0.4213905845641671.
L_max,row-positive = 0.45976127079428586.
```

对应记录来自 `L>=0.35` regime：

```text
L = 0.4213905845641671,
E = 0.14506027602408123,
R = 8.43864381496763,
N = 230,
W = 1558,
M = 97.
```

因此在当前局部证书体系内，可安全取

```text
L_cap = 0.48,
L_cap^2/20 = 0.01152.
```

这里存在两个容量口径：资源曲线口径最大约 `0.42139`，容量支付更直接相关的行级正收缩口径最大约 `0.45976`。因此本地付款安全阈值应取 `0.48`，而不是早先只覆盖资源曲线口径的 `0.45`。这仍只是一条有限窗口容量证据，不能直接作为全局定理使用。随后 `experiments/d4_r5_G1_lyapunov_energy_audit.py` 对多窗口扫描复核，发现行级正收缩容量最大达到 `0.4750671263244978`，故统一采用更安全的本地阈值 `L_cap=0.48`，并记录 `L_cap^2/20=0.01152`。

## 2. G1 不应表述为裸经验上界

裸命题

```text
对所有尺度链均有 L_j <= 0.48
```

目前没有证明，而且从递归剥离观点看也过强。随着尺度增加，新壳层同余约束增多，活动容量的定义若不随规范化重新归一，`L_j` 未必保持固定窗口经验上界。

更可证明的 G1 形式应是容量-能量二择：存在显式常数 `L_cap, eta_cap>0`，使任意规范化 R5 危险链在每个 stable 正质量步满足

```text
要么 L_j <= L_cap，
要么 D_j >= eta_cap * Phi(L_j-L_cap)，从而退出危险类。
```

其中 `Phi(t)` 是非负递增函数，最弱可先取 `Phi(t)=t^2` 或分段线性函数。这样 G1 不要求所有状态都有小容量，只要求“大容量必产生正缺陷”。

## 3. 可证明接口 G1'

建议把全局闸门从 G1 改写为 G1'：

**G1'（容量-缺陷联合闸门）。** 对任意递归剥离链 `S_j`，存在统一归一化后的资源对 `(L_j,D_j)`，满足：

1. stable 正质量步中 `Delta L_j>=0`；
2. 若 `L_j<=L_cap`，则容量支付可由 `L_cap^2/20` 望远镜控制；
3. 若 `L_j>L_cap`，则同一状态满足 `D_j>=eta_cap Phi(L_j-L_cap)`；
4. R5 危险类要求 `D_j<D_danger`，并且 `eta_cap Phi(L_j-L_cap)>=D_danger` 时该状态自动排除。

于是只需在危险链内部使用截断容量

```text
L_j^* = min(L_j,L_cap),
```

并把超额容量转化为正缺陷，而非强行证明全局 `L_j<=L_cap`。

## 4. 从局部证据到全局证明的三步

### 4.1 规范化不变性

必须证明 R5 的 `L,E,D` 在尺度变换 `X -> 2X` 和壳层剥离后保持同一语义。具体要检查：

```text
L = sum layer masses,
E = l2/energy resource,
D = E - L^2/20
```

在每个 dyadic 壳、light/short/transition 分层、以及成员关系冻结单元内使用同一权重归一化。

### 4.2 大容量强迫能量

若容量 `L` 很大，而每个单元的点态质量上界为 `b_i<=b_max`，则 Cauchy/凸性给出

```text
E >= L^2/N_eff.
```

R5 中的危险结构还要求资源分布集中在有限类型层内；因此需要证明有效自由度 `N_eff` 不能超过危险类允许值。局部窗口中 `L>=0.4` 的记录已经显示大容量伴随明显正能量：最大点 `L=0.42139` 时 `E=0.14506`，远大于 `L^2/20≈0.00888`。这支持“大容量即正缺陷”的方向。

### 4.3 递归传递

若某大尺度状态触发 `L>L_cap` 且没有被正缺陷排除，则它必须具有异常的超分散结构。将其剥离到上一尺度时，超分散结构只能发生三种情况：

```text
stable: 超额容量保留，继续触发正缺陷；
jump: 类型边界穿越，被 G3 吸收或送入证书窗口；
backflow: 投影损失 eps_j 计入 G4 求和。
```

因此 G1' 与 G2/G3/G4 是兼容的：G1' 不单独闭合全文，但把最危险的“大容量但低缺陷”状态压缩成唯一需要排除的硬核。

## 5. 下一硬点

G1 的真正剩余硬点不是再扩大有限窗口扫描，而是证明以下命题：

```text
不存在规范化 R5 危险状态同时满足 L>L_cap 且 D<D_danger。
```

这可以先在外向舍入候选盒语言中表述为全局模板不等式：对任意冻结成员单元，若行级付款容量 `L>=0.48`，则正确能量口径下的 `D` 的区间下界为正并超过危险阈值；若该不等式失败，则失败单元必须投影到现有有限证书候选族。注意：本轮审计显示裸 `l2` 口径的 `E-L^2/20` 可为负，而平方根层和口径的 `E_{sqrt}-L^2/20` 在高容量区保持明显正余量。因此下一步必须先固定全局 Lyapunov 能量口径，不能混用两种 `E`。

## 6. G1''：可攻的容量--平方根层缺陷命题

多窗口审计给出一个更具体的候选命题。令

```text
L(X) = positive_contract_sum(X),
E_*(X) = transition_high_tail_l2_sqrt
       + transition_low_start_l2_sqrt
       + short_chain_l2_sqrt
       + light_l2_sqrt,
D_*(X) = E_*(X) - L(X)^2/20.
```

局部证据显示，在所有已审计窗口中，若 `L>=0.45`，则

```text
D_* >= 0.0201239507452508.
```

而裸 `layer_l2` 缺陷可低至负值，故不能作为 G1 的 Lyapunov 缺陷。下一步真正可攻命题是：

**G1''（高容量平方根层缺陷）。** 存在显式常数 `eta_*=0.015` 与全局安全阈值 `L_cap=0.48`，使任意规范化 R5 冻结成员单元满足二择：

```text
L <= L_cap，或 D_* >= eta_*。
```

若 `D_*>=eta_*` 与 R5 危险阈值不相容，则 G1' 闭合；若相容，则需把危险阈值改为同时包含 `D_*` 的二维条件。

## 7. G1'' 的证明路线

证明不应依赖有限窗口枚举，而应从分层 Cauchy 事实推出。把活动质量按层分块为 `B_1,...,B_m`，对应层资源为 `e_i=sqrt(sum_{h in layer i} b_h^2)`。则

```text
E_* = sum_i e_i,
L = sum_i B_i.
```

若每层的有效扩散度满足 `B_i <= A_i e_i`，则

```text
L <= sum_i A_i e_i <= A_eff E_*.
```

于是高容量给出

```text
E_* >= L/A_eff,
D_* >= L/A_eff - L^2/20.
```

因此只需证明危险类中 `A_eff` 有统一上界，且在 `L>=0.48` 时右端大于 `eta_*`。局部数据反推 `A_eff≈L/E_*` 的高容量最大值仍很小；这说明 G1 的结构本质不是总容量偶然小，而是高容量必须分散到多个层资源中，平方根层能量自动抬升。

## 8. 当前严格义务

1. 从冻结成员单元定义中推导每层 `B_i <= A_i e_i`，并给出显式 `A_i`；
2. 证明 `A_eff` 在尺度递推、壳层剥离、类型重分类下不增或只产生可求和误差；
3. 把 `D_*` 与 stable 恒等式中的付款缺陷统一，或明确证明 `D_*` 是可叠加的辅助排除泛函；
4. 若 `L>0.48` 但 `D_*<0.015`，证明该状态只能是冻结成员失败单元，并投影到外向舍入证书族。
