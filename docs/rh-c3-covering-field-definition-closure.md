# C3 覆盖场方程定义化闭合稿

本文补 `docs/rh-merge-unconditional-checklist.md` 中的 C3：精确定义 `ACC_z,O_z,Gap_z,DGap_z`，并说明覆盖场恒等式在当前合并稿中的审稿口径。本文仍不宣称 RH 已证；它把 C3 从“符号方程”推进为“可内联的编号引理”。

## 1. 基本对象

固定尺度窗口 `I_X` 与筛层 `z=(log X)^A`。令

`C_z={n∈I_X: (n,M_z)=1}`, `M_z=∏_{p<=z}p`。

令 `P_z` 为 `C_z` 中由 von Mangoldt/Chebyshev 权计入的素数账本，令

`B_z=C_z-P_z`

为候选集中非素数余量。按当前主文口径，素数幂项和权重平滑边界均吸收到 `X^{1/2}log^C X` 或 `X^{o(1)}` 误差；在 `β>1/2` 的反设尺度下均为 `o(Δ)`。

## 2. 覆盖关系与允许覆盖

对每个允许锚 `a` 定义一条或一族覆盖证书 `L(a)`。在数论含义上，`n∈L(a)` 表示 `n` 的合性由某个已登记因子、同余类或倒数相位证书解释。令

`m(n)=#{a: n∈L(a)}`

为点 `n` 的证书重数。定义

`ACC_z=Σ_{n∈C_z} 1_{m(n)>=1}`，

即至少被一个证书解释的候选点数。定义 overlap 扣重

`O_z=Σ_{n∈C_z} (m(n)-1)_+`。

若使用带权证书，先把证书分解为有限固定复杂度的 dyadic/相位原子，再把每个原子展开为 0-1 证书；由固定复杂度假设，展开只造成 `log^{O(1)}X` 损失并由全局常数层级吸收。

## 3. 缺口账本

定义未被证书解释的合成候选缺口

`Gap_z=Σ_{n∈C_z\P_z} 1_{m(n)=0}`。

于是对每个 `n∈C_z\P_z` 有逐点恒等式

`1 = 1_{m(n)>=1} - (m(n)-1)_+ + R(n)`，

其中 `R(n)` 不是一般取 `1_{m(n)=0}` 时的逐点恒等式，而是把“多证书原始计数”归一到“至少一次覆盖”的修正余量。更稳妥的主文写法应采用原始证书总数

`T_z=Σ_{n∈C_z\P_z} m(n)`，

则逐点恒等式严格为

`1_{n∈C_z\P_z}=m(n)-(m(n)-1)_+-1_{m(n)=0}`

在 `m(n)>=1` 时成立，但在 `m(n)=0` 时右端为 `-1`。因此当前 `ACC-O+Gap` 写法应解释为覆盖分解的“规范化账本”，而不是对任意 `m(n)` 的无条件逐点恒等式。为避免审稿漏洞，最终主稿必须二选一：

1. 采用 `ACC_z=#{m(n)>=1}` 与 `Gap_z=#{m(n)=0}`，则严格恒等式为
   `B_z=ACC_z+Gap_z`，overlap 只进入第二层能量分支；
2. 采用原始证书总数 `T_z`，则严格恒等式为
   `B_z=T_z-O_z+Gap'_z`，其中 `Gap'_z` 按逐点修正定义，而不是简单未覆盖点数。

本文建议最终主稿采用方案 1，因为它最少引入符号，并把 overlap 作为“若 `T_z-ACC_z` 大则进入 OV2”的分支触发量。

## 4. 推荐替换后的覆盖场主公式

推荐主稿把第 4 节改写为：

`B_z=ACC_z+Hole_z+o(Δ)`，

其中 `Hole_z` 是未被允许覆盖证书解释的粗合数候选数。相减得

`-E_z=(ACC_z-ACC_z^0)+(Hole_z-Hole_z^0)+o(Δ)`。

另外定义 overlap 能量

`OV_z=T_z-ACC_z=Σ_{n∈C_z}(m(n)-1)_+`。

于是二分为：

- 若 `E_z<=-Δ`，则 `ACC_z-ACC_z^0`、`Hole_z-Hole_z^0` 或 `OV_z-OV_z^0` 至少一项承载固定比例异常；分别进入 `A`、`LV/LSMP/CE` 或 `OV2/PC3`。
- 若 `E_z>=Δ`，则 `ACC_z^0-ACC_z` 或 `Hole_z^0-Hole_z` 承载固定比例异常；后者命名为 `DGap_z`，进入 Dual/DGap。

这样 overlap 不再被错误放入第一层线性恒等式，而是作为第二层“覆盖证书过度复用”的结构事件。

## 5. C3 审稿结论

**Lemma C3-Covering-Field-Defined.** 若最终主稿采用 `B_z=ACC_z+Hole_z+o(Δ)` 作为一层覆盖分解，并把 `OV_z=T_z-ACC_z` 作为二层重叠事件，则覆盖场二分是严格可审查的：过疏异常必进入 `A/Hole/OV2`，过密异常必进入 `A/DGap` 或基线失败。

**证明。** `C_z\P_z` 中每个粗合数候选要么至少被一个允许证书覆盖，要么未被覆盖，故 `B_z=ACC_z+Hole_z` 是集合划分恒等式；平滑边界和素数幂误差按全局归一化为 `o(Δ)`。与 PC2 的 `B_z-B_z^0=-E_z+o(Δ)` 相减，任一 `Δ` 级偏差必须由 `ACC` 或 `Hole` 承载。若同时记录原始证书总数 `T_z`，则 `OV_z=T_z-ACC_z` 衡量覆盖证书复用；当 `ACC` 不足以承载过疏异常而 `T_z` 异常大时，异常只能落入 `OV2/PC3` 的双锚正规形。过密时 `Hole_z^0-Hole_z` 即对偶缺口压缩 `DGap_z`。故 C3 在此改写下闭合。证毕。

## 6. 对合并稿 v1 的修改义务

`docs/rh-merged-proof-draft-v1.md` 第 4 节中

`B_z=ACC_z-O_z+Gap_z+o(Δ)`

应替换为推荐公式

`B_z=ACC_z+Hole_z+o(Δ)`，

并把 `O_z` 重命名为 `OV_z=T_z-ACC_z`，只在 OV2/PC3 分支中使用。否则原公式可能被审稿人质疑为非逐点恒等式。
